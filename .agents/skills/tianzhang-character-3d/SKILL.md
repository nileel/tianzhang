# 角色三维制作与部件拆分

将已确认设计变成可编辑、可拆分、可验证动作的模型。本 skill 提炼本地 Charakuru 1.1.1 的提示词机制，并纳入苻渊第 42–44 版的修复证据。具体来源和版本差异见 [来源与适用边界](references/sources.md)。

## 从当前资产进入

先查看原画、已采用视图、现有模型和用户指定成果，确认当前阶段。新制或重做按项目规则先制作正、背、本人左、本人右四视图，再交 Tripo。已有可用模型可直接进入拆件、局部贴图或绑定修复。

| 当前任务 | 按需读取 | 本阶段成果 |
|---|---|---|
| 原画到全身四视图、头／体部件图 | [图像提示词](references/image-prompts.md) | 方向一致、比例可核对的单张视图及实际提示词 |
| 图像到 3D、候选比较 | [生成与拆件](references/model-and-parts.md) 的生成段 | 带贴图的原始导出件、来源和选择依据 |
| 网格拆件、贴图分组、部件合装 | 同上拆件和贴图段 | 可定位的部件、原形对照、有效 UV／材质 |
| 宽袖、长袍、手指、物理或动作质量 | [绑定与验证](references/rig-and-validation.md) | 保存源文件与实际导出件的同帧验证 |
| Charakuru 内继续制作 | [来源与适用边界](references/sources.md) 的本地入口 | 同一正本内登记的最新文件 |

调用图像生成时使用当前可用的 imagegen skill。进入 Blender 编辑、导出或场景检查时使用 [tianzhang-blender-pipeline](../tianzhang-blender-pipeline/SKILL.md)。本 skill 的提示词可以独立于 Charakuru 使用，包内专用命令只在核实本地安装和当前配置后调用。

## 贯穿各阶段的约定

- 原画和用户最后确认的修改决定设计。先列清脸型、年龄感、发长、衣装结构、左右非对称和饰品数量，再写提示词。生成图、旧提示词、候选模型之间的冲突必须回到这份依据。
- 新图使用同一角色、同一姿势、同一组设计约束。本人左右与屏幕方向同时写清。依次采用正面，再以正面锚定其它方向的尺度，逐张看实际输出。
- 拆件前说明目标属于图像拆部位、现有网格分割、贴图分组还是物理分组。一个长袍可以有多个物理区域，同时共享一套下半身贴图。
- 先复用已有原包。需付费生成时核实当前报价，累计计算该款资产的生成、分割、贴图和绑骨费用。按本项目规则，已授权完整流程累计低于 70 个 Studio 点可执行，达到 70 点先确认，只用现有余额。候选数服从当前预算和停止条件。
- 提示词中的正交、4K、对齐、留白只是目标。对实际图片、网格、材质和动作逐项核对，记录本次真正验证到的范围。
- 在原形、分割结果、改绑结果之间保留可追溯输入。局部修复先查明问题发生在哪一阶段，修复已确认的最小范围。同一缺陷反复出现且需要扩大边界时，先重新判断原因。

## 最小交付

按本次任务提供实际使用的提示词／视图、可编辑源模型、带齐贴图的检查导出件和对应前后图。只做图像或拆件时，到该成果结束。做动作时用实际 VRM 或用户指定运行时验证，并明确仍存在的穿插和拉伸。

本地 Charakuru 工程通过现有登记入口回写同一 `.charakit`。继续编辑时指向最新登记 Blend，核对 `sourceBlend`、模型和预览 VRM 的哈希。将采用依据、必要参数与实测结论放在该资产已有记录中。
