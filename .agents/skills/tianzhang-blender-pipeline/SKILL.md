# 《天章》Blender 流程

## 目标

用最小且可复核的操作完成 Blender/FBX 工作，并把项目事实、工具连通性和业务验收分开证明。

## 工作流

1. 先定位当轮事实，不沿用旧对话中的任务状态：
   - 读取仓库根目录 `AGENTS.md`。
   - 需要选择或确认活跃任务时，读取 `开发管理/当前任务队列.txt`；选中 ID 后只把仍存在的 `开发管理/任务卡/<ID>.txt` 当作活跃任务事实。
   - 已完成或追溯历史时，才读取 `开发管理/任务归档/<ID>.txt`。
   - 按 `AGENTS.md` 路由读取与本次对象直接相关的 `docs/`、`开发管理/` 或 `src/` 原文。
2. 把请求归入一种操作：当前场景只读检查、当前场景写入，或无界面 FBX 验证。
3. 选择工具前完整读取 `references/tool-routing.md`，一次只走其中一条工具通道。
4. 写入前确认绝对目标路径、用户授权范围、任务卡允许路径、停止条件与验收入口；项目文件写入还要按 `AGENTS.md` 检查 Git 状态、活动 run 和集成锁。
5. 先查明场景或文件实际状态，再做满足需求的最小修改；不要叠加备用插件、第二条导出路线、自动重试或外部资产提供商。
6. 用任务所要求的证据验证结果。MCP 返回成功只证明调用成功，不等于资产业务验收通过。

## 写入与安全边界

- 临时烟测文件只写入 `D:\Temp\TianZhang-Blender\` 下的本次专用目录。
- 未经当前任务明确授权，不向 `src/Assets/` 写入或复制资产。
- 只有当前任务事实、路径所有权和用户授权都允许时，才修改 `assets/source/`。
- 覆盖、删除、保存现有 `.blend` 或导出到已有 FBX 前，先确认精确绝对路径和授权。
- `execute_blender_code` 可运行任意本地 Python。调用前先只读检查当前场景，并把代码限制在本次场景和已确认路径内。
- 不启用外部资产、图像生成或第三方账号能力；不要上传项目资产。
- 若任务事实冲突、目标文件有未授权改动、停止条件命中或验证入口缺失，停止写入并报告具体证据。

## 交付证据

报告以下内容：

- 使用的事实源、任务 ID（如有）和工具通道。
- 实际读取或写入的绝对路径。
- 场景/FBX 验证结果及其能力边界。
- 未执行的高风险动作、剩余阻塞和下一步所需授权。
