> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Do not dispatch subagents unless the user explicitly requests delegation.

**Goal:** 将《天章》的现行设定统一迁移到“本界天意—上界天庭—绝地天通—上古太玄道庭—三项核心遗产—册界规则”体系，并彻底取消全局“上古仙朝”概念。

**Architecture:** 先建立唯一宇宙观事实源，再依次迁移境界边界、遗产规则、世界主线和下游内容；远古绝地天通与近代龙脊之变保持为两场独立事件。规则实现复用现有金丹冲突、山河节点、世界状态提交和战场环境档案边界，不建立第二套任意规则系统。

## 一、审核结论

《天章》不需要改名，但必须改变名字在现行游戏中的解释。

现行上层叙事以“天门意外崩塌、唯一高位承认来源消失、玩家重建承认边界”为主轴。新方向则要求：太玄界天意真实存在；上界天庭曾以较温和的册封和知识传播把太玄界纳为藩界；天庭准备把藩界改成不可脱离的直属界域；本界天意在最后挣扎中扶持人间反抗者，由人主动完成绝地天通。双方都是秩序与主体性的立场冲突，不是善恶战争。

这不是局部名词修订，必须重写世界背景和世界主线的最高层因果。不过，现有内容中以下部分可以保留：

1. 昊天历 371、372、387 年的近代时间锚点。
2. 苻渊自辟德业元婴方向失败及龙脊之变。
3. 王玄略的边界校准、谢观微的风险推演、钟离幽的深层目击。
4. 九域格局、门派矛盾和各地区主题。
5. 太一道庭“稳定但不天然正确”的公共法箓秩序。
6. 已拆出的第一章任务和关中野外副本。它们没有写死天门、仙朝、飞升、上界或承认权，不应推倒重做。
7. 现行十七道路、源／化／界、金丹冲突、元婴道路锚点和五行战场环境规则。

最小迁移策略是把两场历史事件分开：

- 远古事件：绝地天通。它主动切断两界联系，终结上古太玄道庭的全界行政网络。
- 近代事件：龙脊之变。苻渊的新道失败冲击了叠建在古代遗存之上的龙脊承接网络，重新触动绝地天通留下的深层结构和册界节点残层。

这样可以保留现有第一章和龙脊主线的大部分结构，同时让“天章”真正成为世界标题、核心遗物和终局议题。

## 二、已确认的设计口径

执行时以下内容视为已经锁定，不应重新发散：

1. 大道先于天而存在；天意也在大道之中。天庭不创造大道，不授予所有修士境界或个体位格。
2. 太玄界天意是本界世界意志。它可以通过征兆、许可、异常窗口和道路暴露帮助人，但不能直接赐予金丹、元婴或更高境界。
3. 天庭是上界统治组织。其优势来自跨界治理位格、界籍和制度性权柄，不等同于太玄界修士境界表上的“更高一级”。
4. 上界传下的是系统化修仙知识、标准和公共设施，不是五行、大道、灵根或所有修士能力的创造权。
5. 太玄界曾是受册封的藩界。天庭试图彻底接管本界天意，把它改为不可脱离的直属界域。
6. 反抗者由本界天意最后扶持，主动从内部斩断两界联系。绝地天通保住了主体性，也造成古代行政网络、灵脉调度和跨界通路的大规模损伤。
7. 上古太玄道庭是藩界时期的人间管理机构，不是现行宗门，也不是皇权王朝。
8. 当前太一道庭不能直接等同于上古太玄道庭；它只能继承其中一部分法箓、官署和正统叙事。
9. 全局“上古仙朝”已经取消。太玄道庭崩解后直接进入遗产分散、地方政权与现世宗门兴起，不再插入一个统一仙朝时代。
10. 三项核心遗产的职责固定为：`《开阖九章》`负责通行，`太玄界印`负责归属与行政权限，`《册界天章》`负责地区规则调衡。
11. `《开阖九章》`只能开启旧制门禁和传送阵，不能接管设施、命令守卫、打开核心档案或修复损坏阵法。
12. `太玄界印`决定旧公共设施承认谁、服务谁和由谁管理；它不代替门禁术法，也不能修改世界规则。
13. `《册界天章》`只能调用已经登记并被玩家收集的治理条目，不能创造大道、授予境界、修改先天资质或凭空生成世界中不存在的现象。
14. 每条册界规则取得后永久登记，可在兼容区域重复调用；规则不是消耗品碎片。
15. 五行相关地纪必须以一个原子生态包同时影响天气、地形演化、灵气结构和资源产出，不能拆成四个自由滑杆。
16. 派生属性继续保留自身身份，但读取既有五行母属性：风、毒归木，雷归金，冰归水，暗归土，星归火。
17. 册界规则必须声明收益和世界代价；它不是无代价许愿，也不使用通用的每日物业费包装。
18. 册界规则影响长期环境基础态；金丹规则属于介入态。长期维持的金丹山河规则也是“常驻介入”，不会被改写成自然基础态。
19. 同变量冲突仍走现有确定性冲突。天章只可通过遗物、界印、节点和现实供给获得有边界的挑战资格，不自动获胜。
20. 元婴道路锚点锁定同一道路变量时，天章不能单件覆盖；只能协商、等待撤回、破坏现实支点或取得相应高位帮助。
21. 效果范围由册界节点和真实地理／网络辖域决定，不能由玩家拖动半径。

## 四、已锁定决议与执行前决策门

### 已锁定：取消全局“上古仙朝”

权威历史中不存在统一的“上古仙朝”。古代全界机构只有上古太玄道庭；其崩解后直接进入遗产分散和宗门时代。具体地方政权只有确实需要王朝结构、且不会被误读为全局仙朝时才可保留；其余优先称古国、旧朝、古城、道统或宗门遗址。

### 已锁定：太一道庭与上古太玄道庭的关系

太一道庭是上古太玄道庭南方法箓支系的后继者和正统声索者，只保存一部分官署、法箓和界籍解释传统。它不是古道庭本体，也没有全界行政权。

司马承景固定为后世太一道庭公共法统的重整者与当代残损承接者，不是统一仙朝的末代道主，也不是上古太玄道庭的直接管理者。

以下 D2～D4 继续采用推荐答案；新会话执行到相关切片时若需要改变，必须先请求用户决定。

### D2：上界力量是否映射为太玄界更高境界

推荐：不映射。太玄界境界仍止于化神；飞升是跨界迁移与制度筛选，不是自动进入炼虚。天庭的跨界治理位格只说明组织和权柄层级，不建立新的玩家线性境界表。

收益：不与现行最高境界、元婴唯一锚点和 17 道路冲突，也不必解释“所有元婴都由天授”。

### D3：谁完成了绝地天通

推荐：先锁定为“本界天意扶持的一批古道庭内部反对者、地方宗门和人间共同体”，暂不命名单一领袖或唯一组织。

收益：保留群体选择和无正邪主题，避免过早新增一个全知古代英雄势力。

### D4：册界天章何时进入玩家常规玩法

推荐：先做据点级纵向切片，再开放片区和整域。首个可玩切片只验证一条通行、一次设施归属、一个册界节点和一条生态规则，不直接实现整域天气经济模拟。

收益：能证明三件遗产确实参与日常玩法，同时不提前建设完整世界经营系统。

- `劫威缓厉`只作用于登记渡劫地，普通雷电不等于天劫；它不降低证位和境界条件。

- 单一节点：洞府、宝库、渡劫台或一个据点。
- 连通节点：同一灵脉、水系、气候单元或地质结构中的片区。
- 地区总枢：满足完整节点网络和行政授权后覆盖整域。

传播边界按规则读取：灵机沿灵脉，水府沿流域，火脉沿连通地火，天气生态沿气候／地理单元，劫威只覆盖登记渡劫场。宗门边界不能凭文字改变自然范围，但可以阻止授权和节点接入。

#### 4. 与金丹和元婴的关系

规则层顺序：自然基础态 → 天章登记基础态 → 金丹战斗／山河介入态 → 元婴道路锚点。

这不是固定数值优先级。命中同一变量时：

1. 天章先校验条目、界印／组织授权、节点、范围、现实供给和世界代价。
2. 无高阶冲突时提交地区基础态。
3. 遭遇金丹介入时使用现有冲突五要素；天章只能凭版本化 `CrossTierChallengeGrant` 参加列明变量的一次冲突。
4. 遭遇元婴道路锚点时标记为 `受锚`，单件天章不得直接覆盖。
5. 金丹山河规则停止后，天章基础态重新显现；不把已结束的介入效果永久写成自然法则。

#### 5. 维护与代价

现有山河规则的日常通用费用仍是灵石。只为 `sourceKind = CHARTER_RELIC` 增加一个明确例外：它复用节点、授权、周期、世界提交和事件信号流程，但支付 `CharterTradeoffProfile` 中的世界状态代价，不收通用每日灵石物业费。

剧情遗物的“充能／耐久”要求扩展为“充能、耐久或等价的受限承载账本”。册界天章使用条目占用、节点承载、界印认可和现实供给，不用随意掉耐久制造忙碌。

- 每次走查都能回答：影响什么、范围到哪、谁授权、支点是什么、收益是什么、代价是什么、遇金丹／元婴怎么办。
- 五行地纪没有拆成四个自由滑杆。

## 七、完成标准

全部迁移完成后，必须同时满足：

1. 新玩家只看世界背景，就能理解《天章》为何叫“天章”。
2. “天”既是太玄界真实天意，又不会成为给每个修士发境界的拟人神明。
3. 天庭拥有跨界统治能力，但不占用太玄界十七道路和元婴锚点。
4. 绝地天通是人主动完成的历史选择，并同时具有正面和负面后果。
5. 权威事实源中不再存在统一上古仙朝；上古太玄道庭与当前太一道庭的有限继承关系清楚可追溯。
6. 龙脊之变仍保持现有近代因果，又能自然触发古代主线。
7. 三项遗产分别提供通行、归属和调衡的常用玩法，没有功能重叠。
8. 册界天章的每条规则都有完整正负提交、影响范围、现实支点和冲突边界。
9. 五行地纪统一影响天气、地形、灵气和资源，不变成四个自由调参滑杆。
10. 玩家使用天章不等于取得金丹、元婴或对世界的绝对控制权。
11. 第一章现有任务无需推倒重做，后续章节能按新真相逐层揭露。
12. 生产文档、数据、运行时和数值状态被清楚分层，不把规划写成已实现。

## 八、全局停止条件

遇到以下任一情况，停止执行并回到根因或请求用户决定：

- 为消除一个旧词开始批量改写所有“天命、天道、天劫、仙朝”用语。
- 开始把上界治理位格硬映射为炼虚、真仙或新的玩家境界表。
- 开始让天庭或本界天意直接授予金丹、元婴和五行大道。
- 开始让太一道庭自动继承上古太玄道庭的全界合法性。
- 开始让《册界天章》绕过节点、界印／组织授权、现实供给、代价和高阶冲突。
- 为实现首条规则引入完整世界模拟、第二套冲突引擎或任意脚本编辑器。
- 生产文件与用户现有改动重叠且无法安全区分。
- 内容冻结尚未解除，却开始生产九域条目、L2/L3 任务或运行时功能。

本计划的核心原则是：先把“为什么叫天章”写成唯一可信的世界根因，再让三项遗产成为可玩的日常接口，最后才扩展为九域规则和终局选择。
