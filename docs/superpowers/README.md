# 设计与执行过程文档

这里保存设计讨论、实施计划及其历史记录。文件位于 `specs/` 或 `plans/`，不代表内容仍有效或已经实施；使用前应核对对应活跃任务卡和正式事实源。

- `specs/`：保留原路径的设计、合同、研究及被引用的历史材料。
- `plans/`：保留原路径的实施计划及被引用的历史材料。
- [历史过程文档归档](archive/2026-10-04/README.md)：2026-10-04 迁入 81 份工作流设计与执行计划，附原路径映射；正文仅调整本批文件的完整路径引用。

当前规则与任务以 `AGENTS.md`、`开发管理/` 的对应规则和活跃任务卡为准；游戏设定读取 `docs/` 对应业务原文，当前实现读取 `src/` 或相应工具。归档中的命令、授权、完成标记和旧状态只用于追溯。

本次整理前共有 213 份方案和计划，81 份归档，132 份留在原处。仍被任务卡、脚本、历史证据或保留文档引用的文件，以及游戏设计、资产合同和近期讨论，均未仅因日期较早而迁移。

仓库根 `.rgignore` 让普通 `rg` 搜索跳过归档；需要追溯时运行：

```powershell
rg --no-ignore "关键词" docs/superpowers/archive
```
