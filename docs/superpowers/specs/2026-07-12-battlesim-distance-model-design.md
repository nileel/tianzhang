# BattleSim 一对一距离模型设计

## 目标

让 BattleSim 的 1v1 战斗遵循 Unity 已有的六角格语义：每个术法、神通和基础攻击有自己的最小/最大距离；单位使用移力进入合法射程后才能攻击。该切片替换现有的 `rangePenalty` 近似，不改任何伤害、成长、冷却、眩晕、元素或 2v2 规则。

## 范围

- 仅 `Combat.Simulate` 的 1v1 路径。
- 平地、无障碍、无视野遮挡、单目标六角距离。
- 每场初始距离固定为 6 格；每次行动可在攻击前移动至多 `Primary["移力"]` 格。
- 2v2、地形、朝向、击退、视野、占格和 Unity UI 不在本切片。

## 行动规则

1. 行动开始时，优先选择当前距离合法、资源和冷却均满足的神通；其次是术法；最后是基础攻击。
2. 若没有可用攻击，单位朝目标移动最少格数，使最高优先级可用攻击进入其最大距离；若已小于该攻击最小距离，则后退到最小距离。
3. 移动后立即重新判定并施放；仍不合法则本次行动只移动。
4. 近战基础攻击范围固定为 1–1；每个 `ArtConfig` 和 `DivineConfig` 增加独立 `MinRange`、`MaxRange`。现有物理、法术、符修、太虚、玉清等模拟技能在 `GameData` 各自登记数值。
5. 删除“使用某种 style 后使对方下一击乘 0.35”的 `rangePenalty`。距离本身是唯一的射程机制，因此不存在全局“远程流派资格”。

## 普攻与主战法宝

- 普攻是独立的攻击档案，优先由当前装备的主战法宝/武器决定伤害类型、元素、倍率、最小/最大射程与特效。
- 未装备主战法宝时，角色使用无装备兜底普攻；它不是功法固有攻击。
- 功法只能修正普攻或以明确机制替代普攻，例如苦行剑典的血剑气与雷劫满层的万钧天刑；替代效果仍须声明自己的距离档案。
- 当前 BattleSim 尚无装备数据链路，因此第 1 阶段用可替换的 `BasicAttackProfile` 接口和无装备兜底档案建模，禁止把任一门派/功法写死为普攻来源。

## 数值与兼容边界

- 不调整现有技能倍率、MP 消耗、冷却、成长表、初始属性、元素修正或眩晕概率。
- 移力沿用现有一级属性；本切片不重新映射其公式。
- 默认 200 轮模拟和 G2 400 轮审计都使用新距离模型，因此其矩阵变化属于机制修复后的新基线，不能和旧 `rangePenalty` 结果混用。
- `--g2-attribution` 保留功法包和先天交换；移除远程资格统一反事实，改为距离模型下的基线结果，避免比较已废弃规则。

## 后续演进路线

1. **平地 1v1（本规格）**：主战法宝普攻档案、独立技能射程、移动后施法和 BattleSim/Unity 基础语义对齐。
2. **1v1 战场**：地形、高低差、视野以及击退、定身等位置控制；每项都必须有可观察的距离/移动回归。
3. **2v2 战术**：队友占格与阻挡、目标选择、范围技能、协同走位和 AI 优先级；不得复用 1v1 的无位置近似。
4. **运行时数据链路**：以 CSV/asset 为主战法宝和技能攻击档案的权威来源，BattleSim 与 Unity 读取同一语义；支持新增法宝而不改战斗代码。

## 验证

新增 BattleSim self-test 锁定：

1. 初始距离 6 时，近战单位必须先消耗移动后才造成伤害。
2. 最大距离覆盖初始距离的远程技能可在首个行动造成伤害。
3. 最小距离大于当前距离时，单位必须后退，不能贴脸施放。
4. 移除 `rangePenalty` 后，默认 1v1 的结果仅由位置、移力和技能距离决定。
5. 运行 Release build、距离 self-test、CT/暴击既有 self-test、默认模拟、400 轮 G2 审计与 `git diff --check`。
6. 验证主战法宝档案优先于无装备兜底，功法替代普攻仅在其触发条件成立时生效。
