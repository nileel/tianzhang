# 默认男主四视图背视右手遮挡修复设计

## 1. 当前结论

前两张候选均不得作为正式四视图输入：

- 第一张候选的背视右手与衣袖断开；
- 第二张候选虽然连接了衣袖和手腕，却把右手放到角色右肩外侧、接近头部高度，仍不符合与正面及侧视图相同姿势的背视投影。

正式原画中的角色右手位于前胸，右前臂由身体右侧向躯干中线内收。纯背视观察时，躯干位于相机与右前臂、右手之间，因此右前臂末段和剑指应被躯干遮挡，不能为了展示手势而移动到右肩外轮廓。

## 2. 选定方案

采用方案 A：以第一张原始错误候选为唯一编辑目标，执行一次定点图片编辑。

编辑目标：

`assets/source/characters/combat-pieces/formal-player-static-3d-v2/evidence/rejected/formal_player_default_male_fourview-back-hand-invalid-20260831.png`

选择第一张候选是因为它尚未叠加第二次候选的整图轻微重渲染。第二张候选只保留为否决证据，不作为新的编辑基础。

## 3. 唯一允许的变化

只允许修改右下背视格中角色身体右侧的上臂、肘部、衣袖外轮廓，以及移除错误露出的右手。

修复后的背视必须满足：

- 角色右上臂位于画面右侧，与右肩自然连接；
- 右肘保持弯曲，袖形能够表达前臂正转向躯干前方；
- 右前臂末段、袖口、手腕、手掌和剑指位于躯干前侧，在纯背视中由身体遮挡；
- 背视外轮廓不得出现右手、剑指或漂浮手指；
- 不得把右手抬到肩旁、头旁或身体右侧空白区；
- 不得把右臂改成自然下垂，因为四格仍须表达同一套弯肘前胸剑指姿势。

## 4. 冻结项

以下内容不得发生实质变化：

- 左上正面、右上 `face-left-side`、左下 `face-right-side` 三个面板的全部内容；
- 四格位置、槽位方向、面板边界、相机尺度和完整全身构图；
- 背视格的头、头发、颈肩中线、躯干、腰带、左臂、左手、袍身、双腿、靴子和背景；
- 角色身份、七头身比例、服装结构、颜色、材质、光照和无文字要求。

若生成工具对冻结项造成身份、比例、槽位、姿势或服装结构的实质漂移，该候选直接失败，不追加第二次编辑。

## 6. 验收与停止条件

候选必须同时通过：

1. 背视外轮廓中没有右手或剑指；
2. 右肩、上臂、弯肘和衣袖连接可信，袖形明确表达前臂转到躯干前方，而不是右臂下垂；
3. 正面和两个侧视图仍清楚显示相同的前胸剑指姿势；
4. 右上鼻尖朝画面左、左下鼻尖朝画面右；
5. 冻结项无实质漂移；
6. 候选文件的路径、尺寸、字节数和 SHA-256 已记录；
7. 任务保持 `blocked`，状态原因写明“背视右手遮挡候选等待负责人视觉批准”。

只允许一次内置 ImageGen 定点编辑。若输出仍露出背视右手、把右臂改成下垂、错误修改冻结项或出现其他解剖问题，立即归档为否决证据并停止；不得自动重试、局部补画或改用整图重生成。
