# 金丹丹相与丹枢成阵设计规格

状态：⚠️ 已修改/未审核
日期：2026-06-19
来源：用户确认“B + 丹相命名”方向成立
用途：作为后续修改 `docs/基础设定/境界特性.txt`、`docs/基础设定/修行境界.txt`、神通/术法设计规范与 TQ-013 数据迁移差异表的设计输入；本文件不直接替代已审核主设定。

## 一、设计目标

新版金丹不再以“本命神通 + 本命法宝”作为主要能力表达。金丹期的自身能力应由角色当前的丹籍、丹名、丹性，以及筑基/紫府阶段修成的根本神通统合生成。

本设计采用“丹相”作为金丹自身能力总称，采用“丹枢成阵”解释根本神通如何在金丹中形成能力结构。

目标如下：

1. 让金丹能力承接筑基期的根本神通经营，而不是金丹后突然挑选一两个技能升格。
2. 让丹籍、丹名、丹性都参与能力生成，避免三层表达只停留在叙事标签。
3. 保留旧本命神通的战斗招牌价值，但把它降级为丹相内部的主枢技。
4. 保留旧本命法宝的修仙味道，但改为部分丹相的外显形态，不再作为所有金丹的必备系统。

## 二、核心名词

### 丹相

丹相是金丹成就后显化出的金丹能力形态。

丹相不是单个技能，也不是一件法宝，而是“丹籍位格 + 丹名道途 + 丹性回响 + 根本神通结构”的统合结果。

示例命名：

- 九霄雷劫丹相
- 南华梦魂丹相
- 混元铁军丹相
- 太一玄箓丹相
- 秋水游心丹相

### 丹枢

丹枢是根本神通进入金丹后形成的能力节点。

筑基/紫府阶段修成的根本神通不会在金丹期被简单替换或丢弃，而是转化为丹相中的丹枢。四到五道根本神通共同入阵，构成角色的金丹能力结构。

### 主枢

主枢是丹相中最核心的一到两道丹枢，承担旧本命神通的战斗招牌职能。

主枢数量由丹籍位格决定：

| 丹籍类型 | 主枢上限 | 说明 |
| --- | --- | --- |
| 正籍 | 2 | 丹相完整，可形成双核心 |
| 辅籍 | 1 | 分支完整，但只突出一条主轴 |
| 敕籍 | 1 | 受敕封法统约束，主枢与敕封来源相关 |
| 寄丹 | 1 | 丹相不稳，主枢效果受限或带代价 |

### 辅枢

辅枢是未被选为主枢的丹枢。辅枢不会消失，而是提供被动、触发、资源循环、抗性、范围、代价减免或丹域回响支撑。

辅枢让金丹能力体现“多道根本神通统合”，避免玩家只关心一两个主技能。

### 丹器显化

丹器显化是部分丹相的外在表现，用于替代旧“本命法宝”的通用地位。

不是所有金丹都必然炼化一件本命法宝。是否出现丹器，由丹相类型决定：

- 剑修可显化丹剑。
- 符修可显化本命法箓。
- 丹修可显化丹炉或丹火法坛。
- 军阵修士可显化令旗、兵符或战鼓。
- 魂修、梦修、因果修可以不显化实体法宝，而显化梦界、魂灯、因果线等非实体丹器。

## 三、生成规则

丹相由四层输入共同生成：

| 输入 | 决定内容 |
| --- | --- |
| 丹籍 | 丹相位格、主枢数量、丹域规模、社会地位 |
| 丹名 | 丹相主题、道途标签、主枢候选池 |
| 丹性 | 五行/变异/特殊属性、丹域回响、属性匹配 |
| 丹枢 | 具体战斗机制、被动结构、触发链与资源循环 |

生成流程：

1. 检查根本神通数量与府位覆盖，确认是否能成丹。
2. 根据丹籍判定主枢数量上限。
3. 根据丹名筛选最契合道途的主枢候选。
4. 根据丹性决定丹相属性、环境回响和部分附加效果。
5. 将剩余丹枢转为辅枢，形成被动、触发或资源循环。
6. 若丹相适合外显器物，则生成丹器显化；否则以丹域、魂景、法箓、军阵等非器物形态表现。

## 四、与旧系统的关系

### 旧本命神通

旧本命神通不再作为金丹能力总称。

迁移后：

- 旧“本命神通”改为“丹相主枢技”。
- 获取条件不再写“一品金丹可铭刻”或“金丹期从某术法直接升格”。
- 新条件应写为：对应术法已成为本命术法候选，锤炼为根本神通，进入金丹后成为丹相主枢。
- 旧成长性中元婴、化神、炼虚段落保留时，应标注为 NPC/资料片预留。

### 旧本命法宝

旧本命法宝不再作为金丹通用系统。

迁移后：

- 适合实体器物表达的路线，改为“丹器显化”。
- 不适合实体器物的路线，使用丹域、魂景、梦界、因果线、法箓、军阵等外显形态。
- 太一道庭的本命符箓与本命法坛可视为丹器显化的门派特例，但仍应受丹相、丹籍与丹枢结构约束。

### 根本神通

根本神通是丹相的主要材料。

迁移后：

- 根本神通仍在筑基/紫府阶段形成。
- 成丹时根本神通转入金丹，成为丹枢。
- 四道根本神通可形成基础丹相或寄丹/敕籍候选。
- 五道根本神通且形成闭环时，丹相完整度更高，可争辅籍或正籍。

## 五、门派示例

### 玉清崖：九霄雷劫丹相

结构示例：

| 府位 | 丹枢方向 | 作用 |
| --- | --- | --- |
| 命府 | 苦行/雷体 | 承伤、代价转化、濒危强化 |
| 气府 | 雷法 | 雷系术法循环、雷劫印记 |
| 识府 | 剑心 | 命中、预判、暴击 |
| 魂府 | 劫意 | 神魂压迫、心魔抗性 |
| 运府 | 应劫 | 劫数触发、反击、爆发窗口 |

主枢可选“雷剑”或“剑心”。正籍可形成双主枢：雷剑负责主动爆发，剑心负责被动暴击与控制抵抗。辅枢提供雷劫印记、承伤转化和应劫触发。

丹器显化可表现为丹剑，也可表现为雷印。

### 太虚观：南华梦魂丹相

结构示例：

| 府位 | 丹枢方向 | 作用 |
| --- | --- | --- |
| 魂府 | 梦界 | 控场、入梦、恐惧 |
| 识府 | 观照 | 命中、识破、控制判定 |
| 运府 | 因果 | 反制、转嫁、触发 |
| 气府 | 虚实 | 消耗转换、虚化、术法折返 |
| 命府 | 替劫 | 保命、复原、代价吸收 |

主枢可选“梦界”或“因果”。正籍可形成“梦界控场 + 因果反制”的双核心。辅枢提供虚化、替劫和识破能力。

丹器显化不必是实体法宝，可表现为梦界、魂灯或因果线。

### 混元山：混元铁军丹相

结构示例：

| 府位 | 丹枢方向 | 作用 |
| --- | --- | --- |
| 命府 | 铁骨 | 减伤、再生、格挡 |
| 气府 | 军势 | 资源循环、号令消耗减免 |
| 识府 | 号令 | 阵型、协同、目标锁定 |
| 运府 | 胜机 | 追击、暴击、战机触发 |
| 魂府 | 军魂 | 士气、恐惧抗性、队友支援 |

主枢可选“铁骨”或“征旗”。正籍可形成“铁骨前线 + 征旗号令”的双核心。辅枢提供阵型压制、协同攻击和士气循环。

丹器显化可表现为令旗、兵符、战鼓或阵图。

## 七、平衡原则

1. 丹相不是额外叠加在旧本命神通之上的新系统，而是替代旧本命神通/本命法宝总称。
2. 主枢承担战斗爽点，辅枢承担结构完整性。
3. 正籍强在完整与双核心，不应只做数值倍率更高。
4. 寄丹不是坏档，但丹相应有不稳定、代价或缺口，给玩家继续争真籍的目标。
5. 丹器显化不应强迫所有路线拿实体法宝，避免魂修、梦修、因果修被迫套入剑/鼎/旗的器物模板。
6. 丹相必须反映筑基期选择。若玩家在紫府阶段主修府位不同，即使丹名相同，丹相表现也应不同。

## 八、审核问题

正式迁入主设定前，需要确认三件事：

1. 是否将“本命神通”作为 UI 或玩家口语保留，系统字段使用“丹相主枢技”。
2. 是否允许四根本神通形成不完整丹相，作为寄丹和敕籍候选的核心差异。
3. 是否在 TQ-013 第一版中只做差异表，不立刻改 BattleSim/Unity 代码。

推荐答案：

1. 可以保留“本命神通”作为旧称或民间称呼，但主系统名使用“丹相主枢技”。
2. 允许四根本神通形成不完整丹相，避免低位路线无可玩性。
3. TQ-013 第一版只做差异表，等文档口径审核通过后再进入代码和 CSV 迁移。
