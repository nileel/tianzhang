# 2D 六向战术角色生产合同

状态：2026-08-21 冻结；只服务于 `A-CHAR-BATTLE-VISUAL-DIRECTION-01` 的 2D 战术精灵试制线。

## 一、范围与唯一目标

- 首个样例固定为苻渊／含弘真君。它只是在现有固定正交斜俯视六角测试台中与静态 3D 棋子比较视觉路线的样例；不把闭关中的苻渊接入第一章、正式遭遇或常规可战斗单位。
- 本合同只约束一组六向静态战术精灵、其来源与固定比较图，以及下游 Unity 样例应如何取证。它不生产完整角色批次、逐帧动作集、UI 立绘或 Unity 资源。
- 已批准的透明全身立绘和 16:9 人物介绍图只提供脸、年龄、发型、服饰、配色、材质气质与标志物参考。它们的站姿、三分之四构图、背景、题字、印章、特效和裁切均不是战场输入；不得缩小、裁切、透视变形、描摹或修补后冒充战术精灵。
- 2D 资产只消费既有角色根节点、六向选择与表现事件；它不拥有或改写 `Character.Facing`、格位、路径、可达性、射程、伤害、状态、死亡、存档、装备或战斗时点。

## 二、苻渊身份、配色与唯一战斗姿态

### 2.1 不可漂移的身份合同

苻渊是沉稳、疲惫而自持的年长男性修士，承受未竟责任但仍可行动；不得画成帝王、反派、重伤垂败者或年轻主角。每个方向必须同时保持：

- 宽实肩背、成熟棱角脸、克制严肃目光；白灰单一顶髻，及贴近肩背的一整块后发；短尖白须和八字胡。
- 紧凑约 4.5–5 头身的棋偶比例；头、手、收束宽袖、袍摆和脸部大平面优先于近景细碎饰物。
- 厚重、旧而未破的炭黑层叠道袍，灰白内领／内袖，少量终止在衣料内的断契金线；恰好一个旧铜圆腰扣和一枚小型淡玉坠。布料为粗糙哑光，旧铜与淡玉只作克制的小面积材质分离。
- 主色只能是深炭黑、暖灰、灰白、旧铜金和一点淡玉；无饱和色、荧光、透明布、亮面塑料、光环、烟雾、飞散墨迹或脱离衣体的能量物。

### 2.2 新的固定斜俯视战斗姿态

- 人物直立而警觉：左脚向本地 `+Z` 前方半步，右脚后撤半步，双膝只作自然微屈，重心落在两足之间。躯干与头部保持本地 `+Z` 正对，不扭腰、不作三分之四肖像姿势。
- 左臂贴近左侧自然下垂，左手在袖口前方可见；右前臂在腰前自然弯曲，右手半握且可见。双手为空手，故持物轮廓固定为无武器、无剑、杖、扇、卷册、瓶、外置法器或浮游物；基础攻击与施法只能由下游既有表现事件和一次性效果表达。
- 成对宽袖必须不透明、连贯、靠近躯干，并与可见双手、袍摆及双足构成一个完整清晰的主体轮廓；不得展开成翼、硬板、尖刺、透明片、跨背框架，或吞没手、交叉遮住躯干。
- 姿态仅表达克制、承担压力后的警觉与可行动性；不得变成攻击蓄力、施法、奔跑、坐姿、胜利展示、A/T Pose 或旧 UI 立绘站姿。六个方向只因观察方向而不同，不能各自换脚步、手势、衣袍结构、宽袖体积、腰饰数量、后发长度或姿态语义。

## 三、固定输出、画布与六向映射

### 3.1 唯一批次与文件

下一张卡只能在 `assets/generated-character-art/fuyuan-2d-tactical-sprite/` 交付同一批次的以下文件：

| 类型 | 固定文件 | 要求 |
|------|----------|------|
| 原始六格来源 | `fuyuan_tactical_six_direction_source.png` | 一张无文字 3×2、2304×1536 px 的源图，行优先顺序为 `0, 1, 2 / 3, 4, 5`；各格之间没有边框或留白。 |
| 六个输出 | `fuyuan_tactical_direction_0.png` 至 `fuyuan_tactical_direction_5.png` | 从源图按 768×768 px 原像素格无损分槽并统一转为 RGBA；禁止翻转、镜像、重画、单向修图或重排。 |
| 固定比较图 | `fuyuan_tactical_six_direction.png` | 由六个最终 RGBA 输出按同一 `0, 1, 2 / 3, 4, 5` 顺序无缩放拼成的 2304×1536 px 3×2 联系表。 |
| 来源记录 | `prompts.md` | 记录完整实际提示词、批准身份参考及 SHA-256、源图／六槽／联系表 SHA-256、分槽坐标、方向映射和人工 QA 结论。 |

- 源图只能出现同一人物、统一纯 `#00ff00` 抠图背景和六个无标签画格；不得有地面、投影、六角地块、环境、标题、文字、印章、UI、水印或 logo。透明输出的四角 alpha 必须为 0，且不得留绿边。
- 每个最终方向图严格为 768×768 px、RGBA、512 pixels per unit；Sprite pivot 固定为 `(0.5, 0.125)`，即左下原点的 `(384, 96)` px。两足最低不透明像素都在 `y=96` 的共同地面线上，根锚点位于两足之间；人物最高不透明像素为 `y=623`，故可见身高为 528 px，即 `1.03125 m`。若任何方向不能同时满足这些数值，整组失败，不在 Unity 以私有缩放或偏移补偿。

### 3.2 斜俯视与引擎方向

- 六张图都为既有正交相机 `(0, 8, -10)`、欧拉角 `(38°, 0°, 0°)`、`orthographicSize=6.2` 下可读的预构图战术视角：顶髻、肩、袖口和袍摆允许有受该固定俯视影响的可读顶面，但不能出现透视夸张、鱼眼、单向特写或从 UI 正面肖像转出的视角。
- 方向语义唯一复用 `HexCoord.Directions`、六向测试台和角色本地 `+Z`；运行时不旋转、镜像或重排图像来补偿角色、镜头、地块或场景。每个文件的身份如下：

| 方向 | 规则邻格 `(q,r)` | 根节点 Y 旋转 | 约束 |
|------|------------------|---------------|------|
| `0` | `(1,0)` | `90°` | 本地 `+Z` 对准该邻格中心。 |
| `1` | `(1,-1)` | `150°` | 同上。 |
| `2` | `(0,-1)` | `210°` | 同上。 |
| `3` | `(-1,0)` | `270°` | 同上。 |
| `4` | `(-1,1)` | `330°` | 同上。 |
| `5` | `(0,1)` | `30°` | 同上。 |

- 同一人物的六张图必须保持单一、连通的 alpha 轮廓；不得有额外肢体、错误手指、重复／缺失腰饰、脸部身份漂移、衣料中烘焙手发、独立飘丝、破洞、透明衣片或无法解释的重叠结构。方向本身可改变正背面可见性，但背向不得复制前襟、腰扣或淡玉坠。

## 四、遮挡、有限帧边界与 Unity 取证

- 精灵只含人物的单一透明主体，不烘焙地面、接触阴影、底座、光圈、法阵、攻击特效或遮挡层。它以固定脚底锚点落在既有 `VisualBaselineBoard` 格位中心；上层地块与 `VisualBaselineOccluder` 负责遮挡，而不是靠透明边缘、私人 Y 偏移或每向不同裁切伪造深度。
- 本试制只交付六张静态方向图：每方向恰有一帧。不得额外生产 Idle／Move／Attack／Hit／Cast／Death 动画帧、序列、逐帧攻击图、完整动作批次或角色特效包。下游样例若需要六类表现语义，只能消费这六张静态图、同一角色根节点及既有表现事件；若必须新增时序帧才能证明语义，停止并交回路线比较父项。
- Unity 样例的比较证据固定为同一 `AdventureScene`、`VisualBaselineBoard`、正交相机、光照、九格技术矩阵和 1920×1080 输出条件。它必须按下表记录，不得以另一场景、不同镜头、不同地块或不同事件时点替代：

| 取证行 | 固定列 | 必须证明 |
|--------|--------|----------|
| 六向 | `0` 至 `5` | 每个 `fuyuan_tactical_direction_<n>.png` 与对应规则邻格、根节点角度和本地 `+Z` 一一对应；脸、宽袖、双手、黑白金身份和朝向均可读。 |
| 接地与遮挡 | 六向各一张清晰格位图，加一张使用现有遮挡物的图 | 六向脚底都落在格位中心，人物高度不靠私有缩放补偿；前景遮挡可覆盖应被遮挡的部分，且人物不被错误排序到地形／遮挡物之前。 |
| 表现语义 | 待机、移动、基础攻击、受击、施法、死亡 | 与静态 3D 路线消费同一既有事件开始／结束时点和规则结果；仅根节点位移／倾斜／淡出或已有一次性效果可变，精灵不写回规则。 |

## 五、QA、失败关闭与下游解锁

| 阶段 | 必须证明 | 失败即止 | 合法后续输入 |
|------|----------|----------|--------------|
| 六格生产 | 文件名、尺寸、RGBA、同一 3×2 来源、六向映射、脚底锚点、身份、配色、新姿态与宽袖／空手轮廓。 | 任一方向漂移、透视不统一、锚点不稳定、旧立绘复用、单向修补或来源无法追溯。 | 唯一源图、六槽、联系表与 `prompts.md`。 |
| Unity 样例 | 固定镜头六向、接地、遮挡和六类表现语义，且规则结果不变。 | 私有缩放／偏移、镜像／重排方向、错误遮挡、缺方向、额外帧依赖或视觉对象成为状态所有者。 | 与静态 3D 样例同条件的固定比较证据。 |

- 源图或任一输出不通过时，只记录来源、哈希、固定视角证据和失败层；不得从合格方向抠图拼出缺项，不得逐方向重画结构，不得减少方向，也不得把 UI 立绘当作替代。
- 本合同只在完成时解锁 `A-CHAR-2D-FUYUAN-SPRITE-01`。它通过后才可解锁 `U-CHAR-2D-TACTICAL-PROTO-01`；两条路线都只在固定相机、六向、事件时点和规则结果上比较，不能改规则换取视觉通过。
- 若新的战斗姿态、固定俯视、六向、尺度、脚底锚点、透明遮挡或有限帧边界不能按本合同复核，或只能靠旧 UI 立绘、减少方向、逐角色例外和额外动画成立，立即停止；不建立第三条混合路线。
