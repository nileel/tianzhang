# 全局“上古仙朝”设定移除设计

状态：用户已确认；全部决议已整合进 `docs/superpowers/plans/2026-07-22-tianzhang-cosmology-story-and-rules-migration.md`。本文保留为决议溯源，不作为新对话的第二执行入口。

## 一、决议

取消“上古仙朝”作为太玄界历史中的统一世界政权、正式时代名称和独立主线概念。

新历史主链固定为：

```text
天庭册封太玄界
  → 上古太玄道庭治理藩界
  → 天庭推动直属界域化
  → 本界天意扶持人间反抗者
  → 人主动完成绝地天通
  → 太玄道庭崩解
  → 道庭遗产分散，现世宗门与地方政权兴起
```

绝地天通与现世宗门时代之间不再增加一个统一“仙朝”层。该概念不承担复国、皇权、帝脉、末代帝君或天下共主主线。

## 二、名称使用边界

现行作者视角和权威事实源不再使用以下概念：

- 上古仙朝。
- 仙朝正统。
- 仙朝法箓。
- 仙朝工部。
- 仙朝末代道主或末代帝君。
- 把所有古代遗迹统称为仙朝遗迹。

对应表达按真实来源改写：

| 旧称 | 新处理 |
|---|---|
| 上古仙朝 | 删除；按语义改为上古太玄道庭、古道庭时代或具体地方古国 |
| 仙朝遗迹 | 太玄道庭遗址、册界设施、跨界通路遗存或具体古国遗址 |
| 仙朝法箓 | 太一道庭后世整理、自辟并维持的公共法统 |
| 仙朝工部 | 太玄道庭的古代工造机构；具体机构名仅在有玩法职责时另行设计 |
| 仙朝正统 | 太一道庭对古道庭部分遗产的正统声索，不是客观全界合法性 |
| 天门崩塌时代 | 后世对绝地天通及其余波的不完整理解；正式历史称绝地天通 |

“仙朝”不是禁用汉字组合，但不再作为默认古代文明称谓。地方历史中只有确实需要王朝结构、且与全界主线能够清楚区分的具体政权才可保留类似称谓；其余优先使用“古国、旧朝、古城、道统、宗门遗址”。现有“月氏仙朝”等条目必须逐项复核，不能因旧文本已经存在便自动保留。

## 三、关键内容承接

### 1. 太一道庭

太一道庭是绝地天通后形成的现世宗门政体。它继承上古太玄道庭南方法箓支系、部分官署传统和古籍解释权，但不是上古太玄道庭本体，也不继承全界行政权。

“天下玄门正统”是太一道庭的政治主张和宗门叙事，不是作者视角确认的天命事实。

### 2. 司马承景

司马承景固定为后世太一道庭公共法统的重整者与当代残损承接者，不再是统一仙朝的末代道主，也不是上古太玄道庭的直接管理者。

他了解太一道庭法箓如何运行，却不了解完整绝地天通真相。这一知识边界因此自然成立，不需要失忆或额外封印解释。

### 3. 白玉京与天工城

白玉京改为上古太玄道庭的浮空行政、转运或跨界设施遗存之一，只保存局部记录。

天工城继承古道庭工造、设施维护和节点修复知识。它能修复设备，不因技术传承而取得太玄界印的行政权限或《册界天章》的规则修改权。

### 4. 地图与遗迹

地图中的古代内容必须按来源分为：

- 太玄道庭的全界治理设施。
- 绝地天通造成的跨界断裂遗存。
- 绝地天通后形成的地方古国、宗门和城市遗址。
- 与新宇宙观无关的普通历史遗迹。

不再用一个“上古仙朝”标签包揽所有古代文明和遗迹。

## 四、叙事效果

移除后，玩家需要理解的最高层历史主体只剩：

1. 上界天庭。
2. 太玄界天意。
3. 上古太玄道庭及绝地天通参与者。
4. 绝地天通后兴起的现世宗门和地方共同体。

这使《天章》的核心冲突保持为“上界秩序与本界主体性”，避免玩家误以为主线还要处理仙朝复国、帝位传承或皇权正统。

早期低信息叙事可以使用“古道庭时代”“天门旧世”“古代大断绝”等不完整称呼，但不能重新塑造一个名为“上古仙朝”的统一政权。

## 五、验收标准

后续迁移完成时必须满足：

1. 权威事实源中不存在作为真实全界政权的“上古仙朝”。
2. 太玄道庭崩解后直接进入遗产分散和宗门兴起，不增加功能重复的中间统一王朝。
3. 太一道庭只继承有限支系，不自动取得全界正统。
4. 司马承景的法箓知识与绝地天通知识边界不矛盾。
5. 白玉京、天工城和古代遗迹都能回溯到具体来源。
6. 具体地方古国不会被误读成已删除的全局上古仙朝。
7. 删除该设定不会改变龙脊之变、九域结构、第一章任务或现行境界规则。

## 六、范围限制

本文不命名古道庭工造机构，不设计地方古国完整年表，不扩写上界地图，不改变现行境界表，也不实施生产文件迁移。

生产迁移只从已整合的《天章》宇宙观、剧情与规则迁移计划进入，不再要求执行者同时维护两份计划。
