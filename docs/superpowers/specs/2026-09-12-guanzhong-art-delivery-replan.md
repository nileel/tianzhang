## 目标与范围

近期唯一美术里程碑：关中城接悬赏 → 关中野外一场玩家对石甲兽战斗 → 返回关中城领取奖励，整段达到画面统一、行动可读、可实际展示的品质。沿用当前小族出身与既有正式场景，不新增 NPC、地区、怪物、玩法、经济或数值内容。

采用精绘 2D 人物母版与头像、固定镜头下静态 3D 棋子、整体动作及有限特效。静态 3D 是本轮交付路线；若完整实机场景的观感仍不被接受，停止扩产并根据整场证据重新决策，不把历史批准或投入视为继续理由。

默认男主仍沿用已批准 v2 身份、原画和四视图；石甲兽沿用现有 source 作为待实机检验输入。不会因为文件已存在就认定品质合格。角色规则、六向、稳定 profile ID、单一正式 provider 与存档边界保持既有合同。

## 生产与批准边界

1. LOOKDEV 以现有批准角色、关中原文和当前镜头为输入；实际查看图片后形成城镇/战斗整屏样板。样板明确标为设计示意，不能当实机证据。基准看角色、地面、UI整体，不能只看放大人物。技术导入检查与用户审美批准分别记录。
2. 第一轮内置图片生成最多四次：两张整屏样板及最多两次针对已定位问题的修订，不新增模型服务订阅、外部 credits 或采购。若环境/工具无法提供该能力，准备现有素材组成的可审阅方案并准确说明，不把未生成图片记为完成。
3. LOOKDEV 冻结首包资产逐项来源、精确路径、数量和每卡制作/返工上限。批次外付费未授权；平台价格与可用服务须执行时核验，先形成具体交易材料再请求费用批准。整屏基准审批不代替交易批准，也不要求每张非关键贴图重复批准。
4. ASSET-04 对同一批准输入允许一次初始导出，以及最多两轮查明根因后的本地修正/复导出；仅适用于原卡允许的清理和导入兼容范围。每轮记录原因、改动、导出次数与受影响复验；没有自动重试、额外兜底或新工具路线。输入、设计、所有者或范围变化立即停止。本条替代该卡及 2026-08-29 v2 规格中“第二次 FBX 导出即停止”的次数条款，其他约束继续有效；01/02/03 失败旧卡不重启、不提供输入。
5. AI 优先承担完整立绘、背景、视觉候选；程序承担确定性裁切、资源组织、接入和反馈。若需专业美术，先提交本首包内的具体交付与报价，不直接外包或联系第三方。
6. 总成本记录包括素材制作、生成等待、失败返工、Unity 接入、实际验证；缺失数据写未知。两个不同形体完成不等于量产成立；以后再用一个同类资产验证复用成本。

- 正式单位当前由 AdventureUnitSpawner 创建 Marker，EncounterCoordinator 持有并销毁；比较资源不等于正式玩家/敌人输入。
