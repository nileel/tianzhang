# 静态 3D 棋子角色生产合同

状态：2026-08-21 冻结；只服务于 `A-CHAR-BATTLE-VISUAL-DIRECTION-01` 的静态 3D 试制线。

## 一、范围与唯一目标

- 首个样例固定为苻渊／含弘真君。它只是在固定正交斜俯视六角测试台中比较视觉路线的样例，不把当前闭关中的苻渊接入第一章、正式遭遇或常规可战斗单位。
- 本合同依次约束：新的苻渊战斗定姿四视图、一次获单独 credits 授权后的 Tripo 无绑定原包、Blender 静态候选和 Unity 静态棋子样例。每一阶段都消费同一身份、姿态、尺度、朝向和表现语义，不得从旧立绘或 `strict-round-02` 的人形绑定候选反推新资产。
- 旧立绘和已批准的对话透明母版只作脸、发型、服饰、配色、材质气质和标志物参考。它们的站姿、构图、座椅、背景、光效与任何旧四视图都不是战场输入，也不得缩小、裁切、透视变形或修补后充当新四视图。
- 此路线不生产运行时骨骼动画、Avatar、Animator、统一换绑、A/T Pose、换头、袖根蒙皮补丁、Quad 硬门或完整境界底座批次。任何 Tripo credits 消费仍须在四视图完成后获得一次新的明确授权。

## 二、苻渊身份与静态定姿

### 2.1 不可漂移的身份合同

苻渊是沉稳、疲惫而自持的年长男性修士，不是帝王、反派或衰败伤者。四视图与后续静态模型必须同时保持下列事实：

- 宽实肩背、成熟棱角脸、克制严肃的目光；白灰发为一个简洁顶髻，加一整块贴近肩背的后发；短尖白须和八字胡。
- 约 4.5–5 头身的紧凑棋偶比例；头、手、宽袖、袍摆和脸部大平面优先于近景细碎饰物。
- 完整、厚重、旧而未破的炭黑道袍，灰白内领／内袖，少量终止在衣料内的断契金线；一个旧铜圆形腰扣和一枚小型淡玉坠。没有盔甲、王冠、帝王徽记、武器、法杖、外置法器、座椅、光环、浮游节点或脱离衣体的能量效果。
- 宽袖是成对、连贯而靠近躯干的实体轮廓，不展开成翼、硬板、尖刺、透明片或跨背框架。腰扣与玉坠各只能有一件；背视图不得复制其正面形状。

### 2.2 唯一自然战斗定姿

- 角色直立，双足完整踩在同一水平面；左脚向前半步、足尖朝本地 `+Z`，右脚后撤半步，双膝只作自然微屈。重心落在两足之间，躯干与头部保持正对本地 `+Z`，不得扭腰或作三分之四肖像姿势。
- 左臂自然下垂，左手在左侧袖口前方可见；右前臂在腰前自然弯曲，右手半握且可见。双手不持物，袖口不得吞没手、交叉遮住躯干或把任何手指、衣带和玉坠悬浮成独立碎片。
- 这一定姿同时用于正面、脸朝左侧、脸朝右侧和背面。视角改变不能改变脚步、手臂、手势、头身比例、衣袍结构、宽袖体积、腰饰数量或后发长度；四图不是四张独立姿势设计。
- 姿态的情绪是承担压力后的警觉、克制和可行动，不是攻击蓄力、施法、奔跑、坐姿、胜利展示或完全放松的头像站姿。

### 3.2 构图与一致性硬门

- 四图同为无文字、无 UI、无印章、无水印、无背景环境、无地面、无投影、无座椅、无烟雾和无粒子效果的完整单人全身图。头髻、后发、双手、双足、袍摆和袖口必须完整入画。
- 使用同一中性正交或等效无透视人物构图、同一画面尺度、同一平视高度、同一柔和中性光和同一低饱和深炭黑／暖灰／灰白／旧铜金／小淡玉调色。不得以强烈镜头透视、阴影、背景、边缘发光或局部遮挡伪造轮廓。
- 四图的脸型、年龄、发髻、后发长度、胡须、衣袍分层、宽袖收束、手势、腰扣、玉坠、鞋和断契金线必须逐项一致。侧面只显示该视角本来可见的物件；背面必须显示连贯后发、袍背和袖背，而不是复制前襟、腰扣或玉坠。
- 单张图出现额外肢体、手指错误、重复或缺失腰饰、面部身份漂移、衣料中烘焙手发、独立飘丝、破洞、透明布、无法解释的重叠衣片，或需要逐图重画结构才能对齐时，整组失败并停止；不得从合格图中修剪问题以拼成输入集。

## 四、尺度、朝向与独立修炼底座

### 4.1 静态人物尺度与导出坐标

- Blender 候选把人物双足接地面设为局部 `Y=0`，人物根节点位于两足之间的地面投影，未附底座时含顶髻的最高点为 `Y=1.03 m`。这与六向测试台 `UnitMarker` 的现有人物高度包络一致；不得为苻渊或任何场景加私有缩放偏移。
- 成品人物网格以本地 `+Z` 为正面、`+Y` 为上方、单位缩放 `(1,1,1)` 导出。人物根节点不承载骨骼、角色数值、占格、Facing、路径或事件状态；它只消费已存在的表现位置、朝向和表现事件。
- 六向映射唯一复用已通过的 `HexCoord.Directions` 和六向测试台：索引 `0–5` 的根节点 Y 旋转严格为 `90/150/210/270/330/30` 度。每个方向的本地 `+Z` 必须对准对应规则邻格中心；不允许按角色、镜头、地块或资源追加朝向偏移、镜像或重排。

### 4.2 修炼底座接口

- 人物、鞋底和袍摆不合并六角地块、底座、法阵、光效或修炼境界几何。人物不带底座也必须在 `Y=0` 稳定站立。
- 底座是可替换的独立 3D 组件：其根节点与人物根节点同一地面锚点、同一缩放和同一 `+Z` 正面；顶面是人物的 `Y=0` 接触面。底座只能改变视觉承载，不改变人物网格、材质、占格、高度、朝向、碰撞、路径或规则距离。
- 本试制只允许最小无语义占位来证明挂接关系；不生产完整境界底座、独立光环或把底座烘焙进人物贴图。底座接口未成立时停止在 Blender／Unity 样例，不把人物缩放或地块偏移作为替代方案。

## 五、材质与静态模型边界

- 后续 Tripo 只生成一个无绑定、无动画的静态人物原包；不以四边面数量、平台自动绑定或平台动作作为通过条件。原包必须先通过脸、姿态、衣料和结构静态门，才可交给 Blender。
- Blender 只对同一原包做最小静态清理、法线／材质核对、尺度／朝向冻结和候选导出。不得恢复 `strict-round-02` 的换头、袖根权重、统一骨架、动作、局部重拓扑或任何连续修补工作流。
- 材质观感为低饱和手绘水墨棋偶：粗糙哑光布料、深色克制笔触边缘、柔和去饱和阴影、手绘大色块，以及旧铜与淡玉的可分辨材质差异。二至三档 Toon 明暗是静态样张的视觉目标；Unity 样例只消费既有 URP 技术基线，不在本路线新增或要求新 Shader。不得把透明、亮面、发光或复杂粒子当作身份／六向／动作语义的补偿。

## 六、根节点表现语义与规则隔离

静态棋子的模型本身在所有事件中保持静态；允许变化只发生在表现根节点和一次性特效，且由既有表现事件驱动。根节点绝不写回或重新推断任何规则事实。

| 表现事件 | 静态棋子允许表现 | 明确禁止 |
|----------|------------------|----------|
| 待机 | 静止模型、稳定阴影和朝向。 | 骨骼呼吸、布料、IK 或自主转向。 |
| 移动 | 根节点抬起、随已批准的格位移动、落下；模型不变形。 | Root Motion、模型决定路径、位置或占格。 |
| 基础攻击 | 根节点朝既有 Facing 作短促前倾／位移和一次性特效；结束复位。 | 挥臂骨骼动画、命中判定或改变攻击时点。 |
| 受击 | 根节点短促震动或后仰和命中特效；结束复位。 | 重新计算伤害、击退、状态或朝向。 |
| 施法 | 人物保持静态，由脚下以外的短促特效表现。 | 手臂／袖袍骨骼动作、平台动画或生成光环。 |
| 死亡 | 根节点一次性倾倒／降低并淡出或替换为既有死亡特效。 | 骨骼倒地、改变死亡结算、阻挡或占格。 |

移动、攻击、受击、施法和死亡的开始时点、完成时点、结果与六向选择必须与 2D 路线消费同一既有表现事件。角色根、人物网格、底座和特效都不是 `Character.Facing`、坐标、可达性、射程、视线、伤害、状态、死亡、存档或装备的所有者。

## 七、静态 QA 矩阵与失败关闭

| 阶段 | 必须证明 | 失败即止 | 不可替代的后续输入 |
|------|----------|----------|--------------------|
| 四视图 | 四槽命名、哈希、同一定姿、身份、宽袖／后发／腰饰结构和无污染。 | 单槽身份或结构漂移、无可见手／足、背面错误或逐图修补。 | 批准的四张 PNG、联系表和 `prompts.md`。 |
| Tripo 原包 | 唯一获得授权的消费、实际任务／价格／参数、输入哈希和平台静态门。 | 未授权、第二次生成、脸／服饰／姿态漂移或手发纹理污染。 | 未绑定原包、平台静态证据和哈希。 |
| Blender 候选 | 同一原包、无骨骼动画、清洁法线与材质、`Y=0` 接地、`1.03 m` 高度、单位缩放和 `+Z` 正面。 | 需要绑定、换头、袖面补丁、重拓扑扩张、底座合并或私人朝向偏移。 | 可复核的静态候选文件与检查记录。 |
| Unity 样例 | 六向 `90/150/210/270/330/30`、固定正交镜头、六方向可读、地块接地、独立底座、阴影／遮挡和六类表现事件。 | 规则结果变化、模型／底座成为状态所有者、任何运行时骨骼动画或无法分辨的方向。 | 与 2D 样例同条件的固定比较证据。 |

四图、平台、Blender 或 Unity 任一硬门失败时，只记录输入、哈希、固定视角证据和失败层；不追加生成、不消费免费重试、不改战斗规则，也不把 2D 路线的结果当作静态 3D 的通过。合同中的确定性命名、哈希和坐标检查不能替代负责人对身份、姿态、袖袍轮廓与六向可读性的视觉结论。
