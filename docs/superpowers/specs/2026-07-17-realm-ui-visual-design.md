## 一、界面目标

境界界面承担四项核心职责：

1. 展示当前大境界、小阶段与修行进度。
2. 展示与当前境界直接相关的结构，例如练气期的丹田灵气、筑基期的道基与紫府府位、金丹期的位格状态。
3. 作为大境界突破的确认与演出入口。
4. 让玩家直观看见自己的修行结构如何从上一境界连续转化，而不是只看到数字增长。

角色全部属性不默认堆进本界面。境界页只显示与当前修行和突破直接相关的少量信息；完整属性汇总放在独立属性页，或通过可收起的详情抽屉查看。

## 二、已确认视觉方向

暂定采用第一版概念样图的方向：

- 全幅深色背景，中央修行结构自发光，形成体内观想与丹田内景的封闭感。
- 每个大境界拥有全新的中央视觉主体和构图，不把所有境界套入同一个固定容器。
- 保留较强的仪式感、空间层次和高对比度，不强求与浅色角色立绘使用同一背景。
- 与角色立绘的统一主要来自中国修仙题材、纹样、材料、色彩和笔触，而不是所有界面都改成同一种平面水墨设定页。
- 金色边框与装饰目前随第一版一起保留为暂定基准；后续可调整用量，但不在本轮继续生成折中版本。
- 四阶段并排图只用于验证形态继承与突破转化，不是最终游戏界面的四栏布局。

后续探索中产生的浅纸 2.5D、重复丹田腔室和亮纸沉墨版本不作为当前基准。它们分别暴露了天外秘境感、宗教解剖图感和脏污纸面感等问题。

## 三、界面总体结构

每个大境界使用独立中央舞台，但保留稳定的外围交互位置，避免玩家每次突破都重新学习操作：

- 中央：当前境界的核心修行结构，可轻微旋转、悬停或点击查看组成部分。
- 上方：境界名、小阶段和最简进度信息。
- 侧边：与当前境界直接相关的结构摘要，默认收起。
- 下方：修炼、突破或确认按钮；不满足条件时显示缺失项，不只显示灰色按钮。
- 详情：点击道基、府位、神通或位格后打开局部信息，不常驻铺满屏幕。

大境界变化时，中央舞台完全重构；外围导航、返回、帮助、属性入口和确认按钮位置尽量保持一致。

## 四、各境界的视觉与状态

### 4.1 练气期

核心意象是盘坐修士与腹部丹田空腔。

- 丹田中展示灵根结构。
- 灵气随练气九品进度逐渐填充空腔，不只使用一条普通经验条。
- 灵气颜色依据角色当前主修功法或主要灵力属性变化；项目正式术语使用“灵力/功法属性”，不继续扩散“内力属性”称呼。
- 多属性角色不能只靠混合颜色表达，必须同时使用纹理、流动方式或分层结构，避免色盲问题和颜色混浊。
- 练气圆满时，空腔接近充盈，但仍需保留突破条件和成功率信息。

突破至筑基时，丹田空腔与其中灵气向中心压缩，最终凝成道基的基础形态。

### 4.2 筑基期

核心意象是角色独有的道基，以及依附其上的五个紫府府位。

- 不同道基类型和品级应拥有不同的轮廓、材料、纹样与槽位组织方式。
- 太一道庭修士不使用通用道基外观，须按现有事实源表现为初授法箓及其后续结构。
- 五府分别为命府、魂府、识府、气府和运府。视觉上可以使用五座微缩建筑或五个内部空间，但必须让玩家看出它们是不同职责的府位，而不是五个等价技能槽。
- 主修二至三府应比其他府位更明亮、更完整、更有纵深，不要求五府均衡发展。
- 完成的府位应支持空置状态、候选术法状态和已植入紫府神通状态。
- 紫府神通可以拥有独立图像或微缩模型；原型阶段先使用可区分的符号资源，正式资产量在美术预算确认后再扩展。

原始灵感提出“劣质道基可能不足五个紫府位置”。当前不直接采纳为正式规则：五府是现有设定中的五类固定府位，低品道基更适合表现为府位亲和度低、受损、开发困难或成长上限受限，而不是直接删除某一类府位。若未来确实需要减少可开发府位数量，必须先修改境界事实源并验证 Build 影响。

筑基内部阶段需遵守现有五段制：

- 筑基初期：凝聚道基。
- 筑基中期：道基稳固，本命术法候选首次出现。
- 筑基后期：道基圆满。
- 紫府初开：五府显现，开始成为主要界面内容。
- 紫府圆满：府位与紫府神通形成成丹输入。

因此，不能简单写成“筑基前半段建完五府、后半段再装神通”。可保留逐步修建和装载的视觉节奏，但具体开放顺序以五段制和后续机制确认结果为准。

### 4.3 金丹期

突破演出将完整道基、府位和紫府神通共同压缩为一颗金丹，再拉近视角进入金丹内部。

金丹内部暂用三层视觉隐喻：

- 中心凝实核心：源位。
- 中间流动层：化位。
- 外部包覆层：界位。

三部分只表示不同职责，不表示源高于化、化高于界。每部分必须能够独立处于已获得、未获得、暂寄、不稳定或失去等视觉状态，并显示所属道路纹理。

当前已审核事实源仍以单一目标位格表达金丹；2026-07-15 的金丹重构交接稿提出金丹初期、中期、圆满依次取得三个真实位别且顺序自由。该重构尚未迁入全部正式事实源，因此本界面的三层独立点亮只能作为候选视觉方案，不能先行写入运行时数据。

### 4.4 元婴期

元婴是远期、NPC 与资料片方向，当前玩家完整成长链止于金丹。本轮只记录视觉锚点，不排入近期实现。

- 三个位格条件满足后，突破演出可表现为元婴从源位核心孕生，并破开金丹外壳。
- 元婴应明显带有“新生”与“破壳”意象，不能画成普通成年元神。
- 元婴界面根据道路更换中央主视觉，但建议保留共享外围交互骨架，避免十七条道路都制作完全无关的整套 UI。
- 阴/阳道路示例可使用阴阳图中的两个婴孩形态；角色实际承接哪一道路，就点亮对应形态，另一形态保持暗淡或虚影。该表现不能暗示角色同时持有两个元婴位格。
- 每个具体元婴位格仍须保持唯一性，不出现可批量复制的通用元婴模板。

## 五、突破动画语法

各境界使用同一条“压缩、固化、破壳”的连续视觉语法：

1. 练气至筑基：空腔与灵气压缩并固化为道基。
2. 筑基至金丹：道基、五府和神通纹理向中心坍缩，凝为金丹。
3. 金丹至元婴：内部条件完成后孕生元婴，金丹从内向外破壳。

动画必须让上一境界的材料、纹样和选择痕迹进入下一境界，不能只用白光遮屏后替换模型。不同道基、主修府位、紫府神通和位格道路应改变转化后的细节。

## 六、适配判断

该方向总体合适，核心优点是：

- 把境界成长变成可见、可记忆的个人修行结构。
- 每次大境界突破都有自然的形态转化依据，仪式感强。
- 道基、府位、神通和位格不再只是列表字段，可直接承载 Build 差异。
- 中央视觉信息强，外围可以保持简洁，符合单界面少信息的审美偏好。

主要风险是：

- 每个境界、道基和道路都完全独立制作会造成较高美术资产量。
- 紫府神通独立模型会随内容数量快速膨胀，应先验证图像、符号和少量关键模型的混合方案。
- 金丹三位格玩法仍在重构，UI 不得先于规则锁死。
- 只靠颜色表示灵力、府位或位格会造成可读性和无障碍问题。
- 高阶元婴界面不属于当前版本近期交付范围。

## 七、当前结论与后续验证

当前结论：第一版概念样图作为阶段性视觉基准试用；后续不再为了机械统一角色立绘背景而削弱深色丹田内景和境界仪式感。

下一轮如果继续细化，应停止生成四阶段总览，改为选择一个境界制作单界面样稿。推荐先验证筑基界面，因为它能同时检验道基差异、五府可读性、主修府位、空槽位、紫府神通装载和信息收纳。

单界面样稿通过标准：

1. 不看文字也能识别当前境界和核心进度。
2. 五府可区分，但不会被误解为五个普通技能槽。
3. 主修二至三府与非主修府位层级清晰。
4. 突破入口明显，但不抢夺中央结构的视觉焦点。
5. 默认界面保持简洁，详细数值按需展开。
6. 能说明关键状态如何由数据驱动，而不是每种组合都依赖一张完整静态图。
