## 二、四阶段现行语义（命名依据）

四阶段同属一条连续养基进度上的状态节点，不是四次独立突破 —— `docs/superpowers/specs/2026-07-20-foundation-purple-mansion-danxiang-integration-design.md#6.2 阶段推进`。

| 阶段 | 现行机制 | 天然容量释放 | 道基核心效果（N-FPD-GROWTH-01 代表曲线） |
|---|---|---|---|
| 第一阶段 | 筑基考验完成后必定形成，是整条进度的起点；灵根不限制阶段 | 未跨节点，不释放 | 0.350 |
| 第二阶段 | 养基进度跨过第一节点后自然进入 | 最多释放第 1 座 | 0.515 |
| 第三阶段 | 跨过第二节点后自然进入 | 最多释放第 2 座 | 0.742 |
| 第四阶段 | 跨过第三节点后自然进入；完成后为筑基圆满，此后养基不再合法 | 最多释放第 3 座 | 1.000 |

- 阶段推进只提交同一条连续进度，跨越节点不创建新的突破考验，普通养基周期也没有独立随机失败 —— `docs/superpowers/specs/2026-07-21-foundation-mansion-cultivation-actions-design.md#3.2 连续养基`。
- 命名需要同时表达三层语义：①处于同一道基的连续积累；②可用紫府容量随节点逐步释放；③第四阶段完成即筑基圆满。

## 三、候选与出处逐条

`基` 统一指现行术语“道基”（§一），本文件不为 `基` 声明典籍出处。修饰语分别对应该阶段的机制动作：形成、培进、拓容、圆成。

| 阶段 | 候选名 | 出处级别 | 字义依据 | 连续养基语义 |
|---|---|---|---|---|
| 第一阶段 | 元基 | 原创 | `元` 有典籍引文（3.1）；`基` 取现行术语 | 道基初成，是整条养基进度的本元起点；未跨节点，紫府容量尚未释放 |
| 第二阶段 | 培基 | 原创 | `培` 有典籍引文（3.2）；`基` 取现行术语 | 以固定周期持续培进同一条道基进度；跨过第一节点，开始释放紫府容量 |
| 第三阶段 | 拓基 | 原创 | 无典籍引文，只作现代词义说明（3.3） | 进度过半，已释放容量继续扩张至第二座；仍在同一进度上推进 |
| 第四阶段 | 圆基 | 原创 | 无典籍引文，只作现代词义说明（3.3） | 进度走完，道基圆满；容量释放至第三座，此后养基不再合法 |

- 四个候选名均为单一名称，无重复，不互为同义。
- 第二阶段候选"培基"与现行行动名"养基"同为"动词 + 基"的表达方式，与既有术语方向一致。
- 第四阶段候选"圆基"与现行结果表述"筑基圆满"同义，不引入新概念。

### 3.1 第一阶段“元基”的修饰字字义依据

- 《周易·乾·彖传》："彖曰：大哉乾元，万物资始，乃统天。"取"乾元"为万物本始之义，对应道基形成即为养基进度的本元起点。
- 出处说明：`元` 的典籍原文如上，只作 `元基` 中 `元` 的字义依据；`元基` 这个两字词本身未核到典籍原文出处，`基` 取本项目现行术语“道基”（`docs/基础设定/境界特性.txt#一、筑基期 —— 唯一道基与四阶段`）。故 `元基` 的出处级别为**原创**，既不列为「出处词组」，也不再使用已取消的「用字有据」级别。

### 3.2 第二阶段“培基”的修饰字字义依据

- 《庄子·逍遥游》："风之积也不厚，则其负大翼也无力……而后乃今培风。"培风谓凭风积厚而后图南，取"积而后进"之义。
- 《礼记·中庸》："故天之生物，必因其材而笃焉。故栽者培之，倾者覆之。"培谓因材培壅，取"持续培进"之义。
- 两处均支持第二阶段的"按固定周期积累"语义。
- 出处说明：`培` 的典籍原文如上，只作 `培基` 中 `培` 的字义依据；`培基` 这个两字词本身未核到典籍原文出处，`基` 同 §3.1 取现行术语，本文件不为 `基` 声明典籍出处。故 `培基` 的出处级别为**原创**。

### 3.3 第三、第四阶段“拓基”“圆基”的原创声明

- **拓基** —— 项目原创命名，不声明古典词组出处，也无修饰字典籍引文。与现行机制一致的字义：`拓` 表"开拓、扩展"，现行事实源用"扩府"表示容量增加（`docs/基础设定/境界特性.txt#二.1 天然容量与扩府`），与第三阶段"已释放容量继续扩张"一致。
- **圆基** —— 项目原创命名，不声明古典词组出处，也无修饰字典籍引文。与现行机制一致的字义：`圆` 表"周全、完满"，现行事实源本身即用"筑基圆满"表示第四阶段完成（`docs/基础设定/境界特性.txt#一.3 四个连续阶段`），`圆基` 与该现行表述同义。
- 上述字义说明只用于解释命名意图，不等于该词有典籍出处。
- 本组四个候选名的出处级别均为**原创**；差别只在修饰字是否有逐字核验的典籍引文作字义依据，不构成出处级别差异。

## 四、推荐组与替代组

### 4.1 推荐组

| 阶段 | 名称 | 出处级别 |
|---|---|---|
| 第一阶段 | 元基 | 原创 |
| 第二阶段 | 培基 | 原创 |
| 第三阶段 | 拓基 | 原创 |
| 第四阶段 | 圆基 | 原创 |

- 四个名称的出处级别均为**原创**；修饰字的字义依据见 §3.1～§3.3，`基` 取现行术语且本文件不为其声明典籍出处。

推荐理由：

1. 四个名称统一为"修饰语 + 基"的二字单名结构，不出现长短不一的命名家族。
2. 四个修饰语分别对应该阶段唯一新增的机制事实：形成（元）、积累（培）、扩容（拓）、完成（圆），不重复指代同一件事。
3. 不含品级、容量数量或阶段序号，也不含"初／中／后"字样，不形成旧五段同义复刻。
4. 与现行术语一致：行动名"养基"、结果名"筑基圆满"、容量名"扩府"均保持不变，新增的只是四个阶段节点名。

### 4.2 替代组

| 阶段 | 名称 | 出处级别 | 字义依据 |
|---|---|---|---|
| 第一阶段 | 元基 | 原创 | `元`：《周易·乾·彖传》"大哉乾元，万物资始" |
| 第二阶段 | 培基 | 原创 | `培`：《庄子·逍遥游》"而后乃今培风"；《礼记·中庸》"故栽者培之，倾者覆之" |
| 第三阶段 | 渐基 | 原创 | `渐`：《周易·渐卦》"鸿渐于干"／"鸿渐于磐"／"鸿渐于陆" |
| 第四阶段 | 渐陆 | 原创 | `渐`／`陆`：《周易·渐卦》九三"鸿渐于陆" |

- 替代组以《周易·渐卦》"鸿渐于干 → 鸿渐于磐 → 鸿渐于陆"的依次推进为意，强调"渐进有序、不跳阶"；`鸿渐于干`、`鸿渐于磐`、`鸿渐于陆` 三句均为《周易·渐卦》爻辞原文。
- 出处说明：替代组四项出处级别均为**原创**。`渐基` 与 `渐陆` 两个两字词本身均未核到典籍原文出处；`渐陆` 的 `渐`／`陆` 二字虽都见于上列爻辞原文，整词仍是项目凝缩，不因此升级出处级别；`渐` 的爻辞原文只作字义依据；`基` 同 §3.1 取现行术语，本文件不为 `基` 声明典籍出处。
- 形式差异：替代组的第三、第四阶段不再统一带 `基` 字，第四阶段"渐陆"是《渐卦》爻辞中的落地之象，与"圆基"的收束语义不同；`渐陆` 需读作"渐至于陆"的两字凝缩，不如 `圆基` 直白。

### 4.3 两组对比

| 维度 | 推荐组（元基／培基／拓基／圆基） | 替代组（元基／培基／渐基／渐陆） |
|---|---|---|
| 结构统一 | 四个均为"修饰语 + 基" | 第三、第四阶段结构不同 |
| 语义指向 | 每阶段指向一个独立机制动作 | 统一指向"渐进"，阶段间区分度较低 |
| 出处级别 | 四项均为原创，无「出处词组」 | 四项均为原创，无「出处词组」 |
| 字义依据 | `元`／`培` 有逐字核验的典籍引文；`拓`／`圆` 无 | `元`／`培`／`渐` 有逐字核验的典籍引文；`陆` 见于《渐卦》爻辞原文 |
| 与"扩府"表述的关系 | `拓基` 与现行"扩府"同向 | `渐基` 不直接体现容量扩张 |

- 两组全部候选的出处级别均为**原创**；上表「字义依据」只区分修饰字是否有逐字核验的典籍引文，既不代表名称本身有典籍出处，也不构成出处级别差异。
