# 默认男主严格四视图姿势修订设计

状态：负责人已选择方案 A 并明确要求实施；修订设计已经同步落地。负责人随后在当前对话另行批准新完整提示词代码块；该批准不追溯到旧提示词或旧调用，当前仍未执行新的 ImageGen 调用。

关联任务：`A-CHAR-BATTLE-STATIC3D-PLAYER-FOURVIEW-01`

## 1. 根因与目标

已拒绝四视图候选把批准原画的单手剑指和自然不对称重心改成双臂下垂的对称站姿，形成僵硬的建模人台观感。该结果并非生成器单独违反旧合同，而是旧生产规格、任务卡和已消费提示词共同要求“不沿用对话剑指姿态”。

本修订以负责人选择的方案 A 为唯一方向：保留批准原画的姿势身份和不对称气质，同时为多视图 3D 几何识别留出必要的肢体间隙。严格正交相机、同一冻结姿势和既有身份／服装不变量继续成立。

## 2. 新姿势合同

- 正面保持严格正交，不继承原画的三分之四相机角度。
- 角色保留批准原画的右手单手剑指、右前臂抬至下胸前、左臂自然下垂和轻微自然重心；不得改成双臂下垂的对称建模人台。
- 右手食指与中指并拢伸直，其余手指自然收拢。右肘靠近躯干，但右肘、前臂、手指、衣袖与躯干之间必须留有清楚可读的间隙。
- 剑指不得遮挡脸、领口或主要服装结构；左手必须完整可见。
- 四个面板展示同一个冻结姿势，只改变正交观察方向。侧面和背面不得把右臂还原成下垂状态，也不得把不同视图拼成不同姿势。
- 手印仍是无施法效果的日常修行习惯动作；不得添加光效、气场、粒子、烟雾、符文、能量或风效。

## 3. 保持不变的四视图合同

- 唯一决定性身份参考、16 岁身份、脸、七头身、半束长发、服装结构、配色和禁止新增物件的规则不变。
- 四宫格物理位置仍为：左上严格正面，右上角色自身左侧且鼻尖朝画面右，左下角色自身右侧且鼻尖朝画面左，右下严格背面。
- 四图继续使用相同近正交镜头、相机高度、人物尺度、落脚线、暖灰背景和中性光照。
- 一份负责人逐字批准的完整提示词仍只对应一次 ImageGen 调用；不自动重试、不逐槽补画、不镜像或翻转。

## 4. 视觉验收与停止条件

以下任一情况出现即判定姿势失败并停止：

- 双臂下垂、左右对称或整体重新呈现僵硬建模人台姿势。
- 右手不是单手剑指，剑指高度明显偏离下胸前，或右臂在任一视图中变成下垂状态。
- 剑指遮挡脸、领口或主要衣片；右肘、前臂、手指、衣袖与躯干粘连而无法辨识。
- 手指融合、缺失、多指，左手不可见，或四个面板的肢体姿势互不一致。
- 为保留姿势而破坏严格正交方向、七头身、完整全身构图或既有身份／服装连续性。
