# 功法设计规范

## 文件位置
- 功法原文：`docs/角色养成/功法/[门派]/功法名.txt`
- 通用模版参考：`docs/角色养成/功法/功法设计.txt`

## 模板字段（设计新功法时全部必填）

基础信息：
- 名称 — 格式 = [古典哲学概念] + [后缀：法/经/录/典/书/藏/笺]。必须从经典典籍中取意，不可用白话词
- 原型 — 注明灵感来源的历史人物或典籍原文
- 品级 — 凡品/下品/中品/上品/极品
- 归属 — 所属门派或"古修"
- 初始境界 — 最低修习境界；凡人境=无修为门槛
- 境界上限 — 最高可修炼到的境界
- 属性倾向 — 5项先天属性权重，用★☆☆☆☆~★★★★★标注，支持半星（½）
- 灵根要求 — 所需灵根种类 + 最低品级
- 功法属性 — 五行/变异属性，标注主属性和辅属性
- 灵力纯度 — 标准值=1.0；越高灵力越精纯（消耗更省），但成长越慢
- 灵力成长 — 每日灵力获取（点/天），已含纯度影响
- 设计理念 — 一段话解释核心机制与性格/哲学来源

篇章（每篇一个表格行）：
- 篇章名 — 2~4字，必须取自经典原文关键词，不可自造
- 所需境界 — 解锁该篇的最低境界
- 道基/神通 — 首篇为"道基"，后续为"神通"（写明进化链）
- 典籍出处 — 必须引用该典籍的真实原文（含篇章名），不可杜撰古文
- 先天属性成长 — 该篇章解锁后永久获得的先天属性点数（按★权重计算）

## 核心约束

1. **一品级一境界跨度**：境界上限决定篇章数。每个大境界至少对应一个篇章；大境界的圆满阶段可额外设置篇章（如同属元婴大境界的"元婴"与"元婴圆满"，同属化神大境界的"化神"与"化神圆满"）。练气期因九品跨度较大，通常仅在入门品级和九品圆满各设一篇，不逐品展开。
2. **一篇章一进化链**：后一篇章的神通必须覆盖/增强前一篇章，形成完整进化链
3. **品级与纯度正向**：功法品级越高，灵力纯度应越高（凡品<下品<中品<上品<极品）。纯度基准：极品≥1.2、上品≥1.0、中品≥0.8。低品级高纯度或高品级低纯度仅在我明确要求或原文素材极强支撑时方可使用（如混元同尘典 0.7 有苻坚大军庞杂不精的文本依据）
4. **成长与纯度反向**：灵力纯度越高 → 灵力成长越低。纯度>1.0的功法修炼慢但灵力含金量高（转化时更保值）
5. **命名不出典不立**：功法名/篇章名必须在标注典籍中找到原文依据，禁止自创
6. **设计围绕性格**：功法围绕原型人物的性格与处事方式设计，不围绕历史事件（尤其失败事件）
7. **风险内生**：功法附带风险来自性格本身的内生缺陷，而非外部历史事件

## 功法转化规则

1. 旧有效灵力 = 旧实际灵力 × 旧纯度
2. 保留有效灵力 = 旧有效灵力 × 属性转换系数
3. 新实际灵力 = 保留有效灵力 ÷ 新纯度
4. 属性转换系数：相生=80%，无关联=60%，相克=40%（丹药/灵髓可加成，上限100%）
5. 强制废功：转换系数=0%，灵力值清零、金丹重凝

## 先天属性权重参考刻度

- ★★★★★ — 绝对核心属性（如暗系功法的魂魄、体修功法的根骨）
- ★★★★☆~★★★★½ — 重要输出/生存属性
- ★★★☆☆ — 辅助属性
- ★★☆☆☆ — 非必要但略有影响
- ★☆☆☆☆ — 几乎不依赖此属性

- [ ] 典籍出处栏填写了真实原文

- [ ] 风险来自性格内生（非外部事件）
- [ ] 灵根要求与门派属性匹配
- [ ] 每篇章填写了二级属性加成（总量符合品级规则）
