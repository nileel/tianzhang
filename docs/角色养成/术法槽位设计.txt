【术法槽位系统设计】

✅ 已审核（2026-06-19 Codex / gpt-5.5 复审通过；依据：9c45b22 + 0b67cce）

═══════════════════════════════════════════════════════════════

第一章：设计目的
═══════════════════════════════════════════════════════════════

现存术法无装备数量上限，导致 Build 选择无意义——玩家
可以携带全部可学术法进入战斗，消解了战术准备的策略深度。

术法槽位系统为修士设定术法与神通的携带上限，
强制玩家在有限槽位中做出取舍，构建差异化 Build。

v3.5 重构：槽位不再随境界线性增长到炼虚，改为受紫府府位开发
与金丹丹籍影响，将槽位成长融入筑基深度经营与丹籍竞争。

设计说明：
- 筑基 5/2 为紫府开启前的基准槽位。
- 紫府府位开发提供额外槽位，反映修士的深度经营成果。
- 金丹丹籍在结丹时提供最终槽位加成，不同丹籍的槽位差形成 Build 分化。
- 高阶境界（元婴/化神/炼虚）在当前版本为 NPC/世界背景，不再提供玩家槽位增长。
- 旧线性槽位表（练气 4/1→筑基 5/2→金丹 6/2→元婴 7/3→化神 8/3→炼虚 8/4）已废止。

二.1 紫府府位槽位加成
────────────────────────────────────

┌──────────┬──────────┬──────────┬──────────────────────────────┐
│ 主修府位 │ 术法槽   │ 神通槽   │ 说明                         │
├──────────┼──────────┼──────────┼──────────────────────────────┤
│ 命府     │ +1       │ —        │ 肉身型术法槽，防御/恢复向     │
│ 魂府     │ +1       │ —        │ 神魂型术法槽，攻击/控制向     │
│ 识府     │ —        │ +1       │ 神识扩张，神通槽+1            │
│ 气府     │ +1       │ —        │ 灵力循环增强，术法槽+1        │
│ 运府     │ —        │ +1       │ 因果感知，神通槽+1            │
└──────────┴──────────┴──────────┴──────────────────────────────┘

规则：
  - 紫府初开后，每主修一府获得对应加成。主修府位由功法和 Build 决定。
  - 术法槽加成上限 +3（即最多三个府位提供术法槽），神通槽加成上限 +2。
  - 同府多段开发可提升槽位质量（减少特定术法的冷却/消耗），但槽位数量仅加一次。
  - 紫府成长来自事件、试炼、地脉、灵眼等目标，非经验条。

  - 自辟丹籍的槽位加成与正籍相同（开辟者获得新丹系的完整位格）。

二.3 玩家可达槽位范围
────────────────────────────────────

┌────────────────────┬──────────┬──────────┐
│ 路线               │ 术法槽   │ 神通槽   │

每派约 14 个术法，8~10 槽可装备过半至大半，留下 4~6 个被舍弃的术法形成 Build 差异。
术法槽与神通槽的差异化成长取代旧线性解锁，将 Build 深度融入养成。


═══════════════════════════════════════════════════════════════
第三章：非战斗替换规则
═══════════════════════════════════════════════════════════════

一、安全区域（道观/洞府/城镇/营地）
  - 可随时自由替换术法和神通，无任何代价
  - 替换即时生效

二、野外/副本（非战斗状态）
  - 可自由替换，但需消耗时间（每次替换 = 1 刻游戏时间）
  - 替换期间有概率遭遇随机事件（敌人巡逻/天象变化）
  - 概率 = 5% × 替换次数（第 3 次起 15%，鼓励一次性配好）

三、战斗前准备阶段
  - 看到敌方阵容后、开战前，有一次免费调整槽位的机会
  - 调整次数不限，但仅限战斗触发前的准备窗口
  - 开战后槽位锁定


═══════════════════════════════════════════════════════════════
第四章：战斗中切换规则
═══════════════════════════════════════════════════════════════

一、基本原则
  - 战斗中不可自由切换术法，槽位在开战时锁定
  - 但提供"临阵换法"特殊行动作为紧急出口

二、临阵换法（战斗中特殊行动）
  消耗：1 次完整行动权（不可移动、不可同时攻击）
  效果：将一个已装备术法替换为术法库中另一个术法
  代价：
    - 新术法获得双倍冷却惩罚（CD × 2）
    - 被替换的术法本场战斗不可再装备
    - 每次战斗最多执行 2 次临阵换法
    - 神通不可临阵更换（神通为"根本大法"，战斗中不可变更）

三、解除锁定
  - 战斗结束后所有槽位自动解锁
  - 被"本场不可再装备"标记的术法在战后恢复可用


═══════════════════════════════════════════════════════════════
第五章：槽位与神通的关系
═══════════════════════════════════════════════════════════════

一、神通槽独立
  - 神通槽和术法槽完全独立，不共享数量
  - 神通不可放入术法槽，术法不可放入神通槽

二、本命神通规则（v3.5 重构）
  - 金丹期可从根本神通中将一道或多道升格为本命神通
  - 升格数量由丹籍位格决定：正籍最多 2 道，辅籍/敕籍/寄丹最多 1 道
  - 本命神通占据神通槽，不占术法槽
  - 本命神通不消耗灵力、无冷却
  - 本命神通绑定角色，不可替换

三、太一道庭法箓例外
  - 本命符箓和本命法坛都占据神通槽，不新增独立法箓槽
  - 本命符箓不占术法槽；来源术法仍保留在术法库中
  - 本命法坛按神通处理，展开后的召唤、阵地或法司效果由具体神通/功法声明


═══════════════════════════════════════════════════════════════
第六章：Unity 实现接口
═══════════════════════════════════════════════════════════════

一、数据层
  - CharacterData 已有 equippedSpells / equippedSkills 数组
  - 新增字段：
    * maxSpellSlots: int（由境界+府位+丹籍决定，战斗中不变）
    * maxSkillSlots: int
    * availableSpells: string[]（术法库，玩家已学会的全部术法）
    * developedMansions: string[]（已主修府位列表）
    * danJiType: string（丹籍类型：正籍/辅籍/敕籍/寄丹）

二、运行时
  - Character 类新增：
    * SpellSlots: List<SpellSlot>（含当前装备术法引用 + CD 状态）
    * SwapSpellInCombat(int slotIndex, string newSpellId): bool
    * GetAvailableSpells(): List<string>
    * RecalculateSlots()（根据当前府位+丹籍重算槽位数）

三、UI 层
  - 战斗 UI 术法按钮区域按 maxSpellSlots 动态生成
  - 空槽位显示为灰色"+"图标（仅在非战斗时可用）
  - 临阵换法按钮（战斗中，位于术法栏旁）→ 点击打开术法库弹窗
  - 灰化规则：MP 不足/冷却中/已消耗次数的术法按钮灰化

第七章：与现有体系兼容性
═══════════════════════════════════════════════════════════════

一、现有数据兼容
  - 太一修士当前装备 3 术法 + 2 神通，练气 4/1 槽位可容纳
  - 散修强盗当前装备 2 术法 + 0 神通，练气 4/1 槽位有余量
  - 血影魔修（筑基）装备 1 术法，筑基 5/2 槽位有余量
  → 现有数据全部兼容，无需修改

二、BattleSim 兼容
  - 模拟器 BuildDef 中 spells/skills 数组即为"已装备"
  - 当前 Build 术法数为 3-6 个，均在槽位范围内
  - 模拟器暂不实现槽位硬限制（不影响矩阵验证）
  - Unity 端实现槽位限制后，模拟器输出可保持现状

三、CSV 导入兼容
  - Enemies.csv 的 equippedSpells 列保持不变
  - Characters.csv 同
  - 若装备术法数 > 该阶段槽位数 → 导入时警告并截断


═══════════════════════════════════════════════════════════════
第八章：边界情况
═══════════════════════════════════════════════════════════════

一、槽位不足
  - 府位未开发时槽位停留在筑基基准值
  - 学会新术法但槽位已满 → 提示替换或放弃学习
  - 寄丹修士槽位较少，需更精细的 Build 规划

二、多门派术法
  - 术法库不区分门派来源，玩家可混搭装备
  - 但部分术法有门派前置要求（见术法设计规范），
    未满足则无法学习，与槽位无关

三、二周目/传承
  - 重生后术法库清空，槽位按当前境界+府位重新计算
  - 传承角色可保留部分术法（具体规则见传承系统，TBD）
