【术法槽位系统设计】

✅ 已审核（2026-06-21 Codex / gpt-5.5；金丹槽位迁移为源/化/界席位、占据状态与丹相接口；依据：f3ebf04）
已完成／已验证（2026-07-28 N-SLOT-01；锁定显式丹枢槽位绑定的输入、输出与上限，未实施 Unity 数据字段）

═══════════════════════════════════════════════════════════════

第一章：设计目的
═══════════════════════════════════════════════════════════════

现存术法无装备数量上限，导致 Build 选择无意义——玩家
可以携带全部可学术法进入战斗，消解了战术准备的策略深度。

术法槽位系统为修士设定术法与神通的携带上限，
强制玩家在有限槽位中做出取舍，构建差异化 Build。

当前重构口径：紫府本身不自动生成通用术法槽或神通槽；每座完整紫府固定承载的
镇府神通也不因紫府数量自动占用或生成普通神通槽。具体槽位预算必须由独立数值设计锁定。


═══════════════════════════════════════════════════════════════
第二章：槽位数量
═══════════════════════════════════════════════════════════════

槽位只限制战斗携带量。练气 4/1 仍是旧迁移输入；筑基基准固定为术法 `5`、普通神通
`2`。金丹不按境界倍率、紫府数量、府属、辅助引用或位格名称自动增槽；它只能通过
已验证的显式丹枢槽位效果绑定修正该基准。

`N-SLOT-01` 锁定的数值口径如下。其中 `a` 是显式术法槽位绑定数量，`d` 是显式普通
神通槽位绑定数量，`s` 是当前 `STABLE` 真实位格数量：

```text
术法槽 = 5 + a
普通神通槽 = 2 + d

a、d 为非负整数；a ≤ 3，d ≤ 2，a + d ≤ s，s ∈ {1, 2, 3}
```

没有合法绑定时 `a = d = 0`，金丹仍为 `5/2`。因此初结／温养／圆满只分别开放至多
`1/2/3` 个可分配单位，并不自动发放单位；最终硬上限为术法 `8`、普通神通 `4`。
同一实位只能贡献其中一类的一个 `+1`，不能同时给两类槽位或给出 `+2`。


────────────────────────────────────
二.1 紫府与镇府神通边界
────────────────────────────────────

规则：
  - 命、魂、识、悟、运是五座独立紫府，每类最多一座，不再使用“主修府位”槽位表。
  - 每座完整紫府恰有一项镇府神通；已建紫府总数可以是 1～5。
  - 紫府数量、府属或第四、第五府都不会自动生成额外术法槽、普通神通槽、位格或丹相。
  - 府体效果、镇府神通和辅助引用本身不输出普通槽位；它们只有在被某个稳定实位选为
    主承载并另有合法丹枢槽位效果绑定时，才可参与该实位的一次 `+1` 修正。
  - 第四、第五府继续保留府体、镇府神通、完整丹相输入与合法辅助连接；即使一至三实位
    已满，也没有数量性槽位补偿。


────────────────────────────────────
二.2 金丹席位与丹相槽位接口
────────────────────────────────────

金丹不使用通用层级槽位表。`DanshuSlotEffectBinding` 是唯一可产生普通槽位容量的计划接口；
它必须同时给出以下输入，任一缺失、错配或未声明即输出零并拒绝绑定：

1. `bindingId`、目标位格的矩阵 `danshuInterfaceId = DANSHU_SLOT_CAPACITY_V1` 和槽位效果
   `effectId`（`DANSHU_SLOT_ART_CAPACITY` 或 `DANSHU_SLOT_ORDINARY_DIVINE_CAPACITY`）。
2. 同一不可变 `JindanCoreBinding.danshuCoreId`、目标 `STABLE` 位格的 `positionId`／
   `positionType`、该位格的 `primaryCarrierAbilityInstanceId` 与已验证的
   `compatibilityProfileId`。
3. `slotKind ∈ {ART, ORDINARY_DIVINE}` 与固定 `delta = +1`。一个实位最多一条绑定；
   同一绑定不可同时增加两类槽位。

接口输出只是在战斗准备时把容量加到 `5/2` 基准上；不创建术法、普通神通、基础效果装配槽、
位格、丹相、丹枢或资源／冷却／充能账本。这里的“普通神通槽”不包含每座紫府固定的镇府
神通，也不改变镇府神通、丹相主／辅承载或金丹基础效果的独立行动与持续承载规则。

规则：

  - 源／化／界没有按名称固定的高低槽位；只有矩阵明确开放该接口、稳定占据和上述绑定
    同时成立时才得到一个 `+1`。
  - `TEMPORARY`、暂寄、未占据、失稳或缺少独立主承载的记录不是 `STABLE` 位格，槽位输出
    恒为零；自辟也不是通用加成标签。
  - 辅助连接只保留 `0.25` 组织审计预算，不可冒充目标实位的主承载，不复制绑定或把单次
    `+1` 扩散到其他实位。
  - 当前矩阵和 Unity 数据尚未写入 `DANSHU_SLOT_CAPACITY_V1` 的内容记录，所以现有运行时
    没有已生效的金丹加槽；后续实现必须新增显式字段并逐项填值，不能回填为按府数或阶段自动计算。


────────────────────────────────────
二.3 阶段预算与旧实现对照
────────────────────────────────────

┌──────────────────────┬────────────────────────────┬────────────────────────────┐
│ 阶段／稳定实位数     │ 术法槽                     │ 普通神通槽                 │
├──────────────────────┼────────────────────────────┼────────────────────────────┤
│ 练气                 │ 4                          │ 1                          │
│ 筑基基准             │ 5                          │ 2                          │
│ 初结／1 位           │ 5 + a，a + d ≤ 1           │ 2 + d                      │
│ 温养／2 位           │ 5 + a，a + d ≤ 2           │ 2 + d                      │
│ 圆满／3 位           │ 5 + a，a + d ≤ 3，a ≤ 3    │ 2 + d，d ≤ 2               │
└──────────────────────┴────────────────────────────┴────────────────────────────┘

每一行均允许无绑定而保持 `5/2`；表中只表示可分配上限，不是阶段自动发放。最终的 `8/4`
包络保留了旧实现 `5~8 / 2~4` 的迁移识别范围，但新的来源是逐项可审计的丹枢效果绑定，
不再是旧府位或线性境界公式。


═══════════════════════════════════════════════════════════════
第三章：非战斗替换规则
═══════════════════════════════════════════════════════════════

一、安全区域（道观/洞府/城镇/营地）
  - 可随时自由替换术法和神通，无任何代价
  - 替换即时生效

二、野外/副本（非战斗状态）
  - 可自由替换，但需消耗时间（每次替换 = 1 刻游戏时间）
  - 替换期间有概率遭遇随机事件（敌人巡逻/天象变化）
  - 概率 = 5% × 替换次数（第 3 次起 15%，鼓励一次性配好）

三、战斗前准备阶段
  - 看到敌方阵容后、开战前，有一次免费调整槽位的机会
  - 调整次数不限，但仅限战斗触发前的准备窗口
  - 开战后槽位锁定


═══════════════════════════════════════════════════════════════
第四章：战斗中切换规则
═══════════════════════════════════════════════════════════════

一、基本原则
  - 战斗中不可自由切换术法，槽位在开战时锁定
  - 但提供"临阵换法"特殊行动作为紧急出口

二、临阵换法（战斗中特殊行动）
  消耗：1 次完整行动权（不可移动、不可同时攻击）
  效果：将一个已装备术法替换为术法库中另一个术法
  代价：
    - 新术法获得双倍冷却惩罚（CD × 2）
    - 被替换的术法本场战斗不可再装备
    - 每次战斗最多执行 2 次临阵换法
    - 神通不可临阵更换（神通为"根本大法"，战斗中不可变更）

三、解除锁定
  - 战斗结束后所有槽位自动解锁
  - 被"本场不可再装备"标记的术法在战后恢复可用


═══════════════════════════════════════════════════════════════
第五章：槽位与神通的关系
═══════════════════════════════════════════════════════════════

一、神通槽独立
  - 神通槽和术法槽完全独立，不共享数量
  - 神通不可放入术法槽，术法不可放入神通槽

二、镇府神通与唯一丹相规则
  - 每座完整紫府恰有一项镇府神通，全部已建紫府共同进入一个丹枢核心和一个丹相。
  - 每个稳定位格仍需不同镇府神通担任主承载；其他镇府神通可作为完整辅助输入。
  - 已验证的丹相组织预算为：每座完整紫府 `1.00` 输入预算分、每个稳定实位 `1.00` 主承载表现预算分、每个实位全部辅助连接共用最多 `0.25` 预算分。三者不是伤害倍率或可叠加资源；辅助引用不复制实例账本。
  - 全部完整紫府都必须保留在唯一丹相输入中。第四、第五府继续提供完整输入和已声明辅助连接，但不增加术法槽、普通神通槽、稳定位格、丹相或普通效果槽。
  - `N-SLOT-01` 的全局容量只允许稳定实位的 `DanshuSlotEffectBinding` 在 `5/2` 基准上
    各给一个 `+1`；主承载或辅助表现本身不占据、也不自动提供普通神通槽。
    绑定的总数与类别仍受 `a ≤ 3`、`d ≤ 2`、`a + d ≤ 稳定实位数` 约束。
  - 主承载关系绑定角色与目标席位，战斗中不可更换；丹成后的安全重铸只能在结丹时已固化的镇府神通集合内进行，并保留同一丹枢、丹相、全部紫府输入和资源／冷却账本。

三、太一道庭法箓例外
  - 本命符箓和本命法坛是太一道庭丹相的门派表达；是否占据神通槽由具体实现声明，不新增独立法箓槽
  - 本命符箓不占术法槽；来源术法仍保留在术法库中
  - 本命法坛的召唤、阵地或法司效果由具体丹相、神通/功法声明，且不得越过目标席位边界

═══════════════════════════════════════════════════════════════
第八章：边界情况
═══════════════════════════════════════════════════════════════

一、槽位不足
  - 无合法显式绑定时，金丹始终按 `5/2`，不按紫府是否建成自动增减槽位
  - 学会新术法但槽位已满 → 提示替换或放弃学习
  - 暂寄、`TEMPORARY` 或失稳修士没有稳定实位槽位输出；具体可用能力由其不完整丹相与合法辅助接口声明

二、多门派术法
  - 术法库不区分门派来源，玩家可混搭装备
  - 但部分术法有门派前置要求（见术法设计规范），
    未满足则无法学习，与槽位无关

三、二周目/传承
  - 重生后的术法库与槽位重算规则待传承系统和新槽位预算共同锁定
  - 传承角色可保留部分术法（具体规则见传承系统，TBD）
