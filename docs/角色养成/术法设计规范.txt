# 术法设计规范


⚠️ 已修改/未审核（2026-06-21：术法金丹进路迁移为紫府神通与丹相）

## 文件位置
- 术法原文：`docs/角色养成/术法/[门派]/术法名.txt`
- 通用模版参考：`docs/角色养成/术法/术法设计.txt`
- 术法按门派分文件夹存放，不属于任何门派的通用术法放入散修文件夹

## 模板字段（设计新术法时全部必填）

- 名称 — 格式与功法命名规则一致，需有古典出处或人物典故为原型
- 类型 — 物理术法 | 神魂术法 | 混合术法
- 效能 — 攻击 | 防御 | 恢复 | 移动 | 控制 | 辅助
- 物理倍率 — 物理伤害倍率（无物理伤害填 ×0）
- 神魂倍率 — 神魂伤害倍率（无神魂伤害填 ×0）
- 灵力消耗 — 释放所需灵力值（单位：MP）
- 冷却惩罚 — 行动后CT门槛加成，数值越高则下次行动间隔越长
- 最小射程 — 0=近战（需相邻），1+=远程
- 最大射程 — 六角格距离上限
- 范围类型 — 单体 | 直线 | 扇形 | 圆形 | 十字 | 自身
- 范围参数 — N=直线长度/扇形半径/圆形半径/十字延伸格数
- 特殊效果 — 格式：效果名称，数值，持续回合。buff/debuff/位移/控制/恢复等
- 境界要求 — 学习该术法所需的最低境界（当前版本主线：练气/筑基/金丹；元婴/化神仅限 NPC）
- 灵根种类 — 所需灵根类型（"任意"=不限）
- 灵根品级 — 最低灵根品级要求
五行属性 — 术法自身的五行属性（金/木/水/火/土/风/雷/冰/暗/星/毒/混沌/无）。与灵根种类是独立维度。
    (决定施法匹配与受击匹配效果，详见灵根设定第八节)
- 前置/门派 — 前置术法 | 门派 | 职业 要求
- 熟练度上限 — 满熟练后解锁强化版本，标注强化后的具体变化
- 丹相转化 — 必填。写明该术法是否成为本命术法候选、如何锤炼为紫府神通、在金丹中形成丹相主枢或辅枢，以及金丹期成长性。不得要求每个术法都成为主枢。
- 目标源化界席位适配 — 必填。引用矩阵中的目标席位、占据状态适配和不可越界项；暂寄状态不得生成丹相主枢。
- 丹枢接口 — 必填。写明该术法可参与的媒介、偏向对象、代价分配、丹域景象、战斗表现和宗门叙事；不得改写矩阵的世界变量或边界。
- 丹器显化 — 可选。说明该术法若参与实体或非实体丹器显化时的表现，不得把丹器当作通用必备系统。
- 法箓归类 — 太一道庭术法必填。标注该术法可升格为"本命符箓"还是"本命法坛组件"，并注明所属法司（如王氏符诏、水府都箓、太清丹坛、桓氏兵马坛）。
- 说明 — 一段话解释术法的来源、使用场景和特色

## 核心设计原则

### 1. 倍率与冷却正相关
| 倍率档位 | 冷却惩罚 | 定位 |
|----------|----------|------|
| ×1.0 ~ ×1.2 | +0 ~ +10 | 基础攻击级 |
| ×1.5 ~ ×1.8 | +15 ~ +25 | 强力技能级 |
| ×2.0+ | +30 ~ +50 | 大招级 |

### 2. 神魂倍率低于同档物理倍率
- 神魂攻击可绕过格挡，且体修/剑修的神魂防御普遍较低
- 神魂倍率通常比同档物理倍率低 10%~20%

### 3. 混合术法单线倍率低于纯色术法
- 物理线 + 神魂线独立结算，总伤害不低
- 适合"法体双修"流派，纯物理或纯神魂路线不建议使用混合术法

### 4. 术法必须包含丹相转化

v3.5 注：术法从筑基中期起可成为本命术法候选，并在紫府阶段锤炼为紫府神通；金丹阶段由目标席位、占据状态、丹名、丹性和丹枢接口决定其是否形成丹相主枢或辅枢。

- 每个术法设计时必须同步给出其丹相转化去向，但可明确为“不参与丹相主枢”。
- 丹相转化不得改变术法的核心定位（攻击术法仍是攻击方向，辅助术法仍是辅助方向）。
- 成长性当前版本至少写明金丹期效果；元婴、化神增强仅在 NPC 或资料片预留内容中填写。
- 太一道庭专属例外：转化结果可写为本命符箓或本命法坛组件，作为太一道庭丹相表达，不另建平行本命系统。

### 5. 控制/恢复/移动术法不设伤害倍率
- 以效用换伤害，灵力消耗和冷却惩罚用于平衡战术价值
- 控制成功率公式使用游戏内属性差值计算（如神识对抗），不设固定概率

### 6. 灵根品级与境界对应
| 术法境界 | 灵根品级要求 |
|----------|-------------|
| 练气期 | ≥ 凡品 |
| 筑基期 | ≥ 下品 |
| 金丹期 | ≥ 中品 |
| 元婴期（NPC） | ≥ 中品（资料片预留） |
| 化神期（NPC） | ≥ 上品（资料片预留） |

v3.5 注：元婴/化神在当前版本仅限 NPC，玩家主线最高至金丹。

### 7. 熟练度系统
- 攻击术法看命中次数积累熟练度，辅助术法看使用次数
- 熟练度满后解锁"强化版本"：伤害+10% 或 消耗-10% 或 范围/效果增强
- 强化后的术法名称应有变化（如"崩山拳"→"崩山裂地拳"）

## 通用约束（与功法共用）

1. **命名不出典不立**：术法名必须有历史典故或人物原型支撑
2. **设计围绕原型人物**：术法应体现其归属人物的性格与处事方式
3. **文件按门派归档**：放入 `docs/角色养成/术法/[门派]/`，无门派的放入散修文件夹
4. **风险机制内生**：术法附带的风险/代价应来自人物的性格缺陷或处事风格，而非外部事件

## 新增术法前置检查清单

- [ ] 名称有历史典故或人物原型
- [ ] 倍率与冷却符合正相关规则
- [ ] 神魂倍率合理（低于同档物理10~20%）
- [ ] 控制/恢复类未设置伤害倍率
- [ ] 灵根品级与境界要求对应
- [ ] 五行属性已标注（与灵根种类独立判断）
- [ ] 五行属性匹配规则已确认（内圈施法、外圈受击）
- [ ] 熟练度上限标注了强化版本的具体变化
- [ ] 丹相转化完整（紫府神通、主枢/辅枢角色与金丹期效果明确）
- [ ] 目标源化界席位、占据状态适配和丹枢接口已标注，且未越过矩阵边界
- [ ] 太一道庭术法已填写法箓归类（本命符箓/本命法坛组件 + 法司）
- [ ] 特殊效果格式规范（名称，数值，持续回合）
- [ ] 说明解释了术法来源与使用场景
- [ ] 设计体现了原型人物的性格特征
- [ ] 文件放入正确门派文件夹
