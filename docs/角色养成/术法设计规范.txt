# 术法设计规范


✅ 已审核（2026-07-22 Codex；增加最小功能术法分支）

## 文件位置
- 术法原文：`docs/角色养成/术法/[门派]/术法名.txt`
- 通用模版参考：`docs/角色养成/术法/术法设计.txt`
- 术法按门派分文件夹存放，不属于任何门派的通用术法放入散修文件夹

## 模板字段（战斗术法全部必填）

- 名称 — 格式与功法命名规则一致，需有古典出处或人物典故为原型
- 类型 — 物理术法 | 神魂术法 | 混合术法
- 效能 — 攻击 | 防御 | 恢复 | 移动 | 控制 | 辅助
- 物理倍率 — 物理伤害倍率（无物理伤害填 ×0）
- 神魂倍率 — 神魂伤害倍率（无神魂伤害填 ×0）
- 灵力消耗 — 释放所需灵力值（单位：MP）
- 冷却惩罚 — 行动后CT门槛加成，数值越高则下次行动间隔越长
- 最小射程 — 0=近战（需相邻），1+=远程
- 最大射程 — 六角格距离上限
- 范围类型 — 单体 | 直线 | 扇形 | 圆形 | 十字 | 自身
- 范围参数 — N=直线长度/扇形半径/圆形半径/十字延伸格数
- 效果绑定 — 平铺填写若干条“触发、条件、目标、效果类型、参数”。造成伤害、状态、位移、控制、恢复等都引用统一原子效果类型；连续结果用有序多条绑定，不递归调用效果包
- 境界要求 — 学习该术法所需的最低境界（当前版本主线：练气/筑基/金丹；元婴/化神仅限 NPC）
- 灵根种类 — 所需灵根类型（"任意"=不限）
- 灵根品级 — 最低灵根品级要求
五行属性 — 术法自身的五行属性（金/木/水/火/土/风/雷/冰/暗/星/毒/混沌/无）。与灵根种类是独立维度。
    (决定施法匹配与受击匹配效果，详见灵根设定第八节)
- 前置/门派 — 前置术法 | 门派 | 职业 要求
- 熟练度上限 — 满熟练后解锁强化版本，标注强化后的具体变化
- 升格方案 — 必填。写明固定镇府神通本体、1～2 个兼容府属、术法熟练度、可记录行为、升格知识、材料／地点／环境条件和防刷要求。条件必须是系统可执行、可记录的真实行为
- 源术法处置 — 必填。保留 | 取代 | 内化，明确升格后原术法如何处理
- 神通形态 — 必填。主动 | 被动 | 触发；可以改变使用方式，但必须保留源术法核心主题
- 强化与府间节点 — 按需填写行为、修持、资源、府间或特殊节点；不要求统一等级、统一经验条或全部节点类型
- 目标源化界位格适配 — 必填。列出可兼容的一至三个稳定源/化/界位格、占据状态和不可越界项；暂寄状态不得生成丹相主枢
- 主承载／辅助接口 — 必填。写明该镇府神通可以主承载哪些位格，以及可为哪些位格提供明确辅助输入；主承载不独占来源紫府
- 丹枢接口 — 必填。只能填写媒介、偏向对象、代价分配、丹域景象、战斗表现和宗门叙事；不得改写矩阵世界变量或边界
- 丹器显化 — 可选。说明该术法若参与实体或非实体丹器显化时的表现，不得把丹器当作通用必备系统。
- 法箓归类 — 太一道庭术法必填。标注该术法可升格为"本命符箓"还是"本命法坛组件"，并注明所属法司（如王氏符诏、水府都箓、太清丹坛、桓氏兵马坛）。
- 说明 — 一段话解释术法的来源、使用场景和特色

## 功能术法分支

功能术法用于探索、门禁、传送和设施交互，不进入战斗伤害、射程与金丹承载链。只有内容核心确实是操作世界目标、且不能由现有战斗术法字段准确表达时，才使用本分支。

功能术法必须填写：

- 名称 — 仍须有典籍、制度或历史原型。
- 内容类型 — 固定为“功能术法”。
- 功能效能 — 探索 | 门禁 | 传送 | 设施交互，可多选。
- 目标类型 — 可操作对象及协议范围，不得用“任意目标”。
- 交互时长 — 引用目标交互时长档案，或明确瞬时／持续引导／分阶段；中断结果必须可判断。
- 消耗来源 — 施术者、目标设施、外部供能或多方共同支付；不得凭空补足目标缺失能源。
- 前置条件 — 知识、距离、目标状态、兼容协议、钥印或目标自身权限要求。
- 效果绑定 — 按顺序平铺写触发、条件、目标、功能效果和结果，不递归调用任意效果包。
- 失败原因 — 至少覆盖目标不兼容、目标损坏、供能不足、权限不足和交互中断中适用的项。
- 可用场景 — 明确 World、Settlement、Adventure 或特定设施场景。
- 禁止越权项 — 明确该术法不能取得的管理权、档案权、守卫指挥权、修复权或世界规则修改权。
- 成长边界 — 说明熟练只改善哪些操作表现；若不进入熟练、紫府、神通、金丹或丹相链，明确写“不适用”。
- 说明 — 来源、日常用途及与相邻道具／规则的边界。

功能术法不强行填写物理倍率、神魂倍率、战斗射程、范围类型、冷却惩罚、战斗熟练强化、镇府神通升格、位格适配、主承载、丹枢接口或丹器显化。若一项内容同时具有战斗效果和设施功能，应拆成战斗术法与功能交互两个明确接口，不能借功能分支绕过战斗规范。

## 核心设计原则

### 1. 倍率与冷却正相关
| 倍率档位 | 冷却惩罚 | 定位 |
|----------|----------|------|
| ×1.0 ~ ×1.2 | +0 ~ +10 | 基础攻击级 |
| ×1.5 ~ ×1.8 | +15 ~ +25 | 强力技能级 |
| ×2.0+ | +30 ~ +50 | 大招级 |

### 2. 神魂倍率低于同档物理倍率
- 神魂攻击可绕过格挡，且体修/剑修的神魂防御普遍较低
- 神魂倍率通常比同档物理倍率低 10%~20%

### 3. 混合术法单线倍率低于纯色术法
- 物理线 + 神魂线独立结算，总伤害不低
- 适合"法体双修"流派，纯物理或纯神魂路线不建议使用混合术法

### 4. 术法必须包含升格方案与丹相边界

结构完整的术法应配置一个固定镇府神通结果，并声明一至两个兼容府属。选择不同府属时只装载对应府属模块，不为同一术法复制完全不同的神通本体。

- 每个术法设计时必须给出升格条件、源术法处置、神通形态、兼容府属和主承载／辅助边界。
- 升格不得改变术法核心定位（攻击仍是攻击方向，辅助仍是辅助方向）。
- 丹成后只能从结丹前已固化的镇府神通中选择主承载；不能在金丹期补做术法升格或新增紫府。
- 太一道庭可把结果表现为本命符箓或本命法坛组件，但它仍是一项镇府神通，不另建平行本命系统。

### 5. 控制/恢复/移动术法不设伤害倍率
- 以效用换伤害，灵力消耗和冷却惩罚用于平衡战术价值
- 控制成功率公式使用游戏内属性差值计算（如神识对抗），不设固定概率

### 6. 灵根品级与术法学习门槛

- 不再按术法境界自动生成最低灵根品级，也不得用灵根品级推导角色的最高境界。
- 若术法确实需要最低灵根品级，必须由学习难度、属性驾驭或传承条件独立说明；没有独立理由时填“任意”。
- 凡品不能筑基；下品灵根可以通过筑基期扩府取得紫府并结丹，不能再以“无法凝结金丹”解释金丹术法门槛。
- 元婴/化神在当前版本仅限 NPC，玩家主线最高至金丹；该内容边界不自动产生灵根品级门槛。

### 7. 熟练度系统
- 攻击术法看命中次数积累熟练度，辅助术法看使用次数
- 熟练度满后解锁"强化版本"：伤害+10% 或 消耗-10% 或 范围/效果增强
- 强化后的术法名称应有变化（如"崩山拳"→"崩山裂地拳"）

## 通用约束（与功法共用）

1. **命名不出典不立**：术法名必须有历史典故或人物原型支撑
2. **设计围绕原型人物**：术法应体现其归属人物的性格与处事方式
3. **文件按门派归档**：放入 `docs/角色养成/术法/[门派]/`，无门派的放入散修文件夹
4. **风险机制内生**：术法附带的风险/代价应来自人物的性格缺陷或处事风格，而非外部事件

## 新增术法前置检查清单

先判断内容分支：

- [ ] 战斗术法按下列战斗检查执行；功能术法改按末尾功能检查执行，不混填两套字段

- [ ] 名称有历史典故或人物原型
- [ ] 倍率与冷却符合正相关规则
- [ ] 神魂倍率合理（低于同档物理10~20%）
- [ ] 控制/恢复类未设置伤害倍率
- [ ] 灵根品级门槛有独立内容理由，未按境界自动映射
- [ ] 五行属性已标注（与灵根种类独立判断）
- [ ] 五行属性匹配规则已确认（内圈施法、外圈受击）
- [ ] 熟练度上限标注了强化版本的具体变化
- [ ] 效果绑定平铺填写，未递归调用效果包
- [ ] 升格方案完整（固定神通本体、1～2 个兼容府属、可记录条件、知识与防刷要求）
- [ ] 源术法处置、主动／被动／触发形态和可选强化节点明确
- [ ] 目标源化界位格、占据状态、主承载／辅助接口和丹枢边界已标注
- [ ] 太一道庭术法已填写法箓归类（本命符箓/本命法坛组件 + 法司）
- [ ] 所有效果引用统一原子效果类型，参数与顺序明确
- [ ] 说明解释了术法来源与使用场景
- [ ] 设计体现了原型人物的性格特征
- [ ] 文件放入正确门派文件夹

功能术法检查：

- [ ] 目标类型、交互时长、消耗来源和前置条件明确
- [ ] 失败原因覆盖不兼容、损坏、供能、权限和中断中的适用项
- [ ] 可用场景与顺序效果绑定明确
- [ ] 禁止越权项明确，未借操作能力取得管理、修复或规则修改权限
- [ ] 未伪造战斗倍率、镇府神通、位格适配或丹相字段
