【太一道庭法箓规则】


═══════════════════════════════════════════════════════════════
一、定位
═══════════════════════════════════════════════════════════════

法箓是太一道庭专属的修行根基，兼具道籍、官印、兵符、戒约四重含义。
通用境界仍按练气、筑基、金丹、元婴、化神、炼虚推进，但太一道庭修士
不再使用通用“道基类型”和“金丹类型”作为核心机制，而以法箓替代。

法箓不是一张符，而是一套由道庭承认的法权。修士持箓后，才有资格调用
对应法司、符诏、兵马坛、水府坛、丹坛、礼坛等力量。

═══════════════════════════════════════════════════════════════
二、境界对应
═══════════════════════════════════════════════════════════════

┌──────────┬────────────┬────────────────────────────────────┐
│ 境界     │ 法箓阶段   │ 说明                               │
├──────────┼────────────┼────────────────────────────────────┤
│ 练气     │ 登籍       │ 入道庭道籍，修习经法和基础符箓     │
│ 筑基     │ 初授       │ 获得第一道正式法箓，替代通用道基   │
│ 金丹     │ 升箓       │ 选择本命符箓或本命法坛             │
│ 元婴     │ 加授       │ 可役使高阶兵马、坛官或法司权限     │
│ 化神     │ 血盟       │ 高品法箓需与道庭缔结血盟之约       │
│ 炼虚     │ 都箓       │ 法箓外化为法域，形成天曹辖境       │
└──────────┴────────────┴────────────────────────────────────┘

练气阶段只有道籍，不算正式法箓；筑基初授后才视为“入箓修士”。
血盟之后，修士与太一道庭形成因果绑定。背叛、叛逃或强行解除血盟时，
会触发法箓反噬、法司追索和宗门敌对。

═══════════════════════════════════════════════════════════════
三、授箓规则
═══════════════════════════════════════════════════════════════

低品法箓可由高品法箓持有者主持仪式授予。主持者必须高出受箓者至少
一个法箓阶段，并持有同系或上级法司权限。

高品法箓只能通过血盟获得。血盟不是普通入门誓言，而是道庭中枢认可的
法权契约：修士获得高阶法箓、官署资源和本命法坛权限，同时不得再自由
转投敌对宗门。

法箓分为两类：
- 公箓：道庭直属，所有太一道庭修士理论上可通过功绩获得。
- 家箓：四大道脉掌握，通常需要血脉、门阀背书或重大功勋。

═══════════════════════════════════════════════════════════════
四、本命符箓与本命法坛
═══════════════════════════════════════════════════════════════

太一道庭修士金丹升箓后，必须在两种本命核心中选择一类：

1. 本命符箓
   - 来源：已习得的太一道庭术法升格。
   - 定位：个人斗法核心，保留术法方向但符箓化。
   - 规则：不消耗灵力或大幅降低消耗，冷却降低，随法箓阶段成长。

2. 本命法坛
   - 来源：功法、法司或术法组合升格。
   - 定位：召唤、阵地、恢复、军阵、领域预备。
   - 规则：通常占据神通槽，展开后持续改变战场规则。

普通术法、神通和法宝仍可学习与使用，但不作为太一道庭金丹的本命核心。
外派或散修术法若要成为本命，必须先被重铸为道庭认可的符箓或法坛组件。

═══════════════════════════════════════════════════════════════
五、四大道脉法箓
═══════════════════════════════════════════════════════════════

王氏：符诏、云篆、镇岳、五雷。主符阵、控制、神识牵引。
谢氏：水府、九江舰队、棋局观势。主范围法术、调度、队伍协同。
庾氏：丹箓、斋醮、礼法护命。主恢复、净化、防御、戒律。
桓氏：兵马坛、征伐、将吏。主召唤、冲阵、军阵压迫。

四脉家箓不是普通功法分支，而是门阀掌握的法司权限。寒门修士可以修习
通用功法并获得公箓，但若想取得四脉核心家箓，必须获得对应道脉背书。

═══════════════════════════════════════════════════════════════
六、与通用境界兼容
═══════════════════════════════════════════════════════════════

太一道庭仍需按通用境界突破，并仍会经历凝结金丹、碎丹成婴、化神、炼虚
等修行过程。差异在于：
- 筑基特性由法箓替代通用道基。
- 金丹类型被法箓品秩与本命符箓/法坛替代。
- 金丹品级仍暂时保留为灵力上限与元婴门槛口径，后续数值系统若重构再统一调整。
