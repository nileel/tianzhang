【太一道庭法箓规则】


═══════════════════════════════════════════════════════════════
一、定位
═══════════════════════════════════════════════════════════════

法箓是太一道庭专属的道基形态，兼具修行根基、道籍、官印、兵符、戒约
五重含义。太一道庭修士仍使用统一的道基、紫府、金丹位格、丹枢核心和
丹相结构；“初授法箓”是其筑基方案形成的道基身份与宗门表现，不替代
道基，也不建立平行生命周期。

法箓不是一张符，而是一套由道庭承认的法权。修士持箓后，才有资格调用
对应法司、符诏、兵马坛、水府坛、丹坛、礼坛等力量。

═══════════════════════════════════════════════════════════════
二、境界对应
═══════════════════════════════════════════════════════════════

┌──────────┬────────────┬────────────────────────────────────┐
│ 境界     │ 法箓阶段   │ 说明                               │
├──────────┼────────────┼────────────────────────────────────┤
│ 练气     │ 登籍       │ 入道庭道籍，修习经法和基础符箓     │
│ 筑基     │ 初授       │ 形成法箓道基，进入统一四阶段       │
│ 金丹     │ 升箓       │ 法箓道基与全部已建紫府进入唯一丹相 │
│ 元婴     │ 加授       │ 可役使高阶兵马、坛官或法司权限     │
│ 化神     │ 血盟       │ 高品法箓需与道庭缔结血盟之约       │
└──────────┴────────────┴────────────────────────────────────┘

练气阶段只有道籍，不算正式法箓；筑基初授后才视为“入箓修士”。
血盟之后，修士与太一道庭形成因果绑定。背叛、叛逃或强行解除血盟时，
会触发法箓反噬、法司追索和宗门敌对。

═══════════════════════════════════════════════════════════════
三、授箓规则
═══════════════════════════════════════════════════════════════

低品法箓可由高品法箓持有者主持仪式授予。主持者必须高出受箓者至少
一个法箓阶段，并持有同系或上级法司权限。

高品法箓只能通过血盟获得。血盟不是普通入门誓言，而是道庭中枢认可的
法权契约：修士获得高阶法箓、官署资源和本命法坛权限，同时不得再自由
转投敌对宗门。

法箓分为两类：
- 公箓：道庭直属，所有太一道庭修士理论上可通过功绩获得。
- 家箓：四大道脉掌握，通常需要血脉、门阀背书或重大功勋。

═══════════════════════════════════════════════════════════════
四、本命符箓与本命法坛表现
═══════════════════════════════════════════════════════════════

本命符箓与本命法坛不是第二套金丹核心。它们是太一道庭术法升格为镇府
神通以及进入丹相后的门派表现形式，仍受一府一神通、位格权限、独立主承载
和唯一 `JindanCoreBinding` 约束。

1. 本命符箓
   - 来源：已习得的太一道庭术法按升格方案成为镇府神通。
   - 定位：保留源术法方向的符箓化表现，可主动、被动或触发。
   - 规则：效果、资源与冷却按统一效果绑定和唯一神通实例结算，不预设免费或全局减冷却。

2. 本命法坛
   - 来源：兼容术法按升格方案内化或显化为法坛组件型镇府神通。
   - 定位：召唤、阵地、恢复、军阵或领域预备的门派表现。
   - 规则：不得自动增加神通槽；展开效果必须服从目标位格和丹枢接口边界。

普通术法、神通和法宝仍可学习与使用。外派或散修术法若要成为太一道庭
镇府神通，必须拥有法箓道基兼容的升格方案；这只改变内容表现，不新增核心。

═══════════════════════════════════════════════════════════════
五、四大道脉法箓
═══════════════════════════════════════════════════════════════

王氏：符诏、云篆、镇岳、五雷。主符阵、控制、神识牵引。
谢氏：水府、九江舰队、棋局观势。主范围法术、调度、队伍协同。
庾氏：丹箓、斋醮、礼法护命。主恢复、净化、防御、戒律。
桓氏：兵马坛、征伐、将吏。主召唤、冲阵、军阵压迫。

四脉家箓不是普通功法分支，而是门阀掌握的法司权限。寒门修士可以修习
通用功法并获得公箓，但若想取得四脉核心家箓，必须获得对应道脉背书。

═══════════════════════════════════════════════════════════════
六、与通用境界兼容
═══════════════════════════════════════════════════════════════

太一道庭仍按通用境界突破。差异只在内容身份与宗门法权表达：
- 初授法箓是道基的一种，使用所有道基共有的四个连续阶段。
- 法箓道基的相容灵根决定天然紫府容量；扩府、筑府和丹成锁定没有门派例外。
- 本命符箓或本命法坛只能作为镇府神通、主承载或丹相的合法表现，不能替代唯一丹枢核心。
- 太一道庭金丹仍按十七道路、真实位格、效果装配、独立主承载和唯一丹相表达，不保留金丹类型或金丹品级。
