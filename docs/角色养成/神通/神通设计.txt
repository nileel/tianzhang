【神通设计】

神通是不消耗灵力、无冷却惩罚（冷却=0）的特殊技能。
神通数量极少，来源固定，代表着修士的核心能力与独特身份。
神通分为三类：本命神通、血脉神通、领域神通。

二、神通类型说明
═══════════════════════════════════════════════════════════════

1. 本命神通
   - 来源：金丹期铭刻在金丹上的术法
   - 数量：1~2个（取决于金丹品级：一品金丹可铭刻2个，三品以上1个）
   - 特点：不消耗灵力，无冷却，效果随角色整体成长
   - 选择：从已学会的术法中选择一个"升格"为本命神通，效果增强
   - 变更：碎丹成婴时可重新选择

2. 血脉神通
   - 来源：出生自带（隐藏灵根激活时可能附带）或特殊血脉觉醒
   - 数量：固定1个
   - 特点：与角色绑定，不可更换，往往有独特机制
   - 获取：角色创建时随机或根据血脉背景决定
   - 特殊：部分血脉神通在特定条件（濒死、暴怒、月圆等）下效果翻倍

3. 领域神通
   - 来源：炼虚期展开领域
   - 数量：1个
   - 特点：消耗灵力维持领域，领域内大幅增强自身属性
   - 类型：由功法和道基决定领域类型

三、神通设计原则
═══════════════════════════════════════════════════════════════

1. 本命神通 = 核心术法的"终极版"
   - 从已有术法升格，效果增强但方向一致
   - 给玩家选择的自由度：你想把哪个技能变成你的招牌？

2. 血脉神通 = 角色身份的"灵魂标签"
   - 创建角色时选择，不可更改
   - 应该有"变身""召唤""被动守护"等机制层面的独特性
   - 强度随着境界自然增长，不需要额外投入

3. 领域神通 = 炼虚的"终极武器"
   - 高消耗（每回合5%灵力），高回报
   - 改变整个战场的规则
   - 两个炼虚领域碰撞时，境界系数高者压制低者

4. 神通数量严格控制
   ┌──────────┬──────────────┐
   │ 类型     │ 最大数量     │
   ├──────────┼──────────────┤
   │ 本命神通 │ 1~2（金丹）  │
   │ 血脉神通 │ 1（创建时）  │
   │ 领域神通 │ 1（炼虚）    │
   │ 合计     │ 3~4          │
