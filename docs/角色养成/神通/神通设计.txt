【神通设计】

⚠️ 已修改/未审核；修改方：DeepSeek V4 Pro；变更范围：TQ-011 口径适配——删除一品金丹铭刻引用、新增根本神通来源、领域降为NPC/资料片预留


神通是不消耗灵力、无冷却惩罚（冷却=0）的特殊技能。
神通数量极少，来源固定，代表着修士的核心能力与独特身份。
神通分为四类：根本神通、本命神通、血脉神通、领域神通。

v3.5 注：新增"根本神通"类型，作为筑基期本命术法候选锤炼后的紫府府位核心神通，
      是成丹的资粮。领域神通在当前版本降为NPC/资料片预留。

二、神通类型说明
═══════════════════════════════════════════════════════════════

1. 根本神通（v3.5 新增）
   - 来源：筑基期将本命术法候选锤炼后植入紫府府位
   - 数量：2~5道（取决于府位开发程度与 Build 选择）
   - 特点：绑定紫府府位，是成丹的资粮，驱动金丹丹籍资格
   - 升格：金丹期可升格为本命神通（数量受丹籍限制）
   - 变更：府位绑定不可更改，但可废弃后换新术法重新锤炼

2. 本命神通
   - 来源：金丹期从根本神通中选择升格
   - 数量：1~2个（取决于丹籍位格：正籍2个，辅籍/敕籍/寄丹1个）
   - 特点：不消耗灵力，无冷却，效果随角色整体成长
   - 变更：碎丹成婴时可重新选择（资料片预留）

   v3.5 注：旧版"一品金丹可铭刻2个，三品以上1个"的规则已废止。

3. 血脉神通
   - 来源：出生自带（隐藏灵根激活时可能附带）或特殊血脉觉醒
   - 数量：固定1个
   - 特点：与角色绑定，不可更换，往往有独特机制
   - 获取：角色创建时随机或根据血脉背景决定
   - 特殊：部分血脉神通在特定条件（濒死、暴怒、月圆等）下效果翻倍

4. 领域神通（v3.5 降为NPC/资料片预留）
   - 来源：炼虚期展开领域
   - 数量：1个
   - 特点：消耗灵力维持领域，领域内大幅增强自身属性
   - 类型：由功法和道基决定领域类型
   - 当前用途：终极 NPC 威慑与世界背景设定

三、神通设计原则
═══════════════════════════════════════════════════════════════

1. 根本神通 = 成丹的资粮
   - 从本命术法候选锤炼而来，绑定紫府府位
   - 府位成长程度决定根本神通强度
   - 根本神通的数量与府位覆盖决定成丹判定与丹籍竞争资格

2. 本命神通 = 根本神通的"终极版"
   - 从根本神通升格，效果增强但方向一致
   - 给玩家选择的自由度：你想把哪个根本神通变成你的招牌？
   - 升格数量由丹籍位格决定

3. 血脉神通 = 角色身份的"灵魂标签"
   - 创建角色时选择，不可更改
   - 应该有"变身""召唤""被动守护"等机制层面的独特性
   - 强度随着境界自然增长，不需要额外投入

4. 领域神通 = 炼虚的"终极武器"（资料片预留）
   - 高消耗（每回合5%灵力），高回报
   - 改变整个战场的规则
   - 两个炼虚领域碰撞时，境界系数高者压制低者

5. 神通数量严格控制
   ┌──────────┬──────────────────┐
   │ 类型     │ 最大数量         │
   ├──────────┼──────────────────┤
   │ 根本神通 │ 2~5（筑基）      │
   │ 本命神通 │ 1~2（金丹，丹籍）│
   │ 血脉神通 │ 1（创建时）      │
   │ 领域神通 │ 1（炼虚，NPC）   │
   └──────────┴──────────────────┘
