# 神通设计规范


✅ 已审核（2026-06-19 Codex / gpt-5.5 复审通过；依据：9c45b22 + 0b67cce）

## 文件位置
- 神通原文：`docs/角色养成/神通/[门派]/神通名.txt`
- 通用模版参考：`docs/角色养成/神通/神通设计.txt`
- 神通按门派分文件夹存放，一个门派的所有神通可放在一个文件或拆分多个文件

## 模板字段（设计新神通时全部必填）

- 名称 — 格式与功法命名规则一致，需有古典出处或人物典故为原型
- 来源 — 本命 | 根本神通 | 血脉 | 领域。太一道庭专属可写：本命符箓 | 本命法坛。

  v3.5 注：新增"根本神通"来源，表示该神通是筑基期本命术法候选锤炼后植入紫府府位的核心神通，可进一步升格为本命神通。领域在当前版本为NPC/资料片预留。

- 类型 — 被动（永久生效） | 主动（战斗中释放）
- 伤害类型 — 物理 | 神魂 | 混合 | —（非攻击类神通填"—"）
五行属性 — 神通自身的五行属性。本命神通继承来源术法的五行属性；
           血脉神通由血脉来源决定；领域神通继承功法属性。
           被动神通若无属性关联则标注「—」。
           （详见灵根设定第八节：五行属性匹配规则）
- 物理倍率 — 主动攻击类填写，非攻击类可省略
- 神魂倍率 — 主动攻击类填写，非攻击类可省略
- 冷却惩罚 — 本命和血脉通常为 0，领域可能设 +50
- 射程/范围 — 主动类填写，格式同术法
- 核心效果 — 神通的核心机制描述，被动写永久效果，主动写释放效果
- 数值 — 具体数值或公式
- 获取条件 — 如何获得该神通（本命：金丹升格；根本神通：紫府锤炼；血脉：创建时选择；领域：炼虚+条件，当前版本 NPC 专属）
- 成长性 — 随境界提升的增强方式（写明每个增强节点的境界和效果变化）
- 说明 — 一段话解释神通的来源、在游戏世界中的意义

## 四种神通类型

### 本命神通
- 来源：金丹期从根本神通中选择一道或多道升格
- 数量：由丹籍位格决定——正籍最多2道，辅籍/敕籍/寄丹最多1道

  v3.5 注：旧版"一品金丹可铭刻2个，三品以上1个"的规则已废止。金丹九品制已取消，本命神通数量现由丹籍位格决定。

- 核心特征：不消耗灵力、冷却5回合、效果随境界成长
- 设计规则：必须是根本神通的"终极版"，效果增强但方向一致
- 变更：碎丹成婴时可重新选择（资料片预留）

太一道庭专属例外：
- 金丹期不是普通"铭刻本命神通"，而是"升箓"。
- 升箓后只能选择本命符箓或本命法坛作为本命核心。
- 本命符箓由术法符箓化升格；本命法坛由功法、法司或术法组合升格。
- 血脉神通仍保留，用于表示王、谢、庾、桓四大道脉的血脉特性和家箓亲和。

### 根本神通（v3.5 新增）
- 来源：筑基期将本命术法候选锤炼后植入紫府府位
- 数量：2~5道，取决于府位开发程度与 Build 选择
- 核心特征：是成丹的资粮，驱动金丹丹籍资格与丹名方向
- 设计规则：与紫府府位绑定，府位成长程度决定根本神通强度
- 升格：金丹期可将根本神通升格为本命神通（数量受丹籍限制）

### 血脉神通
- 来源：角色创建时选择血脉背景 或 特定条件觉醒
- 数量：固定1个，不可更换
- 核心特征：与角色绑定，有独特机制（变身/召唤/被动守护等）
- 设计规则：应体现门派/家族的历史特征，强度随境界自然增长
- 特殊：可在特定条件下效果翻倍（濒死/暴怒/特定环境等）

### 领域神通（v3.5 降为 NPC/资料片预留）
- 来源：炼虚期展开领域（当前版本为 NPC 专属）
- 数量：1个
- 核心特征：每回合消耗最大灵力值的5%，改变整个战场的规则
- 设计规则：由功法和道基类型决定领域类型，领域内大幅增强自身属性
- 冲突规则：两个炼虚领域碰撞时，境界系数高者压制低者
- 当前用途：终极 NPC 威慑与世界背景设定

## 核心设计原则

### 1. 神通总量严格控制
| 类型 | 最大数量 | 获取时机 |
|------|----------|----------|
| 根本神通 | 2~5 | 筑基期（紫府锤炼） |
| 本命神通 | 1~2 | 金丹期（丹籍决定数量） |
| 血脉神通 | 1 | 角色创建 |
| 领域神通 | 1 | 炼虚期（NPC/资料片预留） |

### 2. 本命神通 = 根本神通的终极进化
- 从根本神通升格，保留核心定位但效果全面增强
- 每个根本神通理论上都可以有一个"本命版本"
- 给玩家选择自由度——选择哪个根本神通升格决定了整个build的核心方向

### 3. 血脉神通 = 灵魂标签
- 必须在机制层面有独特性，不能是简单的数值加成
- 优先设计"变身""召唤""特殊状态""被动守护"等机制类效果
- 血脉神通不消耗任何资源（灵力/行动权），是"天生"的能力

### 4. 领域神通 = 终极武器（资料片预留）
- 高消耗（每回合5%灵力），高回报
- 必须改变战场规则，不能只是属性加成
- 领域类型与功法/道基严格绑定

## 通用约束（与功法、术法共用）

1. **命名不出典不立**：神通名必须有历史典故、典籍出处或人物原型支撑
2. **设计围绕原型人物**：血脉神通应体现归属门派/家族的历史特征
3. **文件按门派归档**：放入 `docs/角色养成/神通/[门派]/`
4. **成长性必须明确**：每个增强节点的境界和具体效果变化都要写明

## 新增神通前置检查清单

- [ ] 来源类型明确（本命/根本神通/血脉/领域）
- [ ] 数量在控制范围内（不超出该类型上限）
- [ ] 本命神通：有对应的根本神通作为升格基础
- [ ] 根本神通：与紫府府位绑定，注明绑定府位
- [ ] 太一道庭本命类写为本命符箓或本命法坛，并注明升箓条件
- [ ] 血脉神通：有独特机制（非纯数值加成）
- [ ] 领域神通：消耗灵力（每回合5%）、改变战场规则（NPC/资料片预留）
- [ ] 成长性逐级写明（每个境界节点的效果变化）
- [ ] 名称有典故出处
- [ ] 设计体现了归属门派/人物的特征
- [ ] 五行属性已标注（本命继承术法/血脉来源/领域继承功法）
- [ ] 获取条件具体可执行（根本神通=紫府锤炼；本命=金丹升格；血脉=创建选择/觉醒条件；领域=炼虚+道基，NPC专属）
- [ ] 丹籍适配已标注（本命神通在不同丹籍下的数量与强度差异）
- [ ] 文件放入正确门派文件夹
- [ ] 附带了说明文字
