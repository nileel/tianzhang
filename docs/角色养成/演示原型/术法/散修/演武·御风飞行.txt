# 演武·御风飞行

2026-10-24；定义 ID `demo_20261024_yufeng_flight`；版本1.0。独立的演示专用移动能力原型，使用普通术法的施放／维护接口，固定筑基能力档；不是《御风凌虚》的强化或改名，不读取《扶摇》的目标上空停留，不引用旧《万象玄门》。以下配置尚未导入／运行验证，不构成平衡结论。

## 身份、来源与预算

原型与出处：取《庄子·逍遥游》列子御风而行的意象，只定义有限飞行资格，不修改空间尺度或凭境界自动飞行。
类型／效能：神魂术法接口；移动。伤害类型无，物理／神魂倍率0。五行风，`elementTag=wind`、`relationElement=wood`，不额外获取木道路能力。
内容取得：仅指定的演武单格人形角色已在筑基期取得此移动术知识并独立装备；灵根种类任意、品级任意，不以位格元素或达到金丹自动授予。非所属角色、双格石甲兽不授予此能力。正式成长、熟练度、升格、紫府主承载、辅助与丹枢接口均不适用：这是D1明确独立的演示原型，不另开第四个镇府、源术升格或正式学习流程。后续若转为正式术法，必须另行完成该内容的成长设计，本轮不能据名称发放。
实例：各角色读取`demo_20261024_<actorSuffix>_flight`唯一abilityInstanceId；如土持有者为`demo_20261024_earth_flight`，与earth_guardian不同实例，共用角色同一AP／MP和调度器，不共享位格权限。不预授全部人物飞行；演武预设表明确列拥有者及来源灵根。
标准预算：AP-GROWTH@0.1筑基固定档，Q1／R1，固定形态／升力／期限参数，无攻防承载；TZ_EFFECT_BUDGET@0.1数值派生未迁移，不能把AP／MP费用换成无限高度或移动距离。角色升级不改费／档。无AP返还、v增益、额外回合、CT／CD减免或独立移力池。
射程／范围：自身，最小／最大射程0，范围参数0；只单格、bodyScaleRank=1人形。所有转换先查整柱占位、当前高度、顶棚、气流、禁飞、防空与空间封锁；不以模型Transform作规则。

## 动作、时钟与费用

| 动作 | AP／MP／CT／CD tick | 前提与结果 |
|---|---|---|
| 起飞 | 250／200／0／1 | GROUND且未被定身／封灵，原地转换FLY低空；不额外移动一格 |
| 升高一档 | 125／0／0／0 | 飞行仍有效且升力允许，低空→高空，原柱不变 |
| 降低一档 | 125／0／0／0 | 飞行仍有效，高空→低空，原柱不变 |
| 主动降落 | 50／0／0／0 | 低空且本柱普通GROUND落点合法，转换GROUND并停止飞行维护 |
| 续御脱离失效处理 | 250／200／0／1 | 仅在下述失效过程中，能力／控制／升力与本柱低空资格已恢复时，重新开始一个有限飞行实例；不横向换格 |

主动降落／升降是既有移动形态转换命令，属于有战斗收益的正费动作，不套零CD主动术法涨价；起飞／续御是共用同一施法CD的术法动作。转换不重置CD、角色AP、个人回合或其他实例；飞行中不能重复起飞刷新期限。所有主动费用净下限等于表中AP，无减耗来源。现有同源起飞CD不阻止已经取得飞行后的普通移动／升降／降落，后者没有第二份术法CD或资源池。
持续：最多3个施术者后续本人回合结束，按《战斗状态与时空因果结算规则》§六，施放当回合结束不减期限。每个后续本人回合开始、正常资源恢复后先检查飞行能力／合法性，再支付维护100MP；不足不欠费，立即进入失效处理。维护自动事件AP0／CT0，不重启CD、不发响应次数。期限在第三个后续本人回合结束时失效；合法降落立即终止，不能免费重新起飞。死亡释放占位，不建立尸体飞行；战终清除飞行／维护／失效过程。
取消、预览或提交前任一状态／资格／费用／落点失效，保持原形态、位置与资源，不能部分扣费。提交后未来维护失败不退已支付费用；敌我费用、期限与处理相同。

## 低空、高空、路径与攻击

GROUND的altitudeBand=0，低空=1，高空=2，有效高度=`heightLevel+altitudeBand`；米制悬浮仅表现，不参与规则。地表接触仅GROUND为真；浅水涉水仍接地，低／高空不接受仅接地的普通燃烧、水击或潮推，但仍接受明确具备空中目标与垂直触及资格的攻击、风场、禁飞和重力。
FLY沿相邻六角边移动，一柱仍只容纳一个单位，任何高度都不能停在已有单位占格上方。普通水平路径费沿现有`metricDistance`、飞行移动专用负担与本人v逐边结算；本能力不提高v。飞行额外移动负担默认0，即正常一倍基础边价，不读地面泥泞／浅水／深水／上坡的额外负担；声明对飞行生效的气流／重力另按原型，不把移动负担改成攻击距离，也不把K=2的加法单位当倍率。
开放断崖／攀爬／单向落差在低空允许相邻地格高差绝对值≤1，高空≤2；路径每一步仍查飞行许可、完整落柱与净空。实体封墙两档均不可穿；顶棚最高有效高度明确的格，超限即不可进入或升高；本文件不授越墙、桥下同柱、无落点虚空、穿过空间封锁或任意非相邻跨格。地图缺失明确空中边／顶棚数据时不能以视觉“看起来能飞”通过。
本能力不改攻击模板。施法／攻击继续读取各自sourceModeMask、targetModeMask及verticalReachRank，先查有效高度差与原作用路径，再查水平加权射程；没有明确空中来源／目标资格的动作不能因起飞自动获准。高地／空中忽略普通低位掩体只按既有掩体规则，不追加通用增伤。

## 重力、强制位移与失效落地

liftRank=2，普通loadRank=bodyScaleRank=1；有效load读取合法重力状态而非装备重量。load≤2可维持两档；load=3只允许低空，高空立即原柱压低且不扣目标AP；load≥4不能维持飞行，进入强制落地。失重只帮助已有本飞行维持，不向没有能力的单位授飞行。被压低后重力消失不自动免费升高，仍需升档命令；状态变化、每次移动／升降报价与维护前共用同一判断。
飞行仍可遭明确有FLY目标资格的强制位移；检查当前高度下完整路径、格边、锚定与落柱，目标不扣主动移动AP。普通潮汐没有该资格。空间封锁先于重力／锚定；镇岳不能单独禁瞬移。
飞行来源被封禁／合法移除、维护不足、期限结束、禁飞变化或直接压落时，先仅检查当前柱的普通GROUND落点；合法则原柱接地、altitudeBand=0、停止飞行，免费强制落地，不扣目标AP、不自动结束其个人回合。成功落地进入地表时正常触发一次该地表接触事件。两档成功受迫落地统一承受一次`ceil(HP_max×0.10)`坠落伤害，可致死；作为原型环境伤害不受防御／暴击／格挡，不造成额外击退，不再重复结算同次压落伤害。
GROUND落点资格读取当前地表原型。本演武的深水允许GROUND涉行／留驻，因此可以原柱落地并正常接地，深水的额外移动负担2单位只在后续自主路径移动计价，不因落地另扣AP，也不授SWIM。本演武浅水／泥岸额外1单位、深水额外2单位均按K=2的加法负担读取；通用水面是否允许GROUND由其自身原型决定，不能单凭“深水”名字推断非法。
若当前柱是不可站立地面、明确禁止GROUND的其他水面、实体占用或其他非法地面，不能传送到附近空格、挤开其他单位或把FLY资格无限保留。保留原完整占地与当前空间姿态，写入`processState=demo_20261024_flight_failed_landing`；这只是现有过程载体，FLY空间标签不代表仍有飞行许可。期间禁止普通自主移动和升降；允许不依赖有效飞行的原合法命令、手动结束、合法解除危险及上表有费续御。
失败过程建立当刻只记一次坠落伤害，取上述10%HP_max；之后每个后续本人回合结束再承受一次`ceil(HP_max×0.20)`，可致死，无独立CT。当前本人回合刚建立时不立刻追加20%；过程不因移除普通状态、换装、重复预览或重复收到压落事件重建／重置时钟。地表／占位改变、本人回合开始或合法救援完成后重查当前柱；合法则免费落地并结束失败过程，不再追加第二笔10%坠落伤害。若选择续御且所有低空资格、升力及费用满足，则退出失败过程并按新的3回合期限飞行；缺能力、封灵或重力仍不允许时不能续御。
地图不支持的横向救援或瞬移不会由本原型生成；若另有合法能力改变位置，依其费用／封锁／落点原规则完成后再检查，不借失效过程免费移动。死亡立即释放单格，占地不遗留；战斗终结彻底清理，不写回飞行存档。
