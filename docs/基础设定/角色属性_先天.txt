【角色属性（先天）】

先天属性共5项，为角色出生时即确定、后天极难改变的根本资质。
每个先天属性影响多项一级属性。战斗二级属性由功法、装备、丹药提供。

═══════════════════════════════════════
一、根骨 —— 肉身根基
═══════════════════════════════════════

仙骨天成，肉体凡胎亦可铸就不灭金身。
根骨决定修士的身体强度与肉身攻防能力，是体修、剑修、战修的根本。

影响一级属性：
- 生命值：骨骼为肉身之架，根骨强者气血旺盛
- 肉身攻击：骨劲通力，根基深厚则拳重千钧
- 肉身防御：骨密如铁，身如磐石

- 生命恢复：骨髓造血，根骨深厚则自愈极快
- 格挡率：下盘稳固，招架从容
- 物理抗性：筋骨皮膜浑然一体，物理伤害天然减免

═══════════════════════════════════════
二、魂魄 —— 神魂本源
═══════════════════════════════════════

魂为灵之舍，魄乃神之根。魂魄强则道法兴。
魂魄决定修士的神魂攻击力与灵力容量，是法修、丹修的根本。

影响一级属性：
- 神魂攻击：魂魄如刃，可斩人元神
- 灵力值：魂魄是灵力容器，魂强则灵海广阔

- 灵力恢复：魂魄吞吐天地灵气，效率决于魂质
- 神魂抗性：魂魄稳固则外邪不侵
- 暴击伤害：魂力凝聚一击，穿透弱点时伤害倍增

═══════════════════════════════════════
三、神识 —— 精神感知
═══════════════════════════════════════

神游太虚，一念知千里；识破天机，弹指断因果。
神识决定修士的精神防御力、行动速度与感知能力，是符修、阵修、魂修的重要属性。

影响一级属性：
- 神魂防御：神识为盾，抵御神魂入侵
- 反应速度：神念如电，先发制人
- 神识强度：神识外放即为视野，即为侦察

- 暴击率：神识锐利可洞察破绽
- 命中率：神念锁定，术法不落空

═══════════════════════════════════════
四、资质 —— 修行天赋
═══════════════════════════════════════

天赋者，天授之器也。器大者容天地，器利者破玄关。
资质不提供战斗属性，但决定修炼速度与突破成功率，是纯成长型先天属性。

影响一级属性：
- 无直接战斗属性加成

影响非战斗属性：`r`n- 修炼速度：天赋决定灵气转化效率，资质越高修炼越快`r`n- 悟性：术法学习速度与境界突破成功率加成`r`n`r`n设计逻辑：`r`n资质不直接提供战斗属性（v3.2起战斗二级属性全部由功法/装备/丹药提供），`r`n但高资质意味着更快的修炼速度和更容易的突破，是纯成长型选择。

═══════════════════════════════════════
五、气运 —— 命运造化
═══════════════════════════════════════

天机一线，冥冥有定。气运加身者，逢凶化吉，遇难成祥。
气运影响角色的运气维度，对探索、交易、剧情有全方位加成。

影响一级属性：`r`n- （无直接一级属性，移力由境界固定值决定）

影响非战斗属性：`r`n- 幸运值：气运即幸运的本源，影响掉落与事件成功率`r`n- 魅力值：天道垂青之人，众生自然亲近

════════════════════════════════════════
六、先天属性成长机制（v3.4）
════════════════════════════════════════

先天属性的成长仅在大境界突破时发生（共6次突破）。
每次突破获得的先天属性点数由所修功法的品级决定，
按功法属性倾向（★权重）比例分配至5项先天属性。

一、每次突破获得点数

┌──────────┬────────────────┐
│ 功法品级 │ 先天点数/突破  │
├──────────┼────────────────┤
│ 凡品     │  8             │
│ 下品     │ 10             │
│ 中品     │ 12             │
│ 上品     │ 14             │
│ 极品     │ 16             │
└──────────┴────────────────┘

突破时机（共6次）：
  凡人→练气 → 练气→筑基 → 筑基→金丹 → 金丹→元婴 → 元婴→化神 → 化神→炼虚

二、分配方式

每次突破点数按功法属性倾向的★权重比例分配，各项取整：

  单项获得 = 每次总点数 × (该项★权重 / 全部权重之和)

尾数向权重最高的属性倾斜取整。

三、总计成长潜力

以常见品级为例：

┌──────────┬──────────┬────────────────────┐
│ 功法品级 │ 每次点数 │ 6次总计先天点数    │
├──────────┼──────────┼────────────────────┤
│ 凡品     │  8       │  48                │
│ 下品     │ 10       │  60                │
│ 中品     │ 12       │  72                │
│ 上品     │ 14       │  84                │
│ 极品     │ 16       │  96                │
└──────────┴──────────┴────────────────────┘

创建时初始先天属性（25自由分配 + 15基础 = 40点）
上品功法修炼至炼虚：40 + 84 = 124点（受各境界先天上限约束后实际约85~95）

四、先天属性对一级属性的影响（v3.4）

先天属性继续通过以下公式对一级属性产生底层加成：

  先天属性加成 = 先天属性 × 境界系数 × (功法权重 / 0.6)

此加成叠加在境界基础值和小境界累积成长之上：
  一级属性 = 境界基础 + Σ小境界成长 + 先天属性加成

（详细公式参数见「角色数值设计.txt」）

═══════════════════════════════════════
七、灵根体系说明
═══════════════════════════════════════

灵根不属于先天属性，而是独立的角色构建系统（详见灵根设定.txt）。
灵根决定角色的功法属性与术法倾向（类似"职业+元素"），其品级决定
基础修炼速度系数与境界上限，最终数值流入二级属性"修炼速度"形成闭环。

灵根与先天属性的交互：`r`n- 修炼速度基础值由灵根品级决定，再受资质加成`r`n- 多灵根修士的修炼速度惩罚与相生加成独立计算
