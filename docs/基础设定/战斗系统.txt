第一章：行动轴 —— CTB 充能制
═══════════════════════════════════════════════════════════
一、基本规则
战斗使用 CTB（Charge Time Battle）充能行动轴。
时间以"刻"（tick）为最小单位推进，所有单位在同一时间轴上竞争行动权。
每刻流程：
1. 所有在场单位行动条（CT） += 自身反应速度
2. 检查是否有单位 CT ≥ 100
3. 若有：CT ≥ 100 的单位进入"待行动"队列，按反应速度降序依次行动
4. 每个单位行动完毕后 CT 归零，继续累积
5. 若无单位达标：推进到下一刻
二、行动条公式
CT 充能值 = CT_当前 + 反应速度（每刻）
行动触发条件：CT ≥ 100
行动完毕后：CT = 0
三、术法冷却
每个术法/攻击有独立的"冷却惩罚"值（单位：刻的等效CT）。
冷却惩罚叠加在下次行动门槛上：
下次行动门槛 = 100 + 冷却惩罚
示例：
- 基础攻击（冷却0）：AT=100即动，最快节奏
- 大火球（冷却+30）：需要CT≥130才可行动
- 禁忌术法（冷却+80）：需要CT≥180，节奏极慢
反应速度50的单位：
- 基础攻击：每2刻行动一次
- 大火球：每2.6刻行动一次
- 禁忌术法：每3.6刻行动一次
四、待机规则
选择"待机"不执行任何行动时：
- 保留当前CT充能值的50%（而非归零）
- 无冷却惩罚
- 用途：等待队友、积蓄能量、观察敌方行动
五、行动回合内操作
每个行动回合内，按顺序执行：
  移动阶段 → 行动阶段
  或
  行动阶段 → 移动阶段（使用剩余移动力）
┌────────────┬──────────────┬────────────────────────┐
│ 操作       │ 消耗         │ 说明                   │
├────────────┼──────────────┼────────────────────────┤
│ 移动       │ 移动力（格） │ 每格消耗1移力          │
│ 攻击/术法  │ 1次行动权+MP │ 释放后进入冷却         │
│ 使用道具   │ 1次行动权    │ 丹药、符箓、法宝等     │
│ 切换装备   │ 1次行动权    │ 战斗中更换武器/法宝    │
│ 待机       │ 1次行动权    │ 保留50%CT，无冷却惩罚  │
│ 防御姿态   │ 1次行动权    │ 本回合防御×1.5，无冷却 │
└────────────┴──────────────┴────────────────────────┘

第二章：六角格棋盘与移动
═══════════════════════════════════════════════════════════
一、权威规则引用

六角拓扑、加权空间距离、环境供给、2.5D 高度、有向格边、地表、区域现象、掩体、实体障碍、体型和移动形态统一以《战场空间与环境规则》为准。

五行事件、显化载体、植物、火种、重力、磁阵和潮汐统一以《五行显化与环境交互规则》为准。

临时状态、状态回溯与时空因果特殊结算统一以《战斗状态与时空因果结算规则》为准。

本文件只维护 CTB、行动回合、朝向、攻击流程、伤害、技能框架与界面基础信息，不另建第二套地形、距离、视野或状态权威表。

二、六角格与移动摘要

- 每个 `HexCoord(q,r)` 固定连接六个拓扑邻格；每个六角柱最多一个单位最终停留。
- 每行动回合可按行动阶段前后拆分使用移动力。
- 路线先检查占位、高度、有向格边、实体障碍和移动形态，再按各边 `metricDistance` 与移动专用负担计算消耗。
- 移动、攻击、施法、强制位移、范围和视野统一调用加权距离服务；环境连通、共享格边和占位仍使用固定拓扑。
- 能否穿过友军、敌军或兼容占用格，由当前移动形态和占位规则决定；任何单位均不得停在已被占用的六角柱。

三、朝向系统
每个单位有明确朝向（六角格6个方向之一）。
朝向判定规则：
- 单位移动后，朝向默认指向移动方向
- 行动阶段结束后，可自由旋转朝向（消耗剩余移动力，每60°消耗0移力）
- 被控制（定身、眩晕）期间朝向锁定
朝向影响受击效果：
┌──────────┬──────────┬──────────┬──────────┐
│ 攻击方向 │ 命中加成 │ 伤害加成 │ 格挡     │
├──────────┼──────────┼──────────┼──────────┤
│ 正面     │ +0%      │ +0%      │ 正常判定 │
│ 侧面     │ +15%     │ +10%     │ 正常判定 │
│ 背面     │ +30%     │ +25%     │ 无法格挡/魂盾 │
└──────────┴──────────┴──────────┴──────────┘
六角格朝向分布（以单位面朝"北"为例）：
        (正面)
        ⬡ ⬡
      侧 ⬡ 侧
        ⬡ ⬡ ⬡
        背 背
- 正前方2格 = 正面
- 左右前侧各1格 = 侧面
- 后方3格 = 背面
四、环境、视野与作用路径摘要

- 基础地形、单一地表状态、主要场景交互物和区域现象分别按专责事实源结算，不使用森林闪避、废墟抗性等硬编码地形加成。
- 低位掩体只提供方向性命中惩罚；实体障碍才阻断移动、视线与普通直线作用路径。
- 视野先按加权距离检查上限，再检查高度、观察资格、能见度通道和实体障碍。具体隐匿与识破进入相应能力及规则冲突，不使用通用神识阈值表。
- 友方共享视野只共享已经合法取得的观察结果，不得穿过实体封闭或绕过同阶隐匿规则。

第三章：战斗结算流程
═══════════════════════════════════════════════════════════
一、攻击结算顺序
1. 选择目标 → 2. 射程检查 → 3. 视野检查 → 4. 命中判定
→ 5. 五行属性匹配 → 6. 暴击判定 → 7. 基础伤害计算 → 8. 格挡判定 → 9. 魂盾判定 → 10. 护盾/附加效果
二、命中判定
实际命中率 = 基础命中(100%) + 攻击方命中率 - 防守方闪避率
注意：
- 防守方闪避率包含朝向加成（背面+30%命中率即闪避率-30%）
- 实际命中率最低5%（保底命中），最高100%
- 闪避成功 → 完全不受伤，结算结束
三、暴击判定
命中后独立判定暴击：
- 暴击概率 = 攻击方暴击率 + 五行内圈暴击率修正（不受防守方闪避/格挡影响）
- 暴击成功 → 本次伤害使用"技能基础倍率 × 暴击伤害倍率"
- 暴击伤害倍率 = 基础暴击伤害(150%，即×1.5) + 装备/功法/五行内圈暴击伤害加成
- 运行时字段 `critDamage`/“暴击伤害”表示相对基础150%的附加百分比点，不是总倍率：`critDamage = 0` 时为×1.50，`critDamage = 15` 时为×1.65；五行内圈暴击伤害修正也按百分比点相加。
四、格挡判定
仅物理伤害可被格挡（神魂伤害不受格挡影响）：
- 格挡概率 = 防守方格挡率（来源：功法/装备/丹药）
- 背面攻击 → 格挡率强制为0
- 格挡成功 → 物理伤害 × (1 - 防守方格挡减伤率%)
五、魂盾判定
仅神魂伤害可被魂盾格挡（物理伤害不受魂盾影响）：
- 魂盾概率 = 防守方魂盾率（来源：功法/装备/丹药）
- 背面攻击 → 魂盾率强制为0
- 魂盾成功 → 神魂伤害 × (1 - 防守方魂盾减伤率%)
六、伤害计算
分别计算物理和神魂伤害（详见伤害公式.txt），两者独立结算后叠加：
物理伤害 = 肉攻 × 技能物理倍率 × 境界系数比 × 肉攻/(肉攻+肉防)
          × [1 - 物抗 × (防境系数÷攻境系数)^0.5]
神魂伤害 = 神攻 × 技能神魂倍率 × 境界系数比 × 神攻/(神攻+神防)
          × [1 - 魂抗 × (防境系数÷攻境系数)^0.5]
最终伤害 = 物理伤害 × (1 - 格挡减伤率) + 神魂伤害 × (1 - 魂盾减伤率)
（格挡/魂盾减伤率仅在各自判定成功时生效，未触发则为0%）
七、属性克制
五行属性匹配采用 v5.10 内外圈规则（详见灵根设定.txt 第八节），
不沿用旧版 ±20% 简表；以灵根设定.txt 第八节内外圈叠加规则为准。
五行匹配同时产出基础伤害倍率修正与内圈相克的暴击率/暴击伤害修正；
因此必须先完成五行匹配，再进行暴击判定。
八、伤害浮动
基础伤害有 ±5% 的随机浮动，模拟实战中的不确定性。

二、六角格范围定义
以下形状定义基础拓扑模板；实际选取必须经加权距离、高度、作用路径、观察资格和障碍检查。同一半径在空间尺度影响下可以覆盖更多或更少拓扑格。

单体：  指定一个目标格
直线：  从施法者沿一个方向延伸N格的一条直线
        （六角格直线：选择6个方向之一，依次命中路径上的所有格）
扇形：  以施法者为中心，面向方向的锥形区域
        半径1→3格，半径2→7格，半径3→12格
圆形：  以目标格为中心，半径R内的所有格（含中心）
        半径1→7格（中心+6邻格），半径2→19格
十字：  以目标格为中心，三个轴向各延伸R格的十字形
全屏：  整个战场所有格
三、技能分类
1. 物理攻击技（肉身伤害）
   - 拳法、掌法、腿法：近战，高暴击，体修专属
   - 剑术、刀术：近~中程，高暴击伤害，剑修专属
   - 法宝实体攻击：中~远程，器修专属
2. 神魂攻击技（神魂伤害）
   - 神识冲击：远程单体，魂修基础技能
   - 诅咒/镇魂：远程单体，附加debuff
   - 幻术：中程范围，降低敌方命中率
   - 元神攻击：远程单体，无视部分神魂防御
3. 混合攻击技（双属性）
   - 雷法：中程范围，物理+神魂混合
   - 剑意：中程单体，物理为主+神魂破防
   - 丹火：中~远程，物理+神魂持续伤害
4. 防御技
   - 护体罡气：提升自身肉身防御N回合
   - 凝神静气：提升自身神魂防御N回合
   - 金刚体：提升自身物理抗性+格挡率N回合
5. 恢复技
   - 回春术：恢复目标生命值
   - 聚灵术：恢复自身灵力值
   - 清心诀：解除debuff
6. 移动技
   - 缩地成寸：瞬移至N格内任意位置
   - 御风术：本回合移动力+N
   - 换位术：与友方单位交换位置
7. 控制技
   - 定身术：目标下回合无法移动
   - 封灵术：目标下回合无法释放术法（沉默）
   - 眩晕：目标失去下回合行动权
   - 减速：目标反应速度-N%
四、神通（特殊技能）
神通不消耗灵力，无冷却惩罚（冷却=0），但数量有限：
- 本命神通：金丹期铭刻，1~2个，随境界成长
- 血脉神通：出生自带或激活隐藏灵根获得，1个
- 领域神通：[旧口径/资料片保留] 炼虚期获得，展开领域（修行境界.txt 已声明炼虚删除，当前最高境界为化神）
五、技能学习与成长
术法学习需要：
- 满足境界要求
- 满足灵根属性要求
- 消耗"悟性时间"（学习时间 = 基础时间 ÷ 悟性系数）
- 部分稀有术法需要门派贡献或特殊机缘
术法熟练度：
- 使用次数越多，术法效果微幅提升（最大+10%伤害或-10%消耗）
- 熟练度满后可"悟道"，解锁该术法的强化版本

第五章：状态效果
═══════════════════════════════════════════════════════════
一、状态职责

- 有持续或解除条件的战斗增益、减益与混合效果使用 `temporaryStatus`。
- 姿态、蓄力／引导过程、任务标记与生死分别使用 `stanceState`、`processState`、`taskMarker`、`lifeState`；不得塞入“中性状态”规避清除和保护规则。
- 具体攻击、防御、速度、控制、周期伤害、恢复和护盾内容由各自状态原型定义，持续与数值进入内容配置。

二、权威结算引用

状态极性、功能标签、来源、清除保护、写入禁令、混合状态整体处理与状态回溯，统一以《战斗状态与时空因果结算规则》为准。本文件不维护“同类取最高”“后施加覆盖先施加”等通用叠加表；每个状态原型必须声明自己的合并、刷新、互斥、冲突和解除策略，缺失时失败关闭。

第六章：战斗界面信息
═══════════════════════════════════════════════════════════
战斗中每个单位应清晰显示：
1. 头像/模型 + 朝向指示器
2. 生命值条 + 灵力值条
3. 当前CT充能进度（行动条上相对位置）
4. 当前buff/debuff图标
5. 选中单位时显示：
   - 可移动范围（高亮格）
   - 可攻击范围（红色格）
   - 术法作用范围预览
   - 预计伤害数值（浮动显示）
   - 命中率百分比
6. 行动轴预览条（顶部或侧边，显示所有单位的下次行动顺序）
