【战斗系统】

第一章：行动轴 —— CTB 充能制
═══════════════════════════════════════════════════════════

一、基本规则

战斗使用 CTB（Charge Time Battle）充能行动轴。
时间以"刻"（tick）为最小单位推进，所有单位在同一时间轴上竞争行动权。

每刻流程：
1. 所有在场单位行动条（CT） += 自身反应速度
2. 检查是否有单位 CT ≥ 100
3. 若有：CT ≥ 100 的单位进入"待行动"队列，按反应速度降序依次行动
4. 每个单位行动完毕后 CT 归零，继续累积
5. 若无单位达标：推进到下一刻

二、行动条公式

CT 充能值 = CT_当前 + 反应速度（每刻）

行动触发条件：CT ≥ 100
行动完毕后：CT = 0

三、术法冷却

每个术法/攻击有独立的"冷却惩罚"值（单位：刻的等效CT）。
冷却惩罚叠加在下次行动门槛上：

下次行动门槛 = 100 + 冷却惩罚

示例：
- 基础攻击（冷却0）：AT=100即动，最快节奏
- 大火球（冷却+30）：需要CT≥130才可行动
- 禁忌术法（冷却+80）：需要CT≥180，节奏极慢

反应速度50的单位：
- 基础攻击：每2刻行动一次
- 大火球：每2.6刻行动一次
- 禁忌术法：每3.6刻行动一次

四、待机规则

选择"待机"不执行任何行动时：
- 保留当前CT充能值的50%（而非归零）
- 无冷却惩罚
- 用途：等待队友、积蓄能量、观察敌方行动

五、行动回合内操作

每个行动回合内，按顺序执行：
  移动阶段 → 行动阶段
  或
  行动阶段 → 移动阶段（使用剩余移动力）

┌────────────┬──────────────┬────────────────────────┐
│ 操作       │ 消耗         │ 说明                   │
├────────────┼──────────────┼────────────────────────┤
│ 移动       │ 移动力（格） │ 每格消耗1移力          │
│ 攻击/术法  │ 1次行动权+MP │ 释放后进入冷却         │
│ 使用道具   │ 1次行动权    │ 丹药、符箓、法宝等     │
│ 切换装备   │ 1次行动权    │ 战斗中更换武器/法宝    │
│ 待机       │ 1次行动权    │ 保留50%CT，无冷却惩罚  │
│ 防御姿态   │ 1次行动权    │ 本回合防御×1.5，无冷却 │
└────────────┴──────────────┴────────────────────────┘

第二章：六角格棋盘与移动
═══════════════════════════════════════════════════════════

一、六角格基本规则

- 每个六角格最多容纳 1 个单位
- 距离以六角格最短路径计算（六角曼哈顿距离）
- 相邻格 = 6个方向（东、东北、西北、西、西南、东南）

二、移动

- 每行动回合可移动最多 移动力 格
- 移动可拆分：行动前移动N格→行动→行动后移动剩余格
- 不可穿过敌方单位所在的格子
- 可穿过友方单位所在的格子（不消耗额外移力）

三、朝向系统

每个单位有明确朝向（六角格6个方向之一）。

朝向判定规则：
- 单位移动后，朝向默认指向移动方向
- 行动阶段结束后，可自由旋转朝向（消耗剩余移动力，每60°消耗0移力）
- 被控制（定身、眩晕）期间朝向锁定

朝向影响受击效果：

┌──────────┬──────────┬──────────┬──────────┐
│ 攻击方向 │ 命中加成 │ 伤害加成 │ 格挡     │
├──────────┼──────────┼──────────┼──────────┤
│ 正面     │ +0%      │ +0%      │ 正常判定 │
│ 侧面     │ +15%     │ +10%     │ 正常判定 │
│ 背面     │ +30%     │ +25%     │ 无法格挡/魂盾 │
└──────────┴──────────┴──────────┴──────────┘

六角格朝向分布（以单位面朝"北"为例）：

        (正面)
        ⬡ ⬡
      侧 ⬡ 侧
        ⬡ ⬡ ⬡
        背 背

- 正前方2格 = 正面
- 左右前侧各1格 = 侧面
- 后方3格 = 背面

四、地形系统

每个六角格有一个地形类型，影响移动消耗、攻防和视野。

┌──────────┬──────────┬──────────────────────────────────┐
│ 地形     │ 移力消耗 │ 效果                             │
├──────────┼──────────┼──────────────────────────────────┤
│ 平原     │ 1        │ 无特殊效果                       │
│ 森林     │ 2        │ 驻守方闪避率+20%，阻挡视野       │
│ 高地     │ 2        │ 驻守方射程+1，被攻击方射程-1     │
│ 浅水     │ 2        │ 火系术法伤害-30%，雷系伤害+30%   │
│ 深水     │ 3        │ 无法释放火系术法，雷系伤害+50%   │
│ 毒沼     │ 2        │ 每回合扣最大生命值5%             │
│ 灵脉节点 │ 1        │ 驻守方灵力恢复×2                │
│ 废墟/掩体│ 1        │ 驻守方物理抗性+15%               │
│ 墙壁/障碍│ 不可通行 │ 阻挡移动和视野                   │
│ 云海     │ 不可通行 │ 仅元婴以上可飞越（无视移力消耗） │
└──────────┴──────────┴──────────────────────────────────┘

五、视野与侦察

- 每个单位的视野半径 = 神识强度（格，六角距离）
- 视野受障碍物（墙壁、森林）阻挡
- 友方单位共享视野
- 隐形单位：需神识强度 ≥ 隐形单位等级才能发现
  ┌──────────┬──────────────────┐
  │ 隐形等级 │ 所需神识强度     │
  ├──────────┼──────────────────┤
  │ 低级隐形 │ 神识 ≥ 15        │
  │ 中级隐形 │ 神识 ≥ 30        │
  │ 高级隐形 │ 神识 ≥ 50        │
  │ 完全隐匿 │ 神识 ≥ 70 或领域 │
  └──────────┴──────────────────┘

第三章：战斗结算流程
═══════════════════════════════════════════════════════════

一、攻击结算顺序

1. 选择目标 → 2. 射程检查 → 3. 视野检查 → 4. 命中判定
→ 5. 暴击判定 → 6. 格挡判定 → 7. 魂盾判定 → 8. 伤害计算 → 9. 附加效果

二、命中判定

实际命中率 = 基础命中(100%) + 攻击方命中率 - 防守方闪避率

注意：
- 防守方闪避率包含朝向加成（背面+30%命中率即闪避率-30%）
- 实际命中率最低5%（保底命中），最高100%
- 闪避成功 → 完全不受伤，结算结束

三、暴击判定

命中后独立判定暴击：
- 暴击概率 = 攻击方暴击率（不受防守方影响）
- 暴击成功 → 本次伤害使用"暴击伤害倍率"替代技能基础倍率
- 暴击伤害倍率 = 基础暴击伤害(150%) + 装备/功法加成


四、格挡判定

仅物理伤害可被格挡（神魂伤害不受格挡影响）：
- 格挡概率 = 防守方格挡率（来源：功法/装备/丹药）
- 背面攻击 → 格挡率强制为0
- 格挡成功 → 物理伤害 × (1 - 防守方格挡减伤率%)

五、魂盾判定

仅神魂伤害可被魂盾格挡（物理伤害不受魂盾影响）：
- 魂盾概率 = 防守方魂盾率（来源：功法/装备/丹药）
- 背面攻击 → 魂盾率强制为0
- 魂盾成功 → 神魂伤害 × (1 - 防守方魂盾减伤率%)

六、伤害计算

分别计算物理和神魂伤害（详见伤害公式.txt），两者独立结算后叠加：

物理伤害 = 肉攻 × 技能物理倍率 × 境界系数比 × 肉攻/(肉攻+肉防)
          × [1 - 物抗 × (防境系数÷攻境系数)^0.5]

神魂伤害 = 神攻 × 技能神魂倍率 × 境界系数比 × 神攻/(神攻+神防)
          × [1 - 魂抗 × (防境系数÷攻境系数)^0.5]

最终伤害 = 物理伤害 × (1 - 格挡减伤率) + 神魂伤害 × (1 - 魂盾减伤率)`r`n`r`n（格挡/魂盾减伤率仅在各自判定成功时生效，未触发则为0%）

七、属性克制

灵根相生相克影响伤害（详见灵根设定.txt）：
- 属性相生（如木→火）：伤害 +20%
- 属性相克（如水→火）：伤害 -20%
- 无关或无灵根：伤害不变

属性克制在"技能倍率"项上直接乘算。

八、伤害浮动

基础伤害有 ±5% 的随机浮动，模拟实战中的不确定性。

一、技能字段定义

每个技能（术法/攻击/神通）包含以下字段：

┌──────────────┬──────────────────────────────────────────┐
│ 字段         │ 说明                                     │
├──────────────┼──────────────────────────────────────────┤
│ 名称         │ 技能名称                                 │
│ 类型         │ 物理术法 | 神魂术法 | 混合术法 | 神通    │
│ 物理倍率     │ 物理伤害倍率（纯神魂术法填0）            │

二、六角格范围定义

单体：  指定一个目标格

直线：  从施法者沿一个方向延伸N格的一条直线
        （六角格直线：选择6个方向之一，依次命中路径上的所有格）

扇形：  以施法者为中心，面向方向的锥形区域
        半径1→3格，半径2→7格，半径3→12格

圆形：  以目标格为中心，半径R内的所有格（含中心）
        半径1→7格（中心+6邻格），半径2→19格

十字：  以目标格为中心，三个轴向各延伸R格的十字形

全屏：  整个战场所有格

三、技能分类

1. 物理攻击技（肉身伤害）
   - 拳法、掌法、腿法：近战，高暴击，体修专属
   - 剑术、刀术：近~中程，高暴击伤害，剑修专属
   - 法宝实体攻击：中~远程，器修专属

2. 神魂攻击技（神魂伤害）
   - 神识冲击：远程单体，魂修基础技能
   - 诅咒/镇魂：远程单体，附加debuff
   - 幻术：中程范围，降低敌方命中率
   - 元神攻击：远程单体，无视部分神魂防御

3. 混合攻击技（双属性）
   - 雷法：中程范围，物理+神魂混合
   - 剑意：中程单体，物理为主+神魂破防
   - 丹火：中~远程，物理+神魂持续伤害

4. 防御技
   - 护体罡气：提升自身肉身防御N回合
   - 凝神静气：提升自身神魂防御N回合
   - 金刚体：提升自身物理抗性+格挡率N回合

5. 恢复技
   - 回春术：恢复目标生命值
   - 聚灵术：恢复自身灵力值
   - 清心诀：解除debuff

6. 移动技
   - 缩地成寸：瞬移至N格内任意位置
   - 御风术：本回合移动力+N
   - 换位术：与友方单位交换位置

7. 控制技
   - 定身术：目标下回合无法移动
   - 封灵术：目标下回合无法释放术法（沉默）
   - 眩晕：目标失去下回合行动权
   - 减速：目标反应速度-N%

四、神通（特殊技能）

神通不消耗灵力，无冷却惩罚（冷却=0），但数量有限：
- 本命神通：金丹期铭刻，1~2个，随境界成长
- 血脉神通：出生自带或激活隐藏灵根获得，1个
- 领域神通：炼虚期获得，展开领域

五、技能学习与成长

术法学习需要：
- 满足境界要求
- 满足灵根属性要求
- 消耗"悟性时间"（学习时间 = 基础时间 ÷ 悟性系数）
- 部分稀有术法需要门派贡献或特殊机缘

术法熟练度：
- 使用次数越多，术法效果微幅提升（最大+10%伤害或-10%消耗）
- 熟练度满后可"悟道"，解锁该术法的强化版本

四、状态叠加规则

- 同类buff/debuff不叠加，取最高值
- 不同类buff/debuff可共存（如"攻击提升"+"速度提升"可同时生效）
- 控制效果互斥：同一时间只有一个控制效果生效，后施加的覆盖先施加的
- 护盾独立计算，不与防御buff冲突

第六章：战斗界面信息
═══════════════════════════════════════════════════════════

战斗中每个单位应清晰显示：

1. 头像/模型 + 朝向指示器
2. 生命值条 + 灵力值条
3. 当前CT充能进度（行动条上相对位置）
4. 当前buff/debuff图标
5. 选中单位时显示：
   - 可移动范围（高亮格）
   - 可攻击范围（红色格）
   - 术法作用范围预览
   - 预计伤害数值（浮动显示）
   - 命中率百分比
6. 行动轴预览条（顶部或侧边，显示所有单位的下次行动顺序）
