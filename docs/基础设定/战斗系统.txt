第一章：行动轴 —— CTB 充能制
═══════════════════════════════════════════════════════════
一、基本规则
战斗使用 CTB（Charge Time Battle）充能行动轴。
时间以整数“刻”（tick）推进，所有单位在同一时间轴上竞争个人回合控制权。反应决定获得个人回合的频率，AP 决定该回合能执行多少动作，两者独立。
每刻流程：
1. 所有在场单位行动条（CT） += 自身反应速度
2. 检查是否有单位 CT ≥ 自身当前行动门槛；初始门槛为 100
3. 达标单位进入“待行动”队列，按反应速度降序依次取得个人回合
4. 一个个人回合内可连续执行多个合法动作，移动、施法、演出与等待输入均不推进刻
5. 个人回合结束只结算一次 CT；同刻待行动队列处理完后，才推进下一刻
二、行动条公式
CT 充能值 = CT_当前 + 反应速度（每刻）
个人回合触发条件：CT ≥ 当前行动门槛
正常个人回合结束：CT = 0；下次行动门槛 = 100 + 本回合成功动作的累计 CT 惩罚
三、术法冷却
CT 惩罚与技能重用冷却是两个独立量：
- CT 惩罚以非负 CT 值声明，每次成功动作累加到 P_turn；移动及未声明惩罚的行为加 0。正常结束时只设置一次下次门槛 100 + P_turn，不取最后一次或最大值。合法出手但未命中仍累加，拒绝／取消不累加。
- 技能重用冷却以全局整数 tick 声明，成功施放后启动，只随全局刻推进递减。本个人回合内的子动作与演出不能减冷却；同技能冷却为 0 且其余条件合法可重复，正冷却时不可重用，不同技能各查自身账本。
- 金丹多个外显表现共享来源 abilityInstanceId 的唯一资源、冷却与额度账本，不因换表现复制或重置。
- 旧字段或模拟器“回合冷却”须逐项核对单位与迁移值，不将 CT 惩罚当作 tick，也不把回合数直接倍乘换算。具体值待后续合同与数值验证。
整数刻示例（仅说明量纲，不定生产费用）：反应 50、CT 从 0 开始时，门槛 100、130、180 分别需 2、3、4 刻，按 ceil(门槛／反应) 预览。两个成功动作惩罚 10、30，任意顺序正常结束的门槛都是 140；随后惩罚 0 的动作不抹掉累计值。
已确认位格的 CT 例外：普通 `TIME_CT` 按本章及《元婴锚点与金丹位格矩阵》结算。逆流河附性在公开时点对域内全阵营角色统一逆推当前轴位置，允许跨零后从轴尾继续；按各角色当前行动门槛归一化，并一致更新就绪状态与行动顺序。它不恢复历史 CT，也不改变普通 CT 算法；完整触发、费用与预算见 `docs/基础设定/金丹位格/界位/JD_Cosmos_Time_DOMAIN01_逆流河.txt#【位格附性】`。
四、待机规则
普通待机为 0 AP 终结命令，仅本个人回合未提交任何有战斗收益的动作时可选：
- 结束后保留当前 CT 的 50%，下一门槛恢复 100，无新惩罚，剩余 AP 清空。
- 预览／取消不影响资格；成功移动、攻击／施法、防御、道具、换装／换术或合法免费主动收益后均不能待机，须正常结束，不能洗去累计惩罚。
- 控制导致跳过的个人回合直接正常结束，不能取得待机 CT 保留。
五、行动回合内操作
一次动作是一次通过权威校验并提交的命令，可含多个目标／效果；移动命令是一段完整合法路径。个人回合是 CT 就绪取得控制权至结束、AP 耗尽、控制跳过或战斗终结的全过程，只有一次开始／结束事件。预览、取消、拒绝及刷新快照不算成功动作或新回合。

新设计基础行动力 AP_max 按第一章§八的境界行读取，凡人／练气仍100，筑基300、金丹1000；固定移动基准 AP_ref = 100。合法养成可提高 AP_max，个人回合开始快照上限并发放 AP_remaining = AP_max；没有独立移力余额。剩余 AP 不结转，不兑换灵力或 CT。途中换装或永久上限成长于下个个人回合生效，不补发差额；明示临时 AP 效果也不得超过本回合快照上限。

个人回合顺序：
1. 选中活角色后清除上次普通防御姿态，结算声明在本人回合开始的状态效果、持续伤害、控制及到期处理。死亡／战斗结束立即终结，不恢复或复活。
2. 仍存活者自动生命／灵力恢复一次并截断到上限，随后快照 AP 上限。控制跳过者仍计一次本人回合和恢复，但 AP 为 0，直接正常结束。
3. 可行动者取得 AP，按当前合法性逐次提交动作。移动与其他动作可任意穿插，多次普攻／同术法或不同术法均可；不设通用每回合一次攻击／施法限制。AP、MP、库存、资格、范围、冷却与控制仍须全部满足。
4. 结束时执行本人回合结束原型效果、持续时长及每回合计数，清空余额，结算一次 CT。战斗终结清除会话预算／姿态；结果与长期资源写回仍由现有结果所有者处理。

| 操作 | 统一 AP 及其他成本 | 回合边界 |
|---|---|---|
| 自愿路径移动 | 固定 100/v 按合法路径每边定点收费，见《战场空间与环境规则》§一 | 不独占阶段，不推进刻 |
| 普攻／术法／主动神通 | 各自声明正 AP；另查 MP、资源及独立冷却，主动血脉也声明正 AP | 成功后可继续合法动作 |
| 被动／自动触发 | 按原型条件与唯一账本；不为自动事件重复扣主动 AP，血脉自动／被动保留天生免费 | 不重发 AP 或每回合额度 |
| 道具 | 声明单项正 AP、库存／次数与目标，一次命令原子扣费 | 不自动结束 |
| 换装备／换术 | 声明正 AP 与资格；换术保留每战次数及换入冷却 | 不重发 AP，不刷新额度 |
| 普通防御 | 独立正 AP；肉防与魂防各×1.5，不自动结束 | 姿态至下一个人回合开始 |
| 结束行动 | 0 AP，任何可行动的当前角色均可选，包括未花 AP 时 | 放弃余额，正常 CT 清零及累计惩罚 |
| 普通待机 | 0 AP，仅未提交收益动作时可选 | 按本章§四结算 |

成功动作后 AP 恰为 0 自动走同一正常结束入口；有余额却无合法付费动作时可显式结束，敌方确定性结束。取消／拒绝不自动结束。演出忙碌只防重入，演出结束后仍有预算与合法动作即可继续操作。敌我使用同一费用与合法性。

普通防御再次激活无效且不扣费，不叠倍率或延长持续。下一次成功自愿移动、攻击／施法、道具、换术／换装先退出姿态再结算该动作；失败／取消不退出，结束行动保留姿态覆盖敌方行动，死亡／离场退出。其他技能状态按各自原型，不套普通防御。防御属性×1.5不能等同于最终伤害×0.5。

六、成本声明与原子提交
每个动作分别声明 AP、灵力／物品等资源、非负 CT 惩罚与全局 tick 重用冷却；没有 MP 成本不代表没有 AP 成本。攻击成本沿对应 docs → AttackProfiles.csv → 导入资产 → 运行时／BattleSim 只读投影传递，AttackProfiles 是唯一攻击成本生产者；术法／神通投影不得另建可编辑成本表。行为与角色字段名由后续公共数据合同冻结，本文不抢定字段或生产参数。

预览纯读取，不取随机数、不扣费。确认时同源重查角色／个人回合／上下文、能力资格、冷却／控制、路径／目标、AP／MP／库存；任一失败、取消、陈旧确认或重复提交均保持资源、位置、冷却、惩罚与回合额度不变。合法动作一次权威提交完整扣费、记录动作、启动冷却并结算结果；未命中仍按已执行动作付费。合法治疗／聚灵即使目标已满仍按原成本结算；效果无法提交时整个命令不提交。已经合法提交的动作中，某个状态写入被规则阻止不是整次命令失败，按《战斗状态与时空因果结算规则》§一.11继续其他结果，不退款。

七、行动力养成与修正
- AP 上限、独立位移效率 v、特定动作减耗、条件 AP 返还、CT／冷却修正分别声明来源、作用对象与预算，不从反应或 MP 减耗自动推导 AP／移动优惠。同一来源按唯一实例计算；同来源同时提高 v 与给同一移动折扣须明确共用成长预算。
- 非路径动作费用按“基础费用 → 合法固定减耗 → 合法比例减耗 → 正最小成本夹限 → 最小单位向上取整”处理，同类来源先按既有互斥／叠加合同聚合，缺合同不得自行叠乘。具体动作费与正下限待验证。
- 普通路径移动修正统一并入 v，逐边收费，不按命令段数给固定减耗或返还。
- 每个根动作成功结算后只返还一次：R ≤ min(声明返还, 本人回合剩余返还预算, 本次实付 AP−正最小净费, 本回合快照上限−当前余额)。声明触发条件、本人回合次数与总量上限；超额截断、不结转，返还、免费自动事件与派生效果不作为新付费根动作递归返还。每个可重复收益主动动作保持正净支出，预算有限；具体返还预算待验证。
- 纯显示、选目标、预览和无收益朝向调整可免费，不能恢复 AP、推进冷却或触发付费奖励。眩晕跳过整回合，定身阻止自愿移动，封灵阻止对应施法；AP 充足或返还不绕过控制。
- 长期保存仅记录合法成长输入或可重建来源，不保存 AP 余额、回合惩罚或移动预览；不新增战斗中途存档。旧档与初始角色映射由后续合同核定，不以固定 100 或反应派生值填补未定输入。
八、境界成长、固定能力档与连续使用新标准（AP-GROWTH@0.1）

境界AP／基础v依次为凡人100／2、练气100／4、筑基300／4、金丹1000／4.8；元婴3000／8、化神12000／12仅NPC与远期占位。小阶段先共用大境界行，玩家仍到金丹；全预算普通等效距离为2／4／12／48／240／1440，地形与定点取整另验。21部功法额外AP仍0，移动按当前境界的旧合法累计加成相对换算，完整来源与取整见《功法数值模板》§九，不把旧绝对v再叠新AP。

2026-10-10空手修订：普通修士、体修和妖兽均可由合法身体攻击档案普攻；无武器不再禁止普攻。人形肉身档位沿现有凡人/练气/筑基/金丹境界映射，功法通过已有肉攻来源强化体修，不凭流派标签授属性。基础AP与承载同步成长，候选为20/30、25/120、75/500、250/2400（AP/肉攻承载）；石甲兽自身练气撞击候选25/120。具名ID、唯一配表、取整与保存6见《空手普攻成长接入合同》§二至五；候选尚未实跑，不表示生产已恢复。旧basic_unarmed仍不合法，不隐式补档或装备。有合法主手时武器优先，无主手才用派生空手，本次无主动切空手/卸装操作。

武器与能力各有独立于使用者境界的固定档，低档能力不会因角色升级自动改价、换档或更换计数键。费用参照、MP独立预算、攻击／恢复／状态承载及能力身份见《术法神通数值模板》§11.1；伤害先截施术攻击再入原公式，目标防御不截，不重复乘状态境界系数。百分比属性状态与概率强控按施受大境界差修正，普通相对幅度总峰值30%、概率属性15个百分点、强控概率最高90%，具体C与具名水系例外见§11.2；低阶自益同境也受能力承载。

冷却按完整效果与固定能力档声明整数tick：基础武器／空手普攻及基础纯伤CD0、CT0；爆发／强增益／复杂战术CD4／1／1；强控12／3／3；显著恢复16／4／4（练气／筑基／金丹）。特例保留原资源或CT代价，例如聚灵CT5与血剑气生命费。该节替代以伤害倍率一概分配CT或从当前角色速度重算CD的做法，不把tick改成本人回合计数。

零CD主动术法、主动神通及武器／空手普攻的同回合同动作第1／2／3／4次及以后乘数为1／1／1.25／1.5，第4次起封顶，不复利，不设通用次数上限。原合法减耗与正净费夹限先算基础净费，再乘重复倍率、向上取整至1000单位/AP；最低净费不抵消附加费。本轮不新增减耗或返还来源，灵力与其他资格仍独立满足，额外实付不增加效果预算。移动、道具、换装不纳入；正CD、被动与自动触发不套此主动涨价。

不同真实术法／神通分别计数，同实例多表现共享且换术／重装不能重置。角色所有武器／空手普攻共用本回合次数，换武器或肉身变档后用当前基础费报价，不清次数、不补当回合AP；移动、换目标或其他技能不清零。预览不增加次数，成功提交计一次，合法未命中计、取消／拒绝不计，多目标和派生效果仍一次。下一本人回合重置，报价与提交同源。仅规则算术：1000AP可付14次50AP动作共987.5AP，不表示灵力、目标或平衡已满足。

二、六角格与移动摘要

- 每个 `HexCoord(q,r)` 固定连接六个拓扑邻格；每个六角柱最多一个单位最终停留。
- 每个人回合可按剩余 AP 多次移动，与攻击／施法穿插；位移效率 v 独立于反应，不存在独立移力余额。
- 路线先检查占位、高度、有向格边、实体障碍和移动形态，再按各边 `metricDistance` 与移动专用负担计算消耗。
- 移动、攻击、施法、强制位移、范围和视野统一调用加权距离服务；环境连通、共享格边和占位仍使用固定拓扑。
- 能否穿过友军、敌军或兼容占用格，由当前移动形态和占位规则决定；任何单位均不得停在已被占用的六角柱。

三、朝向系统
每个单位有明确朝向（六角格6个方向之一）。
朝向判定规则：
- 单位移动后，朝向默认指向移动方向
- 本人可行动的个人回合内，无收益朝向调整为 0 AP，不触发付费动作奖励或重置额度
- 被控制（定身、眩晕）期间朝向锁定

四、环境、视野与作用路径摘要

- 基础地形、单一地表状态、主要场景交互物和区域现象分别按专责事实源结算，不使用森林闪避、废墟抗性等硬编码地形加成。
- 低位掩体只提供方向性命中惩罚；实体障碍才阻断移动、视线与普通直线作用路径。
- 视野先按加权距离检查上限，再检查高度、观察资格、能见度通道和实体障碍。具体隐匿与识破进入相应能力及规则冲突，不使用通用神识阈值表。
- 友方共享视野只共享已经合法取得的观察结果，不得穿过实体封闭或绕过同阶隐匿规则。

第三章：战斗结算流程
═══════════════════════════════════════════════════════════
一、攻击结算顺序
1. 选择目标 → 2. 射程检查 → 3. 视野检查 → 4. 命中判定
→ 5. 五行属性匹配 → 6. 暴击判定 → 7. 基础伤害计算 → 8. 格挡判定 → 9. 魂盾判定 → 10. 护盾/附加效果
二、命中判定
实际命中率 = 基础命中(100%) + 攻击方命中率 - 防守方闪避率
注意：
- 防守方闪避率包含朝向加成（背面+30%命中率即闪避率-30%）
- 实际命中率最低5%（保底命中），最高100%
- 闪避成功 → 完全不受伤，结算结束
三、暴击判定
命中后独立判定暴击：
- 暴击概率 = 攻击方暴击率 + 五行内圈暴击率修正（不受防守方闪避/格挡影响）
- 暴击成功 → 本次伤害使用"技能基础倍率 × 暴击伤害倍率"
- 暴击伤害倍率 = 基础暴击伤害(150%，即×1.5) + 装备/功法/五行内圈暴击伤害加成
- 运行时字段 `critDamage`/“暴击伤害”表示相对基础150%的附加百分比点，不是总倍率：`critDamage = 0` 时为×1.50，`critDamage = 15` 时为×1.65；五行内圈暴击伤害修正也按百分比点相加。
四、格挡判定
仅物理伤害可被格挡（神魂伤害不受格挡影响）：
- 格挡概率 = 防守方格挡率（来源：功法/装备/丹药）
- 背面攻击 → 格挡率强制为0
- 格挡成功 → 物理伤害 × (1 - 防守方格挡减伤率%)
五、魂盾判定
仅神魂伤害可被魂盾格挡（物理伤害不受魂盾影响）：
- 魂盾概率 = 防守方魂盾率（来源：功法/装备/丹药）
- 背面攻击 → 魂盾率强制为0
- 魂盾成功 → 神魂伤害 × (1 - 防守方魂盾减伤率%)
六、伤害计算
普通伤害分别计算物理和神魂伤害（详见伤害公式.txt），两者独立结算后叠加：
物理伤害 = 肉攻 × 技能物理倍率 × 境界系数比 × 肉攻/(肉攻+肉防)
          × [1 - 物抗 × (防境系数÷攻境系数)^0.5]
神魂伤害 = 神攻 × 技能神魂倍率 × 境界系数比 × 神攻/(神攻+神防)
          × [1 - 魂抗 × (防境系数÷攻境系数)^0.5]
最终伤害 = 物理伤害 × (1 - 格挡减伤率) + 神魂伤害 × (1 - 魂盾减伤率)
（格挡/魂盾减伤率仅在各自判定成功时生效，未触发则为0%）
白帝砧的通道重铸按《伤害公式》第一节例外处理：原攻击来源与伤害预算不变，在防御前分配通道，随后分别检查对应防御、抗性、格挡／魂盾和免疫；不把原物伤改用神攻重算。
七、属性克制
五行属性匹配采用 v5.10 内外圈规则（详见灵根设定.txt 第八节），
不沿用旧版 ±20% 简表；以灵根设定.txt 第八节内外圈叠加规则为准。
五行匹配同时产出基础伤害倍率修正与内圈相克的暴击率/暴击伤害修正；
因此必须先完成五行匹配，再进行暴击判定。
八、伤害浮动
基础伤害有 ±5% 的随机浮动，模拟实战中的不确定性。

二、六角格范围定义
以下形状定义基础拓扑模板；实际选取必须经加权距离、高度、作用路径、观察资格和障碍检查。同一半径在空间尺度影响下可以覆盖更多或更少拓扑格。

单体：  指定一个目标格
直线：  从施法者沿一个方向延伸N格的一条直线
        （六角格直线：选择6个方向之一，依次命中路径上的所有格）
扇形：  以施法者为中心，面向方向的锥形区域
        半径1→3格，半径2→7格，半径3→12格
圆形：  以目标格为中心，半径R内的所有格（含中心）
        半径1→7格（中心+6邻格），半径2→19格
十字：  以目标格为中心，三个轴向各延伸R格的十字形
全屏：  整个战场所有格
三、技能分类
1. 物理攻击技（肉身伤害）
   - 拳法、掌法、腿法：近战，高暴击，体修专属
   - 剑术、刀术：近~中程，高暴击伤害，剑修专属
   - 法宝实体攻击：中~远程，器修专属
2. 神魂攻击技（神魂伤害）
   - 神识冲击：远程单体，魂修基础技能
   - 诅咒/镇魂：远程单体，附加debuff
   - 幻术：中程范围，降低敌方命中率
   - 元神攻击：远程单体，无视部分神魂防御
3. 混合攻击技（双属性）
   - 雷法：中程范围，物理+神魂混合
   - 剑意：中程单体，物理为主+神魂破防
   - 丹火：中~远程，物理+神魂持续伤害
4. 防御技
   - 护体罡气：提升自身肉身防御N回合
   - 凝神静气：提升自身神魂防御N回合
   - 金刚体：提升自身物理抗性+格挡率N回合
5. 恢复技
   - 回春术：恢复目标生命值
   - 聚灵术：恢复自身灵力值
   - 清心诀：解除debuff
6. 移动技
   - 缩地成寸：瞬移至N格内任意位置
   - 御风术：声明独立位移效率 v 修正及持续时点，具体参数待验证
   - 换位术：与友方单位交换位置
7. 控制技
   - 定身术：目标下回合无法移动
   - 封灵术：目标下回合无法释放术法（沉默）
   - 眩晕：目标跳过下一整个个人回合，仍按本人回合结算恢复与持续
   - 减速：目标反应速度-N%
四、神通（特殊技能）
神通本体默认不消耗灵力、CT惩罚为0；具体原型另行声明的特殊资源、CT惩罚与独立重用冷却仍须分别遵守，不由CT惩罚0推导重用冷却0。主动释放必须声明正 AP，不能由无 MP 推导 AP 免费。血脉主动同样支付 AP，被动／自动触发保留天生免费，不因此新增灵力费。金丹装配、已确认位格附性、兼容合施、蓄力或追加作用仍按各自档案额外支付，共享来源能力实例的唯一账本；不得由本体免费推导附性免费。数量边界保留：
- 本命神通：金丹期铭刻，1~2个，随境界成长
- 血脉神通：出生自带或激活隐藏灵根获得，1个
- 领域神通：[旧口径/资料片保留] 炼虚期获得，展开领域（修行境界.txt 已声明炼虚删除，当前最高境界为化神）
五、技能学习与成长
术法学习需要：
- 满足境界要求
- 满足灵根属性要求
- 消耗"悟性时间"（学习时间 = 基础时间 ÷ 悟性系数）
- 部分稀有术法需要门派贡献或特殊机缘
术法熟练度：
- 使用次数越多，术法效果微幅提升（最大+10%伤害或-10%消耗）
- 熟练度满后可"悟道"，解锁该术法的强化版本；消耗强化须明确作用于 MP 还是 AP，不自动同时减两者，AP 修正仍满足第一章§七的正净费与预算规则

第五章：状态效果
═══════════════════════════════════════════════════════════
一、状态职责

- 有持续或解除条件的战斗增益、减益与混合效果使用 `temporaryStatus`。

二、权威结算引用

状态极性、功能标签、来源、清除保护、写入禁令、混合状态整体处理与状态回溯，统一以《战斗状态与时空因果结算规则》为准。本文件不维护“同类取最高”“后施加覆盖先施加”等通用叠加表；每个状态原型必须声明自己的合并、刷新、互斥、冲突和解除策略，缺失时失败关闭。
本人回合开始／结束、持续 N 回合、每次动作／命中／受击与每回合额度的单位见该规则§六；不得把多次子动作当成多个个人回合。AP 不进入状态回溯白名单。
