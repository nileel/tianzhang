一、筑基期 —— 道基（筑基初期解锁）
═══════════════════════════════════════

太一道庭专属例外：太一道庭修士筑基后不凝聚通用道基，而是"初授法箓"。
法箓承担道基的根基、品级、被动效果和后续升格职责。其他门派仍按本章
通用道基规则执行。详见 `docs/角色养成/太一道庭法箓规则.txt`。

────────────────────────────────────
一.1 道基类型
────────────────────────────────────

道基类型由修士当前修炼的功法决定，每本功法的首篇锁定唯一道基类型。
道基一旦凝聚即「固化」——废功重修后道基类型不变，金丹需重新凝结。

功法示例 → 道基类型：
- 含弘光大典 → 【坤德】：肉身防御+10%，防御姿态额外减免5%伤害
- 南华阐衍典 → 【自生】：每回合未受击获得独化印记（每层神魂攻击+5%）
- 白屋青云录 → 【寒门】：每习得新术法+1%暴击率，初始灵力-20%
- 心无性有法 → 【无知之知】：神识强度+5，神识高于目标时命中率+20%
（完整列表见各功法文件首篇章的道基字段）

────────────────────────────────────
一.2 道基品级
────────────────────────────────────

道基生成时不仅有类型，还有品级（天、地、玄、黄四品，天品最高，黄品最低）。
若凝聚值过低则无法生成道基（无道基）。
品级决定道基被动效果的生效倍率：

┌──────────┬──────────┬──────────────────────────────┐
│ 道基品级 │ 效果倍率 │ 说明                         │
├──────────┼──────────┼──────────────────────────────┤
│ 天品     │ ×1.30    │ 天道之基，极其罕见           │
│ 地品     │ ×1.10    │ 上品根基，宗门真传水准       │
│ 玄品     │ ×1.00    │ 中品根基（标准）             │
│ 黄品     │ ×0.85    │ 下品根基，勉强可用           │
│ 无道基   │ —        │ 凝聚失败，无被动效果         │
└──────────┴──────────┴──────────────────────────────┘

效果倍率 = 道基效果中的各项数值 × 对应倍率。
例：【坤德】玄品 → 肉身防御+10%×1.00=+10%；天品 → +10%×1.30=+13%；
    黄品 → +10%×0.85=+8.5%（向下取整为8%）；无道基 → +0%。

v3.5 注：道基品级是道基自身品质的标尺，不再直接映射金丹品级上限。
        道基品级影响根本神通的基础强度与紫府府位的先天亲和度。

────────────────────────────────────
一.3 道基凝聚值（品级判定公式）
────────────────────────────────────

道基品级由「道基凝聚值」落入的区间决定：

  道基凝聚值 = 灵根基数 + 功法修正 + 灵力超额修正 + 随机骰 + 天材地宝加成

各因子说明：

① 灵根基数（角色先天资质）：
┌──────────┬──────┐
│ 灵根品级 │ 基数 │
├──────────┼──────┤
│ 凡品     │  10  │
│ 下品     │  20  │
│ 中品     │  30  │
│ 上品     │  40  │
│ 极品     │  50  │
└──────────┴──────┘
多灵根取最高品级计算，不叠加。

② 功法修正（当前功法的品级）：
┌──────────┬──────┐
│ 功法品级 │ 修正 │
├──────────┼──────┤
│ 凡品     │   0  │
│ 下品     │   5  │
│ 中品     │  10  │
│ 上品     │  15  │
│ 极品     │  20  │
└──────────┴──────┘

③ 灵力超额修正（突破时的积蓄溢出）：
  修正 = (突破时有效灵力 − 100) ÷ 50
  即每超出筑基门槛 50 点有效灵力，凝聚值 +1（向下取整）。
  例：以 300 有效灵力突破 → (300−100)/50=4，修正 +4
      以 1000 有效灵力突破 → 修正 +18

④ 随机骰（核心随机性来源）：
  1d30 —— 在 1~30 区间内均匀随机。
  每次道基生成时独立骰一次，不可重骰。

⑤ 天材地宝加成：
  筑基丹/道基丹等可固定增加凝聚值。
  具体数值见丹药体系（TBD）。

────────────────────────────────────
一.4 道基品级区间判定
────────────────────────────────────

┌──────────┬────────────────┐
│ 道基品级 │ 凝聚值区间     │
├──────────┼────────────────┤
│ 天品     │ ≥ 80           │
│ 地品     │ 60 ~ 79        │
│ 玄品     │ 40 ~ 59        │
│ 黄品     │ 20 ~ 39        │
│ 无道基   │ ＜ 20           │
└──────────┴────────────────┘

v3.5 注：旧版曾将道基品级直接映射为金丹九品上限（天品→一至三品、地品→一至五品等）。
        该映射关系已随金丹九品制取消而废止。道基品级现仅影响根本神通强度与府位亲和度。

二、紫府 —— 筑基后半段的质变（紫府初开解锁）
═══════════════════════════════════════

紫府不是独立大境界，而是筑基后半段的显示包装与质变状态。
紫府初开后，修士体内开辟五府，承载本命术法候选、根本神通与成丹根基。

────────────────────────────────────
二.1 紫府五府
────────────────────────────────────

┌──────────┬──────────────────────────────────────────────┐
│ 府位     │ 管辖领域                                     │
├──────────┼──────────────────────────────────────────────┤
│ 命府     │ 生命、根骨、肉身、防御、恢复                 │
│ 魂府     │ 魂魄、神魂攻击、魂盾、心魔、梦境             │
│ 识府     │ 神识、侦察、命中、预判、控制、阵法           │
│ 气府     │ 灵力、术法循环、符箓、丹火、五行转化         │
│ 运府     │ 气运、因果、暴击、闪避、奇遇、劫数           │
└──────────┴──────────────────────────────────────────────┘

府位成长规则：
  - 不同 Build 主修二到三府，不要求五府均衡。
  - 紫府成长优先来自事件、资源、门派试炼、地脉、灵眼、符诏、雷池、梦种、
    强敌和心魔等目标，不做单一经验条。
  - 每府有独立的开启条件与成长阶段，具体见各门派/功法设计。

────────────────────────────────────
二.2 本命术法候选
────────────────────────────────────

本命术法候选是筑基后半段出现的、可升格为根本神通（进而驱动成丹）的术法种子位。
与金丹期才突然决定本命神通的跳变节奏不同，候选术法的选择与培养贯穿筑基后半段。

候选数量与时机：
  - 筑基中期：出现第 1 个本命术法候选
  - 紫府初开：候选槽位增至 2 个
  - 紫府圆满：候选槽位最多 3 个

重选规则：
  - 可高成本重选（消耗特定丹药/灵材/时间）
  - 候选术法升格为根本神通后固化为金丹资粮，不可再替换

候选术法需覆盖府位：
  - 本命术法候选应尽量覆盖修士主修的府位方向
  - 候选术法的升格方向与紫府府位亲和度决定根本神通强度

────────────────────────────────────
二.3 根本神通
────────────────────────────────────

根本神通是修士在筑基期将本命术法候选进一步锤炼后，植入紫府府位的核心神通。
根本神通与通用神通不同——它是成丹的资粮，决定金丹的丹籍资格与丹名方向。

根本神通门槛：
  - 四道根本神通且覆盖至少三个府位 → 允许进入成丹判定
  - 五道根本神通且至少一道与道基完全契合 → 可竞争辅籍
  - 五道根本神通并形成完整道途闭环 → 可竞争正籍

四神通出口：
  - 四道神通可成寄丹、敕籍候选或临时承籍路线
  - 没有正/辅籍条件时，不直接争一正二辅自然丹籍

根本神通与府位的关系：
  - 每道根本神通绑定一个府位（可多道同府，但同府加成递减）
  - 府位的成长程度决定对应根本神通的最终强度
  - 覆盖府位越多 → 丹籍竞争面越广，但单府深度越浅（Build 取舍）

═══════════════════════════════════════

金丹不再采用一至九品制。金丹的核心表达改为三层：
丹籍（位格）、丹名（道途标签）、丹性（五行/变异回响）。

丹籍常设规则：
  - 天地自然丹籍采用「一正二辅」：同一丹系一席正籍，两席辅籍。

  - 寄丹是旧"假丹"的古典包装名，不是坏档或永久惩罚。

────────────────────────────────────
三.3 成丹条件与丹籍判定流程
────────────────────────────────────

步骤一：根本神通资格审查
  检视修士的根本神通数量与府位覆盖：
    - 不足四道 → 无法成丹，需继续积累
    - 四道且覆盖 ≥ 三个府位 → 可进入成丹判定
    - 五道且至少一道与道基完全契合 → 候选辅籍
    - 五道并形成完整道途闭环 → 候选正籍

步骤二：成丹判定值计算
  成丹判定值 = 灵根基数 + 道基品级修正 + 府位完成度 + 根本神通强度 + 丹材加成 + 随机骰

  成丹判定值的效果：
    - 回答"能否成丹"（下限阈值 = 40）
    - 回答"是否稳固"（稳固阈值 = 60）
    - 回答"是否足以承接目标丹籍"（正籍阈值 = 85，辅籍阈值 = 70）

步骤三：丹籍竞争
  若目标丹籍已被占据，进入夺籍判定：
    - 成丹判定值差 ≥ 15 → 可直接夺籍
    - 成丹判定值差 5~14 → 需配合政治/战斗手段
    - 成丹判定值差 < 5 → 无法夺籍，需选择其他丹籍或寄丹

────────────────────────────────────
三.5 本命神通（金丹期）
────────────────────────────────────

金丹期可将根本神通中的一道或多道升格为本命神通。
本命神通不消耗灵力、无冷却，效果随境界成长。

本命神通数量与丹籍关系：
  - 正籍：最多 2 道根本神通升格为本命神通
  - 辅籍：最多 1 道根本神通升格为本命神通
  - 敕籍/寄丹：最多 1 道，或仅保留根本神通不升格

v3.5 注：旧版"一品金丹可铭刻 2 个本命神通、三品以上 1 个"的规则已废止。
        本命神通数量现由丹籍位格决定，不再与金丹品级挂钩。

────────────────────────────────────
三.6 本命法宝（金丹期）
────────────────────────────────────

金丹期可炼化一件本命法宝，与修士金丹同源共生。
本命法宝的类型与品级由丹性与丹材决定。

附录：高阶境界特性（NPC/世界背景）
═══════════════════════════════════════

以下境界特性保留为世界设定与 NPC 能力参考，
当前版本不作为玩家必须支持的系统。

────────────────────────────────────
A. 元婴期 —— 元婴、元婴出窍
────────────────────────────────────

元婴：碎丹成婴，修士新生，大幅度提升灵力值上限。
元婴出窍：元婴脱离肉身独立出击。
  - 肉身防御降至 0（元婴无实体），神魂防御保持不变
  - 反应速度大幅提升（×2）
  - 可直接无视地形瞬移
  - 神魂攻击获得 +30% 加成
  - 元婴被击碎则角色死亡

当前版本用途：NPC 宗门老祖、敕籍点化者。

────────────────────────────────────
B. 化神期 —— 元神、第二化身
────────────────────────────────────

元神：元婴的成熟形态，神魂完全独立。
  - 元神出窍不再强制肉身防御归零
  - 元神状态下神魂攻击 +50%，神魂防御 +30%
  - 元神不灭则修士不死

第二化身：分化元神凝练独立化身。
  - 化身拥有本体 60% 属性，独立行动单位
  - 化身被毁则本体神魂攻击 −20%

当前版本用途：传说级 NPC、上古修士。

────────────────────────────────────
C. 炼虚期 —— 领域
────────────────────────────────────

领域：将自身"道"外化为领域，覆盖战场区域。
  - 领域内自身全属性 +30%，敌方全属性 −15%
  - 领域内移动力翻倍，神识覆盖全领域
  - 每回合消耗最大灵力值的 5%
  - 同阶领域碰撞：境界系数高者压制低者

当前版本用途：终极 NPC 威慑、世界背景设定。
旧版炼虚领域作为当前主循环战斗机制目标的口径已降级，保留为远期资料片内容。
