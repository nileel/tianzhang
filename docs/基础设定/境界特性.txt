═══════════════════════════════════════
一、筑基期 —— 唯一道基与四阶段
═══════════════════════════════════════

每个角色只有一个道基。太一道庭的“初授法箓”是道基的一种宗门表现，
同样遵守四阶段、天然容量、扩府、筑府和结丹锁定规则。详见
`docs/角色养成/太一道庭法箓规则.txt`。

────────────────────────────────────
一.1 道基来源与筑基方案
────────────────────────────────────

启动筑基时必须选择一部主修功法。该功法的筑基方案决定道基的效果组合、
名称、外观和内容身份；与功法主属性或兼容属性相符的最高品级灵根决定
天然紫府容量。多条相容灵根不叠加，不相容灵根不提供容量。

道基成功形成后，其主修来源、天然容量和核心效果固化。后来改修其他功法
不会改变已经形成的道基，也不允许重新筑基取得第二个道基。

“道基本相”只表示该具体道基的名称、外观和内容身份，不再建立天地玄黄
品级、稳固／循环／连结等通用主构型或随机品质版本。

────────────────────────────────────
一.2 筑基考验
────────────────────────────────────

筑基使用简短的专属突破流程：选择主修功法、地点和辅助资源后，角色停留
原地，按固定修炼周期推进，只在关键考验、资源耗尽或外部事件时暂停。

考验影响成功前的处理、耗时和损耗，不生成永久劣化版本。完整处理全部
考验后必定成功并形成第一阶段道基，不进行最终随机抽签。失败只损失时间、
部分资源并造成可恢复伤势，恢复后可以重试。

────────────────────────────────────
一.3 四个连续阶段
────────────────────────────────────

原筑基五小阶段被四个道基阶段整体替换，不再同时保存“筑基小境界进度”
和“道基培养进度”两条角色阶段。正式名称尚未锁定，现阶段只称第一、
第二、第三、第四阶段。

筑基成功后处于第一阶段。主动执行“养基”时，每个固定修炼周期增加连续
道基进度；跨过节点自然进入下一阶段，不重复制作完整突破考验。第四阶段
完成即为筑基圆满。

所有成功筑基者都能完成四阶段。灵根不限制阶段，只决定天然紫府容量。
功法、灵地和辅助资源可以影响每周期养基效率，但具体曲线尚未锁定。

────────────────────────────────────
一.4 阶段收益
────────────────────────────────────

1. 主修功法按四阶段成长表提供永久一级属性成长；五段总预算如何重分配须
   由独立数值任务与 BattleSim 验证，本文件不平均拆分。
2. 道基核心效果随连续养基进度成长。可数值化参数可以连续变化，非数值
   效果只在明示节点启用。
3. 第二、第三、第四阶段按天然容量逐步释放紫府建造容量。


═══════════════════════════════════════
二、天然容量与五座独立紫府
═══════════════════════════════════════

────────────────────────────────────
二.1 天然容量与扩府
────────────────────────────────────

天然容量由筑基时采用的最高相容灵根决定：下、中、上、极品分别为
0、1、2、3。凡品不能筑基。

  当前已释放天然容量 = min（道基天然容量，道基阶段 - 1）

筑基期可以通过天材地宝永久获得“紫府容量 +1”，同一角色最多两层。
扩府不建立独立玩法，不区分天然府、额外府或劣等外府。结丹后不能扩府。

  当前紫府总容量 = 当前已释放天然容量 + 扩府效果层数（最多 2）

────────────────────────────────────
二.2 五座独立紫府
────────────────────────────────────

┌──────────┬──────────────┬──────────────────────────────────────┐
│ 紫府     │ 对应先天属性 │ 内容边界                             │
├──────────┼──────────────┼──────────────────────────────────────┤
│ 命府     │ 根骨         │ 一项命府府体效果 + 一项镇府神通     │
│ 魂府     │ 魂魄         │ 一项魂府府体效果 + 一项镇府神通     │
│ 识府     │ 神识         │ 一项识府府体效果 + 一项镇府神通     │
│ 悟府     │ 资质         │ 一项悟府府体效果 + 一项镇府神通     │
│ 运府     │ 气运         │ 一项运府府体效果 + 一项镇府神通     │
└──────────┴──────────────┴──────────────────────────────────────┘

五府地位平等，每类每个角色最多一座，不设置主府、辅府或转修开启。
容量不足五座时由角色选择其中一部分；只有总容量达到五座才能集齐五府。

对应先天属性和筑基方案亲和只影响筑府时间、资源、考验难度与过程容错，
不能硬性禁用府属，也不能降低建成后的最终强度。五府府体固定机制见
`docs/superpowers/specs/2026-07-21-five-mansion-body-effects-design.md`；具体数值
参数与预算仍待独立数值任务锁定。

────────────────────────────────────
二.3 两段式筑府与源术法升格
────────────────────────────────────

开始蕴养紫府必须仍处于筑基期、有未使用容量、目标府属尚未建造，并已
选择兼容源术法、掌握升格知识、完成升格方案的真实条件。

第一段“蕴养府胚”按固定修炼周期积累进度，可以暂停或闭关重复。第二段
“正式开府”是一次不能中途离开的考验。失败不占容量、不使源术法消失，
只损失部分府胚进度、资源并造成可恢复伤势；不生成永久残缺紫府。

每项术法的升格方案声明固定神通本体、一至两个兼容府属、可执行条件和
源术法的保留／取代／内化方式。不存在固定三个候选槽或独立资格对象。

────────────────────────────────────
二.4 镇府神通与后续强化
────────────────────────────────────

每座紫府只能承载一项镇府神通。府体效果不占用该名额；血脉神通、通用
神通和其他来源能力不占紫府，也不能替代镇府神通作为筑基成果。

镇府神通不使用统一等级或经验条。每项神通按需声明行为、修持、资源、
府间或特殊强化节点；单项神通不要求包含全部节点类型。府间联动直接使用
明确条件与统一效果绑定，不另建共鸣引擎，也不重新引入主府、辅府。

结丹成功后，道基阶段、紫府总数、五府选择、府体效果和镇府神通实例永久
锁定，不能再养基、扩府、开府、替换府属或重选镇府神通。既有镇府神通
仍可完成升格方案明确允许的后续强化节点。


═══════════════════════════════════════
三、金丹期 —— 道路／位格／装配／承载／丹枢核心
═══════════════════════════════════════

金丹不采用一至九品制，也不设计低配或无位格金丹。每个金丹必须属于十七道路之一，并以真实位格、装配效果、占据状态、金丹名称、丹性、镇府神通承载和不可变丹枢核心共同表达。

────────────────────────────────────
三.1 结构对象
────────────────────────────────────

| 对象 | 作用 |
|---|---|
| `road_id` | 决定道路变量、不可越界项和三项基础效果候选 |
| `seatInstanceId` / `positionType` | 记录真实源位、化位或界位及占据关系 |
| `effect_id` | 记录该真实位格当前装配的一项效果 |
| 证位起点／权利来源 | 记录夺取、继承、敕封、暂寄或独立应位等状态；不直接建立稳定占据，也不是新位格 |
| 金丹名称与丹性 | 分别表达所属世界规则和个人长期回响 |
| `SeatCarrierBinding` | 记录每个位格的主承载、辅助神通、来源紫府与兼容档案；来源不表示位格独占紫府 |
| `JindanCoreBinding` | 记录唯一不可更换的丹枢核心 |
| 丹相 | 聚合全部已建紫府、位格、装配效果、主／辅承载和合法丹枢表现；每个金丹只有一个 |

────────────────────────────────────
三.2 三种真实位格与三阶段
────────────────────────────────────

| 位格 | 固定职责 |
|---|---|
| 源位 | 普通距离内具体对象、具体操作与真实媒介 |
| 化位 | 局部阵域的一条固定条件筛选与固定转化 |
| 界位 | 广域粗阵营选择与一条较弱固定规则 |

1. 每一道路固定一个源位、一个化位、一个界位定义，不开放同类位格无限扩展。
2. 金丹初期取得第一种真实位格，中期取得第二种，圆满取得第三种；取得顺序自由。
3. 三阶段共享 `realmRuleTier = JINDAN`。阶段只增加一／二／三个真实位格、装配槽、组合、资源与承载预算，不提供自动压制或隐藏平局权重。
4. 每个真实位格同一时间只装配本道路三项候选中的一项。相同 `effect_id` 可以纵向嵌套；不同效果只有命中显式 `comboProfileId` 才能组合。
5. 各道路、对象、操作、版本与边界以《元婴锚点与金丹位格矩阵》为唯一效果事实源；装配与冲突以《金丹基础效果装配与冲突规则》为准。

────────────────────────────────────
三.3 成丹、承载与核心绑定
────────────────────────────────────

1. 成丹审查读取道基第四阶段、至少一座完整紫府及其镇府神通、目标位格最低条件、兼容主承载、地点、现实支点、材料与其他准备。系统不强制角色用满紫府容量。
2. 结丹时全部已建紫府共同进入唯一丹枢核心和唯一丹相。第四、第五府继续提供府体、镇府神通、府间节点和合法辅助输入，但不增加位格或效果槽。
3. 每个 `STABLE` 位格必须恰好有一个独立 `primaryCarrierAbilityInstanceId`。同一镇府神通实例最多主承载一位；初期、中期、圆满分别需要一、二、三项互不重复的主承载实例。
4. 主承载只表示该神通是目标位格的主要稳定接口，不表示位格独占来源紫府。同一镇府神通可主承载一位并辅助其他位格，也可辅助多位，但辅助只提供档案显式开放的媒介、触发、代价改道或组合接口。
5. 主承载、全部辅助与丹相引用共享 `abilityInstanceId` 的唯一效果、现实支点、充能、冷却、次数、资源和代价账本；多条引用不得复制贡献。
6. 缺少独立主承载的位格只能记为 `TEMPORARY`，不能计入稳定阶段结构、嵌套、组合、山河常驻或晋升资格。
7. 成丹时建立唯一 `JindanCoreBinding`。丹枢核心成丹后不可换绑、移植、顶替、拆分、复制或在重铸中重选。

────────────────────────────────────
三.4 安全重铸、失稳与丹毁
────────────────────────────────────

1. 结丹前已经建成的紫府与镇府神通实例永久固化。位格主承载关系可以在安全洞府原子重铸，战斗中禁止；重铸不能新增或替换紫府、府属、府体效果或镇府神通。
2. 新主承载只能从结丹前固化的镇府神通集合中选择。重铸必须保持真实位格占据和原 `JindanCoreBinding` 不变，并验证兼容性、主承载唯一性、来源紫府、资源和受影响实例；失败保留旧绑定且不扣费。
3. 普通冷却、充能不足或主动效果暂不可用不等于主承载失效。只有紫府接口被封禁、府位破坏、绑定合法切断或神通永久失去时，绑定转为 `UNSTABLE`；此时不能新展开效果，已有实例按后备或结束规则处理。
4. `UNSTABLE`、资源耗尽、效果换装、持续实例结束和暂时权限失效都不等于真实位格丧失。
5. 稳定金丹任一真实位格被剥离、毁坏或转移，或不可变核心被毁坏／切断，立即原子触发丹毁死亡；不回退阶段、不缺位存活、不事后补绑。该历史不可由状态回溯或普通复活改写。

────────────────────────────────────
三.5 占据、元婴升格与丹相表达
────────────────────────────────────

1. 夺取、继承、敕封、暂寄与独立应位描述证位起点、权利来源或过渡状态，不创建第四位格，也不直接建立稳定占据。
2. 原持有者死亡或合法释放后，位格先进入版本化空缺；继承人、受封者、击杀者和独立候选人都必须用自己的履历、主承载、支点与资源完成证位。
3. 多名候选人可并行争位；第一名通过原子绑定者取得位格，同刻完成者进入临界争位，不使用随机或隐藏顺序裁定。
4. 既有金丹取得后续位时不得换核或重结金丹；只追加新的 `SeatCarrierBinding`。
5. 稳定真实位格已经建立后的丧失与丹毁死亡规则保持不变。
6. 合法晋升既有道路元婴时，三个位格、核心与承载只在唯一 `YuanyingRoadAnchor` 建立成功后整体升格；失败保留原金丹，不触发丹毁死亡。
7. 每个金丹只有一个丹相。它是全部已建紫府、道路、位格、装配效果、金丹名称、丹性、主／辅承载和丹枢接口的完整能力形态，不是额外位格或效果槽。取得后续位只向同一丹相追加规则权限。
8. 丹枢只能在已有权限内调整媒介、偏向对象、代价分配、丹域景象、战斗表现和宗门叙事，不得改变量边界、装配数量或核心绑定。
9. 丹相只引用既有效果绑定，不复制镇府神通实例，也不另开资源、充能、冷却或代价账本。
10. “本命神通”可保留为 UI 或叙事旧称，但不作为独立系统字段或固定数量规则。

────────────────────────────────────
三.6 丹器显化
────────────────────────────────────

丹器显化是部分丹相的可选外显形态，不是所有金丹的必备系统。它可以是丹剑、法箓、法坛、丹炉、令旗、兵符、战鼓或阵图，也可以是梦界、魂灯、因果线等非实体形态。

丹器显化必须服从目标席位的矩阵边界和丹枢接口；它不能单独提供超出席位允许范围的世界效果。

附录：高阶境界特性（NPC/世界背景）
═══════════════════════════════════════

以下境界特性保留为世界设定与 NPC 能力参考，
当前版本不作为玩家必须支持的系统。化神是世界最高境界。

────────────────────────────────────
A. 元婴期 —— 元婴、元婴出窍
────────────────────────────────────

元婴：没有常规模板或低配版本。每一个元婴都是唯一高位位格；任一具体元婴位格同一时期只能有一个持有者。碎丹成婴不是单纯数值升境，而是承接或自辟一条唯一高位秩序。
元婴出窍：元婴脱离肉身独立出击。
  - 肉身防御降至 0（元婴无实体），神魂防御保持不变
  - 反应速度大幅提升（×2）
  - 可直接无视地形瞬移
  - 神魂攻击获得 +30% 加成
  - 元婴被击碎则角色死亡

当前版本用途：NPC 宗门老祖、席位敕封者。

────────────────────────────────────
B. 化神期 —— 元神、第二化身
────────────────────────────────────

化神：掌握五行、阴阳、宇宙、五蕴、因果之一的根本法则。
  - 每位化神只能统御一系根本法则，不得以化神身份取得全法则全能。
  - 元婴掌握根本法则下的一条分支；金丹占据该分支下的具体位格。

当前版本用途：传说级 NPC、上古修士与世界法则锚点。
