一、筑基期 —— 道基（筑基初期解锁）
═══════════════════════════════════════

太一道庭专属例外：太一道庭修士筑基后不凝聚通用道基，而是"初授法箓"。
法箓承担道基的根基、品级、被动效果和后续升格职责。其他门派仍按本章
通用道基规则执行。详见 `docs/角色养成/太一道庭法箓规则.txt`。

────────────────────────────────────
一.1 道基类型
────────────────────────────────────

道基类型由修士当前修炼的功法决定，每本功法的首篇锁定唯一道基类型。
道基一旦凝聚即「固化」——废功重修后道基类型不变，金丹需重新凝结。

功法示例 → 道基类型：
- 含弘光大典 → 【坤德】：肉身防御+10%，防御姿态额外减免5%伤害
- 南华阐衍典 → 【自生】：每回合未受击获得独化印记（每层神魂攻击+5%）
- 白屋青云录 → 【寒门】：每习得新术法+1%暴击率，初始灵力-20%
- 心无性有法 → 【无知之知】：神识强度+5，神识高于目标时命中率+20%
（完整列表见各功法文件首篇章的道基字段）

────────────────────────────────────
一.2 道基品级
────────────────────────────────────

道基生成时不仅有类型，还有品级（天、地、玄、黄四品，天品最高，黄品最低）。
若凝聚值过低则无法生成道基（无道基）。
品级决定道基被动效果的生效倍率：

┌──────────┬──────────┬──────────────────────────────┐
│ 道基品级 │ 效果倍率 │ 说明                         │
├──────────┼──────────┼──────────────────────────────┤
│ 天品     │ ×1.30    │ 天道之基，极其罕见           │
│ 地品     │ ×1.10    │ 上品根基，宗门真传水准       │
│ 玄品     │ ×1.00    │ 中品根基（标准）             │
│ 黄品     │ ×0.85    │ 下品根基，勉强可用           │
│ 无道基   │ —        │ 凝聚失败，无被动效果         │
└──────────┴──────────┴──────────────────────────────┘

效果倍率 = 道基效果中的各项数值 × 对应倍率。
例：【坤德】玄品 → 肉身防御+10%×1.00=+10%；天品 → +10%×1.30=+13%；
    黄品 → +10%×0.85=+8.5%（向下取整为8%）；无道基 → +0%。

v3.5 注：道基品级是道基自身品质的标尺，不再直接映射金丹品级上限。
        道基品级影响紫府神通的基础强度与紫府府位的先天亲和度。

────────────────────────────────────
一.3 道基凝聚值（品级判定公式）
────────────────────────────────────

道基品级由「道基凝聚值」落入的区间决定：

  道基凝聚值 = 灵根基数 + 功法修正 + 灵力超额修正 + 随机骰 + 天材地宝加成

各因子说明：

① 灵根基数（角色先天资质）：
┌──────────┬──────┐
│ 灵根品级 │ 基数 │
├──────────┼──────┤
│ 凡品     │  10  │
│ 下品     │  20  │
│ 中品     │  30  │
│ 上品     │  40  │
│ 极品     │  50  │
└──────────┴──────┘
多灵根取最高品级计算，不叠加。

② 功法修正（当前功法的品级）：
┌──────────┬──────┐
│ 功法品级 │ 修正 │
├──────────┼──────┤
│ 凡品     │   0  │
│ 下品     │   5  │
│ 中品     │  10  │
│ 上品     │  15  │
│ 极品     │  20  │
└──────────┴──────┘

③ 灵力超额修正（突破时的积蓄溢出）：
  修正 = (突破时有效灵力 − 100) ÷ 50
  即每超出筑基门槛 50 点有效灵力，凝聚值 +1（向下取整）。
  例：以 300 有效灵力突破 → (300−100)/50=4，修正 +4
      以 1000 有效灵力突破 → 修正 +18

④ 随机骰（核心随机性来源）：
  1d30 —— 在 1~30 区间内均匀随机。
  每次道基生成时独立骰一次，不可重骰。

⑤ 天材地宝加成：
  筑基丹/道基丹等可固定增加凝聚值。
  具体数值见丹药体系（TBD）。

一.4 道基品级区间判定
────────────────────────────────────

┌──────────┬────────────────┐
│ 道基品级 │ 凝聚值区间     │
├──────────┼────────────────┤
│ 天品     │ ≥ 80           │
│ 地品     │ 60 ~ 79        │
│ 玄品     │ 40 ~ 59        │
│ 黄品     │ 20 ~ 39        │
│ 无道基   │ ＜ 20           │
└──────────┴────────────────┘

        该映射关系已随金丹九品制取消而废止。道基品级现仅影响紫府神通强度与府位亲和度。

二、紫府 —— 筑基后半段的质变（紫府初开解锁）
═══════════════════════════════════════

紫府不是独立大境界，而是筑基后半段的显示包装与质变状态。
紫府初开后，修士体内开辟五府，承载本命术法候选、紫府神通与成丹根基。

  - 不同 Build 主修二到三府，不要求五府均衡。

  - 每府有独立的开启条件与成长阶段，具体见各门派/功法设计。

────────────────────────────────────
二.2 本命术法候选
────────────────────────────────────

本命术法候选是筑基后半段出现的、可升格为紫府神通（进而参与丹相形成）的术法种子位。
与金丹期才突然决定本命神通的跳变节奏不同，候选术法的选择与培养贯穿筑基后半段。

候选数量与时机：
  - 筑基中期：出现第 1 个本命术法候选
  - 紫府初开：候选槽位增至 2 个
  - 紫府圆满：候选槽位最多 3 个

重选规则：
  - 可高成本重选（消耗特定丹药/灵材/时间）
  - 候选术法升格为紫府神通后固化为金丹资粮，不可再替换

候选术法需覆盖府位：
  - 本命术法候选应尽量覆盖修士主修的府位方向
  - 候选术法的升格方向与紫府府位亲和度决定紫府神通强度

────────────────────────────────────
二.3 紫府神通
────────────────────────────────────

紫府神通是修士在筑基期将本命术法候选进一步锤炼后，植入紫府府位的核心神通。
紫府神通与通用神通不同——它是成丹的个人资粮，参与金丹丹相的形成，并决定与目标席位、丹名和丹性的适配方向。

紫府神通与府位的关系：
  - 每道紫府神通绑定一个府位（可多道同府，但同府加成递减）
  - 府位的成长程度决定对应紫府神通的最终强度
  - 覆盖府位越多 → 位格适配面越广，但单府深度越浅（Build 取舍）
  - 具体数量、覆盖和闭环阈值由 TQ-015C 以 BattleSim 验证后锁定；当前不得以固定数量直接决定席位或主枢数量。

席位常设规则：
  - 每一具体元婴分支天然固定源、化、界三席；三席并列分工，不设高低位。
  - 敕封是对具体席位授予的使用权或临时承位方式，不产生第四种位格。
  - 暂寄是未稳固占据席位时的中转状态，不是坏档或永久惩罚。
  - 各席位的唯一世界变量、对象、边界、代价与协同关系，以《元婴锚点与金丹位格矩阵》为唯一事实源。

────────────────────────────────────
三.3 成丹条件与席位承接判定
────────────────────────────────────

步骤一：紫府神通与丹相资格审查
  检视修士的紫府神通、府位覆盖、道基契合与丹材准备：
    - 紫府神通必须绑定已开发的紫府府位。
    - 其覆盖和闭环影响丹相与目标席位的适配方向，不直接赋予席位效果。
    - 成丹所需数量、覆盖度、闭环和道基契合阈值由 TQ-015C 以 BattleSim 验证后锁定。

步骤二：成丹判定值计算
  成丹判定值的输入为灵根基数、道基品级修正、府位完成度、紫府神通强度、丹材加成与随机骰。

  成丹判定值用于回答：
    - 能否成丹。
    - 金丹是否稳固。
    - 是否具备承接目标源/化/界席位的基础。

  具体公式、阈值和夺取规则尚未锁定，由 TQ-015C 依据矩阵的唯一世界变量、作用对象、边界、代价与 BattleSim 结果迁移。

步骤三：席位竞争
  若目标源/化/界席位已被占据，必须选择夺取、继承、敕封、暂寄或自辟完整源化界组之一。
  竞争不能只比较单一成丹判定值；还须满足该席位在矩阵中规定的对象、边界与代价。

────────────────────────────────────
三.5 丹相、丹枢与丹相主枢
────────────────────────────────────

丹相是目标席位与占据状态、丹名、丹性、紫府神通统合生成的金丹能力总称。目标席位的世界变量、对象、边界和代价以《元婴锚点与金丹位格效果矩阵》为唯一事实源。

丹枢是该席位允许的个性化接口，只能调整媒介、偏向对象、代价分配、丹域景象、战斗表现和宗门叙事。丹枢不得改写矩阵定义的世界变量、边界和不可替代项。

丹相主枢是兼容紫府神通在丹相中的战斗招牌表达；辅枢是其余兼容紫府神通的被动、触发、资源循环、抗性、范围或代价支撑。

暂寄状态不生成丹相主枢，只保留不完整丹相与辅枢残影。丹相主枢/辅枢的数量、槽位占用、资源消耗和成长数值由 TQ-015C/TQ-013C 以 BattleSim 与运行时迁移共同锁定。

“本命神通”可保留为 UI 或叙事旧称，但不再作为系统字段或独立数量规则。

────────────────────────────────────
三.6 丹器显化
────────────────────────────────────

丹器显化是部分丹相的可选外显形态，不是所有金丹的必备系统。它可以是丹剑、法箓、法坛、丹炉、令旗、兵符、战鼓或阵图，也可以是梦界、魂灯、因果线等非实体形态。

丹器显化必须服从目标席位的矩阵边界和丹枢接口；它不能单独提供超出席位允许范围的世界效果。

以下境界特性保留为世界设定与 NPC 能力参考，
当前版本不作为玩家必须支持的系统。化神是世界最高境界。

────────────────────────────────────
A. 元婴期 —— 元婴、元婴出窍
────────────────────────────────────

元婴：碎丹成婴，修士新生，大幅度提升灵力值上限。
元婴出窍：元婴脱离肉身独立出击。
  - 肉身防御降至 0（元婴无实体），神魂防御保持不变
  - 反应速度大幅提升（×2）
  - 可直接无视地形瞬移
  - 神魂攻击获得 +30% 加成
  - 元婴被击碎则角色死亡

当前版本用途：NPC 宗门老祖、席位敕封者。

────────────────────────────────────
B. 化神期 —— 元神、第二化身
────────────────────────────────────

化神：掌握五行、阴阳、宇宙、五蕴、因果之一的根本法则。
  - 每位化神只能统御一系根本法则，不得以化神身份取得全法则全能。
  - 元婴掌握根本法则下的一条分支；金丹占据该分支下的具体位格。

当前版本用途：传说级 NPC、上古修士与世界法则锚点。
