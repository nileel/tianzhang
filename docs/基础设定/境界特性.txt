一、筑基期 —— 道基（筑基初期解锁）
═══════════════════════════════════════

太一道庭专属例外：太一道庭修士筑基后不凝聚通用道基，而是"初授法箓"。
法箓承担道基的根基、品级、被动效果和后续升格职责。其他门派仍按本章
通用道基规则执行。详见 `docs/角色养成/太一道庭法箓规则.txt`。

────────────────────────────────────
一.1 道基类型
────────────────────────────────────

道基类型由修士当前修炼的功法决定，每本功法的首篇锁定唯一道基类型。
道基一旦凝聚即「固化」——废功重修后道基类型不变，金丹需重新凝结。

功法示例 → 道基类型：
- 含弘光大典 → 【坤德】：肉身防御+10%，防御姿态额外减免5%伤害
- 南华阐衍典 → 【自生】：每回合未受击获得独化印记（每层神魂攻击+5%）
- 白屋青云录 → 【寒门】：每习得新术法+1%暴击率，初始灵力-20%
- 心无性有法 → 【无知之知】：神识强度+5，神识高于目标时命中率+20%
（完整列表见各功法文件首篇章的道基字段）

────────────────────────────────────
一.2 道基品级
────────────────────────────────────

道基生成时不仅有类型，还有品级（天、地、玄、黄四品，天品最高，黄品最低）。
若凝聚值过低则无法生成道基（无道基）。
品级决定道基被动效果的生效倍率：

┌──────────┬──────────┬──────────────────────────────┐
│ 道基品级 │ 效果倍率 │ 说明                         │
├──────────┼──────────┼──────────────────────────────┤
│ 天品     │ ×1.30    │ 天道之基，极其罕见           │
│ 地品     │ ×1.10    │ 上品根基，宗门真传水准       │
│ 玄品     │ ×1.00    │ 中品根基（标准）             │
│ 黄品     │ ×0.85    │ 下品根基，勉强可用           │
│ 无道基   │ —        │ 凝聚失败，无被动效果         │
└──────────┴──────────┴──────────────────────────────┘

效果倍率 = 道基效果中的各项数值 × 对应倍率。
例：【坤德】玄品 → 肉身防御+10%×1.00=+10%；天品 → +10%×1.30=+13%；
    黄品 → +10%×0.85=+8.5%（向下取整为8%）；无道基 → +0%。

v3.5 注：道基品级是道基自身品质的标尺，不再直接映射金丹品级上限。
        道基品级影响紫府神通的基础强度与紫府府位的先天亲和度。

────────────────────────────────────
一.3 道基凝聚值（品级判定公式）
────────────────────────────────────

道基品级由「道基凝聚值」落入的区间决定：

  道基凝聚值 = 灵根基数 + 功法修正 + 灵力超额修正 + 随机骰 + 天材地宝加成

各因子说明：

① 灵根基数（角色先天资质）：
┌──────────┬──────┐
│ 灵根品级 │ 基数 │
├──────────┼──────┤
│ 凡品     │  10  │
│ 下品     │  20  │
│ 中品     │  30  │
│ 上品     │  40  │
│ 极品     │  50  │
└──────────┴──────┘
多灵根取最高品级计算，不叠加。

② 功法修正（当前功法的品级）：
┌──────────┬──────┐
│ 功法品级 │ 修正 │
├──────────┼──────┤
│ 凡品     │   0  │
│ 下品     │   5  │
│ 中品     │  10  │
│ 上品     │  15  │
│ 极品     │  20  │
└──────────┴──────┘

③ 灵力超额修正（突破时的积蓄溢出）：
  修正 = (突破时有效灵力 − 100) ÷ 50
  即每超出筑基门槛 50 点有效灵力，凝聚值 +1（向下取整）。
  例：以 300 有效灵力突破 → (300−100)/50=4，修正 +4
      以 1000 有效灵力突破 → 修正 +18

④ 随机骰（核心随机性来源）：
  1d30 —— 在 1~30 区间内均匀随机。
  每次道基生成时独立骰一次，不可重骰。

⑤ 天材地宝加成：
  筑基丹/道基丹等可固定增加凝聚值。
  具体数值见丹药体系（TBD）。

────────────────────────────────────
一.4 道基品级区间判定
────────────────────────────────────

┌──────────┬────────────────┐
│ 道基品级 │ 凝聚值区间     │
├──────────┼────────────────┤
│ 天品     │ ≥ 80           │
│ 地品     │ 60 ~ 79        │
│ 玄品     │ 40 ~ 59        │
│ 黄品     │ 20 ~ 39        │
│ 无道基   │ ＜ 20           │
└──────────┴────────────────┘

v3.5 注：旧版曾将道基品级直接映射为金丹九品上限（天品→一至三品、地品→一至五品等）。
        该映射关系已随金丹九品制取消而废止。道基品级现仅影响紫府神通强度与府位亲和度。


═══════════════════════════════════════
二、紫府 —— 筑基后半段的质变（紫府初开解锁）
═══════════════════════════════════════

紫府不是独立大境界，而是筑基后半段的显示包装与质变状态。
紫府初开后，修士体内开辟五府，承载本命术法候选、紫府神通与成丹根基。

────────────────────────────────────
二.1 紫府五府
────────────────────────────────────

┌──────────┬──────────────────────────────────────────────┐
│ 府位     │ 管辖领域                                     │
├──────────┼──────────────────────────────────────────────┤
│ 命府     │ 生命、根骨、肉身、防御、恢复                 │
│ 魂府     │ 魂魄、神魂攻击、魂盾、心魔、梦境             │
│ 识府     │ 神识、侦察、命中、预判、控制、阵法           │
│ 气府     │ 灵力、术法循环、符箓、丹火、五行转化         │
│ 运府     │ 气运、因果、暴击、闪避、奇遇、劫数           │
└──────────┴──────────────────────────────────────────────┘

府位成长规则：
  - 不同 Build 主修二到三府，不要求五府均衡。
  - 紫府成长优先来自事件、资源、门派试炼、地脉、灵眼、符诏、雷池、梦种、
    强敌和心魔等目标，不做单一经验条。
  - 每府有独立的开启条件与成长阶段，具体见各门派/功法设计。

────────────────────────────────────
二.2 本命术法候选
────────────────────────────────────

本命术法候选是筑基后半段出现的、可升格为紫府神通（进而参与丹相形成）的术法种子位。
与金丹期才突然决定本命神通的跳变节奏不同，候选术法的选择与培养贯穿筑基后半段。

候选数量与时机：
  - 筑基中期：出现第 1 个本命术法候选
  - 紫府初开：候选槽位增至 2 个
  - 紫府圆满：候选槽位最多 3 个

重选规则：
  - 可高成本重选（消耗特定丹药/灵材/时间）
  - 候选术法升格为紫府神通后固化为金丹资粮，不可再替换

候选术法需覆盖府位：
  - 本命术法候选应尽量覆盖修士主修的府位方向
  - 候选术法的升格方向与紫府府位亲和度决定紫府神通强度

────────────────────────────────────
二.3 紫府神通
────────────────────────────────────

紫府神通是修士在筑基期将本命术法候选进一步锤炼后，植入紫府府位的核心神通。
紫府神通与通用神通不同——它是成丹的个人资粮，参与金丹丹相的形成，并决定与目标席位、丹名和丹性的适配方向。

紫府神通与府位的关系：
  - 每道紫府神通绑定一个府位（可多道同府，但同府加成递减）
  - 府位的成长程度决定对应紫府神通的最终强度
  - 覆盖府位越多 → 位格适配面越广，但单府深度越浅（Build 取舍）
  - 具体数量、覆盖和闭环阈值由 TQ-015C 以 BattleSim 验证后锁定；当前不得以固定数量直接决定席位或主枢数量。


═══════════════════════════════════════
三、金丹期 —— 道路／位格／装配／承载／丹枢核心
═══════════════════════════════════════

金丹不采用一至九品制，也不设计低配或无位格金丹。每个金丹必须属于十七道路之一，并以真实位格、装配效果、占据状态、金丹名称、丹性、紫府神通承载和不可变丹枢核心共同表达。

────────────────────────────────────
三.1 结构对象
────────────────────────────────────

| 对象 | 作用 |
|---|---|
| `road_id` | 决定道路变量、不可越界项和三项基础效果候选 |
| `seatInstanceId` / `positionType` | 记录真实源位、化位或界位及占据关系 |
| `effect_id` | 记录该真实位格当前装配的一项效果 |
| 占据状态 | 记录夺取、继承、敕封、暂寄或自辟等来源／状态，不是新位格 |
| 金丹名称与丹性 | 分别表达所属世界规则和个人长期回响 |
| `SeatCarrierBinding` | 记录每个位格的主承载、辅助神通、府位与兼容档案 |
| `JindanCoreBinding` | 记录唯一不可更换的丹枢核心 |

────────────────────────────────────
三.2 三种真实位格与三阶段
────────────────────────────────────

| 位格 | 固定职责 |
|---|---|
| 源位 | 普通距离内具体对象、具体操作与真实媒介 |
| 化位 | 局部阵域的一条固定条件筛选与固定转化 |
| 界位 | 广域粗阵营选择与一条较弱固定规则 |

1. 每一道路固定一个源位、一个化位、一个界位定义，不开放同类位格无限扩展。
2. 金丹初期取得第一种真实位格，中期取得第二种，圆满取得第三种；取得顺序自由。
3. 三阶段共享 `realmRuleTier = JINDAN`。阶段只增加一／二／三个真实位格、装配槽、组合、资源与承载预算，不提供自动压制或隐藏平局权重。
4. 每个真实位格同一时间只装配本道路三项候选中的一项。相同 `effect_id` 可以纵向嵌套；不同效果只有命中显式 `comboProfileId` 才能组合。
5. 各道路、对象、操作、版本与边界以《元婴锚点与金丹位格矩阵》为唯一效果事实源；装配与冲突以《金丹基础效果装配与冲突规则》为准。

────────────────────────────────────
三.3 成丹、承载与核心绑定
────────────────────────────────────

1. 成丹审查继续读取灵根、道基、府位、紫府神通与丹材；具体公式、数量、覆盖和闭环阈值由后续数值任务与 BattleSim 锁定。
2. 每个 `STABLE` 位格必须恰好有一个独立 `primaryCarrierAbilityInstanceId`。同一紫府神通实例最多主承载一位；初期、中期、圆满分别需要一、二、三项互不重复的主承载实例。
3. 同一紫府神通可主承载一位并辅助其他位格，也可辅助多位，但辅助只提供档案显式开放的媒介、触发、代价改道或组合接口。
4. 主承载与全部辅助共享 `abilityInstanceId` 的唯一效果、现实支点、充能、冷却、次数、资源和代价账本；多条引用不得复制贡献。
5. 缺少独立主承载的位格只能记为 `TEMPORARY`，不能计入稳定阶段结构、嵌套、组合、山河常驻或晋升资格。
6. 成丹时建立唯一 `JindanCoreBinding`。丹枢核心成丹后不可换绑、移植、顶替、拆分、复制或在重铸中重选。

────────────────────────────────────
三.4 安全重铸、失稳与丹毁
────────────────────────────────────

1. 紫府神通实例永久固化，但位格主承载或 `boundMansionSlotId` 可在安全洞府原子重铸；战斗中禁止。
2. 重铸必须保持真实位格占据和原 `JindanCoreBinding` 不变，先验证新神通兼容、主承载唯一性、府位、资源和受影响实例，再结束旧绑定、支付并建立新绑定。失败保留旧绑定且不扣费。
3. 普通冷却、充能不足或主动效果暂不可用不等于主承载失效。只有紫府接口被封禁、府位破坏、绑定合法切断或神通永久失去时，绑定转为 `UNSTABLE`；此时不能新展开效果，已有实例按后备或结束规则处理。
4. `UNSTABLE`、资源耗尽、效果换装、持续实例结束和暂时权限失效都不等于真实位格丧失。
5. 稳定金丹任一真实位格被剥离、毁坏或转移，或不可变核心被毁坏／切断，立即原子触发丹毁死亡；不回退阶段、不缺位存活、不事后补绑。该历史不可由状态回溯或普通复活改写。

────────────────────────────────────
三.5 占据、元婴升格与丹相表达
────────────────────────────────────

1. 夺取、继承、敕封、暂寄、自辟描述位格使用权来源或过渡状态，不创造第四位格。自辟元婴另按《自辟元婴方向设定》及专门晋升事务处理，不能在普通金丹竞争中扩写新同类位格。
2. 夺位必须把原持有者位格丧失与死亡原子提交，新持有者只在死亡记录关闭后建立稳定占据；失败保留原状态。
3. 合法晋升既有道路元婴时，三个位格、核心与承载只在唯一 `YuanyingRoadAnchor` 建立成功后整体升格；失败保留原金丹，不触发丹毁死亡。
4. 丹相是道路、位格、装配效果、金丹名称、丹性、主／辅承载和丹枢接口的战斗表达总称，不是额外位格或效果槽。
5. 丹枢只能在已有权限内调整媒介、偏向对象、代价分配、丹域景象、战斗表现和宗门叙事，不得改变量边界、装配数量或核心绑定。
6. “本命神通”可保留为 UI 或叙事旧称，但不作为独立系统字段或固定数量规则。

────────────────────────────────────
三.6 丹器显化
────────────────────────────────────

丹器显化是部分丹相的可选外显形态，不是所有金丹的必备系统。它可以是丹剑、法箓、法坛、丹炉、令旗、兵符、战鼓或阵图，也可以是梦界、魂灯、因果线等非实体形态。

丹器显化必须服从目标席位的矩阵边界和丹枢接口；它不能单独提供超出席位允许范围的世界效果。

附录：高阶境界特性（NPC/世界背景）
═══════════════════════════════════════

以下境界特性保留为世界设定与 NPC 能力参考，
当前版本不作为玩家必须支持的系统。化神是世界最高境界。

────────────────────────────────────
A. 元婴期 —— 元婴、元婴出窍
────────────────────────────────────

元婴：没有常规模板或低配版本。每一个元婴都是唯一高位位格；任一具体元婴位格同一时期只能有一个持有者。碎丹成婴不是单纯数值升境，而是承接或自辟一条唯一高位秩序。
元婴出窍：元婴脱离肉身独立出击。
  - 肉身防御降至 0（元婴无实体），神魂防御保持不变
  - 反应速度大幅提升（×2）
  - 可直接无视地形瞬移
  - 神魂攻击获得 +30% 加成
  - 元婴被击碎则角色死亡

当前版本用途：NPC 宗门老祖、席位敕封者。

────────────────────────────────────
B. 化神期 —— 元神、第二化身
────────────────────────────────────

化神：掌握五行、阴阳、宇宙、五蕴、因果之一的根本法则。
  - 每位化神只能统御一系根本法则，不得以化神身份取得全法则全能。
  - 元婴掌握根本法则下的一条分支；金丹占据该分支下的具体位格。

当前版本用途：传说级 NPC、上古修士与世界法则锚点。
