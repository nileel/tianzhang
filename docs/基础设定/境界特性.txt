【境界特性】

═══════════════════════════════════════
一、筑基期 —— 道基（筑基初阶解锁）
═══════════════════════════════════════

────────────────────────────────────
一.1 道基类型
────────────────────────────────────

道基类型由修士当前修炼的功法决定，每本功法的首篇锁定唯一道基类型。
道基一旦凝聚即「固化」——废功重修后道基类型不变，金丹需重新凝结。

功法示例 → 道基类型：
- 含弘光大典 → 【坤德】：肉身防御+10%，防御姿态额外减免5%伤害
- 南华阐衍典 → 【自生】：每回合未受击获得独化印记（每层神魂攻击+5%）
- 白屋青云录 → 【寒门】：每习得新术法+1%暴击率，初始灵力-20%
- 心无性有法 → 【无知之知】：神识强度+5，神识高于目标时命中率+20%
（完整列表见各功法文件首篇章的道基字段）

────────────────────────────────────
一.2 道基品级
────────────────────────────────────

道基生成时不仅有类型，还有品级（天、地、玄、黄四品，天品最高，黄品最低）。
若凝聚值过低则无法生成道基（无道基）。
品级决定道基被动效果的生效倍率：

┌──────────┬──────────┬──────────────────────────────┐
│ 道基品级 │ 效果倍率 │ 说明                         │
├──────────┼──────────┼──────────────────────────────┤
│ 天品     │ ×1.30    │ 天道之基，极其罕见           │
│ 地品     │ ×1.10    │ 上品根基，宗门真传水准       │
│ 玄品     │ ×1.00    │ 中品根基（标准）             │
│ 黄品     │ ×0.85    │ 下品根基，勉强可用           │
│ 无道基   │ —        │ 凝聚失败，无被动效果         │
└──────────┴──────────┴──────────────────────────────┘

效果倍率 = 道基效果中的各项数值 × 对应倍率。
例：【坤德】玄品 → 肉身防御+10%×1.00=+10%；天品 → +10%×1.30=+13%；
    黄品 → +10%×0.85=+8.5%（向下取整为8%）；无道基 → +0%。

────────────────────────────────────
一.3 道基凝聚值（品级判定公式）
────────────────────────────────────

道基品级由「道基凝聚值」落入的区间决定：

  道基凝聚值 = 灵根基数 + 功法修正 + 灵力超额修正 + 随机骰 + 天材地宝加成

各因子说明：

① 灵根基数（角色先天资质）：
┌──────────┬──────┐
│ 灵根品级 │ 基数 │
├──────────┼──────┤
│ 凡品     │  10  │
│ 下品     │  20  │
│ 中品     │  30  │
│ 上品     │  40  │
│ 极品     │  50  │
└──────────┴──────┘
多灵根取最高品级计算，不叠加。

② 功法修正（当前功法的品级）：
┌──────────┬──────┐
│ 功法品级 │ 修正 │
├──────────┼──────┤
│ 凡品     │   0  │
│ 下品     │   5  │
│ 中品     │  10  │
│ 上品     │  15  │
│ 极品     │  20  │
└──────────┴──────┘

③ 灵力超额修正（突破时的积蓄溢出）：
  修正 = ?(突破时有效灵力 ? 100) ÷ 50?
  即每超出筑基门槛 50 点有效灵力，凝聚值 +1（向下取整）。
  例：以 300 有效灵力突破 → (300?100)/50=4，修正 +4
      以 1000 有效灵力突破 → 修正 +18

④ 随机骰（核心随机性来源）：
  1d30 —— 在 1~30 区间内均匀随机。
  每次道基生成时独立骰一次，不可重骰。

⑤ 天材地宝加成（可选，详见一.4）：
  突破时服用天材地宝可获得固定加成值。

────────────────────────────────────
品级判定表（凝聚值 → 品级）：

┌──────────────┬──────────┐
│ 道基凝聚值   │ 道基品级 │
├──────────────┼──────────┤
│ ≥ 80         │ 天品     │
│ 50 – 79      │ 地品     │
│ 25 – 49      │ 玄品     │
│ 15 – 24      │ 黄品     │
│ ＜ 15        │ 无道基   │
└──────────────┴──────────┘

────────────────────────────────────
一.3.1 功法品级与道基上下限
────────────────────────────────────

功法品级不仅影响凝聚值修正，还直接限定道基品级的可达成范围。
凝聚值判定出暂定品级后，再按功法品级钳制到上下限内：

┌──────────┬──────────┬──────────┬──────────────────────────┐
│ 功法品级 │ 道基上限 │ 道基下限 │ 说明                     │
├──────────┼──────────┼──────────┼──────────────────────────┤
│ 凡品     │ 黄品     │ 无道基   │ 根基浅薄，可能无法凝聚   │
│ 下品     │ 玄品     │ 黄品     │ 勉强及格，上限玄品       │
│ 中品     │ 地品     │ 黄品     │ 中规中矩，天品无望       │
│ 上品     │ 地品     │ 玄品     │ 稳扎稳打                 │
│ 极品     │ 天品     │ 地品     │ 顶格功法，无短板         │
└──────────┴──────────┴──────────┴──────────────────────────┘

钳制规则：暂定品级 < 下限 → 取下限；暂定品级 > 上限 → 取上限。
「无道基」不可被下限覆盖（凡品功法可能真的没有道基）。
天材地宝仍有效（将暂定品级推向更高），但不可突破功法上限。

────────────────────────────────────
典型场景概率分析（含上下限钳制）：
────────────────────────────────────

（注：下列场景中，"→" 前为凝聚值范围，"→" 后为钳制后的最终品级分布）

【情景A】中品灵根 + 中品功法（上限地品/下限黄品）+ 刚好100灵力, 无天材地宝
  凝聚值 = 30 + 10 + 0 + 1d30 + 0 = 41~70
  暂定：玄品 30% | 地品 70%
  → 钳制后：玄品 30% | 地品 70%（均在范围内）

【情景B】上品灵根 + 上品功法（上限地品/下限玄品）+ 400灵力, 无天材地宝
  凝聚值 = 40 + 15 + 6 + 1d30 + 0 = 62~91
  暂定：地品 60% | 天品 40%
  → 钳制后：地品 100%（上限仅地品，天品全压回）

【情景C】极品灵根 + 极品功法（上限天品/下限地品）+ 1000灵力, 无天材地宝
  凝聚值 = 50 + 20 + 18 + 1d30 + 0 = 89~118
  → 天品 100%

【情景D】下品灵根 + 下品功法（上限玄品/下限黄品）+ 刚好100灵力, 极品天材地宝
  凝聚值 = 20 + 5 + 0 + 1d30 + 40 = 66~95
  暂定：天品 46.7% | 地品 53.3%
  → 钳制后：玄品 100%（上限仅玄品）

【情景E】凡品灵根 + 凡品功法（上限黄品/下限无道基）+ 刚好100灵力, 无天材地宝
  凝聚值 = 10 + 0 + 0 + 1d30 + 0 = 11~40
  暂定：无道基 13.3% | 黄品 33.3% | 玄品 53.3%
  → 钳制后：无道基 13.3% | 黄品 86.7%（玄品触及上限，压回黄品）
  （凡品功法凝聚道基本身即有 13.3% 失败风险）

────────────────────────────────────
一.4 天材地宝（道基凝聚用）
────────────────────────────────────

天材地宝在道基凝聚时服用，品质固定不浮动，效果为凝聚值加成。
品质越高，低品级道基概率越低直至为 0。

┌──────────────┬──────────┬──────────────────────────────────┐
│ 天材地宝     │ 品质     │ 凝聚值加成 + 效果说明            │
├──────────────┼──────────┼──────────────────────────────────┤
│ 凝基草       │ 下品     │ +10，标准入门草药               │
│ 筑基丹       │ 下品     │ +10                            │
│ 地髓灵乳     │ 中品     │ +20，黄品概率→0%               │
│ 上品筑基丹   │ 中品     │ +20                            │
│ 天脉凝基液   │ 上品     │ +30，保底玄品                  │
│ 极品筑基丹   │ 上品     │ +30                            │
│ 道基灵胎     │ 极品     │ +40，保底地品（玄~黄品→0%）    │
│ 九转筑基丹   │ 极品     │ +40                            │
│ 五行灵髓     │ 极品     │ +40（仅功法属性相生时可服用）   │
└──────────────┴──────────┴──────────────────────────────────┘

说明：
- 同一角色每次突破仅可服用一种天材地宝，不可叠加。
- 天材地宝不改变道基类型（类型仍由功法决定），仅影响品级。
- 天材地宝品质固定，没有浮动品级（如「凝基草永远是下品」）。
- 品质越高的天材地宝越稀有，极品级通常只能通过洞天探险、
  击杀高阶妖兽或完成宗门贡献任务获得。
- 天材地宝可将凝聚值推高，但最终品级仍受功法上下限钳制。

────────────────────────────────────
一.5 道基品级对金丹的影响
────────────────────────────────────

道基是金丹的根基，道基品级直接限制可凝结金丹的上限品级：

┌────────────────────────────────────────────────────┐
│ 金丹最高可达成品级 ≤ 道基品级映射值                │
│                                                    │
│ 天品道基 → 最高可凝结三品金丹                      │
│ 地品道基 → 最高可凝结五品金丹                      │
│ 玄品道基 → 最高可凝结七品金丹                      │
│ 黄品道基 → 最高可凝结九品金丹                      │
│ 无道基   → 无法凝结金丹（须先以天材地宝重凝道基）  │
└────────────────────────────────────────────────────┘

此外，若道基品级低于目标金丹品级，金丹凝练灵力消耗 ×1.5。

道基类型（功法决定） + 道基品级 → 共同决定金丹类型
（详见二、金丹期设定）

═══════════════════════════════════════
二、金丹期 —— 金丹、本命神通、本命法宝（金丹初阶解锁）

────────────────────────────────────
二.1 金丹品级概述
────────────────────────────────────

金丹以道基为核心、消耗灵力凝炼而成。品级从一至九品，一品最高、九品最低。
金丹品级由「金丹凝聚值」统一决定，凝聚值同时判定成功率与品级高低。
道基品级决定金丹品级的硬性上限：

  天品道基→最高一品 | 地品道基→最高三品 | 玄品道基→最高五品 | 黄品道基→最高八品
  无道基→无法凝结金丹

────────────────────────────────────
二.2 金丹凝聚值公式
────────────────────────────────────

金丹凝聚值 = 道基延续分 + 灵根基数 + 灵力投入分 + 随机骰(1d30) + 天材地宝

各因子说明：

① 道基延续分：
  天品=60 | 地品=40 | 玄品=25 | 黄品=10
  道基作为金丹核心，其品质直接影响凝聚初值。

② 灵根基数：
  凡品=10 | 下品=20 | 中品=30 | 上品=40 | 极品=50
  灵根为天地灵力之根，品级越高根基越厚。

③ 灵力投入分（分段函数）：
  突破时投入有效灵力≥1200为门槛。
  投入≤2000灵力时：每超出门槛100灵力 +3分
  投入>2000灵力时：超出2000部分每100灵力 +1分

  例：
    投入1200灵力（九品门槛）→ (1200?1200)/100×3 = 0分
    投入2000灵力 → (2000?1200)/100×3 = 24分
    投入3500灵力 → 24 + (3500?2000)/100×1 = 39分
    投入5000灵力 → 24 + (5000?2000)/100×1 = 54分

④ 随机骰：
  1d30 —— 在1~30区间内均匀随机。
  每次金丹凝结时独立骰一次，不可重骰。

⑤ 天材地宝加成（突破时服用）：
  下品+5 | 中品+10 | 上品+20 | 极品+30

────────────────────────────────────
二.3 成功率与品级双重判定
────────────────────────────────────

同一个凝聚值同时决定「能否成功」与「品级高低」。

成功率公式：
  成功率(%) = 30% + (凝聚值?15)×0.5% + 悟性修正 + 资质修正 + 气运修正
  悟性修正 = +(悟性?1.0)×50%
  资质修正 = +资质×0.8%
  气运修正 = +气运×0.3%
  上限95%，下限20%

品级判定表（凝聚值 → 金丹品级，受道基硬上限钳制）：

┌──────────────┬──────────┬──────────────────────┐
│ 凝聚值       │ 金丹品级 │ 成功率（不计修正）    │
├──────────────┼──────────┼──────────────────────┤
│ ≥120         │ 一品     │ 83%                  │
│ ≥105         │ 二品     │ 75%                  │
│ ≥90          │ 三品     │ 68%                  │
│ ≥75          │ 四品     │ 60%                  │
│ ≥60          │ 五品     │ 53%                  │
│ ≥48          │ 六品     │ 47%                  │
│ ≥36          │ 七品     │ 41%                  │
│ ≥25          │ 八品     │ 35%                  │
│ ≥15          │ 九品     │ 30%                  │
│ <15          │ 凝结失败 │ —                    │
└──────────────┴──────────┴──────────────────────┘

道基硬上限钳制说明：
  若凝聚值达到一品门槛但道基仅为地品（上限三品），最终金丹仍为三品。
  多余凝聚值不产生额外收益，建议玩家根据自身道基合理规划灵力投入。

失败惩罚：
  灵力扣除10%~20%（当前有效灵力），退回筑基中阶（有效灵力≈400），
  道基保留。需重新积累灵力后再次冲击。

────────────────────────────────────
二.4 金丹品级效果
────────────────────────────────────

① MP上限倍率：
  凝结金丹后MP上限 = 境界基础MP × 金丹品级倍率 × 灵根修正

  一品×3.0 | 二品×2.5 | 三品×2.0 | 四品×1.7 | 五品×1.4
  六品×1.2 | 七品×1.0 | 八品×0.85 | 九品×0.70

  例：境界基础MP=1000，中品灵根(×1.0)
    一品金丹 → 3000有效灵力
    三品金丹 → 2000有效灵力
    九品金丹 → 700有效灵力

② 无灵力成长惩罚：
  金丹凝结后，各品级金丹的后续灵力增长速度完全一致。
  高品金丹的优势在起点而非成长速度。

③ 本命神通/法宝自由占用制：
  无槽位限制。每个本命神通/法宝各自声明灵力占用值，从总MP中直接扣除。
  术法/法宝越强，占用的灵力值越多。

  参考占用值（具体以各术法/法宝文件声明为准）：

  ┌──────────┬──────────┬──────────┐
  │ 品级     │ 神通占用 │ 法宝占用 │
  ├──────────┼──────────┼──────────┤
  │ 凡品     │ 200      │ 300      │
  │ 下品     │ 350      │ 500      │
  │ 中品     │ 500      │ 800      │
  │ 上品     │ 750      │ 1200     │
  │ 极品     │ 1000     │ 1800     │
  └──────────┴──────────┴──────────┘

④ 铭刻倾向：
  金丹类型匹配时，铭刻同属性术法/法宝的灵力占用 ?30%。
  （详见二.6金丹类型体系）

────────────────────────────────────
二.5 永久绑定规则
────────────────────────────────────

- 铭刻本命神通 / 绑定本命法宝后不可随意解除
- 解除占用必须消耗特殊道具

  解契丹（下品·稀有）：解除一道本命神通
  解契丹（中品·极稀有）：解除一道本命神通，返还术法秘卷
  碎禁符（下品·稀有）：解除一件本命法宝
  碎禁符（上品·极稀有）：解除一件本命法宝，法宝保留不毁
  涅槃丹（极品·传说）：解除全部本命神通与法宝，保留术法与法宝

- 解除后术法/法宝消失（除非道具说明保留），需重新获取
- 道基进化的免费本命神通不占用灵力，亦不可解除
- 金丹重凝时，原铭刻全部解除并销毁（解契丹/碎禁符无效）

────────────────────────────────────
二.6 金丹类型体系
────────────────────────────────────

金丹类型由功法主属性 + 灵根属性决定，与道基类型无关。
（道基已进化为免费本命神通，独立于金丹类型。）

类型决定规则：
  - 功法主属性与灵根属性相同 → 纯化金丹（被动加成×1.3）
  - 两者不同 → 以功法属性为主类型，灵根属性不产生额外影响
  - 天材地宝「五行灵髓」（极品）可在凝结时强制指定类型

每个金丹类型提供两种效果：

  ① 被动数值加成（随金丹品级缩放）
  ② 铭刻倾向：匹配属性术法/法宝的灵力占用 ?30%

金丹类型表：

┌──────────┬────────────────────┬──────────────────┐
│ 金丹类型 │ 被动加成           │ 铭刻倾向         │
├──────────┼────────────────────┼──────────────────┤
│ 金       │ 肉身攻击 +10%      │ 金属性术法/法宝  │
│ 木       │ 生命恢复 +15%      │ 木属性           │
│ 水       │ 灵力恢复 +15%      │ 水属性           │
│ 火       │ 暴击伤害 +15%      │ 火属性           │
│ 土       │ 肉身防御 +10%      │ 土属性           │
│ 风       │ 反应速度 +10%      │ 风属性           │
│ 雷       │ 暴击率 +8%         │ 雷属性           │
│ 冰       │ 敌方反应?10%(光环) │ 冰属性           │
│ 暗       │ 神魂攻击 +10%      │ 暗属性           │
│ 星       │ 神识强度 +15%      │ 星属性           │
│ 毒       │ 持续伤害 +20%      │ 毒属性           │
│ 混沌     │ 全属性 +5%         │ 兼容所有（无折扣）│
└──────────┴────────────────────┴──────────────────┘

被动加成随金丹品级缩放：

┌────┬────┬────┬────┬────┬────┬────┬────┬────┐
│一品│二品│三品│四品│五品│六品│七品│八品│九品│
├────┼────┼────┼────┼────┼────┼────┼────┼────┤
│×1.3│×1.2│×1.1│×1.0│×0.9│×0.8│×0.7│×0.6│×0.5│
└────┴────┴────┴────┴────┴────┴────┴────┴────┘

例：火金丹 + 一品 → 暴击伤害 +15%×1.3 = +19.5%
    火金丹 + 五品 → 暴击伤害 +15%×0.9 = +13.5%

类型变更：
  - 废功重修：金丹类型不变（金丹已固化），须重凝金丹方可改变
  - 金丹重凝：重新判定类型（基于新功法+灵根，或天材地宝覆盖）
  - 重凝时原铭刻全部解除并销毁

────────────────────────────────────
二.7 道基进化（免费本命神通）
────────────────────────────────────

凝结金丹时，道基自动转化为一道免费本命神通：

  - 不占用灵力值，不可解除
  - 效果固定，不受金丹品级影响
  - 品级 = 原道基品级，效果倍率沿用道基品级体系

道基品级倍率：
  天品×1.30 | 地品×1.10 | 玄品×1.00 | 黄品×0.85

示例：
  【坤德】道基(玄品) → 本命神通「坤德」
    肉身防御+10%×1.00=+10%，防御姿态额外减免5%伤害
  【坤德】道基(天品) → 本命神通「坤德」
    肉身防御+10%×1.30=+13%，防御姿态额外减免5%×1.30≈6.5%伤害
  【自生】道基(地品) → 本命神通「自生」
    每回合未受击获得独化印记（神魂攻击+5%/层）×1.10

═══════════════════════════════════════
三、元婴期 —— 元婴（元婴初阶解锁）
═══════════════════════════════════════

元婴：
元婴乃是修士度过天劫之后碎丹新生所化，代表着修士的新生，会再次大幅度提升修士的灵力值上限。

元婴出窍（主动能力）：
元婴可以脱离肉身独自出击。出窍后效果如下：
- 肉身防御降至0（元婴无实体），神魂防御保持不变
- 反应速度大幅提升（×2）
- 可直接无视地形瞬移到达目的地
- 肉身原地不动，无法控制
- 依托于肉身的术法和神通无法释放（拳法、剑术等物理技能不可用）
- 神魂类术法和本命神通仍可正常释放，且神魂攻击获得+30%加成
- 元婴受到攻击时直接扣除生命值，元婴被击碎则角色死亡

碎丹成婴时，本命神通与本命法宝都将随之提升品级。
元婴回归肉身时，重新获得完整的肉身防御和物理技能。

═══════════════════════════════════════
四、化神期 —— 元神、第二化身（化神初阶解锁）
═══════════════════════════════════════

元神：
元神是元婴的成熟形态，代表着修士神魂的完全独立。
- 元神出窍时不再强制肉身防御归零（元神已可引动天地之力护体）
- 元神出窍距离远大于元婴，可跨越整个战场
- 元神状态下神魂攻击+50%，神魂防御+30%
- 元神不灭则修士不死：肉身被毁后，元神可夺舍或重塑肉身（需消耗大量资源与时间）
- 元神被重创则神魂攻击、神魂防御永久下降，需漫长时间恢复

第二化身：
化神修士可分化元神，凝练出一具独立行动的化身。
- 化身拥有本体各项属性的60%（生命值、灵力值独立计算）
- 化身与本体共享神识强度（视野），但独立占据一个行动单位
- 化身被毁则本体神魂攻击-20%，需七七四十九日重新凝练
- 化身不可再分
- 战棋模式中，第二化身相当于多一个可控单位，极大增强战术灵活性

═══════════════════════════════════════
五、炼虚期 —— 领域（炼虚初阶解锁）
═══════════════════════════════════════

领域：
炼虚修士可将自身"道"外化为领域，覆盖战场一片区域。

领域展开效果：
- 领域内自身全属性（攻击/防御/反应速度）+30%
- 领域内敌方全属性-15%（同阶炼虚不受此减益）
- 领域内自身移动力翻倍
- 领域内神识强度覆盖全领域（无需视野线）
- 领域展开消耗灵力：每回合消耗最大灵力值的5%
- 领域范围为"以自身为中心，半径等于神识强度（格）"

领域碰撞：
- 两个炼虚修士的领域重叠时，境界系数较高者压制较低者
- 被压制方领域减益效果减半

领域类型由修士所修功法和道基决定，不同领域可能有额外特殊效果
（如：剑域→额外+暴击率、魂域→敌方神魂防御额外-10%等）。
