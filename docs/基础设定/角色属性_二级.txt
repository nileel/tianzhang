【角色属性（二级）】

二级属性共14项，分为四大类：战斗类（功法/装备/丹药提供）、恢复类（功法/装备提供）、成长类（资质/灵根决定）、气运类（气运决定）。

═══════════════════════════════════════
一、战斗类（7项）
═══════════════════════════════════════

闪避率：完全回避攻击的概率。实际闪避率 = 防守方闪避率 - 攻击方命中率（最低0%）。典型区间：0% ~ 50%。来源：功法篇章、装备、丹药。

命中率：抵消敌方闪避率。与闪避率直接对冲。典型区间：0% ~ 50%。来源：功法篇章、装备、丹药。

暴击率：触发暴击的概率。暴击时将使用暴击伤害倍率替代基础伤害倍率。典型区间：0% ~ 40%。来源：功法篇章、装备、丹药。

暴击伤害：暴击时的伤害倍率。基础值为150%。典型区间：150% ~ 300%。来源：功法篇章、装备、丹药。

物理抗性：最终物理伤害减免百分比。与伤害公式中的减伤因子相乘。典型区间：0% ~ 50%。来源：功法篇章、装备、丹药。

神魂抗性：最终神魂伤害减免百分比。与伤害公式中的减伤因子相乘。典型区间：0% ~ 50%。来源：功法篇章、装备、丹药。

格挡率：格挡物理攻击的概率。格挡成功后，伤害按格挡减伤率减免。典型区间：0% ~ 35%。来源：功法篇章、装备、丹药。说明：闪避判定先于格挡，二者不叠加。

格挡减伤率：格挡成功时减免的物理伤害百分比。典型区间：0% ~ 80%。来源：功法篇章、装备、丹药。

魂盾率：格挡神魂攻击的概率。魂盾成功后，伤害按魂盾减伤率减免。典型区间：0% ~ 35%。来源：功法篇章、装备、丹药。说明：闪避判定先于魂盾，二者不叠加。

魂盾减伤率：魂盾成功时减免的神魂伤害百分比。典型区间：0% ~ 80%。来源：功法篇章、装备、丹药。

═══════════════════════════════════════
二、恢复类（2项）
═══════════════════════════════════════

灵力恢复：每回合自动恢复的灵力值。占同阶灵力值上限的约1% ~ 4%/回合。来源：功法篇章、装备、丹药。

生命恢复：每回合自动恢复的生命值。占同阶生命值上限的约1.5% ~ 3%/回合。来源：功法篇章、装备、丹药。

各境界恢复属性大致区间：

┌──────────┬────────────────────┬────────────────────┐
│ 境界     │ 灵力恢复（每回合） │ 生命恢复（每回合） │
├──────────┼────────────────────┼────────────────────┤
│ 凡人     │ 0 ~ 1              │ 0 ~ 2              │
│ 练气     │ 1 ~ 5              │ 1 ~ 8              │
│ 筑基     │ 4 ~ 20             │ 5 ~ 35             │
│ 金丹     │ 15 ~ 80            │ 20 ~ 150           │
│ 元婴     │ 60 ~ 300           │ 80 ~ 500           │
│ 化神     │ 250 ~ 1,200        │ 400 ~ 2,000        │
│ 炼虚     │ 1,000 ~ 5,000      │ 1,500 ~ 8,000      │
└──────────┴────────────────────┴────────────────────┘

═══════════════════════════════════════
三、成长类（2项）
═══════════════════════════════════════

修炼速度：灵力值经验获取倍率。基础值由灵根品级决定，受资质加成。典型区间：×0.2 ~ ×6.0。来源：灵根品级 + 资质。

悟性：影响术法学习速度和境界突破成功率。术法学习时间 = 基础学习时间 ÷ 悟性系数。典型区间：×0.5 ~ ×3.0。来源：资质。

═══════════════════════════════════════
四、气运类（2项）
═══════════════════════════════════════

幸运值：决定宝物掉落率和事件初始成功率。来源：气运。可通过天材地宝临时提升。

魅力值：决定NPC初始好感度和好感度成长速度，影响交易折扣。高魅力可解锁隐藏剧情和特殊招募。来源：气运。
