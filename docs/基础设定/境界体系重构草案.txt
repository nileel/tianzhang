【境界体系重构草案】

状态：✅ 已审核（2026-06-18 Codex / gpt-5.5 审核通过）
用途：底层设定讨论草案。未替换 `修行境界.txt`、`境界特性.txt` 与数值表。

═══════════════════════════════════════════════════════════════
一、重构目标
═══════════════════════════════════════════════════════════════

本草案尝试将游戏主要内容从“多境界线性爬升”调整为“筑基长期经营、金丹世界位格稀缺”的结构。

核心目标：

1. 缩减玩家需要完整经历的大境界数量。
2. 拉大筑基与金丹之间的叙事、数值、社会地位差距。
3. 将最丰富的功法、术法、神通、宗门斗争、资源争夺与道途选择集中在筑基阶段。
4. 让金丹不只是属性升级，而是改变世界地位和势力格局的“占位”事件。
5. 保留元婴、化神、炼虚作为世界背景、NPC压迫感与远期资料片空间，暂不作为当前主循环必须完整支持的玩家成长链。

设计倾向：

- 练气是入门与适应期。
- 筑基是主游戏期。
- 紫府是筑基后半段的质变状态，而非新增独立大境界。
- 金丹是稀缺位格与阶段性终局。
- 金丹以上先降为传说级存在，不承担当前版本的完整养成压力。

本轮修订判断：

1. 取消金丹九品制。金丹优劣改由丹籍位格、丹名契合、丹性纯杂和世界影响范围体现，避免“品级 + 位格”双重分层造成冗余。
2. 常设金丹位格采用“一正二辅”。同一丹系内，天地自然承认的丹籍只有正籍一席、辅籍二席。
3. 保留假丹，但将其定位为可继续追求真金丹的中转状态，而不是坏档或终身惩罚。
4. 原“支丹位”改为元婴真君点化的“敕籍”。敕籍不是天地自然空缺，而是元婴以自身道行、宗门法统或山河权柄敕封出来的次级丹籍，用来凸显元婴境界对金丹秩序的压制力。
5. 金丹不只改变个人战力，还会回响到所辖地脉、宗门、资源生态与术法环境。
6. 金丹修行与宗门势力半绑定：强宗门提供供养和位格经营优势；弱宗门不会直接削弱金丹本体，只会减少外部助力。
7. 金丹晋升元婴的路线应围绕丹籍组合，而不是单纯经验条或灵力阈值。

═══════════════════════════════════════════════════════════════
二、新境界框架
═══════════════════════════════════════════════════════════════

推荐玩家主线境界：

凡人 → 练气 → 筑基 → 金丹

世界背景境界：

元婴 → 化神 → 炼虚

说明：

1. 玩家当前版本完整养成链以金丹为阶段终点。
2. 元婴以上仍存在于世界观中，可作为掌教、老祖、禁区主宰、天外威胁或资料片目标。
3. 不删除元婴以上设定，但降低其在当前数值、CSV、Unity与BattleSim中的优先级。
4. “紫府”不作为独立大境界插入，避免名义缩减境界、实际增加一层复杂度。

筑基内部建议分段：

筑基初成 → 筑基稳固 → 开辟紫府 → 神通成系 → 筑基圆满

对外显示可按需求采用两种包装：

方案A：保持筑基名义
- 筑基初期
- 筑基中期
- 筑基后期
- 筑基开府
- 筑基圆满

方案B：强调紫府质变
- 筑基初期
- 筑基中期
- 筑基后期
- 紫府初开
- 紫府圆满

推荐方案B。它能让玩家感受到筑基后半段已经不是普通筑基，但不破坏“筑基是主游戏期”的结构。

═══════════════════════════════════════════════════════════════
三、筑基期主循环
═══════════════════════════════════════════════════════════════

筑基期不再只是从道基冲到金丹的过渡，而是角色成型的核心阶段。

筑基期核心内容由五类系统构成：

1. 道基
2. 紫府
3. 本命术法
4. 根本神通
5. 金丹资粮

────────────────────────────────────
三.1 道基
────────────────────────────────────

道基仍在筑基初成时凝聚，是角色道途的根。

道基决定：

- 筑基期基础被动。
- 紫府开辟方向。
- 可修根本神通的类型池。
- 金丹丹籍适配范围。
- 成丹稳固度与可争丹籍范围。

道基品级保留天、地、玄、黄、无道基。

建议调整道基定位：

- 黄品道基：可筑基成型，但金丹路线极窄。
- 玄品道基：标准宗门精英。
- 地品道基：可竞争辅籍或敕籍。
- 天品道基：具备争夺正籍的资格。
- 无道基：不建议作为普通失败状态长期保留，可转化为“外道筑基”路线。

外道筑基：

若凝聚道基失败，角色不直接废掉，而是进入外道筑基分支。
外道筑基通常不能直接争夺正统丹籍，但可先走假丹、魔丹、血丹、器丹等替代路径。
假丹不是终点，后续可通过补全道基、重开紫府、夺取敕籍或自辟丹籍转入真金丹。
此路线适合作为高风险玩法、反派路线或散修补偿路线。

────────────────────────────────────
三.2 紫府
────────────────────────────────────

紫府是筑基后半段的核心包装，代表修士从“有根基”进入“能承载神通体系”的阶段。

紫府不是单纯属性等级，而是一个可建设的内在空间。

紫府包含五个“府位”：

1. 命府：承载生命、根骨、肉身、防御、恢复相关神通。
2. 魂府：承载魂魄、神魂攻击、魂盾、心魔、梦境相关神通。
3. 识府：承载神识、侦察、命中、预判、控制、阵法相关神通。
4. 气府：承载灵力、术法循环、符箓、丹火、五行转化相关神通。
5. 运府：承载气运、因果、暴击、闪避、奇遇、劫数相关神通。

五府不要求全部均衡成长。不同功法、门派和角色Build可以主修其中二到三府。

紫府成长不是经验条，而是通过事件和资源完成：

- 参悟功法篇章。
- 炼化天材地宝。
- 完成门派试炼。
- 夺取地脉、灵眼、符诏、雷池、梦种等关键资源。
- 战胜对应道途的强敌。
- 处理心魔、劫数、因果债。

紫府建设的目标不是让玩家重复刷素材，而是提供一组可选择、可替代、可互斥的长期目标。

────────────────────────────────────
三.3 本命术法
────────────────────────────────────

练气和筑基前半段以术法为主。

筑基后半段开始，玩家需要选择若干术法作为本命术法候选。

本命术法候选具备三个作用：

1. 在战斗中获得额外成长线。
2. 可被紫府府位承载，升格为根本神通。
3. 参与金丹资粮组合，决定可争夺的金丹丹籍。

本命术法候选不建议无限制堆叠。

建议规则：

- 筑基中期：可指定1个本命术法候选。
- 紫府初开：可指定2个本命术法候选。
- 紫府圆满：最多保留3个本命术法候选。

候选可通过特殊资源重选，但成本较高。

────────────────────────────────────
三.4 根本神通
────────────────────────────────────

根本神通是筑基期真正的长期收集目标。

玩家不再等到金丹才突然获得神通，而是在紫府阶段逐步修成神通雏形。
金丹只是将这些神通定型、升格、承接丹籍。

根本神通来源：

- 道基自生。
- 本命术法升格。
- 血脉觉醒。
- 门派秘传。
- 天材地宝炼化。
- 外道契约。
- 击败强敌后夺取道痕。

推荐突破金丹的基础资格：

修成四道根本神通，且至少覆盖三个不同府位。

辅籍资格：

修成五道根本神通，且其中至少一道与道基完全契合。

正籍资格：

修成五道根本神通，并形成完整道途闭环。

道途闭环示例：

- 玉清雷剑：命府炼体、气府雷法、识府剑心、魂府劫意、运府应劫。
- 太一符箓：气府符箓、识府法度、运府天命、命府护身、魂府安神。
- 太虚梦魂：魂府梦界、识府观照、运府因果、气府虚实、命府替劫。
- 混元军阵：命府铁骨、气府军势、识府号令、运府胜机、魂府军魂。
- 散修秋水：气府流水、命府回生、运府逢凶、识府游心、魂府逝水。

设计重点：

1. 不要求所有Build收集同名神通。
2. 要求收集的是“结构完整性”，而不是固定清单。
3. 玩家可以为了冲击高位金丹去追求五府完整，也可以选择四神通成丹，降低目标压力。

────────────────────────────────────
三.5 金丹资粮
────────────────────────────────────

金丹不再只由灵力值、道基品级和随机骰决定，也不再保留一至九品的金丹品级。

金丹资粮建议由五类组成：

1. 道基品级：决定成丹稳固度和可争丹籍范围。
2. 紫府完整度：决定可承载的丹名、丹性与丹域规模。
3. 根本神通数量与契合度：决定假丹、敕籍、辅籍、正籍资格。
4. 金丹外物：丹药、天材地宝、地脉、法箓、雷池、梦种、军印等。
5. 世界丹籍：对应正籍、辅籍是否空缺，是否能夺籍、继籍、受敕或自辟。

原有金丹凝聚值可保留为“成丹判定值”，但不再映射九品金丹。
它只回答三个问题：

1. 能否成丹。
2. 成丹是否稳固。
3. 是否足以承接目标丹籍。

示例：

成丹判定值 = 道基延续分 + 紫府完整分 + 神通契合分 + 灵根分 + 灵力投入分 + 外物分 + 随机骰

但即使判定值足够，也必须满足对应丹籍条件。

═══════════════════════════════════════════════════════════════
四、金丹期定位
═══════════════════════════════════════════════════════════════

金丹期应从普通升级阶段调整为世界位格阶段。

金丹修士不是“比筑基多一档属性的角色”，而是：

- 一个地区的战略级存在。
- 一个道统的门面。
- 一个丹籍的占据者。
- 一个会改变地脉、生态、门派和资源分配的节点。

金丹期内容减少数量，增加密度。

金丹期建议只保留三个阶段：

1. 初结金丹：完成结丹，占据、受敕或暂寄丹籍。
2. 温养金丹：稳定丹籍，扩张丹域，重铸本命神通/法宝。
3. 金丹圆满：经营丹籍组合，准备冲击元婴。

不再强调四阶刷数值，也不再保留一至九品。

────────────────────────────────────
四.1 丹籍、丹名与丹性
────────────────────────────────────

建议将金丹从“九品品级 + 五行类型”改为“丹籍 + 丹名 + 丹性”。

丹籍：

丹籍是天地、地脉、道统或元婴真君承认的位置。
金丹优劣主要由丹籍来源、丹籍完整度、丹域范围和丹名契合度决定。

丹名：

丹名体现角色道途，如：

- 九霄雷劫金丹
- 太一玄箓金丹
- 南华梦魂金丹
- 混元铁军金丹
- 秋水游心金丹
- 白屋青云金丹
- 无性有知金丹

丹名不是纯文本装饰，应决定：

- 金丹被动。
- 本命神通升格方向。
- 术法/神通占用折扣。
- 丹域影响范围。
- NPC态度。
- 可争夺的资源类型。
- 晋升元婴时可组合的丹籍路线。

丹性：

丹性是金丹与天地五行、变异属性或特殊道途的对应关系。
它决定金丹对个人、宗门和地脉的长期回响。

基础丹性：

- 金
- 木
- 水
- 火
- 土

变异丹性：

- 风
- 雷
- 冰
- 暗
- 星
- 毒
- 混沌

特殊丹性：

- 符
- 丹
- 剑
- 阵
- 梦
- 军
- 因果

特殊丹性不一定脱离五行，可理解为“五行为体，道途为用”。
例如太一玄箓金丹可以是“水性·符丹”，九霄雷劫金丹可以是“雷性·剑丹”。

────────────────────────────────────
四.2 丹籍体系
────────────────────────────────────

推荐正式名称：

- 丹籍：金丹位格总称。
- 正籍：天地自然承认的一系主位。
- 辅籍：依附正籍的一系副位。
- 敕籍：元婴真君点化、敕封、赐下的次级丹籍。
- 寄丹：假丹的古典包装名，表示暂寄丹形、未入真籍。

同一丹系的天地自然丹籍采用“一正二辅”。

一、正籍

一系只有一席。
正籍是该丹系最完整、最有号召力的丹籍。
占据正籍者通常是同系金丹秩序的中心。

示例名称：

- 关陇玄域·太虚梦魂正籍。
- 江左天域·太一玄箓正籍。
- 陇西雷域·玉清雷劫正籍。
- 漠北荒域·铁血军阵正籍。

二、辅籍

一系两席。
辅籍不是残缺金丹，而是该丹系的两条副脉。
辅籍可以与正籍同源，也可以代表正籍下的两个分支方向。

示例：

- 玉清雷劫正籍下可有“雷剑辅籍”和“劫体辅籍”。
- 太一玄箓正籍下可有“符箓辅籍”和“法坛辅籍”。
- 太虚梦魂正籍下可有“梦界辅籍”和“因果辅籍”。

三、敕籍

敕籍由元婴真君点化而来。
它不是天地自然空缺的一正二辅，而是元婴以自身道行、宗门法统、山河权柄或洞天根基敕封出来的金丹丹籍。

敕籍的作用：

1. 凸显元婴境界的逼格。元婴不只是强大战斗单位，而是能改写金丹秩序的人。
2. 给宗门经营提供高阶目标。宗门若有元婴坐镇，可以额外培养敕籍金丹。
3. 给玩家提供政治路线。玩家可接受元婴敕封快速成丹，但会受到敕封来源约束。
4. 给反抗路线提供矛盾。敕籍金丹可脱敕、叛门、夺正，形成剧情冲突。

敕籍限制：

- 敕籍通常弱于同系正籍，接近或略低于辅籍。
- 敕籍与敕封者存在因果、法统或山河联系。
- 敕封者陨落、失位或被镇压时，敕籍可能动摇。

四、寄丹

寄丹即假丹。
寄丹战力高于筑基，但未入真丹籍。
寄丹不是坏档，也不是永久失败。

寄丹用途：

- 作为结丹失败后的保护状态。
- 作为散修、外道、魔修的过渡路线。
- 作为玩家暂时获得金丹级战力、继续争夺真丹籍的中转境界。

寄丹转真丹的方式：

- 补全道基，重开紫府。
- 夺取空缺辅籍。
- 接受元婴点化，转为敕籍。
- 击败同系金丹，夺其丹籍。
- 自辟丹籍，洗去寄丹痕迹。

────────────────────────────────────
四.3 丹域与山河回响
────────────────────────────────────

金丹的特色不应只体现在自身成长上，也应体现在世界上。

金丹成就后，会在自身洞府、宗门辖地、受其镇压的地脉范围内形成“丹域回响”。
丹域回响不是战斗领域，而是长期世界规则倾向。

以木性金丹为例：

- 所辖地区木系天材地宝产量增加。
- 木系天材地宝品质上限提高。
- 木系妖兽、灵植、精怪出现概率提高。
- 门派弟子修炼木系功法速度提高。
- 木系术法在宗门辖地、洞府、法坛附近效果增强。
- 被木所克的土系术法、土系地脉或土系怪物受到压制。

其他丹性按五行生克与项目已有属性匹配规则延展。

设计原则：

1. 丹域回响优先作用于“玩家实际控制、供奉或镇压”的区域，不做无限全局光环。
2. 回响强度与丹籍层级、丹域经营、宗门设施、地脉稳定度相关。
3. 回响应同时带来收益和生态变化。木系资源变多，也可能导致木妖、藤灾、灵植争夺变多。
4. 克制关系应造成环境倾向，而不是直接废掉某系玩家。
5. 丹域回响可以成为战略目标：敌对金丹可污染、争夺或封锁玩家丹域。

────────────────────────────────────
四.4 金丹与宗门供养
────────────────────────────────────

金丹成长可以与宗门势力半绑定。

强宗门有利于金丹修行：

- 提供地脉供养。
- 提供弟子气数与法统回响。
- 提供天材地宝、丹药、法宝和护法资源。
- 提供丹域扩张所需的阵法、洞府、灵田和山门设施。
- 提供争夺丹籍、辅籍、敕籍时需要的战争与外交能力。

但宗门弱小不应让金丹本体变弱。

推荐规则：

1. 宗门供养是正向加成，不是负向扣减。
2. 没有宗门或宗门弱小，金丹仍保持自身基础战力和丹籍权柄。
3. 强宗门让金丹修行更快、丹域更广、资源更多、冲婴路线更容易。
4. 弱宗门只意味着外部助力少，玩家可以用洞府、客卿、散修盟约、地脉占据等方式替代。

这样可以保留宗门经营价值，又避免“宗门经营不好导致角色倒退”的挫败感。

────────────────────────────────────
四.5 固定丹籍的可玩性补偿
────────────────────────────────────

固定丹籍会带来强叙事，但也容易变成硬锁。
因此必须提供可玩出口。

出口一：夺籍

玩家可通过击败、逼退、暗杀、封印、政治斗争或宗门战争夺取既有丹籍。

出口二：继籍

若原丹籍占据者死亡、飞升、碎丹、失踪或传位，玩家可通过任务线继承。

出口三：受敕

玩家接受元婴真君、宗门老祖、洞天法统或山河权柄点化，获得敕籍成丹。
受敕成丹较稳定，但会与敕封来源绑定。

出口四：寄丹暂栖

玩家先成寄丹，获得金丹级战力和更长操作空间，再继续追求正籍、辅籍或敕籍。

出口五：自辟丹籍

最难路线。
玩家通过开辟洞天、重塑地脉、立教、斩旧丹籍或承接天命，创造新的正籍与辅籍体系。
此路线适合作为阶段终局。

设计底线：

玩家不能因为“丹籍已满”而只能等待剧情。
丹籍已满应意味着玩家获得明确目标：夺、继、受敕、寄丹、自辟。

────────────────────────────────────
四.6 金丹进阶元婴
────────────────────────────────────

金丹进阶元婴不应只是灵力数值达标。

元婴的核心含义应是：修士不再只是占据一个丹籍，而是能统摄、点化、改写一组丹籍秩序。

冲击元婴的基础条件：

- 金丹圆满。
- 丹籍稳固。
- 本命神通成阵。
- 丹域不被污染或封锁。
- 完成至少一条位格统摄路线。

推荐路线一：一系归元

掌控某一丹系的全部自然丹籍。

最低口径：

- 自身占据正籍。
- 两个辅籍由自身、门人、盟友、化身或受控金丹掌握。

高难口径：

- 同系主要敕籍也纳入自身法统。
- 同系寄丹多数归附或被镇压。

此路线强调“一个人掌控某一系所有位格”的压迫感。

推荐路线二：五行相生

掌握一套五行相生丹籍。

示例：

- 木籍生火籍。
- 火籍生土籍。
- 土籍生金籍。
- 金籍生水籍。
- 水籍生木籍。

玩家不必亲自占据全部五枚丹籍，但必须通过宗门、盟约、法契、敕封、婚盟、附庸或夺籍形成稳定闭环。

此路线适合宗门经营、外交与大型势力玩法。

推荐路线三：山河一统

掌控一个地域内的关键丹籍，使该地域山河、地脉、宗门秩序全部归于自身丹域。

此路线适合领地经营和争霸玩法。

推荐路线四：自辟法统

不走现有丹籍体系，而是自辟正籍，并培养或点化两条辅籍。

此路线难度最高，但最适合玩家作为开宗立派的阶段终局。

元婴点化敕籍：

角色成就元婴后，才真正拥有点化敕籍的能力。
这让元婴在世界中的意义不只是战力提升，而是从“丹籍占据者”变成“丹籍秩序制定者”。

当前版本可只保留冲婴入口和路线条件，不必完整实现元婴后养成。

────────────────────────────────────
四.7 金丹后的内容
────────────────────────────────────

金丹后不建议立刻开启完整元婴养成。

金丹期主要内容应是：

- 稳定丹籍。
- 经营丹域。
- 建立洞府或势力。
- 争夺地域资源。
- 处理同阶金丹外交。
- 镇压筑基势力。
- 重铸本命神通与本命法宝。
- 争夺辅籍、敕籍和相生丹籍组合。
- 决定是否冲击元婴、留在人间、转修外道或开辟新法。

元婴可作为远期目标，但金丹期本身应足够构成完整阶段终局。

═══════════════════════════════════════════════════════════════
五、数值与战棋影响
═══════════════════════════════════════════════════════════════

境界差距需要拉大，但不能让战棋玩法失效。

建议原则：

1. 练气打筑基：需要人数、阵法、地形、道具或剧情条件。
2. 筑基打金丹：默认不可正面对抗，但可通过削位、破府、封丹、阵法、偷袭实现剧情战。
3. 金丹打筑基：战略压制，但在战棋中不应只是单纯秒杀，应该体现行动规则优势。

金丹对筑基的优势建议表现为：

- 更高行动优先级。
- 本命神通无需普通冷却或消耗更低。
- 可压制低阶术法效果。
- 可展开小型丹域，改变局部战场。
- 可跨地图施压，例如封锁地脉、遥控法宝、镇压区域灵力。

不建议只做：

- HP和攻击乘以十倍。
- 低阶完全无法命中。
- 玩家没有任何战术出口。

筑基金丹差距应主要来自“规则层优势”，数值只是支撑。

六、现有内容迁移建议
═══════════════════════════════════════════════════════════════

────────────────────────────────────
六.1 修行境界.txt

需要重写主表：

- 删除或降级元婴、化神、炼虚的玩家主循环描述。
- 将筑基扩展为五段或两层结构。
- 将金丹改为三段式。
- 将紫府、根本神通、金丹资粮写入筑基后半段。

────────────────────────────────────
六.2 境界特性.txt
────────────────────────────────────

需要重构：

- 道基从“筑基被动 + 金丹前置”升级为筑基主轴。
- 紫府新增为筑基后半段承载结构。
- 本命神通从“金丹铭刻”前移为“筑基修成雏形，金丹定型升格”。
- 金丹类型改为“丹籍 + 丹名 + 丹性”，取消一至九品。
- 金丹位格改为正籍、辅籍、敕籍、寄丹。
- 领域暂时保留为炼虚传说，不作为当前版本主要实现目标。

────────────────────────────────────
六.3 术法与神通
────────────────────────────────────

现有高阶术法不必全部删除。

迁移方式：

- 练气术法：保留为入门工具。
- 筑基术法：扩展为主战术池。
- 金丹术法：部分降级为紫府阶段的根本术法候选，部分保留为金丹定型后效果。
- 元婴/化神术法：多数改为金丹丹籍技、宗门秘术、丹域技或NPC专属。
- 炼虚领域神通：保留为传说级，不进入当前主循环。

────────────────────────────────────
六.4 功法篇章
────────────────────────────────────

现有功法篇章建议从“按境界平均铺开”改为“筑基段密集展开”。

建议篇章结构：

- 入门篇：练气
- 筑基篇：凝道基
- 开府篇：紫府初开
- 神通篇：根本神通成系
- 金丹篇：定丹名、争丹籍

高阶功法仍可保留更多篇章，但作为后续扩展。

────────────────────────────────────
六.5 丹药与天材地宝
────────────────────────────────────

道具分层需要重排：

- 练气期资源：帮助筑基和凝道基。
- 筑基期资源：帮助开紫府、修神通、争金丹资粮。
- 金丹期资源：帮助稳定位格、重铸神通、准备元婴入口。
- 元婴以上资源：暂时作为稀有背景或NPC争夺物。

═══════════════════════════════════════════════════════════════
七、首轮可验证改造范围
═══════════════════════════════════════════════════════════════

建议不要一次性修改全部文档和代码。

第一轮只做设计锁口径：

1. 确认新境界框架。
2. 确认筑基五段或紫府两段命名。
3. 确认金丹丹籍口径：一正二辅、元婴敕籍、寄丹中转。
4. 确认突破金丹需要四道或五道根本神通。
5. 确认固定丹籍的五种玩家出口。

第二轮再做文档替换：

1. 重写 `修行境界.txt`。
2. 重写 `境界特性.txt`。
3. 更新 `术法槽位设计.txt`。
4. 更新功法、术法、神通设计规范中关于金丹、本命神通、领域的定义。

第三轮再做数据和模拟：

1. BattleSim 境界表与里程碑重构。
2. Unity CultivationEngine 对齐。
3. Spells.csv / Skills.csv / GongFa.csv 迁移 realmReq。
4. 重新跑 21 Build 筑基/紫府同境矩阵。
5. 新增“筑基 vs 金丹压制战”测试场景。

═══════════════════════════════════════════════════════════════
八、待决问题
═══════════════════════════════════════════════════════════════

1. 紫府是否采用“筑基后半段显示名”，还是正式成为“筑基之后、金丹之前”的独立境界？
   当前建议：不设独立大境界。

2. 金丹突破需要四道根本神通还是五道？
   当前建议：四道可成寄丹或敕籍候选，五道可争辅籍或正籍。

3. 正籍是否按“地域 + 道途”双键唯一？
   当前建议：是。只按道途唯一会过于拥挤，只按地域唯一会压死门派差异。

4. 玩家是否能在首个大版本自辟丹籍？
   当前建议：可以，但作为阶段终局，不作为常规路线。

5. 寄丹是否允许继续游玩并转真金丹？
   当前建议：允许。寄丹应是失败保护、外道路线和真金丹中转，不是坏档。

6. 金丹以上是否继续保留在 CSV 和 Unity 当前数据中？
   当前建议：短期不删除，但标注为NPC/后续扩展，避免大规模资产报废。

7. 术法/神通槽位是否继续随境界线性增加？
   当前建议：改为随“紫府府位”和“金丹丹籍”增加，而不是随境界数量增加。

═══════════════════════════════════════════════════════════════
九、草案结论
═══════════════════════════════════════════════════════════════

本重构方向成立。

最合适的包装不是“减少几个境界名称”，而是改变成长重心：

- 练气负责入门。
- 筑基负责绝大多数可玩内容。
- 紫府负责筑基后半段的神通承载和长期经营。
- 金丹负责世界位格、阶段终局和势力格局变化。
- 元婴以上负责世界压迫感和远期扩展。

这样可以保留修仙题材的宏大阶梯，同时避免当前版本被高阶机制债拖垮。
