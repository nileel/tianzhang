# 太玄界天意与绝地天通设定

✅ 已审核（2026-07-22 Codex；《天章》宇宙观最高层事实源）

> 职责：本文只定义大道、本界天意、上界天庭、人间修士及两界治理史的最高层边界。世界背景叙事见 `docs/剧情/世界背景故事.txt`；境界与位格见对应修行事实源；三项遗产及册界规则见各自内容和规则文件。
> 优先级：下游内容与本文冲突时，以本文为准。旧稿中的“天门意外崩塌”“统一上古仙朝”“天庭创造大道或授予所有位格”不得作为作者视角事实继续生产。

═══════════════════════════════════════
一、四类存在与权限边界
═══════════════════════════════════════

1. 大道先于天而存在。大道不是天庭创制的律令，也不因天庭失联而消失；本界天意、上界天庭与人间修行都在大道之中。
2. 本界天意是太玄界的世界意志。它能以征兆、许可、异常窗口和道路暴露影响本界，却不能像宗门师长一样直接赐予某人金丹、元婴或更高境界。它在绝地天通后沉默、受损，但没有死亡。
3. 上界天庭是掌握跨界治理技术、界籍制度和公共设施的统治组织。它能册封藩界、建立跨界通路、登记治理权柄，却不创造五行、大道、灵根或所有修士的个体位格。
4. 人间修士与共同体自行认识大道、建立道统并承担选择后果。法箓、德业、真形、宿慧和阴河等方向都是人间对大道的新解释，不是天庭发放的职位。

上界传播过系统化修仙知识、标准和公共设施，因此显著降低了学习、协作与跨域治理成本。这不等于“没有天庭就无法修仙”，也不等于一切古法都来自上界。

═══════════════════════════════════════
二、跨界治理术语
═══════════════════════════════════════

- 藩界：保有本界天意与较强内部自治，同时接受天庭册封、界籍登记和有限跨界治理的世界。
- 直属界域：本界天意被纳入天庭直接治理接口，难以再单方面退出跨界制度的世界状态。
- 界籍：记录界域身份、公共设施归属、治理授权和两界责任的制度档案；不是修士个人境界证书。
- 跨界治理位格：天庭组织用于跨界行政和设施调用的制度性权柄。它不映射为太玄界炼虚等新境界，不占用十七道路的元婴锚点，也不自动压过本界修士的道路解释。

飞升因此包含跨界通行、迁移和制度筛选。它不是太玄界修行表中从化神自动进入某个新境界的同义词；上界现状、上界个体力量体系和天庭内部组织谱系仍属未知。

═══════════════════════════════════════
三、上古太玄道庭
═══════════════════════════════════════

太玄界受册封为藩界后，人间建立了上古太玄道庭。它是统筹界籍、法箓、跨界通路、公共设施和地区调衡的人间管理机构，不是皇权王朝，也不是现行太一道庭。

上古太玄道庭保存并使用三项核心遗产：

- 《开阖九章》负责通行：识别并操作兼容的旧门禁与完好传送阵。
- 太玄界印负责归属：确认旧公共设施由谁管理、服务谁及向谁开放权限。
- 《册界天章》负责规则调衡：在合法授权、册界节点、现实支点和世界代价成立时，调用已登记规则，调整地区长期基础态。

三者不能互相替代。通行不等于取得管理权，管理权不等于修改地区规则，规则调衡也不能绕过通行条件、设施状态和现实供给。

现行太一道庭只继承上古太玄道庭南方法箓支系的部分官署、法箓与界籍解释传统。它是有限继承者和正统声索者，不是古道庭本体，不拥有全界正统或自动生效的全界行政权。

═══════════════════════════════════════
四、直属化计划与绝地天通
═══════════════════════════════════════

藩界时期后段，天庭准备把太玄界从可保留主体性的藩界改为不可自行脱离的直属界域。天庭的立场并非单纯毁灭：更稳定的跨界交通、灵脉调度、灾害治理、知识传承和公共标准都是真实收益；其代价是本界天意与人间共同体失去对自身未来的最终退出权。

本界天意在受制前的最后阶段，通过征兆、许可、异常窗口和道路暴露，扶持了古道庭内部反对者、地方宗门与人间共同体。它没有直接赐予他们境界，也没有指定一位唯一救世主。

这些人从太玄界内部主动斩断两界联系，破坏直属化所依赖的通路与治理接点。这场远古选择称为“绝地天通”。

绝地天通同时产生两类后果：

- 正面：阻止直属化完成，保住本界天意与人间共同体继续解释、试错和重订秩序的主体性。
- 负面：跨界通路、古代行政网络、灵脉调度和公共设施大规模损伤；知识断代、地方失联与长期治理成本随之上升。

绝地天通不是善恶战争的结论。支持复联者可以主张公共治理与稳定，支持隔绝者可以主张主体性与退出权；任何一方都必须承认自身方案会让某些地区和共同体承担代价。

═══════════════════════════════════════
五、崩解后的历史层级
═══════════════════════════════════════

绝地天通后，上古太玄道庭随全界行政网络一同崩解。其后直接进入遗产分散、具体地方政权兴亡和现世宗门形成的时代；权威历史中不存在承接古道庭全界权力的统一“上古仙朝”。

“天门崩塌”“飞升路断”“天门旧世”是后世根据断裂通路、失控设施和残缺典籍形成的公共说法。它们可以作为传闻、史家解释或角色误判出现，但不能再被作者视角写成一场纯粹意外灾变的完整真相。

地方古国、旧朝、王庭和皇陵可以按自身事实保留王朝称谓；它们不得被倒推为一个不存在的全界仙朝，也不得自动继承上古太玄道庭的权力。

近代龙脊之变与远古绝地天通是两场独立事件。龙脊之变源于苻渊强行自辟德业元婴方向失败；它触动了叠建于近代承接网络之下的少量古代残层，却不是绝地天通的重演，也不证明混元山三百七十二处节点全是天庭设施。

═══════════════════════════════════════
六、知识边界与禁止推论
═══════════════════════════════════════

1. 本界当代没有任何可靠全知者。古籍、遗物、节点记录与上界回响都只能提供局部证据。
2. 司马承景是后世公共法统的重整者和残损承接者，不是仙朝末代道主，也不是上古太玄道庭的直接管理者。
3. 天庭现状、直属化计划在上界是否仍有效、上界内部是否一致，均保持未知；不得提前写成一个可直接讨伐的完整反派阵营。
4. 天庭、本界天意、太玄界印或《册界天章》都不能创造大道、授予金丹／元婴、修改先天资质或抹除元婴道路锚点。
5. 《册界天章》只能调用完整登记条目；每次调用都必须满足范围、节点、授权、现实支点、现实供给、正负提交和高阶冲突边界。
6. 不得把“仙朝、天命、天道、天劫”等词机械替换。每次命中必须判断它指具体地方政权、角色信仰、自然规则、修行现象、错误史观还是已经废止的全界仙朝。

═══════════════════════════════════════
七、《天章》之名
═══════════════════════════════════════

“天”同时指向太玄界真实但受损的本界天意，以及曾参与本界历史的上界秩序；“章”既是可登记、可解释、可争议的治理条目，也是人间共同体必须共同承担的章程。

玩家最终面对的不是“谁给所有修士发位格”，而是太玄界该继续保持绝地天通后的主体性、重新接受更稳定的上界秩序，还是建立一种既不回到直属统治、也不否认公共治理需要的新天章。
