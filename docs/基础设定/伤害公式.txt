【伤害公式】

一、伤害类型

伤害分为物理伤害与神魂伤害两种，分别独立计算后叠加为最终伤害。
一个术法/攻击可以有物理倍率和神魂倍率（混合伤害），两条线路各自单独结算。

二、物理伤害公式

物理伤害 = 肉身攻击 × 技能物理倍率
         × (攻击方境界系数 ÷ 防御方境界系数)
         × 肉身攻击 / (肉身攻击 + 防御方肉身防御)
         × [1 - 防御方物理抗性 × (防御方境界系数 ÷ 攻击方境界系数)^0.5]

三、神魂伤害公式

神魂伤害 = 神魂攻击 × 技能神魂倍率
         × (攻击方境界系数 ÷ 防御方境界系数)
         × 神魂攻击 / (神魂攻击 + 防御方神魂防御)
         × [1 - 防御方神魂抗性 × (防御方境界系数 ÷ 攻击方境界系数)^0.5]


四、最终伤害

最终伤害 = 物理伤害 × (1 - 格挡减伤率) + 神魂伤害 × (1 - 魂盾减伤率)

其中格挡减伤率和魂盾减伤率仅在各自判定成功时生效（否则为0%）：
- 格挡判定成功 → 物理伤害 × (1 - 格挡减伤率)
- 魂盾判定成功 → 神魂伤害 × (1 - 魂盾减伤率)
- 格挡仅对物理伤害有效，魂盾仅对神魂伤害有效
- 闪避判定先于格挡/魂盾：若闪避成功，则不进入伤害计算
- 格挡减伤率和魂盾减伤率由功法篇章、装备、丹药提供


五、暴击

若攻击触发暴击，则对应伤害线路的"技能倍率"替换为"暴击伤害倍率"。
暴击率与命中率分开判定：先判定命中，再判定暴击。

六、境界系数

┌──────────┬──────┐
│ 境界     │ 系数 │
├──────────┼──────┤
│ 凡人     │ 1.0  │
│ 练气     │ 1.5  │
│ 筑基     │ 3.0  │
│ 金丹     │ 6.0  │
│ 元婴     │ 12.0 │
│ 化神     │ 25.0 │
│ 炼虚     │ 50.0 │
└──────────┴──────┘

境界系数体现了高境界对低境界的天然压制：境界差距越大，伤害越悬殊。

七、公式设计说明

1. 攻击/(攻击+防御) 项确保攻防数值在合理比例时伤害可控。
   同阶攻防持平时此项≈0.5；防御远高于攻击时伤害大幅衰减。

2. 境界系数比值放大高境界优势，平方根衰减项使抗性对跨阶攻击仍有部分效果。

3. 物理和神魂双线独立，意味着：
   - 高肉防低神防的角色（如体修）惧怕魂修
   - 高神防低肉防的角色（如魂修）惧怕体修
   - 均衡型角色无明显短板但也没有极致优势
   - 混合伤害术法可同时打击两种防御维度（物理绕过魂盾、神魂绕过格挡）
