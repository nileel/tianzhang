【修行境界】

重要说明：以下灵力值要求均为"标准纯度"下的数值。
若修士灵力纯度高于1.0，则以"有效灵力值"判定：
  有效灵力值 = 实际灵力值 × 灵力纯度
例如：纯度2.0的修士，实际灵力=50即可满足"灵力≥100"的突破条件（有效灵力=100）。
每个大境界内部包含若干小境界，修士需逐级突破。

═══════════════════════════════════════════════════════════════
零、属性双轨成长总则（v3.4）
═══════════════════════════════════════════════════════════════

修行境界的成长分为两条独立轨道：

轨道一：大境界突破 → 先天属性成长
  - 每次跨越一个大境界时，按所修功法的品级与属性倾向，获得先天属性点数。
  - 先天属性代表修士"根本资质"的蜕变，仅在质变时刻发生。
  - 先天属性继续影响一级属性的基础加成（保留先天→一级的底层公式）。
  - 突破次数：6次（凡人→练气、练气→筑基、筑基→金丹、金丹→元婴、元婴→化神、化神→炼虚）

轨道二：小级别提升 → 一级属性成长
  - 每个大境界内部每提升一个小级别时，按所修功法的"小境界一级属性成长表"获得一级属性增量。
  - 一级属性代表修士"实战能力"的积累，在每个小级别稳步成长。
  - 小级别总数：练气9品 + 筑基4阶 + 金丹4阶 + 元婴4阶 + 化神4阶 + 炼虚4阶 = 29次
  - 移力由境界固定值决定，不参与小级别成长。

一级属性最终公式：
  一级属性 = 境界基础值 + ∑(小境界累积成长) + 先天属性加成

先天属性加成 = 先天属性 × 境界系数 × 功法权重 × 归一化因子
（详细公式及参数见「角色数值设计.txt」）

四、金丹期（四阶制）
═══════════════════════════════════════════════════════════════

灵力值区间：1200-8000（有效灵力，不含金丹品级倍率加成）
先天属性上限：75
说明：金丹期灵力值上限受金丹品级倍率影响（见下文），
      上表为九品金丹基准区间。高品金丹实际MP远超此范围。
境界特性：金丹（于金丹初阶凝结）、本命神通、本命法宝

突破条件：筑基圆满 + 有效灵力≥1200 + 灵根≥中品 + 道基（不可为"无道基"）

突破流程：
  1. 筑基圆满后继续积累灵力至 ≥1200 有效灵力
  2. 主动选择「凝结金丹」，计算金丹凝聚值
  3. 凝聚值同时判定成功率与金丹品级（双重判定）
  4. 成功 → 道基进化为免费本命神通
     失败 → 灵力扣除10%~20%，退回筑基中阶（灵力≈400），道基保留

金丹品级：一至九品，一品最高，九品最低。品级由金丹凝聚值决定。

金丹凝聚值公式：
  凝聚值 = 道基延续分 + 灵根基数 + 灵力投入分 + 随机骰(1d30) + 天材地宝

  ① 道基延续分：天品=60 / 地品=40 / 玄品=25 / 黄品=10
  ② 灵根基数：凡品=10 / 下品=20 / 中品=30 / 上品=40 / 极品=50
  ③ 灵力投入分（分段函数）：
       投入≤2000灵力时：每超出门槛100灵力 +3分
       投入>2000灵力时：超出2000部分每100灵力 +1分
     例：投入2000灵力 → (2000−1200)/100×3 = 24分
         投入3500灵力 → 24 + (3500−2000)/100×1 = 39分
  ④ 随机骰：1d30，凝结时独立骰一次，不可重骰
  ⑤ 天材地宝：下品+5 / 中品+10 / 上品+20 / 极品+30

道基硬上限：道基品级决定金丹品级天花板
  天品→最高一品 | 地品→最高三品 | 玄品→最高五品 | 黄品→最高八品
  无道基→无法凝结金丹

成功率公式：
  成功率(%) = 30% + (凝聚值−15)×0.5% + 悟性修正 + 资质修正 + 气运修正
  悟性修正 = +(悟性−1.0)×50%
  资质修正 = +资质×0.8%
  气运修正 = +气运×0.3%
  上限95%，下限20%

品级判定表（凝聚值 → 品级，受道基硬上限钳制）：
  ≥120→一品 | ≥105→二品 | ≥90→三品 | ≥75→四品 | ≥60→五品
  ≥48→六品  | ≥36→七品  | ≥25→八品 | ≥15→九品 | <15→凝结失败

金丹品级效果：
  ① MP上限倍率（境界基础MP × 品级倍率 × 灵根修正）：
     一品×3.0 | 二品×2.5 | 三品×2.0 | 四品×1.7 | 五品×1.4
     六品×1.2 | 七品×1.0 | 八品×0.85 | 九品×0.70
  ② 无灵力成长惩罚（各品级后续灵力增长速度一致）
  ③ 本命神通/法宝自由占用制（详见境界特性.txt）
  ④ 金丹类型由功法主属性+灵根属性决定（详见境界特性.txt）

道基进化：凝结金丹时，道基自动转化为免费本命神通
  - 不占用灵力值，不可解除
  - 品级=原道基品级，效果倍率沿用道基体系（天×1.30/地×1.10/玄×1.00/黄×0.85）

小境界划分（每阶提升小级别一级属性）：
  金丹初阶   ≥ 1200 有效灵力  |  凝结金丹，道基进化为免费本命神通
  金丹中阶   ≥ 3200 有效灵力  |  金丹稳固，可铭刻本命神通/绑定本命法宝
  金丹高阶   ≥ 5700 有效灵力  |  金丹大成
  金丹圆满   ≥ 8000 有效灵力  |  可冲击元婴（需金丹≥三品）

→ 金丹→元婴 大境界突破：获得功法定义的先天属性成长（3/6次）
