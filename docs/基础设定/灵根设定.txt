【灵根设定】

一、灵根概述
灵根乃修士与天地灵气沟通之根本，决定了修士能否修行、修行何种功法、修行速度几何。
灵根分为"种类"与"品级"两个维度：种类决定可修习的功法属性与术法倾向，品级决定修行速度与境界上限。
灵根于出生时由先天资质决定，极少数情况下可通过后天机缘改变。

二、灵根种类

灵根种类共12种，分为三大体系：

【基础五行灵根】（5种）
1. 金灵根
   属性：金
   特性：锋芒锐利，擅长攻击型术法与剑修
   对应职业：器修、剑修
   主域：关陇玄域

2. 木灵根
   属性：木
   特性：生机盎然，擅长恢复类术法与炼丹
   对应职业：丹修
   主域：江左天域

3. 水灵根
   属性：水
   特性：柔韧多变，擅长持久战与控制类术法
   对应职业：符修
   主域：江左天域

4. 火灵根
   属性：火
   特性：炽烈狂暴，擅长爆发伤害型术法
   对应职业：丹修、器修
   主域：太行火域

5. 土灵根
   属性：土
   特性：厚重沉稳，擅长防御型术法与阵修
   对应职业：阵修、体修
   主域：关陇玄域、漠北荒域

【变异灵根】（5种）
变异灵根由基础五行灵根在特定条件下异变而成，稀有度高于基础五行。

6. 风灵根（木之变异）
   属性：风
   特性：迅捷灵动，擅长速度型术法与闪避
   对应职业：剑修
   主域：漠北荒域

7. 雷灵根（金之变异）
   属性：雷
   特性：天罚毁灭，擅长范围攻击与破防
   对应职业：剑修、器修
   主域：陇西雷域

8. 冰灵根（水之变异）
   属性：冰
   特性：极寒封禁，擅长控制与减速
   对应职业：符修
   主域：辽海寒域

9. 暗灵根（土之变异）
   属性：暗
   特性：幽深诡秘，擅长隐匿、神魂攻击与诅咒
   对应职业：魂修
   主域：蜀川幽域

10. 星灵根（火之变异）
    属性：星
    特性：浩瀚莫测，擅长预知、阵法与远程术法
    对应职业：阵修
    主域：河西星域

【特殊灵根】（2种）
特殊灵根极为罕见，往往与上古血脉或特殊机缘有关。

11. 毒灵根（木之腐变）
    属性：毒
    特性：侵蚀腐化，擅长持续伤害、蛊术与咒术
    对应职业：毒修
    主域：蜀川幽域

12. 混沌灵根（上古遗存）
    属性：混沌（全属性兼容）
    特性：兼容所有属性功法，修炼速度极慢但无境界上限
    对应职业：不限
    主域：中州天域（上古仙朝血脉）

三、灵根品级

灵根品级决定修炼速度与能达到的最高境界，共分五品：

┌──────────┬────────────┬──────────────────────────┬──────────────┐
│ 品级     │ 修炼速度   │ 灵力值上限修正           │ 境界上限     │
├──────────┼────────────┼──────────────────────────┼──────────────┤
│ 凡品     │ ×0.2       │ ×0.7                     │ 练气         │
│ 下品     │ ×0.5       │ ×0.85                    │ 筑基         │
│ 中品     │ ×1.0       │ ×1.0                     │ 元婴         │
│ 上品     │ ×2.0       │ ×1.2                     │ 化神         │
│ 极品     │ ×4.0       │ ×1.5                     │ 炼虚         │
└──────────┴────────────┴──────────────────────────┴──────────────┘

[旧口径/资料片保留：上表中极品灵根境界上限炼虚已删除，当前版本最高境界为化神（修行境界.txt 已声明炼虚删除）]

说明：
- 修炼速度：角色获得灵力值经验时的倍率。极品灵根修炼速度是中品的4倍，是下品的8倍。
- 灵力值上限修正：到达每个境界时，该境界灵力值区间的最大值乘以此系数。
  例：中品灵根筑基圆满灵力值上限=1000×1.0=1000；极品灵根筑基圆满灵力值上限=1000×1.5=1500。
- 境界上限：凡品灵根无法突破练气进入筑基；下品灵根无法凝结金丹。
  这与修行境界设定中"金丹要求灵根≥中品"一致。
- 资质属性决定角色灵根品级的上限，详见角色属性_先天.txt。

四、多灵根

部分修士天生拥有两种或以上的灵根，称为"多灵根"。
多灵根的修炼速度按以下公式计算：

综合修炼速度 = Σ(各灵根修炼速度系数) ÷ 多灵根惩罚除数

┌──────────┬──────────────┬──────────────────────────────┐
│ 灵根数量 │ 惩罚除数     │ 说明                         │
├──────────┼──────────────┼──────────────────────────────┤
│ 单灵根   │ 1.0          │ 专注一道，速度最快           │
│ 双灵根   │ 2.5          │ 略微分散，尚可接受           │
│ 三灵根   │ 4.0          │ 明显拖慢，需大量资源弥补     │
│ 四灵根   │ 6.0          │ 修行艰难，非大机缘难成大器   │
│ 五灵根   │ 8.0          │ 传说中的"废灵根"，几无可能   │
└──────────┴──────────────┴──────────────────────────────┘

举例：
- 双灵根：中品火灵根(1.0) + 中品木灵根(1.0) → 综合速度 = (1.0+1.0)/2.5 = 0.8
- 三灵根：上品金灵根(2.0) + 中品水灵根(1.0) + 下品土灵根(0.5) → 综合速度 = (2.0+1.0+0.5)/4.0 = 0.875

多灵根的优势：
- 可修习多种属性的功法与术法，战术灵活度更高
- 同一品级的多灵根可触发"相生"加成（如木生火：修炼速度+10%）
- 部分上古功法要求特定多灵根组合

多灵根中各灵根品级可不同，最高品级决定境界上限。

五、隐藏灵根

隐藏灵根是潜伏于修士体内、常规检测手段无法发现的灵根。
在太玄界"灵气衰退、飞升断绝"的背景下，隐藏灵根的出现往往与上古仙朝的遗存有关。

【隐藏灵根的成因】
1. 上古血脉封印：祖上为上古仙朝修士，血脉被封印，需特定条件激活
2. 转世遗存：大能转世者可能带有前世灵根，需突破特定境界后逐渐觉醒
3. 洞天机缘：在洞天、福地、禁地中可能受到先天灵气刺激而激发
4. 天材地宝：服用某些上古灵药或灵物可能唤醒隐藏灵根
5. 濒死突破：生死关头可能激发体内潜藏的隐藏灵根

【隐藏灵根的特性】
- 隐藏灵根在激活前不影响修炼速度计算
- 激活后，按多灵根规则重新计算综合修炼速度
- 隐藏灵根的品级通常不低于角色的主灵根品级
- 隐藏灵根一旦激活即变更为永久显性灵根，不可再次隐藏
- 隐藏灵根可能与主灵根属性相克，激活后需谨慎选择功法路线

【隐藏灵根在故事/游戏中的用途】
- 主角"废灵根"反转：看似凡品单灵根，实则隐藏极品变异灵根
- 剧情关键转折：激活隐藏灵根成为突破瓶颈的契机
- 上古仙朝线索：隐藏灵根可能是飞升真相的关键钥匙
- 门派争夺：被发现拥有隐藏灵根的修士可能成为各大宗门争夺的对象

各域因灵气特性不同，对特定灵根有修炼加成：

┌────────────┬──────────────────────┬────────────┐
│ 域         │ 灵根修炼加成         │ 加成幅度   │
├────────────┼──────────────────────┼────────────┤
│ 中州天域   │ 全灵根平衡           │ +0%        │
│ 江左天域   │ 水灵根、木灵根       │ +15%       │
│ 关陇玄域   │ 金灵根、土灵根       │ +15%       │
│ 太行火域   │ 火灵根               │ +25%       │
│ 河西星域   │ 星灵根               │ +25%       │
│ 漠北荒域   │ 风灵根、土灵根       │ +15%       │
│ 蜀川幽域   │ 暗灵根、毒灵根       │ +25%       │

说明：修炼加成为修炼速度系数的额外倍率叠加。例如中品火灵根(1.0)在太行火域修炼时：
实际修炼速度 = 1.0 × (1 + 0.25) = 1.25

七、灵根相生相克

五行相生：木→火→土→金→水→木
五行相克：木→土→水→火→金→木

变异灵根继承其母属性的相生相克关系：
- 风(木) 生 火，克 土
- 雷(金) 生 水，克 木
- 冰(水) 生 木，克 火
- 暗(土) 生 金，克 水
- 星(火) 生 土，克 金

实战效果（通用）：
- 通用属性克制为简化参考值，不直接用于战斗结算。
  术法与神通的精确匹配规则见第八节（v5.10 内外圈），数值以第八节为准；
  不沿用旧版 ±10% 或 ±20% 简表。
八、术法与神通的五行属性匹配规则

【8.1 五行属性字段】

所有术法和神通均需标注五行属性（金/木/水/火/土/风/雷/冰/暗/星/毒/混沌），
与灵根需求是独立的两个维度：
- 灵根需求：学习该术法/神通需要什么灵根（入门门槛）
- 五行属性：该术法/神通自身所属的属性（决定相生相克与匹配效果）

【8.2 施法匹配（内圈）—— 术法属性 vs 施法者功法属性】

术法/神通释放时，其五行属性与施法者所修功法的功法属性进行匹配。
内圈匹配遵循"一正一负"原则——相生和相克各有收益与代价，同属性则无影响。

┌──────────┬────────────────────────────────────────────┐
│ 关系     │ 效果                                       │
├──────────┼────────────────────────────────────────────┤
│ 同属性   │ 无影响（同源灵力，无需额外调动，也不       │
│          │  产生增益）                                │
├──────────┼────────────────────────────────────────────┤
│ 相生     │ 【正】伤害/效果 +10%（相生滋养，术法       │
│          │   威力增强）                               │
│          │ 【负】灵力消耗 +10%（相生之力倾泻而出，    │
│          │   难以精准收束，额外消耗灵力）             │
├──────────┼────────────────────────────────────────────┤
│ 相克     │ 【正】暴击率 +5%，暴击伤害 +10%（强行      │
│          │   催动相克属性，灵力狂暴不稳定，一旦命中    │
│          │   则爆发异常）                             │
│          │ 【负】伤害/效果 -10%（根本属性相克，       │
│          │   基础威力被削弱）                         │
├──────────┼────────────────────────────────────────────┤
│ 无关联   │ 无修正                                     │
└──────────┴────────────────────────────────────────────┘

「相生」指 施法者功法属性 → 生 → 术法/神通五行属性
「相克」指 施法者功法属性 → 克 → 术法/神通五行属性

设计意图：
- 同属性：稳定可靠，无额外风险与收益。适合保守打法。
- 相生：正向收益（伤害↑）但持续施法成本↑，适合爆发收尾的场合。
- 相克：基础伤害↓但暴击期望↑，适合堆暴击的build（高暴击率下期望收益转正）。

【8.3 受击匹配（外圈）—— 术法属性 vs 目标功法属性】

术法/神通命中目标时，其五行属性与目标所修功法的功法属性进行匹配：

┌──────────────────────┬──────────────────────────┐
│ 关系                 │ 效果                     │
├──────────────────────┼──────────────────────────┤
│ 术法克目标           │ 伤害 +10%（属性压制）    │
│ 目标克术法           │ 伤害 -10%（属性被克制）  │
│ 术法生目标           │ 伤害 -5%（目标受益相生） │
│ 目标生术法           │ 伤害 +5%（术法受益相生） │
│ 同属性               │ 无修正                   │
│ 无关联               │ 无修正                   │
└──────────────────────┴──────────────────────────┘

【8.4 内外圈叠加规则】

施法匹配（内圈）与受击匹配（外圈）的效果独立叠加，乘法计算。
注意：内圈相克的暴击增益不参与乘法叠加，仅在命中后独立判定暴击。

基础伤害修正 = (1 + 内圈伤害修正) × (1 + 外圈伤害修正)

示例：火属性术法，施法者功法为木（木生火），目标功法为金（火克金）
  内圈修正（相生）：伤害 +10% → 1.10
  外圈修正（术法克目标）：伤害 +10% → 1.10
  基础伤害修正：1.10 × 1.10 = 1.21 → 伤害 +21%

示例：水属性术法，施法者功法为火（火克水），目标功法为木（水生木）
  内圈修正（相克）：伤害 -10% → 0.90；同时获得暴击率+5%、暴击伤害+10%
  外圈修正（术法生目标）：伤害 -5% → 0.95
  基础伤害修正：0.90 × 0.95 = 0.855 → 伤害 -14.5%（但内圈暴击增益独立结算）

【8.5 变异属性与特殊属性的匹配逻辑】

变异属性（风／雷／冰／暗／星／毒）保留独立显示属性和内容身份，但只继承单一母属性的相生相克关系进行匹配判定：

┌──────────┬────────────┬──────────────────────────────┐
│ 变异属性 │ 母属性     │ 匹配判定规则                  │
├──────────┼────────────┼──────────────────────────────┤
│ 风       │ 木         │ 视为木属性判定相生相克        │
│ 雷       │ 金         │ 视为金属性判定相生相克        │
│ 冰       │ 水         │ 视为水属性判定相生相克        │
│ 暗       │ 土         │ 视为土属性判定相生相克        │
│ 星       │ 火         │ 视为火属性判定相生相克        │
│ 毒       │ 木（腐变） │ 视为木属性判定相生相克；      │
│          │            │ 毒属性术法额外附带中毒判定    │
│ 混沌     │ —          │ 见8.6节（无属性，不匹配）     │
└──────────┴────────────┴──────────────────────────────┘

变异属性不再叠加独立的全局外圈修正。内圈与外圈均只按表中的母属性关系结算一次；风、雷、冰、暗、星、毒的差异由具体术法、状态、学习条件和专属机制表达，不能再以“变异精纯”为由额外提高或降低通用克制倍率。

跨体系匹配示例：
  例1：施法者功法=冰(水)，术法=火
       冰(水)克火 → 内圈相克 → 伤害-10%，暴击率+5%，暴击伤害+10%
  例2：暗属性术法 → 目标功法=水
       暗(土)克水 → 术法克目标 → 外圈+10%
  例3：雷属性术法 → 目标功法=木
       雷(金)克木 → 术法克目标 → 外圈+10%

【8.6 混沌属性规则】

- 混沌属性的术法/神通视为「无属性」，不触发任何匹配修正
- 混沌灵根修士使用任何属性术法/神通时，内圈匹配视为「同属性」（无影响），
  外圈匹配按术法实际属性正常计算

【8.7 无属性术法/神通】

- 纯物理通用技巧（如基础普攻）可标注五行属性为「—」
- 标注为「—」的术法/神通不参与任何属性匹配计算

【8.8 血脉神通的属性确定】

血脉神通的五行属性由其血脉来源决定，通常与所属门派/家族的功法属性一致。

【8.9 领域神通的属性确定】

领域神通的五行属性继承自施法者所修功法的功法属性。

【8.10 被动神通的属性标注】

- 主动类神通：必须标注五行属性
- 被动类神通：若涉及属性伤害加成/减免，标注对应五行属性
- 纯通用被动（如格挡率+N%）：标注为「—」
