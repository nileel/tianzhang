# 元婴锚点与金丹位格设定

✅ 已审核（2026-07-05 Codex；变更范围：同步“一源、多化、多界；元婴位格唯一”规则，废弃常规模板元婴与低配金丹口径）

> 本文是元婴锚点倒推法的规则摘要。具体金丹位格效果、对象、限制、代价、自辟元婴方向与批量生产校验，以 `docs/基础设定/元婴锚点与金丹位格矩阵.txt` 为准。

## 一、境界边界

1. 化神是太玄界的最高境界；炼虚彻底删除，不再作为境界、NPC 身份、道具门槛、功法篇章或世界背景使用。
2. 玩家当前完整成长链仍止于金丹。元婴与化神用于世界背景、顶层 NPC 与金丹位格的倒推锚点，不进入当前玩家线性养成。
3. 化神掌握五类根本法则之一：五行、阴阳、宇宙、五蕴、因果。化神修士只掌握其中一系，不得兼称全知全能。
4. 元婴没有常规模板或低配版本。每一个元婴都是唯一高位位格；任一具体元婴位格同一时期只能有一个持有者。
5. 世界中可以存在多条自辟元婴范式，但每条范式的实际元婴位格仍然唯一，不可批量复制。

## 二、元婴分支

元婴分支共十七条：

- 五行：木、火、土、金、水。
- 阴阳：阴、阳。
- 宇宙：宇、宙。
- 五蕴：色、受、想、行、识。
- 因果：业、缘、轮回。

十七条分支的已审定金丹位格效果、对象、限制、代价、配合关系与丹枢接口，统一以矩阵文件为准。金丹位格正式命名使用矩阵中各席位括号内标注的名称（如「报春根」）。

## 三、源位、化位、界位

1. 源位：每条分支唯一，直抵变量本源，拥有最高解释权与承接权。
2. 化位：每条分支可有多个，每个代表一种变量转化路径。
3. 界位：每条分支可有多个，每个代表一种局部长期规则、地域条件或组织秩序。
4. 矩阵中当前列出的化位、界位是基准位格，不封闭后续扩展。新增化位或界位必须继承本分支变量，写明转化路径或局部规则，且不得新增第二个源变量。
5. 源、化、界是通用位格，不归任何单一宗门所有。宗门只能掌握传承、资源、解释权、占据方式或局部地域，不能垄断整条分支。

## 四、金丹、占据方式与丹枢

1. 金丹必须有真实位格，不再设计低配或无位格金丹。差异来自源/化/界层级、位格方向、道统支持、主场条件、丹枢接口与后续数值成长。
2. 夺取、继承、敕封、暂寄、自辟，是占据源、化、界的方式或状态，不是第四种位格。
3. 敕封若不产生真实源/化/界使用权，只能称血契、妖血契或同类关系。
4. 金丹角色表达为“通用位格 + 个人丹枢”。丹枢至少记录：丹名、丹性、枢材、枢律、代价、丹域回响。
5. 丹枢只能调整媒介、偏向对象、代价分配、丹域景象、战斗表现和宗门叙事，不能改写矩阵定义的世界变量、边界和不可替代项。

## 五、元婴锁定规则

1. 修士碎丹成婴后，其实际承接的元婴位格唯一且不可并持第二个元婴位格。
2. 元婴可锁定、解释并授予与自身高位秩序相容的金丹位格使用权；被敕封者获得真实使用权，但最终承接权仍受元婴位格源头约束。
3. 元婴真君陨落后，其锁定与敕封关系自动解锁，相关金丹位格重新开放竞争。
4. 元婴锚权碎裂但修士本人未死的情况，须逐案判断。苻渊属于“自辟元婴失败 + 德业反噬残留”，不得再按旧口径写成常规升境跌落或旧中心失效。

## 六、批量生产边界

后续扩展人物、丹名、功法、术法、神通、洞府和事件时，必须遵守：

1. 不新增第十八条元婴分支，除非用户明确批准基础设定升级。
2. 不新增第二个源位。
3. 新增化位或界位必须说明与分支变量的关系、转化路径或局部规则。
4. 不出现常规模板元婴、低配金丹或无真实位格的金丹。
5. 自辟元婴方向在命名任务完成前必须保留【名称待定】，不得临时命名。
