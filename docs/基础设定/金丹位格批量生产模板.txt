# 金丹位格批量生产模板

⚠️ 已修改/未审核；修改方：DeepSeek V4 Pro；变更范围：新建批量生产模板，约束 DeepSeek 在 17 分支 × 51 席位矩阵内扩展内容。

> 本文是 DeepSeek V4 Pro 批量扩展角色、丹枢、功法、术法、神通、洞府、事件时强制使用的约束模板。
> 正式名称尚未批准——所有内容只使用"根系·分支·源/化/界"临时代号，不得自行命名。

## 一、通用硬约束（所有模板适用）

### 1.1 禁止事项

- 不得创建正式名称、第十八条元婴分支、第四种位格（源化界以外的席位层级）
- 不得将完整丹系写成单一宗门私产；宗门拥有的是传承、资源、叙事解释权或敕封能力
- 不得在未运行 BattleSim 的情况下自定成丹阈值、夺取数值或本命神通数量
- 不得自行命名化神根系、元婴分支或金丹席位——只能引用 `docs/基础设定/元婴锚点与金丹位格矩阵.txt` 中的临时代号
- 不得把"敕封"写成唯一合法席位获取方式——占据方式为夺取/继承/敕封/暂寄/自辟五种
- 不得把太一道庭写成所有敕封席位的垄断者
- 不得让司马承景作为常规可击杀战斗单位

### 1.2 强制字段（每份产出必须包含）

| 字段 | 说明 | 不填后果 |
|------|------|----------|
| 目标席位 | 引用矩阵中的"根系·分支·源/化/界"代号 | 无法回指矩阵，产出作废 |
| 矩阵回指 | 引用 `元婴锚点与金丹位格矩阵.txt` 的具体节号（如"五行·土·源位"） | 无法交叉验证 |
| 不可越界项 | 列出本席位绝对不能做的事（引用矩阵的对象/限制/代价原文） | 产出可能违反矩阵边界 |
| 代价 | 持有该席位/丹枢/功法的持续代价（引用矩阵的代价原文或类推） | 缺代价=不平衡 |
| 丹枢接口 | 该人物/功法/术法通过丹枢可自定义的六字段（媒介/偏向对象/代价分配/丹域景象/战斗表现/宗门叙事） | 缺丹枢=不可个性化 |

### 1.3 自检表（每批产出提交前必须逐项勾选）

- [ ] 每份产出引用的席位代号是否在 17 分支 × 3 席位矩阵内有对应条目？
- [ ] 是否突破了该席位矩阵原文的对象/限制/代价？
- [ ] 战斗效果是否仅作为丹枢表现，而非取代法则效果？
- [ ] 宗门与人物是否仅解释/利用/占据位格，而非宣称垄断整条分支？
- [ ] 是否误用了已废止的"正籍/辅籍/敕籍/寄丹"层级语义？
- [ ] 是否误用了"炼虚"作为可用境界？
- [ ] 所有名称是否仅使用临时代号，未擅自创建正式名词？
- [ ] 数值类决策（成丹阈值、夺取数值、本命神通数量）是否标注为"待 BattleSim 验证"？

## 三、丹枢模板

### 3.1 丹枢定义

丹枢是席位的个性化接口——同一席位可由不同修士以不同丹枢占据。丹枢只能改变：
- 媒介（通过什么触发/展现席位效果）
- 偏向对象（偏好作用于哪类目标）
- 代价分配（代价的支付方式与节奏）
- 丹域景象（位格外显的视觉/感知形态）
- 战斗表现（把法则效果转化为具体术法/神通形态）
- 宗门叙事（在宗门/势力语境下的解释方式）

丹枢不能改变：
- 矩阵定义的世界变量
- 矩阵定义的无效边界
- 矩阵定义的不可替代项
- 矩阵定义的持续代价本质

### 3.2 丹枢必填字段

```
丹枢名称：（临时代号）
所属席位：（引用矩阵临时代号）
媒介：（通过什么触发/展现）
偏向对象：（偏好作用于哪类目标）
代价分配：（代价的支付方式与节奏）
丹域景象：（位格外显的视觉/感知形态）
战斗表现：（转化为具体术法/神通形态，不写具体数值）
宗门叙事：（在宗门/势力语境下的解释）
不可越界：（引用矩阵原文中的对象/限制/代价清单）
```

## 四、功法/术法/神通模板

### 4.1 通用字段（新增或修改时必须填写）

除原有设计规范模板字段外，新增：

| 字段 | 说明 |
|------|------|

| 丹枢接口 | 该内容通过丹枢可定制的六维度 |

## 七、DeepSeek 执行边界

### 7.1 DeepSeek 可以做

- 在已有 17 分支 × 51 席位矩阵内扩展角色、丹枢、功法、术法、神通、洞府、事件
- 引用矩阵原文的对象/限制/代价约束内容
- 使用临时代号（根系·分支·源/化/界）描述席位
- 标注"待 BattleSim 验证"的数值字段
- 对每份产出运行自检表

### 7.2 DeepSeek 不能做

- 创建正式名称、第十八条分支、第四种位格、全丹系宗门垄断、新的化神根系
- 在未运行 BattleSim 的情况下自定成丹阈值、夺取数值或本命神通数量
- 把 DeepSeek 的修改标为「✅ 已审核」
- 预填"审核方：Codex / ChatGPT5.5"或"已复核"

### 7.3 交接要求

每批产出完成后：
1. 自检表全部勾选
2. 列出"待 Codex / ChatGPT5.5 复审"的边界问题
3. 更新 `开发管理/AI合作沟通.txt` 交接条目
4. 提交信息包含"待 Codex 复审"语义

## 八、示例：一个最小合规角色

以下是最小可验证合规产出示意——表明字段如何回指矩阵、如何不可越界：

```
【某散修·临时代号】

历史锚点：借用——散修"在体系外寻找位格"参考历史上流民/隐士群体
          结构，不照抄任何真实历史人物。不照抄——不设对应真实人物。
叙事层级：本章功能——展示火分支化位的个人丹枢差异。
          当前目标：争夺火分支化位空席。
          失败代价：丧失争夺窗口，需等下次循环。
          行动时限：三个月内（火分支化位计有天然周期）。
知识边界——已知：火分支化位上一任占据者陨落的具体时间。
          误判：以为只有宗门成员有资格争夺。不可知：竞争者确切数量。

元婴分支：五行根系·火分支
位格状态：金丹。占据目标为火分支化位（使已发动的力量沿媒介高速传导）。
          占据方式：争夺（待决斗/丹枢较量）。
          空位状态：当前有空席（上一占据者陨落后仍未确认继任）。
丹枢——媒介：以自身丹火为引燃/传导媒介。
       偏向对象：偏好加速己方术法传导，不直接增强攻击力。
       代价分配：每次加速消耗一层丹火印记（上限三层，每层冷却一天）。
       丹域景象：周身丹火在加速瞬间呈现流星尾迹。
       战斗表现：可在战斗中使一名友方术法在当前轮次获得额外一次发动时机。
       宗门叙事：散修无宗门——此为无归属丹枢，丹域景象仅为个人标记。
不可越界：不得提供传导内容（矩阵化位"不能提供内容或保证理解正确"）；
          不得无代价无限传导（代价为丹火印记冷却）。

关系限制：【待定竞争者】争夺同一席位的另一位散修（强关系1）；
          【天机楼联络人】购买了竞争者情报（弱联系）。

战斗表达——战法标签：辅助型·传导加速。
           战略威胁：可为强力术法者提供"双发"窗口。
           克制关系：传导通道可被水行反流术法中断。
           ※ 具体命中率/伤害倍率待 BattleSim 验证。

自检：[✓] 火分支化位在矩阵有对应条目
      [✓] 不突破"不能提供内容"限制
      [✓] 战斗效果仅丹枢表现
      [✓] 未宣称垄断火分支
      [✓] 未使用正籍/辅籍/敕籍/寄丹
      [✓] 未使用炼虚
      [✓] 仅使用临时代号
      [✓] 数值标注待验证
```
