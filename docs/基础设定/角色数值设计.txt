第三章：一级属性公式
═══════════════════════════════════════════════════════

一级属性 = 境界基础值 + 小境界成长累计 + 先天属性 × 境界系数 × 功法权重。

HP 当前使用 BattleSim 线性根骨项和 HP 专属倍率：

  HP = (境界基础HP + 小境界HP成长 + 根骨 × HP系数 × 根骨权重 × 2.2) × 灵根修正

其他一级属性使用线性公式：

  属性 = (境界基础 + 小境界成长 + 对应先天 × 境界系数 × 功法权重) × 灵根修正

MP 额外乘以金丹稳定度倍率 `DanJiStabilityMult`。当前实现不再使用 `根骨^0.75` 次线性 HP 指数；该公式只保留为 v3.0 历史记录。

|------|------|
| 凡品 | 0.70 |
| 下品 | 0.85 |
| 中品 | 1.00 |
| 上品 | 1.20 |
| 极品 | 1.50 |

| 金丹 | 1800 | 700 | 350 | 350 | 280 | 280 | 90 | 0.8 | 4.0 |

N-FPD-GROWTH-01 锁定的道基四阶段迁移规则：

- 每部功法、每项一级属性先按现行功法筑基单段增量乘以五，取得可追溯的旧五段累计预算。
- 第一至第四阶段依次分配累计预算的 18%、22%、27%、33%；份额严格递增，不平均除以四。
- 整数预算先为每阶段保留 1 点，再按上述份额对剩余预算取整，尾差按小数余数从大到小、阶段顺序从前到后稳定分配。
- 非整数预算直接按份额分配，最后一阶段吸收浮点尾差；迁移前后累计差不得超过 `1E-9`。
- 移力继续使用境界固定值，不从旧五段迁入四阶段成长表。
- 练气出口不获得道基成长；完成第四阶段后的筑基累计预算与旧五段相同，因此金丹入口前的一级属性总预算不变。

道基核心可数值化参数使用代表性连续曲线：

```text
normalizedMagnitude = 0.35 + (1.00 - 0.35) × progress^1.25
```

`progress` 为 `[0, 1]` 的连续养基进度；第一至第四阶段的代表锚点依次为 `0.350`、`0.515`、`0.742`、`1.000`。该曲线不自动启用非数值效果，后者仍须由统一效果绑定显式声明条件。

第六章：战斗二级属性
═══════════════════════════════════════════════════════

设计原则：战斗二级属性不再由裸先天属性直接提供。当前 BattleSim 已将气运、神识、资质的直接直加项改为功法倾向加成，并用 `secondary-detach-a4` self-test 锁定。

战斗二级属性来源：
- 功法篇章或功法倾向
- 装备
- 丹药
- 特定术法、神通或状态

非战斗二级属性来源：
- 修炼速度：灵根品级 + 资质
- 悟性：资质
- 幸运值：气运
- 魅力值：气运

BattleSim 当前二级属性规则：
- `ResolveSecondary` 读取功法五项权重，选取权重大于 0.15 的前两项。
- 选中一项时，每章提供 5% 对应二级属性；选中两项时，每章各提供 3%。
- 根骨倾向 → 格挡率；魂魄倾向 → 魂盾率；神识倾向 → 命中率；资质倾向 → 暴击伤害；气运倾向 → 闪避率。
- 格挡减伤率 = 格挡率 × 0.8。
- 魂盾减伤率 = 魂盾率 × 0.8。
- 功法倾向补偿：闪避率 += 气运权重 × 30；暴击率 += 神识权重 × 30；暴击伤害 += 资质权重 × 80（均为基础150%暴击倍率之上的附加百分比点）。
- `物抗率`、`魂抗率` 当前默认 0，由门派机制或后续装备/丹药系统补入。

注意：上面的“资质权重 / 气运权重”指功法倾向权重，不是角色裸先天资质或气运值。

第六.1章：金丹槽位与丹枢显式容量
═══════════════════════════════════════════════════════

金丹槽位不是一级属性、战斗二级属性、伤害倍率、资源、充能或冷却账本。筑基基准为术法
`5`、普通神通 `2`；金丹只允许稳定真实位格的显式 `DanshuSlotEffectBinding` 修正容量：

```text
术法槽 = 5 + a
普通神通槽 = 2 + d

a、d 为非负整数；a ≤ 3，d ≤ 2，a + d ≤ 当前稳定实位数（1～3）
```

每条绑定必须由目标矩阵明确开放 `DANSHU_SLOT_CAPACITY_V1`，同时匹配唯一
`JindanCoreBinding.danshuCoreId`、稳定 `positionId`／`positionType`、该位格的独立主承载
实例和兼容档案，并且固定 `delta=+1`。一个稳定实位只能绑定术法或普通神通其中一类；
最终容量硬上限为术法 `8`、普通神通 `4`。无绑定、`TEMPORARY`、失稳、紫府数量、府属、
第四／第五府和辅助连接均不改变 `5/2` 基准。

该方案只锁定审计模型和未来数据字段边界，尚未写入矩阵、CSV、Unity 或 BattleSim 角色
运行时；现有运行时没有可生效的金丹加槽记录。详见 `docs/角色养成/术法槽位设计.txt` 与
`开发管理/任务归档/验证记录/金丹槽位与丹枢加成数值验证记录.txt`。

覆盖边界（2026-07-18）：本章保留 2026-07-02 BattleSim 的旧模型数值快照，不把它迁写为新金丹规则的验证结论。该历史模型当时尚未接入五十一个基础效果装配、一／二／三个真实位格、`PositionCompatibilityCompiler`、显式异效组合、同阶领域对抗 QTE／跳过算法、确定性资源冲突、真实位格丧失死亡、不可变 `JindanCoreBinding` 或山河周期账本，且没有可验证这些系统的有效金丹样本。G2 与下列结果只对当时已经实现的旧模型有效；后续静态丹相和槽位审计不改变这组历史战斗结论。

2026-07-02 本轮验证命令：
- `dotnet build -c Release --no-restore "D:\天章游戏开发\simulations\BattleSim"`
- `dotnet run --no-build -c Release --project "D:\天章游戏开发\simulations\BattleSim"`

本轮默认模拟结果：
- 金丹样本：物·修炼 16/20，法·修炼 17/20，水·散修 15/20，太虚·宿慧 2/20；其余 Build 为 0/20。

- 紫府神通、府位覆盖、根本神通闭环仍为未接入状态，不参与成丹、争席或战斗倍率。
- 金丹压制战：旧五段模型中的物·修炼、法·修炼、水·散修、太虚·宿慧“紫府圆满”样本正面对抗金丹初期仍为 0.0% 胜率；该名称和结果都不能验证新四阶段筑基结构。

解释边界：
- 本快照证明模拟器能完整运行，并验证“先天不直加战斗二级属性”的代码口径。
- 本快照不代表 21 Build 全局平衡已经完成；当前筑基、紫府矩阵仍存在明显门派/机制克制与样本极化，后续应通过功法成长表、机制开关或 AI 行为继续校准。
