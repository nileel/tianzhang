## 一、据点身份

| 字段 | 值 |
|------|-----|
| 据点 ID | `guanzhong_city` |
| 正式名称 | 关中城 |
| 内容范围 | `content_scope_production`（生产范围，仅限正式场景与启用功能可引用） |
| 据点类型 | `settlement_type_city`（城市） |
| 所属地区 | `guanzhong`（关陇玄域） |
| 所有者 | `faction_neutral`（中立／关陇坊市联盟实际运营） |
| 视觉主题 | `visual_theme_loess_city`（黄土城镇：夯土墙、灰瓦顶、木构集市、灵矿商号招牌） |

### 定位说明

关中城位于关陇玄域外围的关中平原，是一座依托灵矿贸易兴起的低阶修士城镇。它从废弃的混元山外围军营改造而来，现由关陇坊市联盟实际运营——不是宗门直属据点，也没有固定势力驻军。

城市不承担主线信息：不解释龙脊之变、不为混元山或太虚观站台、不提供地区主线线索。它的叙事作用是在新手外围提供一个功能齐全但氛围低调的安全据点，让玩家在黄土、灵矿与残余灵气的环境中开始探索。

## 二、城市功能

### 功能总表

| 功能 ID | 显示名 | 可用性 | 禁用原因 |
|---------|--------|--------|----------|
| `bounty_board` | 悬赏板 | `enabled` | — |
| `market` | 坊市 | `disabled` | 商店系统、物品定价、库存管理和经济基线尚未建立；禁用期间坊市区域仍可进入，但商贩只显示环境文本，不提供交易界面 |
| `inn` | 客栈 | `disabled` | 客栈恢复规则（灵力回复量、天数消耗、费用）和状态保存尚未定义；禁用期间可查看客栈外观，但不提供休息功能 |
| `intelligence` | 情报 | `disabled` | 情报系统依赖声望等级、NPC 关系网和信息分层规则，这些均未建立；禁用期间情报贩子显示"今日无事"类环境文本，不提供可操作选项 |

### 功能规则

- `bounty_board` 为首个可用功能，由悬赏处理器通过 `SettlementFeatureDispatcher` 接入；其他功能仅在对应处理器注册后改为 `enabled`。
- 禁用功能不得调用处理器，也不得输出 placeholder 完成日志（如"该功能已解锁"）；必须明确返回禁用原因给视图层。
- 功能列表使用稳定 `featureId` 查找，显示名通过本地化键取得；禁止用显示名字符串代替 ID 做功能匹配。
- 新功能上线时，只需在城市档案中新增功能条目并注册处理器，不修改既有功能的 ID 或启用状态。

## 三、冒险入口

### 入口总表

| 入口 ID | 目标冒险 | 进入条件 | 返回规则 |
|---------|----------|----------|----------|
| `guanzhong_wild` | 关中野外·石甲兽阻路（`guanzhong_wild`） | 玩家当前位于关中城；无额外境界、任务、声望或道具前置 | 胜利或败北后均返回关中城；返回目标由 Adventure 场景写入 `Settlement("guanzhong_city")` |

### 入口规则

- `guanzhong_wild` 是当前唯一的正式冒险入口；入口标识使用稳定 `adventureId`，不以显示名或路径匹配。
- 重复进入同一入口每次重演同一场低阶石甲兽遭遇，不累积独立状态、不升级为支线、不展开地区主线。
- 返回关中城后恢复据点场景的完整功能面板和退出至世界地图的入口，保留玩家当前世界节点与角色档案。
- 若正式石甲兽引用缺失或绑定数量不为一，Adventure 场景拒绝启动遭遇但保留"返回来源"出口，不伪造完成也不软锁据点入口。

## 四、场景文本与信息边界

### 四.1 环境描述（首次进入／通用）

关中城的夯土城墙不高但厚实，城门口的灵矿商号招牌被风沙磨得发白。街道两侧是半木构的铺面和临时搭建的矿摊——黄土灵晶、关陇玄铁、锐金砂的样品摆在粗布上，矿工和散修蹲在摊前讨价还价。空气中混着黄土味、灵气残余的微弱嗡鸣和炉火锻铁的焦香。

城内最显眼的建筑是一座由废弃军械库改造的坊市大厅——关陇坊市联盟的总部"长宁厅"就设在里面。大厅外墙还留着混元山时代的军阵刻痕，但已经被人用白灰刷上了各商号的价目表。

### 四.2 服务入口文本（示例，实际由本地化键驱动）

悬赏板（已启用）——"长宁厅东墙挂着一面铁木板，上面钉着几张悬赏令。最上面那张写着：'黄土旧道石甲兽，阻路伤人，击杀有赏。——坊市联盟'。"

坊市（已禁用）——"坊市大厅里人来人往，但柜台上摆的货品都是大宗矿料。散卖法器丹药的散户摊还没出摊——听说最近矿脉变动大，商贩都下矿去了。"

客栈（已禁用）——"'黄土驿站'的门半掩着，里面传来锅勺声。门口的牌子写着'客房已满'——但其实只是伙计偷懒没擦掉旧牌子。"

情报（已禁用）——"长宁厅角落里蹲着一个抱膝打盹的人，旁边立了块木牌：'今日无事。明日也不一定有。'"

### 四.3 信息边界

- 关中城的环境文本和禁用功能说明不得承载以下信息：
  - 龙脊之变的原因、过程或责任人
  - 灵脉共振体系的技术细节或苻渊的角色
  - 混元山与太虚观的道统之争
  - 任何重要 NPC 的行踪、立场或知识
  - 地区主线线索、隐藏副本入口或后续剧情钩子
- 禁用功能的环境文本只描述"此刻为什么不能用"，不给"何时能用"的时间承诺，也不暗示具体机制设计。
- 所有文本最终通过本地化键提供；本文件中的示例文本仅作为设计意图说明，不直接进入 Unity 或 Language asset。

## 五、玩法接口

| 接口 | 关中城提供 |
|------|-----------|
| WorldScene | 通过返回世界按钮退出至关陇世界地图；当前世界节点为 `guanzhong_hub` |
| SettlementScene | 正式据点 ID `guanzhong_city`；功能面板由 `SettlementFeatureDispatcher` 按功能可用性渲染；冒险入口列表由 `adventureEntranceIds` 驱动 |
| AdventureScene | 唯一入口 `guanzhong_wild`；进入前写入返回目标 `Settlement(guanzhong_city)` 与当前据点 ID |
| Combat | 关中城本身不触发战斗；战斗发生于 `guanzhong_wild` 的遭遇阶段 |
| 修炼/境界 | 关中城不提供修炼节点、功法学习或突破功能（客栈禁用，无修炼设施） |
| 经济/奖励 | 关中城本身不产生交易或奖励；悬赏板只负责悬赏的接取、进度查看和领奖入口，具体奖励由 `BountyData` 和悬赏运行时决定 |
| 关系/声望 | 不改变任何势力或 NPC 关系 |
| 道具/线索 | 不直接给予或消耗物品；物品授予由战斗掉落和悬赏领奖流程统一处理 |
| 世界状态 | 不改变节点归属、封锁、天气或地区事件 |

## 六、重复访问规则

- 玩家可随时从世界地图进入关中城，无次数限制、无冷却时间。
- 每次进入关中城时：
  - 恢复完整功能面板（悬赏板可用；坊市、客栈、情报保持禁用及其当前禁用原因）
  - 恢复冒险入口列表（当前仅 `guanzhong_wild`）
  - 环境文本可轮换，但不在本文件定义具体轮换逻辑
- 已领取的悬赏不在悬赏板重复出现；尚未接取或进行中的悬赏保持可见。
- 重复访问不改变城市功能可用性、冒险入口、NPC 对话树（当前无 NPC）、经济数值或世界状态。

## 七、禁止项复核

- 不新增 NPC、对话树、商店库存、价格、客栈恢复、情报交易、声望、地区主线或世界状态。
- 不修改 `SettlementSceneController`、场景、CSV、Language、asset、存档或测试。
- 禁用功能的说明不写成已经可操作；不使用"敬请期待""即将开放""施工中"等暗示完成度的占位表述。
- 不改变 `guanzhong_wild` 既有的进入/返回上下文或石甲兽战斗规则。
- 不使用显示名称、GameObject 名或 asset 路径代替稳定 ID 做功能匹配或场景绑定。
