## 一、模板字段

每名普通NPC单独一个文件，文件名格式：`docs/剧情/普通NPC/<势力>_<名称>.txt`。

以下为必填字段。所有字段必须为纯文本，不嵌入战斗数值或伤害倍率。

### 字段 1：基础信息

```
名称：（占位；批量生产时由DeepSeek拟定，Codex复审确认）
称谓：（NPC在游戏中的显示名称，如"外门执事·周"、"坊市药师·柳"）
类型：（从第三节"可交互职责"表中选择最匹配的一项）
所属势力：（宗门/组织/散修/无）
据点：（主要出现位置；可列出多个候选据点）
境界范围：（练气初期~筑基后期；不超过筑基）
灵根：（无/下品/中品/上品；普通NPC以中下品为主）
寿数：（可选；普通NPC不需要精确寿数，可写"约四十岁"等模糊表述）
外貌：（1-2句简述，用于UI头像或文字描述回退）
```

### 字段 2：可交互职责

```
主要职责：（从第三节类型表中匹配）
次要职责：（可选；最多一个次要职责）
对话功能：（任务接受/提交/信息查询/商品交易/修炼辅助/无）
```

### 字段 3：称谓与对话风格

```
自称方式：（如"老夫""在下""咱""本执事"等）
对玩家称谓：（根据玩家境界变化；示例：练气期称"小友"，筑基期称"道友"）
说话特征：（1-2句概括——如"简练务实，三句话内说完正事"、"爱唠叨旧事，每句话带一个'想当年'"）
情绪范围：（如"平和→焦急（当据点受威胁时）"）
```

### 字段 4：任务钩子

```
主任务钩子：（该NPC可以触发或承接的任务类型；引用任务ID或任务文件名，暂未创建时写"待设计"）
支线钩子：（可选；最多两个）
信息钩子：（可选；该NPC可以提供哪类世界信息——如"关陇灵脉节点分布""当地势力动态""丹药材料采集点"）
章限：（该NPC在哪一章节/阶段解锁；第一章→第二章→不限）
```

### 字段 5：复用限制

```
最大实例数：（该类型NPC在整个游戏世界中的最大数量；如"各据点可有一名同类NPC"、"每域最多2名"、"全游戏唯一"）
可替换性：（该NPC被移除/死亡后，是否可由同类型NPC替代；是/否/部分）
据点迁移条件：（什么条件下该NPC可能出现在不同据点；如"主线节拍推进后""该据点被敌对势力占据后"）
```

### 字段 6：关系边界

普通NPC的关系上限为**弱联系**——不得与重要NPC或玩家建立强关系（强关系定义见 `背景与重要NPC设计规范.txt` 第五节）。

```
关联重要NPC：（可选；只能写"通过XX渠道间接关联"，不能直接认识或对话重要NPC）
关联其他普通NPC：（可选；同据点或同类型NPC之间的弱关系，如"与同据点的坊市药师有交易往来"）
```

## 二、与重要NPC的核心区别

| 维度 | 重要NPC（13人） | 普通NPC |
|------|----------------|---------|
| 文件位置 | `docs/剧情/重要NPC/` | `docs/剧情/普通NPC/` |
| 模板字段 | 六字段（历史锚点/叙事层级/知识边界/位格状态/关系限制/战斗表达） | 六字段（基础信息/可交互职责/称谓对话/任务钩子/复用限制/关系边界） |
| 历史锚点 | 必须 | 不需要 |
| 知识边界（已知/误判/不可知） | 必须明确列出 | 不需要；普通NPC的知识默认为"局部的、可出错的、无全局意义的" |
| 位格状态 | 必须明确元婴分支与金丹席位 | 不需要；普通NPC不占源/化/界席位 |
| 关系限制 | 最多三条强关系 | 仅弱联系；不得有强关系 |
| 战斗表达 | 战法标签+战略威胁+克制关系 | 不需要；普通NPC不参与命名战斗 |
| 叙事层级 | 本章功能/当前目标/失败代价/行动时限 | 不需要；仅通过任务钩子参与叙事 |
| 直接接触章节级重要NPC | 允许（节拍四限定场景） | 禁止 |
| 全知任何真相 | 禁止 | 禁止（且普通NPC默认不知道任何核心悬念） |

## 三、普通NPC可交互职责类型

以下是普通NPC可以承担的全部交互职责类型。批量生产时每个NPC选择最匹配的一项。

| 类型ID | 类型名称 | 主要交互 | 典型据点 | 备注 |
|--------|---------|----------|----------|------|
| STEWARD | 势力执事 | 任务发布、门派规则解说、身份升级办理 | 宗门/据点内部 | 每个势力至少1名 |
| VENDOR | 坊市商贩 | 商品交易（丹药/法器/材料/符箓/功法残卷） | 坊市/据点商业区 | 按交易品类细分 |
| HEALER | 治疗/丹药 | HP/MP/伤势恢复、丹药炼制委托 | 据点医疗/丹房 | 每个据点可配1名 |
| SCOUT | 情报中介 | 地图情报、势力动态、灵脉节点信息出售 | 坊市/散修营地/天机楼观测站 | 信息需分级标价 |
| GUIDE | 冒险入口 | 副本/遗迹/禁地进入条件说明、传送引导 | 据点入口/副本门口/传送阵 | 连接Adventure场景 |
| QUESTER | 散修委托 | 随机/固定支线任务发布与提交 | 散修营地/坊市/野外 | 可与SCOUT/GUIDE复合 |
| TRAINER | 修炼辅助 | 功法领悟提示、术法练习、修炼加速条件 | 宗门修炼区/洞府 | 按境界限制服务范围 |
| DIALOGUE | 氛围对话 | 环境叙事、世界信息闲聊、势力态度表达 | 所有据点 | 纯氛围NPC，无可推进任务 |
| RIVAL | 同行竞争 | 节点争夺、资源竞争（与玩家为竞争关系） | 野外节点/副本入口 | 第一章节拍三引入 |
| ALLY | 临时协作 | 短期组队、资源共享（与玩家为协作关系） | 野外/副本 | 可转为弱关系 |

## 四、全局禁止项

普通NPC必须遵守以下禁止项，违反者不得通过审核：

1. **位格禁止**：不得占据任何源/化/界席位。不得被描述为"正在冲击金丹""接近成丹"。
2. **知识禁止**：不得知晓任何核心悬念（苻渊闭关内容、王玄略坤舆谱残篇完整位置、封禁裂缝的真正来源、司马承景的状态、上古飞升秘密）。可以提供"传闻"，但必须是"不完整的、可能错误的"。
3. **关系禁止**：不得与13名重要NPC中的任何一人建立直接联系。不得被描述为"XX真君的亲传弟子""XX盟主的副手"。可以通过书信/传音符/中间人间接接收指令。
4. **旧口径禁止**：全字段禁用旧口径术语（正籍、辅籍、敕籍、寄丹、妖血敕）。使用当前口径（源位、化位、界位、夺取、继承、敕封、暂寄、自辟、妖血契）。
5. **战力禁止**：不得被赋予具体战斗数值（HP/MP/攻击/防御/倍率）。可以写"略懂几手术法""能对付低阶妖兽"等描述，但不由本模板提供战斗参数。
6. **主剧情独占禁止**：普通NPC只能推动支线任务和环境叙事，不能独占任何主线节拍的推进所需信息。玩家即使不与某普通NPC交互，也能通过其他方式获得继续主线的必要信息。
7. **境界禁止**：所有普通NPC的境界不得超过筑基后期。任何金丹期NPC必须升格为重要NPC并遵循六字段模板。

## 五、与第一章主线的接入点

第一章已定义四类新增NPC（见 `docs/剧情/主线/第一章-龙脊余震.txt` 第四节）。本模板对应的普通NPC类型映射如下：

| 第一章定义的NPC类型 | 本模板对应类型 | 出现节拍 |
|--------------------|---------------|----------|
| 势力执事（太一外门执事、龙骧军府校尉等） | STEWARD | 节拍一/二 |
| 信息中介（天机楼观测员、退役观测员、散修情报贩子） | SCOUT | 节拍二/三 |
| 跨势力NPC（其他势力低阶成员） | DIALOGUE / ALLY / RIVAL | 节拍二/四 |
| 同行竞争/协作（与玩家争夺/协作锚定同一节点的修士） | RIVAL / ALLY | 节拍三 |

## 六、验证要求

批量生产时每批完成后运行：

- `powershell -ExecutionPolicy Bypass -File tools/check-review-text.ps1 -Paths docs/剧情/普通NPC,开发管理`
- `git diff --check`
- 逐文件检查是否存在旧口径术语（`rg -n "正籍|辅籍|敕籍|寄丹|妖血敕" docs/剧情/普通NPC` 应为空）
- 逐文件检查是否误用了重要NPC字段（如"历史锚点""知识边界""位格状态"）
