## 一、基础信息

```
名称：九霄散修·老关
称谓：营地管事·老关
类型：STEWARD（势力执事）
所属势力：九霄盟（外围散修层）
据点：中州玄域·龙脊南麓散修营地（九霄荒原南缘，龙脊裂谷西段入口附近）
境界范围：筑基初期
灵根：中品土灵根
寿数：约五十岁
外貌：一个晒得黝黑的中年老修士，头发用一根旧布条随便扎在脑后，身上穿着缝补过多次的粗布道袍——袖口磨得发白。左手缺了半截小指——据说是早年在一次灵石矿坍塌中被砸断的。腰间挂着一块磨得包了浆的"长庚令"——九霄盟正式成员的身份凭证，但他很少拿出来给人看。
```

## 二、可交互职责

```
主要职责：散修营地人员登记、安全节点名额分配、营地规则解说
次要职责：九霄盟外围任务中介（代长庚殿向营地散修发布低阶任务，但不直接经手报酬结算）
对话功能：任务接受/提交、信息查询（营地规则、安全节点分布、九霄盟散修信用录的基本运作方式）
```

## 三、称谓与对话风格

```
自称方式："老关"（从不自称"本管事"或"本座"，对谁都说"老关"）
对玩家称谓：
  - 刚来营地的：称"新来的"（和吴校尉一个路数，但语气更随意、不带军旅味）
  - 住满三天还没惹事的：称"小友"
  - 完成第一个委托后：直接叫名字
说话特征：话不多但每句都实在。九霄荒原上活了二十年的人特有的务实——不问来历、不打听道途、不管闲事。口头禅是"活着就行"和"别欠人情"。唯一会让他多说几句的话题是如何在灵气紊乱区找安全节点——"你看到地面上的草是朝哪个方向长的没有？逆着那个方向走，多半有节点。"
情绪范围：平静（日常）→无奈（看到新手散修不带定风阵旗就进荒原）→罕见的认真（被问到"互保记号"的含义时——他会沉默片刻，然后说"有些记号不是给你看的，是给欠账的人看的"）
```

## 四、任务钩子

```
主任务钩子：quest_ch01_sanxiu_mutual_mark（第一章节拍一·散修入口——找到未被宗门垄断的安全通道）
支线钩子：
  - quest_ch01_sanxiu_camp_first_quest（散修营地首个委托——护送物资或清剿营地周边妖兽，作为营地入门引导）
  - quest_ch01_sanxiu_mark_reading（互保记号解读——节拍一可选深入，教玩家辨认三种最常见的散修互保记号及其含义）
信息钩子：
  - 龙脊南麓安全节点的最新分布与稳定状态（"这礼拜第三个节点开始抖了——你们自己看着办"）
  - 九霄盟散修信用录的基础规则（如何建立信用、如何避免被列入黑名单）
  - 散修互保记号的基本类型与含义（"有些记号是'此处安全'，有些是'此处欠账未清'——你得分清楚"）
  - 中州各势力对散修的态度差异（"天工城不赶人但也不留人；白玉京看都不看你一眼；九霄荒原才是散修的家——虽然这个家刮风的时候连帐篷都站不住"）
章限：第一章（节拍一起解锁）；第二章后仍可交互，但营地位置可能因龙脊脉冲频率变化而迁移
```

## 五、复用限制

```
最大实例数：全游戏唯一（龙脊南麓散修营地管事仅此一名；其他散修营地可由同模板不同类型 NPC 担任管事）
可替换性：部分——若老关在第一章节拍五后因营地迁移而离开，可保留"老关在某某方向"的传闻；营地管事职责可由九霄盟另行指派 NPC 接替
据点迁移条件：
  - 第一章节拍三（安全节点争夺）后，若散修营地当前节点失守，老关会带人向东迁移至九霄荒原深处的备用营地
  - 若玩家在节拍五选择"巩固当前安全节点"，老关留在原营地并解锁额外的互保网络任务
  - 第二章若龙脊脉冲频率继续增加，散修营地可能整体向北迁移以避开裂谷边缘
```

## 六、关系边界

```
关联重要NPC：
  - 通过长庚殿任务系统间接知晓卫长庚——营地每旬收到的任务清单落款是"长庚殿"，但他从未见过卫长庚本人（"盟主？那是上面的人——我们这些管帐篷的见不着"）
  - 曾在九霄荒原见过一次天机楼的观测队经过——带队者自称"天机楼弟子"，但没有交换姓名
关联其他普通NPC：
  - NPC-SCOUT-01（天机观测·管）：老关与天机楼观测站有不成文的约定——观测站提供灵气风暴预警，营地提供外围巡逻人力。两人半年见一次面，交换情报和灵石
  - NPC-VENDOR-03（符箓贩·小六）：住在同一个营地——老关是小六在营地里唯一不敢用劣质丹砂糊弄的人（"那老家伙一眼就能看出来"）
  - NPC-QUESTER-02（矿脉散修·石根）：石根每次从关陇回来会在老关的营地歇脚，用矿样换营地补给
  - NPC-SCOUT-03（散修情报·黑耳）：老关对黑耳的态度是"消息可以用，但不能全信——这人三句话里有一句是自己编的"
```

## 八、附注：营地规则

老关管这个营地二十年了。他的管理哲学只有三条：

一、不问你从哪来。散修营地不问出身——逃犯、叛门者、被家族驱逐的弃子、或者只是没钱进宗门的穷修士，在这都一样。只要不惹事，就能住。

二、不替你还债。营地给你安全节点、给你任务、给你一口灵气——但你自己在外面欠的人情债、血债、灵契债，跟营地没关系。老关见过太多散修因为欠了不该欠的人情而被追到营地门口——他的处理方式是："出去解决，别在营地里动手。"

三、别欠无名之债。这是老关唯一会认真叮嘱新人的话。他不解释为什么——"你以后会知道的。"
