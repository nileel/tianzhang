## 一、基础信息

```
名称：太一药师·白
称谓：丹堂药师·白
类型：HEALER（治疗/丹药）
所属势力：太一道庭
据点：云川玄域·太一道庭外山丹堂（建康中枢平原·太一外门学宫东侧）
境界范围：筑基中期
灵根：中品水灵根（辅修木系丹药感知）
寿数：约五十岁
外貌：中等身材，肤色比一般修士偏白——不是在丹房里闷的，是长年处理水炼丹药时被水灵气反复浸染的结果。手指修长而稳定，指甲修剪得极整齐（"丹药入炉，指甲缝里不能有半点杂质"）。穿一件素白丹袍，肩上搭着一条半湿的青色拭丹巾——用来擦拭刚出炉的丹瓶。
```

## 二、可交互职责

```
主要职责：基础丹药供应、灵力恢复辅助、轻伤治疗、丹炉租赁管理
次要职责：外门试炼生的丹药安全知识普及（"不要把丹砂和硫磺放在同一个口袋里——去年有个试炼生烧掉了半间丹房"）
对话功能：商品交易（丹药）、修炼辅助（灵力恢复）、信息查询（炼丹入门、丹药材料采集地点）
```

## 三、称谓与对话风格

```
自称方式："白某"（对外）、"本师"（对来租丹炉的试炼生——带一点自嘲式的正式感）
对玩家称谓：
  - 初次来丹堂：称"你"或"这位道友"
  - 成为常客后：直呼姓名
  - 若玩家也修丹道：称"同修"
说话特征：温和但精确。对丹药的成分、用量和禁忌一口清，对"这药多久能好"这类问题永远回答"看情况"。有自己的原则——不卖来源不明的丹药，不替没有丹方的人炼丹，不在灵力不稳定的时候开炉。
情绪范围：平和（日常）→突然严肃（发现有人滥用丹药或私配违禁丹方时）→微妙的得意（有人夸他炼的"清心散"比内门丹房的还纯时——他绝不会承认自己笑了）
```

## 五、复用限制

```
最大实例数：全游戏唯一（太一道庭外山丹堂药师仅此一名，内门另有庾氏丹房的正式丹修）
可替换性：部分——若该 NPC 因剧情事件离开外山（如被调往内门庾氏丹房），丹堂可改由一名练气后期学徒临时管理，但服务内容和对话质量会降低
据点迁移条件：
  - 若玩家在第一章中大量消耗丹堂资源（如反复重伤），庾氏道脉可能派一名正式丹修来"协助"丹堂管理——此时白药师仍留在丹堂，但部分高阶丹药需要与庾氏来员交涉
  - 第二章若触发"谢观微病危"事件，白药师可能被临时调往建康城参与救治——外山丹堂关闭若干日，期间丹药供应中断
```

## 八、附注：水炼法与丹房日常

白药师的水炼丹法不同于太一道庭主流的火炼法。火炼依赖丹炉高温与火灵根控制；水炼则以水灵气为介质，将药材在灵水中缓慢萃取、分层纯化，再用低温结晶成丹。成品纯度通常高于火炼，但耗时更长、不适合需要高温激发的丹药（如兵血淬体类）。

白药师是外山唯一会水炼法的人。外门弟子私下传言他的水炼法是年轻时在云梦南泽跟一个古修残魂学的——白药师从不证实也不否认，只会在被问到时说："水炼法谁都能学，只要你肯花四十年只炼一种丹。"

他已经用水炼法炼了二十三年"清心散"——这是太一外门最常见的低阶丹药，用于稳固心神、辅助入定。二十三年如一日，品控从未波动。庾氏内门曾经派人来考察他的水炼成品，结论是"纯度达到庾氏内门标准"，但没有给他升格——因为他不姓庾。

白药师对此的态度是："不升就不升，反正丹房清净。"
