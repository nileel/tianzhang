## 一、基础信息

```
名称：符箓贩·小六
称谓：符箓贩·小六
类型：VENDOR（坊市商贩）
所属势力：九霄盟（外围散修层）
据点：
  - 中州玄域·龙脊南麓散修坊市（主据点，九霄荒原南缘散修营地内的临时坊市区）
  - 关陇玄域·关陇坊市联盟各临时集市（不定期巡回）
境界范围：练气后期
灵根：下品火灵根
寿数：约二十五岁
外貌：瘦高个、尖下巴，一双眼睛总是滴溜溜转。穿着一件不知从哪淘来的旧道袍——袖口烧焦了好几处（制符失败留下的），腰间挂了至少五个不同材质的符纸卷筒。永远在笑——但笑得不那么让人放心。右手食指和中指上全是丹砂染的红印子，洗不掉的。
```

## 二、可交互职责

```
主要职责：符箓/丹砂/空白符纸交易
次要职责：以劣质丹砂或过期货品换取散修手中的情报碎片（实质上是情报中介的雏形，但他自己不这么称呼——"我就是爱聊天"）
对话功能：商品交易、信息查询（以交易为条件——"你先买两张符，我再告诉你"）
```

## 三、称谓与对话风格

```
自称方式："小六"（第三人称自称——"小六这价格已经亏本了""小六做生意最讲良心"）
对玩家称谓：
  - 第一次交易：称"道友"（不管对方什么境界，一律"道友"——"统称道友比较安全，叫错了境界得罪人"）
  - 交易满三次后：称"老主顾"
  - 如果玩家曾识破他的劣质丹砂：改称"您"（带一丝心虚的笑）
说话特征：语速快、爱绕弯、每三句话里至少一句是在推销。典型的小贩口吻——"这个价你真不亏""上一批同样的符在天机楼坊市卖三倍""小六可以便宜点，但道友得帮小六个忙……"但偶尔会冒出一句极其精准的判断——让人怀疑他远不止表面看起来那么浅。
情绪范围：热情推销（日常）→故作委屈（被砍价时）→突然压低声音（用劣质丹砂换情报时）→真的慌了（被问到消息来源时——他的消息有时候太准了，准到他自己也心虚）
```

## 四、任务钩子

```
主任务钩子：无独立主线任务；在散修入口 quest_ch01_sanxiu_mutual_mark 中可作为可选信息源——用三张劣质符箓的价格向玩家透露一个互保记号的模糊方向
支线钩子：
  - quest_ch01_sanxiu_fu_trade（符箓材料换情报——收集特定材料换取关于龙脊南麓安全节点最新动态的零散信息）
  - quest_ch01_counterfeit_cinnabar（劣质丹砂的来历——小六的丹砂来源不干净，其中一个供货商可能与散修盗匪有联系；玩家可选择揭发或包庇）
信息钩子：
  - 龙脊南麓散修营地周边最近的灵气波动（"昨天西边有块地的草突然全枯了——小六估摸着那边的节点又不行了"）
  - 各势力坊市符箓价格的粗略对比（小六对各坊市行情了如指掌——这是他吃饭的本事）
  - 散修之间的传闻和小道消息——准确度约七成（黑耳给他的，或者是他用丹砂换来的）
章限：第一章（节拍一起解锁）；第二章后仍可交互，但随散修营地迁移而移动
```

## 五、复用限制

```
最大实例数：同类型商贩可在不同据点出现（各散修营地或坊市可各有一名符箓贩），但小六这个具体人物全游戏唯一
可替换性：是——如果小六因事件离开或死亡，其交易功能可由其他 VENDOR 类型 NPC 替代（如 `npc_tpl_market_supplier` 或下一批坊市 NPC）
据点迁移条件：
  - 第一章节拍三（安全节点争夺）后，若散修营地迁移，小六随营地搬迁
  - 若玩家在节拍四揭发其劣质丹砂来源，小六可能被逐出九霄盟坊市、转为在各据点之间流动的"无证摊贩"
  - 若玩家选择包庇，小六留在营地并解锁专属折扣和额外信息渠道
```

## 六、关系边界

```
关联重要NPC：
  - 与九霄盟长庚殿之间仅存在每月缴纳摊位费的单向关系——他从未见过任何长庚殿高层
  - 从散修情报贩子处二手听闻过"卫长庚"这个名字，但对卫长庚的身份只有模糊认识（"好像是个大人物？"）
关联其他普通NPC：
  - NPC-VENDOR-05（残卷商·薛）：小六的符纸供应商之一——薛先生用残卷和小六换符箓材料，两人在天机楼外围坊市每旬碰一次头
  - NPC-SCOUT-03（散修情报·黑耳）：消息来源——小六大约一半的"情报库存"是从黑耳那里用丹砂换来的。知道黑耳的消息不可全信，但他没有更好的渠道
  - NPC-STEWARD-05（营地管事·老关）：同在一个营地——小六是整个营地里唯一不敢在老关面前耍花样的人。老关帮他挡过两次来找麻烦的客人——"别在我营地里骗人"——但也没赶他走
  - NPC-VENDOR-06（灵兽贩·乌）：偶尔在关陇坊市联盟的临时集市上碰面——小六从乌贩子那里收妖兽骨粉当劣质丹砂的填充料
```

## 八、附注：劣质丹砂的交易网络

小六的劣质丹砂不是他自己掺的——他从一个叫"疤脸陈"的散修盗匪手里进货。陈疤脸专门抢劫从中州向关陇运送符箓材料的商队，抢来的丹砂品相不稳定，陈疤脸就掺骨粉、掺黄土灵晶碎末来增加分量。

小六知道丹砂有问题。但他安慰自己说"反正练气期的符箓威力本来就不大，丹砂差一点也差不到哪去"。这话他自己也不太信。

如果玩家在支线 quest_ch01_counterfeit_cinnabar 中深入调查，会发现陈疤脸背后还有一层——他抢劫的不是随机商队，而是特定几支"没有九霄盟保护标记"的商队。这意味着有人在九霄盟内部向他提供情报。

小六对此毫不知情。他只是链条末端的一个小贩——但正是这样的小贩构成了散修经济网络中最真实的毛细血管。
