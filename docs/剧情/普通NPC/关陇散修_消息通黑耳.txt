## 一、基础信息

```
名称：散修情报·黑耳
称谓：消息通·黑耳
类型：SCOUT（情报中介）
所属势力：九霄盟（外围散修层，不属于长庚殿正式注册的情报人员——他是"自雇型"情报贩子，以散修身份在各节点之间倒卖消息）
据点：
  - 关陇玄域·龙脊西段回波峡（主据点——在峡口南侧一处废弃哨塔里搭了窝，哨塔是龙脊旧承接网络时期的遗留建筑，地基里嵌着半块已经不亮的阵基）
  - 中州玄域·龙脊南麓散修营地（每旬回营地一次，更新消息库存）
境界范围：练气后期
灵根：下品土灵根
寿数：约三十岁
外貌：肤色偏黑——不是天生的，是长期在各个节点之间跑路晒的。瘦长脸，耳朵确实有点大（"黑耳"这个外号就是这么来的）。穿着一件灰扑扑的短打，永远背着一个鼓鼓囊囊的旧布包袱——里面塞满了写满暗语的纸片、半截的地图、各种势力的通行令牌（大多数是假的或者过期的）和一块用灵石碎片拼成的"信息板"。走路没声——在矿道和废墟里跑久了的人特有的脚步。
```

## 二、可交互职责

```
主要职责：龙脊西段势力动态与余震扩散方向情报出售（信息分级标价：免费/灵石/人情）
次要职责：散修安全节点分布图的维护与更新——黑耳自称有一份"全龙脊最全的散修节点手绘地图"，但实际准确度约七成
对话功能：信息查询（情报出售——先交灵石或承诺人情，再给消息）
```

## 三、称谓与对话风格

```
自称方式："黑耳"（从不用"在下"——"道上的人都叫我黑耳"）
对玩家称谓：
  - 第一次交易前：称"客人"
  - 交易过一次且付了全价后：称"道友"（但眼神里还是带着掂量——他在判断这个客人会不会成为长期客户）
  - 帮黑耳解决过一次麻烦（比如他卖假消息被追杀时）：称"兄弟/姐妹"——这是他能给出的最高信任级别
说话特征：永远在察言观色。说话时眼睛不看你——看的是你身后、你腰间、你的法器——他在估算你的身价和可信度。每句话开头先声明风险等级："这条是准的""这条我只有七成把握""这条你别全信——我是从回波峡那边听来的，那边最近消息乱"。对自己的消息质量意外的诚实——因为他知道长期生意比一次宰客更值钱。
情绪范围：精明计算（谈价钱时）→闲聊套话（想知道你有什么消息可以卖给他）→紧张（看到不认识的修士接近他的哨塔）→罕见的坦诚（被连续坑过几次后发现玩家没报复他——"你是个好人。好人在这片地不好混。我给你个建议，不要钱"）
```

## 四、任务钩子

```
主任务钩子：quest_ch01_aftershock_rumor_hub（第一章节拍二·余震扩散——黑耳作为可选情报源，提供回波峡及龙脊西段余震扩散方向的碎片化情报。他的信息不足以独立完成节拍二主线，但可以帮助玩家缩小调查范围）
支线钩子：
  - quest_ch01_heier_fake_token（假令牌事件——黑耳卖给玩家的某张通行令牌是假的，玩家被拒之门外后回来找他算账。黑耳会老实交代令牌来源——并愿意补一条真情报作为补偿）
  - quest_ch01_huiboxia_echo_map（回波峡回声测绘——黑耳需要玩家帮他在回波峡三个不同的位置记录灵脉频率读数。他自己不敢去——"那个地方的回声不对，我一个人去怕回不来"）
  - quest_ch01_hidden_post（废弃哨塔的秘密——黑耳住的哨塔地基里嵌着龙脊旧承接网络时期的阵基残片。如果玩家帮他完成回波峡测绘，他会在某个晚上指着地基建说："这东西有时候半夜会亮。不是一直亮，就闪一下。像是什么东西在试着联系它。"——引出节拍四信息碎片的可选前兆）
信息钩子：
  - 龙脊西段各势力的最新动向（谁在回波峡布置了阵旗、谁雇了九霄盟散修在峡口巡逻、天机楼的观测队上周去了哪个方向）
  - 散修安全节点的手绘分布图（付费版比免费版多约三成准确度——付费版标注了黑耳自己验证过的节点，免费版里混着二手甚至三手传闻）
  - 回波峡的异常灵脉频率——黑耳注意到峡口的灵脉频率有三种"重复模式"，但他分析不出原因（此信息与 NPC-GUIDE-04 回波哨兵·孟 的观测数据可以互相印证）
信息分级标价：
  - 免费：过期的势力动向（两周前的）、明显不可靠的二手传闻（黑耳会主动声明"这条别当真"）
  - 灵石（低阶）：当前一周内各大势力的粗略动向、已验证的安全节点位置列表
  - 灵石（中阶）：天机楼观测队的具体位置与行动路线、回波峡灵脉频率的具体读数、关陇各采矿势力之间的暗中角力
  - 人情（"以后你得帮我一个忙"）：黑耳不愿公开写在消息板上的东西——比如他怀疑九霄盟内部有人在向散修盗匪出售情报，或者某个"不应该出现在这里"的修士最近在回波峡附近活动
章限：第一章（节拍一起可交互；节拍二起情报更新频率增加；节拍三后的情报开始涵盖节点争夺动态）；第二章后仍可交互，随情报网络扩展而增加可购买信息范围
```

## 五、复用限制

```
最大实例数：同类型情报中介可在不同节点各有一名（回波峡、苍台、枯荣坪等各节点可各有一名 SCOUT），但黑耳这个具体人物全游戏唯一
可替换性：部分——黑耳的情报功能可由其他 SCOUT 类型 NPC 部分替代（天机观测员提供更准确的数据，退役观测员提供更深入的历史背景）；但黑耳的独特价值在于他的消息来源极其广泛且混杂——他是散修情报网络的活节点，其他 SCOUT 各有各的盲区
据点迁移条件：
  - 第一章节拍三（安全节点争夺）后，若回波峡节点归属发生变化，黑耳可能被迫搬出哨塔、转为在各散修营地之间巡回
  - 若玩家在支线 hidden_post 中帮他完成了回波峡测绘并保护哨塔，黑耳长期驻扎回波峡并逐步将哨塔扩建为一个非正式的情报中转站——在第二章可解锁额外的情报类型和更低的交易价格
```

## 六、关系边界

```
关联重要NPC：
  - 通过情报交易网络间接知晓卫长庚——黑耳知道"九霄盟盟主姓卫"，但从未见过本人。他对卫长庚的评价是商人的评价："那个人不收假消息。你要往长庚殿送情报，必须自己先验证过——验证一次的成本够我跑三趟回波峡。所以我不做长庚殿的生意"
  - 曾在回波峡远远见过一次天机楼的高层观测队——领队的人手持一块他从未见过的星盘法器，黑耳试着跟踪了两天但被甩掉了（"那个人的反追踪意识比我还强——不像是普通搞学问的"）
关联其他普通NPC：
  - NPC-VENDOR-03（符箓贩·小六）：黑耳的首要零售客户——他把大约四成的二手情报卖给小六换丹砂，小六再掺上自己的私货转卖给其他散修。两人的合作建立在互相不太信任的基础上（小六知道黑耳的消息有水分，黑耳知道小六的丹砂是掺了假的）——但他们在龙脊西段的信息生态里谁也离不开谁
  - NPC-STEWARD-05（营地管事·老关）：黑耳每次回营地都住老关的帐篷旁边——因为老关是他在营地里唯一相信不会出卖他的人。老关对他的态度是"你那些真真假假的消息别在营地里传——出了营地我不管"
  - NPC-GUIDE-04（回波哨兵·孟）：同据点的"竞争对手"——孟代表天机楼的正规观测渠道，黑耳代表散修的非正规信息网络。两人都不喜欢对方，但他们心里清楚：孟的数据比黑耳准，黑耳的消息比孟快。偶尔——极少——他们会交换一次情报（孟给他灵脉频率的精确读数，黑耳告诉他天机楼不知道的势力暗流）
  - NPC-SCOUT-01（天机观测·管）：黑耳远远见过管观测员——但没敢上前。天机楼的正式观测员和散修情报贩子之间隔着一道无形的墙——"他们用星盘看灵脉，我用耳朵听传闻。不是一路人"
```

## 八、附注：哨塔、回声与三种模式

黑耳住的废弃哨塔是龙脊旧承接网络时期留下的——地基里嵌着半块阵基，已经失灵了十五年。

但他对玩家说过"有时候半夜会亮"。这不是幻觉。

回波峡的灵脉频率有三种重复模式——这是回波哨兵·孟用天机楼星盘测出来的。孟分析不出原因。黑耳也没有分析能力。但黑耳在哨塔地基上记录到过同样的三种模式——只是时间不对：孟在白天测到频率 A，黑耳在半夜看到地基闪光对应的是频率 C。这意味着回波峡的灵脉异常可能不是"随机紊乱"，而是一种有节律的"响应"——它在响应什么，不知道。

黑耳隐约意识到了这一点。但他不知道怎么验证——"我一个练气期的情报贩子，拿什么去测灵脉频率？我连星盘长什么样都没摸过。"所以他需要玩家——这也是他愿意用人情换回波峡测绘数据的原因。

如果玩家同时从黑耳和孟那里获得完整数据，并交给天机楼或坤舆遗脉分析，可能会成为节拍四"信息碎片"的额外线索源——指向龙脊旧承接网络中一个尚未被发现的"回应节点"。
