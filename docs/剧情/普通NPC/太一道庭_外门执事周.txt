## 一、基础信息

```
名称：谢氏执事·周
称谓：外门执事·周
类型：STEWARD（势力执事）
所属势力：太一道庭
据点：云川玄域·太一道庭外山（建康中枢平原·太一外门学宫）
境界范围：筑基中期
灵根：中品水灵根
寿数：约五十五岁
外貌：瘦高个，眼角微垂，常年一身半旧不新的灰蓝道袍，腰间挂着一枚铜质外门执事令和一卷磨得发亮的竹简名册。说话时习惯用拇指摩挲竹简边缘。
```

## 二、可交互职责

```
主要职责：太一外门任务发布、试炼规则说明、道籍登记与升格申请受理
次要职责：外门秩序维护（劝架、查验道籍、追回偷跑下山的外门弟子）
对话功能：任务接受/提交、信息查询（外门规则、升格条件、四脉基本信息）
```

## 三、称谓与对话风格

```
自称方式："本执事"（正式场合）、"周某"（随口时）
对玩家称谓：
  - 凡人/试炼生阶段：称"你"或直呼姓名
  - 练气期：称"师弟/师妹"（若已入道籍）或"小道友"（未入道籍）
  - 筑基期：称"道友"
说话特征：公事公办，语速稳定，每句话都有明确的"告知—要求—期限"三段结构。不卖关子也不多解释——"试炼规矩贴在墙上，自己看。看不懂的再来问我。"
情绪范围：平和→不耐烦（当试炼生反复问同一问题时）→罕见地放缓语气（当试炼生真正遇到危险后归来）
```

## 四、任务钩子

```
主任务钩子：quest_ch01_taiyi_outer_trial（第一章节拍一·太一外门试炼引导任务）
支线钩子：
  - quest_ch01_taiyi_rule_explain（外门规则与法箓基础说明）
  - quest_ch01_taiyi_cloud_river_anomaly（云川边缘灵气波纹异常调查——第一章节拍一主线任务）
信息钩子：
  - 太一外门晋升内门的条件与考核时间
  - 四大道脉（王/谢/庾/桓）的基本区分和声望入门渠道
  - 云川灵舟码头的航线与安全通行时段
章限：第一章（节拍一起解锁）；第二章后仍可交互但不再提供第一章限定任务
```

## 五、复用限制

```
最大实例数：全游戏唯一（太一道庭外门执事仅此一名）
可替换性：否——该 NPC 是太一入口第一章主线任务的关键接取人，不可被同类型 NPC 替代
据点迁移条件：
  - 第一章节拍五（章末抉择）后，若玩家选择"向龙脊深处推进"路线，周执事可能出现在江津关为玩家办理通行手续
  - 第二章若触发"太一道庭内部人事调整"事件，周执事可能被调至吴郡城，原岗位由一名更年轻的外门执事接替（仅在节拍五之后）
```

## 六、关系边界

```
关联重要NPC：
  - 通过太一道庭外门行政体系，间接触及谢氏道脉的基层人事安排——他处理的外门名册每月上报至谢氏内门，但从未直接面见谢观微或谢凌沧
  - 曾在某份调令上见过"谢凌沧"的署名——那是十年前一艘灵舟途经外山时留下的临时停靠许可
关联其他普通NPC：
  - NPC-HEALER-01（太一药师·白）：同据点同事——外门试炼生受伤后被送到丹堂，周执事会在名册上标注"已就医"或"未报到"
  - NPC-TRAINER-01（太一传功·陆）：工作配合——传功师兄负责教，周执事负责考核与登记成绩
  - NPC-DI-02（老杂役·聋伯）：点头之交——在外山同处四十年，偶尔分一壶灵茶，但从不多聊
```
