## 一、基础信息

```
名称：苍台老兵·冯
称谓：老台守·冯
类型：GUIDE（冒险入口）
所属势力：混元山残部
据点：关陇玄域·苍台节点（龙脊南麓）
境界范围：筑基中期
灵根：中品土灵根
寿数：约六十岁
外貌：花白短发，面容粗糙如风化黄土，脊背微驼但眼神锐利。常年一身混元山旧式玄色布袍，袖口磨得起了毛边。左手缺了小指——被旧承接接口断裂时的碎片切掉的。右手握一根磨得油亮的铁木拐杖，拐杖头上刻着苍台节点的旧编号：CT-044。
```

## 二、可交互职责

```
主要职责：苍台节点废墟导航（安全路线指引、深层遗迹入口说明、旧承接网络遗迹解说）
次要职责：废墟安全警示（警告哪些区域仍有不稳定灵气残余、哪些旧接口可能在下次风暴中二次断裂）
对话功能：信息查询（苍台节点历史、龙脊旧承接网络遗迹、关陇灵脉节点分布）、任务接受（节点修复相关任务）
```

## 三、称谓与对话风格

```
自称方式："老冯"（对所有人——从不自称官职或身份）
对玩家称谓：
  - 初次见面：称"年轻人"或"后生"
  - 完成首次苍台导航后：称"小道友"
  - 若玩家在苍台锚定或修复节点：称"守台人"——带有郑重意味
说话特征：慢、沉、停顿多。每句话之间会有明显的沉默——不是在思考，是习惯了废墟里的节奏。提到龙脊之变当天时，语速会突然变快，然后戛然而止，像碰到一道看不见的墙。从不说"那天的天是黑的"这句话的完整故事——他只说"那天的天是黑的"，然后沉默。
情绪范围：沉静（日常）→突然警觉（感知到苍台节点灵气异常时）→长时间沉默（提到龙脊之变当天时）→很少见但很真实的微笑（看到年轻修士成功修复了一处旧接口——"王先生当年也是这么做的"）
```

## 四、任务钩子

```
主任务钩子：quest_ch01_node_cangtai（第一章节拍三/四·苍台节点废墟探索与旧承接网络遗迹调查）
支线钩子：
  - quest_ch01_cangtai_node_repair（苍台节点修复任务——收集修复材料、清理失控残余灵气）——衔接关陇区域独有"灵脉节点修复"系统
  - quest_ch01_old_linkage_witness（旧承接接口目击记录——冯老兵凭记忆标注旧接口断裂位置，供天机楼或坤舆遗脉后续测绘）
信息钩子：
  - 苍台节点的旧编号（CT-044）、旧承接接口位置、龙脊之变前的正常运作状态

  - 龙脊之变当天的目击碎片——仅限"旧接口断裂的先后顺序"和"灵气冲击波的扩散方向"，不提供因果解释
  - 混元山旧时驻扎苍台的编制与生活细节（环境叙事）
章限：第一章（节拍二起可在苍台节点发现他；节拍三/四正式解锁对话与任务）；第二章后仍在苍台，但解锁更深层的旧承接网络记忆（需节点修复进度达到一定阈值）
```

## 五、复用限制

```
最大实例数：全游戏唯一（苍台节点的唯一长期驻守者）
可替换性：否——他对苍台节点的旧承接接口有第一手目击记忆，该信息无法由其他 NPC 替代提供
据点迁移条件：
  - 第一章节拍三（安全节点争夺）中，若苍台节点被敌对势力（如混元山内部激进派或其他外部势力）占据，冯老兵可能被迫离开苍台，临时迁至关陇坊市联盟的长宁坊——但他总会找机会回到苍台，因为"我得守着那些断口"
  - 第二章若苍台节点被修复至关键阈值，冯老兵可能被坤舆遗脉邀请前往其他节点协助修复——但他会要求在苍台留一名"守台人"替代他
  - 不可被剧情杀死——他的目击记忆是关陇地区线的重要信息源
```

## 六、关系边界

```
关联重要NPC：
  - 龙脊之变前，冯老兵是苍台节点的一名普通值守修士，直属上级是混元山基层节点调度官——此人已死于龙脊之变。他从未面见苻渊或王玄略
  - 他亲眼在苍台节点见过一次王玄略："王先生来过苍台两次。一次是建节点的时候——他拿着一块玉简在地上测了很久，然后说'这里可以承压'。第二次是出事前三个月——他没有测，只是站在旧接口前面看了很久，然后说'如果有一天这里断了，不要等我们，直接往东南跑'"
  - 他不知道王玄略为什么说那句话，也不知道"承压"指什么
关联其他普通NPC：
  - NPC-STEWARD-02（军府校尉·吴）：同为龙脊之变的幸存者，偶尔在营地火堆旁对坐喝酒，不交谈
  - NPC-RIVAL-01（混元残部·石敢）：苍台节点争夺期间，石敢会多次出现在苍台——冯老兵对石敢的态度复杂："他想找回丹枢连接——可那些接口已经断了十五年。找回什么？"
  - NPC-QUESTER-03（灵田农夫·禾）：苍台节点外围的邻居，冯老兵偶尔去禾的灵田边坐一会儿——那里的土壤特别肥沃，冯老兵知道为什么（地下有旧地脉接口的残余灵气），但不告诉禾，只说"这地好，别搬"
  - NPC-DI-03（灵田守望·孤婆）：孤婆的灵田也在苍台外围。冯老兵每旬会去帮孤婆挑一担水——"她儿子是在灵气风暴里走丢的。不是龙脊那次——是后来的小风暴。她不肯搬走，我就帮她挑水。"
```

## 八、附注：苍台节点与"那天的天是黑的"

苍台节点（CT-044）在龙脊之变前是混元山灵脉共振体系中一个中型中转节点——不是核心枢纽，胜在位置稳定：位于龙脊南麓一处自然地脉交汇点，被王玄略标注为"可承压"。

冯老兵是苍台节点的第三任值守修士。他的工作很平常：每日三次巡检节点阵法基座、记录灵气读数、向上一级节点调度官提交日报。在龙脊之变前三十年里，苍台从未出过故障。

昊天历三百七十二年秋的那天下午，冯老兵正在巡检西侧旧接口时，手中的灵气读数玉简突然炸裂——

"不是读数异常——是玉简直接炸了。然后我看到旧接口在发光——不是阵法运行的光，是那种……从内部往外撕裂的光。西边先断的，然后是北边，然后……"

冯老兵在此处会突然沉默。候选清单中那行简短的描述——"那天的天是黑的"——需要在他口中被还原为一段不完整的感知碎片，而非完整叙事。设计意图是：玩家在第一章获得"旧接口断裂有先后顺序"和"冲击波扩散方向"两条感知信息，在后续章节通过天机楼数据、坤舆谱残篇、太虚观因果推演等渠道逐步拼合出龙脊之变的物理过程。

冯老兵的铁木拐杖头上刻着苍台节点的旧编号 CT-044，但拐杖杆上还被他自己刻了四排小字——十五年来一个一个刻上去的——那是他在那天之后陆续确认死亡的苍台驻守同僚的名字。四个名字。玩家在第一章无法完整看清刻字内容，只有在后续章节达到足够声望后，冯老兵才会把拐杖翻过来给玩家看。
