## 一、基础信息

```
名称：龙骧校尉·吴
称谓：军府校尉·吴
类型：STEWARD（势力执事）
所属势力：龙骧军府（混元山分支，实际独立运作）
据点：关陇玄域·龙骧军府外围营地（关中古战场边缘）
境界范围：筑基中期
灵根：中品土灵根
寿数：约四十五岁
外貌：身材敦实，肩宽背厚，一身洗得发白的玄甲常服（铠甲只在巡逻时穿），左脸颊有一道从颧骨到下颌的旧疤——据说是在一次灵气风暴中为掩护新兵被晶石碎片划的。腰间挂的不是法器，是一串磨得光亮的军牌——每块对应一个在他手下阵亡的士兵。
```

## 二、可交互职责

```
主要职责：关陇求生任务发布、巡逻路线分配、外围营地人员登记与管理
次要职责：新兵基础训练督导（不亲自教学，但会站在演武场边上盯着，看到偷懒的就加练）
对话功能：任务接受/提交、信息查询（关陇安全节点分布、灵气风暴预警常识、军府外围规则）
```

## 三、称谓与对话风格

```
自称方式："吴某"（对同级或上级）、"本尉"（对下级或新兵）
对玩家称谓：
  - 初入营地者：称"新来的"（不客气但也不带恶意）
  - 完成首个巡逻任务后：称"小子/丫头"（带一点认可）
  - 获得军功后：改用姓名称呼
说话特征：短句、命令式、不废话。典型的军旅口吻——能用一个字说清绝不用两个字。"巡逻。西线。日落前回报。"但偶尔在火堆边上会多说几句："那年龙脊没断的时候，这片地不是这样的。"
情绪范围：面无表情（日常）→暴怒（看到有人在灵气风暴中擅自离岗）→罕见沉默（被问到"龙脊之变那天你在哪"时——他会转身走开）
```

## 四、任务钩子

```
主任务钩子：quest_ch01_hunyuan_outer_survival（第一章节拍一·关陇外围求生与安全节点定位）
支线钩子：
  - quest_ch01_longxiang_patrol（龙骧外围巡逻任务——清剿散修劫匪或灵脉异兽）
  - quest_ch01_supply_node_failure（补给节点失效调查——第一章节拍二主线前置）
信息钩子：
  - 关陇外围安全节点的最新分布与稳定状态
  - 灵气风暴的基础预警信号和应对方法
  - 龙骧军府的历史与现状（"我们以前不叫龙骧军府——我们以前就是混元山的玄甲道军"）
  - 关中古战场哪些区域夜间不宜单独通行
章限：第一章（节拍一起解锁）；第二章后仍可交互但外围营地在节拍五后可能因封锁升级而搬迁
```

## 五、复用限制

```
最大实例数：全游戏唯一（龙骧外围营地校尉仅此一名）
可替换性：否——该 NPC 是混元山/龙骧入口第一章主线任务的关键接取人
据点迁移条件：
  - 第一章节拍三（安全节点争夺）后，若苍台节点归属发生变化，吴校尉可能率小队进驻苍台以巩固防线
  - 第一章节拍五后，若龙骧军府封锁升级，外围营地可能北撤至河阴方向，吴校尉随营地迁移
  - 若玩家在节拍五中选择"巩固当前安全节点"，吴校尉可能长期驻守原营地并解锁额外军功任务
```

## 六、关系边界

```
关联重要NPC：
  - 龙骧军府曾是混元山玄甲道军的分支——吴校尉在龙脊之变前是一名百夫长，直属上级是苻渊麾下某位已阵亡的玄甲将军。他从未直接面见苻渊，但在阅兵时远远见过一次——"那天他骑着马从我们方阵前过，没有停留"
  - 通过军府公文系统间接知晓吕星枢的名字——军府营地接收过天机楼转发的灵脉数据，落款有"吕星枢"
关联其他普通NPC：
  - NPC-TRAINER-02（龙骧教头·秦）：长期工作搭档——秦教头负责训练，吴校尉负责分派人手。两人对训练强度有过多次争执（秦觉得吴太护犊子，吴觉得秦不把新兵当人）
  - NPC-HEALER-02（军府医官·杜）：老相识——吴校尉脸上的疤就是杜医官缝的
  - NPC-GUIDE-05（苍台老兵·冯）：同为龙脊之变的幸存者。两人偶尔在营地火堆旁对坐，不说话，只喝酒
```

## 八、附注：龙脊之变当天的个人记忆

吴校尉很少主动提起那一天。但若玩家在节拍四（信息碎片）后回来问他，并且在军府声望达到一定等级，他会说几句：

"那天我在外围巡逻。下午的灵气读数突然不正常——不是风暴，风暴是有征兆的。那次是没有征兆的——所有灵脉节点在同一个瞬间开始尖叫。"

"然后天黑了。不是天黑了——是光被灵气冲走了。"

"我们小队十二个人，只回来三个。另外九个不在爆炸区——他们是在后来三天的灵气风暴里走散的。我没找到他们。"

这是吴校尉提供的信息上限。他不知道天为什么"黑"了，不知道苻渊在里面做了什么，也不知道坤舆谱的存在。
