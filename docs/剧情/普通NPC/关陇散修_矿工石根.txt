## 一、基础信息

```
名称：矿脉散修·石根
称谓：矿工·石根
类型：QUESTER（散修委托）
所属势力：无（独立散修矿工，偶尔在关陇坊市联盟的露天集市上以矿样换补给）
据点：
  - 关陇玄域·龙脊南麓散修营地（歇脚点——他大部分时间在矿洞里，只在补给耗尽时回营地）
  - 关陇玄域·黄土裂谷各矿点（主要活动区域）
境界范围：练气后期
灵根：下品金灵根
寿数：约三十五岁
外貌：矮小结实，背微微佝偻——长年弯腰在狭窄矿道里爬行的结果。双手布满老茧和细小的晶石划痕，指甲缝里永远嵌着矿粉。脸上被关陇黄土染得灰扑扑的，眼睛却意外地亮——那是矿工在暗处看久了矿石荧光之后留下的。后腰别着一柄短镐——法器品级很低，但镐头上嵌着一小块黄土灵晶，是他自己攒了三年灵石换的。
```

## 二、可交互职责

```
主要职责：灵矿采集委托发布、矿脉勘探任务引导、矿洞清剿委托（清除占据矿脉的灵脉异兽或散修盗矿者）
次要职责：以矿样交易换取灵石、丹药或情报（非正式商贩——他只在营地歇脚时摆个临时摊，拿矿样换补给）
对话功能：任务接受/提交、物品交易（矿样换补给，不接受灵石购买——"灵石在你手里和在矿洞里是两回事"）
```

## 三、称谓与对话风格

```
自称方式："石根"（从不加"老夫""在下"——"我叫石根，石头的石，树根的根。我爸是矿工，爷爷也是矿工——我们家族起名字离不开土"）
对玩家称谓：
  - 第一次见面：称"道友"（礼貌但保持距离——矿工的习惯，在地下待久了不太会跟人打交道）
  - 一起下一次矿洞后：称"搭档"
  - 帮他解决过一次矿洞里的麻烦后：叫名字（这是他表达信任的方式——"矿工不搞虚的"）
说话特征：说话慢、句子短、从不绕弯。在矿洞里待了二十年的人在阳光下本来就不太自在——能不说的话就不说。但一旦话题转到矿石，他会突然变得滔滔不绝："这块灵脉玻璃——你摸一下——这里发暖，不是地热的暖，是灵气纠缠过的暖。这是虫子在啃灵脉的时候留下的，至少五十年了。"说完了又变回沉默。
情绪范围：沉默（地上）→专注（地下）→极度兴奋（发现新矿脉时——他会激动到说话结巴）→罕见地严肃（在废矿中挖出旧法器残片时——"这不是矿石……这是以前有人用过的东西。坏了很久了"）
```

## 四、任务钩子

```
主任务钩子：quest_ch01_miner_fragment_recovery（第一章节拍四·散修信息碎片辅助——在废矿中发现带有龙脊旧承接网络时期残余灵纹的法器碎片，引出坤舆谱残篇或旧接口线索）
支线钩子：
  - quest_ch01_crystal_geode_clear（晶化土鼍巢穴清剿——石根发现一处富矿脉，但被晶化土鼍占据，需要玩家协助清剿）
  - quest_ch01_vein_prospect（矿脉勘探委托——陪石根深入黄土裂谷的一处未探明矿道，期间可能遭遇灵脉蠕虫或灵气风暴）
  - quest_ch01_old_fragment_trade（旧法器残片的去向——石根手中已有几块挖出来的旧残片，但他不知道该交给谁。玩家可选择建议他交给坤舆遗脉、卖给天机楼、或留下来等第二章线索）
信息钩子：
  - 关陇黄土裂谷各矿点的矿物品类、产量和危险度评估
  - 哪些矿洞近期出现了不稳定的灵气波动（石根凭经验判断——"矿道里的风突然变热，说明下面有东西在动"）
  - 废矿中偶尔出土的"不是矿石的东西"——旧法器残片、残破的灵脉节点组件、刻有旧编号的阵法基座
章限：第一章（节拍二起可交互——节拍二后矿洞灵气波动加剧，石根需要帮手；节拍四的信息碎片钩子需要节拍三完成后才解锁）；第二章后仍可交互，随新矿脉发现而迁移
```

## 五、复用限制

```
最大实例数：同类型矿工 QUESTER 可在不同采矿区域各有一名（关陇北矿带和南矿带可各有一名），但石根这个具体人物全游戏唯一
可替换性：部分——石根的矿脉勘探任务可由其他矿工 NPC 承担；但旧法器残片线索仅由石根持有（因为他的废矿位置特殊——位于旧承接网络时期的废弃地脉接口上方）
据点迁移条件：
  - 每发现一处新矿脉，石根的主要据点会从散修营地迁移至矿脉附近的临时矿工棚
  - 第一章节拍三后，若苍台节点归属发生变化导致其矿区的灵气暴涌加剧，石根可能被迫放弃当前矿点、向西南转移至南矿带
  - 若玩家在支线 old_fragment_trade 中建议他将残片交给坤舆遗脉，石根可能在第二章出现在坤舆遗脉的活动区域
```

## 六、关系边界

```
关联重要NPC：
  - 坤舆遗脉：石根在废矿中挖出的旧法器残片上刻有类似坤舆谱的标记风格——但他不知道坤舆谱是什么，更不知道王玄略。他只是模糊地意识到"这些碎片不是打仗留下的，是有人在管灵脉的时候留下来的"
  - 天机楼：天机楼的勘探队曾在石根的矿点外围做过测绘——石根远远看见过他们的星盘法器，但没有上前交谈（"他们是搞学问的，我是挖矿的——不是一个行当"）
关联其他普通NPC：
  - NPC-STEWARD-05（营地管事·老关）：石根每次回营地先找老关——交保护费（以矿样抵）、问最近的安全节点分布、然后闷头睡一整天
  - NPC-QUESTER-03（灵田农夫·禾）：石根偶然在苍台节点外围的灵田边上遇到禾——两人都是靠天吃饭的人，聊得来。禾告诉石根他田下面有一处旧地脉接口，石根很想去看看——但目前还没拿到许可
  - NPC-GUIDE-05（苍台老兵·冯）：石根慕名去苍台节点问过冯老兵——想知道他废矿里挖出来的那些旧残片是什么。冯老兵只看了一眼就说："旧承接接口的阵基底座。你这块是碎片，完整的比这个大十倍。"石根从此对冯老兵心怀敬畏
```

## 八、附注：矿道里的旧物

石根不是第一个在关陇废矿里挖出旧法器残片的矿工。龙脊之变后，关陇的矿脉因冲击波把深层岩层推至浅层——连带把龙脊旧承接网络时期埋藏在灵脉节点下方的阵法组件也翻了上来。

矿工们管这些东西叫"矿渣"——大多数人不认识，砸碎了当普通灵矿卖。石根是少数几个觉得"不对劲"的人：这些碎片的断裂面不是自然裂开的——上面有灵纹烧灼的痕迹。他在矿道里搭了一个小木架，把这些碎片按大小排列好，像博物馆的展品。

"这些不是矿石。"他在架子上贴了一张纸条，上面歪歪扭扭地写着："以前这里可能不是矿洞。以前这里可能是别的东西。"

他不知道自己在守护的是龙脊旧承接网络的三百七十二分之一。他只知道：这些东西不该被砸碎卖钱。
