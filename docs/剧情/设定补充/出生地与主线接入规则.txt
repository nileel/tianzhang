设计边界：
- 本文只锁可选出生地、第一章本地异常、跨域线索、第二至第五章接入路径和信息边界。
- 本文不写具体 L3 任务、对白、战斗数值、掉落概率、完整章节重写或正式 NPC 分支。
- 玩家可选出生地不包含中州天域。中州只作为第六章证据汇集、第七章终局入口和中后期高危探索区。
- 每个出生地都必须先让玩家处理本地版本的龙脊余震，再通过跨域证据进入第二至第五章；不得把世界主线默认成单一关陇开局。
- 低阶势力、普通 NPC、据点传闻和随机事件只能提供局部证词或补线，不得独占主线必要信息。

## 一、定位

出生地规则解决两个问题：

1. 玩家可以从不同地区、不同低阶身份进入主线，但第一章仍围绕同一个核心现象：龙脊之变十五年后，余震沿承诺、旧约、互保、血脉残响、业痕、观测异常、苦修反证、焚寿账目或阴河回声继续扩散。
2. 各出生地的本地入口不能互相替代。关陇最接近灾变原点，江左最早感到法箓接口失稳，河西最早看见同步数据，北地看见真形与妖血边界，陇西、太行、蜀川分别提供第五章的苦修、焚寿、阴河反证。

第一章的玩家只获得第一份不能单独解释的残篇、回响或见证记录。第二章开始，玩家追查这些线索如何与关陇、河西、太一道庭、太虚观、混元山残部、散修互保网络和外部势力争夺同频。

## 二、可选与不可选出生地

| 类别 | 地区 | 用途 |
|------|------|------|
| 可选出生地 | 关陇玄域、江左天域、漠北荒域、辽海寒域、河西星域、陇西雷域、太行火域、蜀川幽域 | 提供第一章本地异常、低阶身份、地区服务和跨域线索 |
| 不开放出生地 | 中州天域 | 第六章证据汇集、第七章终局入口、白玉京/天工城/九霄盟中后期内容 |

中州不开放出生的理由：
- 中州是龙脊主脉断裂点和上古仙朝遗址密集区，默认难度与信息密度高于新手阶段。
- 中州承载白玉京残知、天工城修复能力、九霄盟见证网络和龙脊断裂核心，过早开放会压缩第一至第五章的证据积累。
- 中州信息不能替代各出生地的局部见证。玩家必须先知道多地异常互相印证，再进入中州汇集证据。

## 三、全局接入规则

| 规则 | 说明 |
|------|------|
| 本地优先 | 每个出生地第一章先处理本地异常，不直接把玩家送到龙脊核心或中州核心。 |
| 三层接入 | 每个出生地至少有本地入口、跨域线索、核心证据三层；本地入口负责动机，跨域线索负责远游，核心证据负责进入后续章节。 |
| 信息分层 | 第一章只显示异常同频和解释不足；第二章确认残篇/观测/记录需要互证；第三至第五章逐步进入法箓、真形、妖血、苦修、焚寿、阴河等证据链。 |
| 长时间线 | 第一章可从昊天历 387 年秋延展到 430 年前后；闭关、远游、低阶势力换代和普通 NPC 接棒都要有世界反馈。 |
| 低阶身份 | 可使用外门、杂役、家族子弟、军府外围、散修互保成员、商路学徒、苦修试炼者、火域通行客、考古助手等低阶身份。 |
| 补线方式 | 关键线索不能只由单个普通 NPC 提供；若玩家错过本地线索，需通过据点档案、宗门委托、天机情报、九霄盟任务、遗物或后续跨域报告补线。 |
| 境界边界 | 第一章玩家不突破至金丹；第二章仍以筑基初中期为主；第三章末才触及金丹门槛；第四、第五章进入金丹阶段后再承接真形和反证线。 |

## 五、章节接入节奏

### 第一章：龙脊余震

目标：让玩家在本地出生地发现异常同频，但只知道自身地区解释不足。

必须包含：
- 一个低阶身份或低阶势力绑定方式。
- 一个本地异常样本。
- 一个跨域线索载体。
- 一个章末残篇、回响或见证记录。
- 一个可错过线索的补线方式。

不得包含：
- 苻渊出场。
- 司马承景直接出现。
- 谢观微给出完整答案。
- 玩家突破金丹。
- 中州核心探索。

### 第二章：坤舆残篇

目标：把各出生地的残篇、回响、观测或记录接入互证链。

接入方式：
- 关陇：坤舆残篇和安全节点再争夺。
- 河西：天机楼观测线和情报交易。
- 江左：太一道庭或谢氏外派报告截取残篇。
- 北地/陇西/太行/蜀川：本地异常被证明与关陇残篇同频。

本章结论只能是：一个势力的解释只能解释一部分；残篇、观测、业痕、法箓、水脉和地方证词必须互证。

### 第三章：法箓将倾

目标：让所有出生地都能理解太一道庭法箓秩序的稳定性、稀缺性和衰退风险。

接入方式：
- 江左玩家直接进入法箓体系内部。
- 关陇/河西玩家携残篇或观测报告进入江左。
- 北地/辽海/太行玩家通过敌对、封锁、交易或外交档案看到法箓排斥和秩序成本。
- 陇西/蜀川玩家从剑道、地脉或死亡见证角度对照法箓秩序。

本章不得把太一道庭写成天然正确答案，也不得把反法箓阵营写成天然正确答案。

### 第四章：北地真形

目标：让真形、妖血、人身、兽魂和祖灵边界进入主线，但只停留在可理解层级。

接入方式：
- 漠北玩家直接进入苍狼真形旧路与万灵真形新路冲突。
- 辽海玩家直接进入妖血至上与人妖边界冲突。
- 关陇玩家从龙脊北麓血脉残响切入。
- 江左/河西玩家通过外派报告、情报和观察接入。
- 陇西/太行/蜀川玩家只作为反证或旁观线，不承担本章主入口。

本章不得正式命名未经论证的新元婴方向，不新增金丹位格，不让玄荒或玄冥独占世界解释权。

### 第五章：诸路互证

目标：用苦修、焚寿、阴河和星术反证前四章答案的边界。

接入方式：
- 陇西：承受、雷劫、剑意自立。
- 太行：燃烧寿元、火种和不可持续承接。
- 蜀川：阴河见证、死亡承接、龙脊封禁外围。
- 河西：星术观测和数据解释分离。
- 其他出生地：携带前四章证据来对读，不重新成为单一主发生地。

本章只能首次确认龙脊深层封禁与天门遗留有关，不揭露全部飞升真相，不开放第六章中州汇集之前的终局答案。

## 六、补线与失败回退

| 情况 | 回退方式 |
|------|----------|
| 玩家错过本地普通 NPC 线索 | 据点档案、继任 NPC、宗门文书、商路传闻或天机低阶情报补线。 |
| 玩家所属低阶势力节点失守 | 第二章提高补线成本，改由九霄盟、天机楼或外派执事提供证词；主线不断。 |
| 玩家拒绝分享第一章残篇 | 第二章初始信任降低，但可通过复制、交换、偷听报告或被动卷入恢复互证链。 |
| 玩家长期闭关跳年 | 普通 NPC 可换代，线索转为遗物、后代证词、继任管事或据点档案。 |
| 玩家与出生地势力决裂 | 改走散修、九霄盟、商路或跨域委托路线，不能因关系失败软锁主线。 |
