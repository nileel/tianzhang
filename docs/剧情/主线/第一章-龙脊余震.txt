# 第一章 · 龙脊余震

✅ 已审核（2026-07-10 WF2-CODEX-ONE / unknown 自产修订；TQ-047 复核时间跨度、出生地入口和境界边界，文本检查通过后闭环）

> 依据文件：`docs/剧情/剧情生产规范.txt`、`docs/剧情/世界背景故事.txt`、`docs/剧情/背景与重要NPC设计规范.txt`、`docs/剧情/主线/世界主线-总纲.txt`、`docs/剧情/设定补充/出生地与主线接入规则.txt`、`docs/基础设定/寿元与时间尺度设定.txt`、`docs/基础设定/元婴锚点与金丹位格矩阵.txt`
> 时间锚点：昊天历 387 年秋（游戏开始）；可随出生地、本地修炼、远游和闭关延展至 430 年前后。

## 一、章节定位

第一章是玩家从凡人/练气期进入修真世界、建立初始位格认知的新手章节。章节主线围绕“龙脊之变十五年后，德业反噬仍在扩散，各方势力争夺安全节点与残存边界数据”展开。

章节边界：

- 玩家境界范围：凡人 → 练气 → 筑基初期；不突破至金丹。
- 地理范围：以玩家所选出生地和低阶身份为核心，先处理本地异常，再通过跨域线索延伸至龙脊山脉边缘安全节点；关陇是近源入口，不是唯一开局。
- 主线问题：龙脊紊乱为什么仍在扩散，且为什么会沿着“承诺、旧约、军府责任、散修互保、血脉残响、观测缺口、寿元旧账、阴河回声”这些关系与现象留下痕迹？
- 叙事暗线：苻渊闭关异动、谢观微临终倒计时、王玄略坤舆谱残篇、太虚观宿慧回溯、龙脊深层封禁裂缝。

第一章不解释完整真相。玩家只知道：十五年前的灾变不是单纯地脉事故，里面混有地脉、人心、道统和旧业的共同反噬。

时间处理：

- 第一章起点固定为昊天历 387 年秋，但不同出生地可通过本地修炼、低阶委托、远游和闭关拉开节奏。
- 第一章结束不得早于玩家取得第一份残篇、回响或见证记录，也不得晚于第二章“坤舆残篇”追索所需的 430 年前后。
- 闭关或跳年必须反馈普通 NPC、低阶势力和据点变化；线索可转为继任 NPC、据点档案、宗门文书、遗物或天机情报补线。
- 玩家可以推进到筑基初期，但不得通过闭关跳过第一章并提前获得金丹位格、高阶系统或终局真相。

## 二、玩家入口

入口开放总则：

- 第一章可以开放中小门派、分院、附庸宗门、修士家族、军府外围、散修营地和地方坊市作为低阶起点或绑定对象。
- 这些入口优先表现为外门、杂役、客卿、供奉、挂名弟子、军府外围修士、家族子弟或散修互保成员，不默认等同于完整主角门派。
- 玩家可以在第一章帮助某个地方共同体守住安全节点、取得见证资格或建立跨势力弱联系；该状态可被第二章及终局多路并界读取。
- 首版不承诺任意小宗都拥有完整功法树、独立全章节主线或宗门经营到世界巅峰路线。若要做宗门成长，只先做一条样板线，目标是“地区锚点”，不是“天下第一宗”。

出生地与入口关系：

- 出生地决定玩家第一章先遇到哪一种本地异常，以及后续远游从哪里被牵引出去。
- 五类玩家入口决定玩家用哪套低阶身份和解释框架理解异常；它们不是五个唯一出生地区。
- 中州天域不开放为出生地。中州只作为第六章证据汇集和第七章终局入口，不承担新手阶段的信息密度。
- 每个出生地必须保留“本地入口、跨域线索、核心证据”三层接入；普通 NPC、随机事件或单一势力都不能独占主线必要信息。

### 入口 A：太一道庭

玩家以试炼生、寒门道籍弟子或没落修士家族后裔身份进入太一道庭外门。

- 初始身份：外门试炼生，尚未获得稳定法箓接口。
- 初始目标：通过试炼，获得进入法箓秩序的资格。
- 首次接触主线：谢氏低阶执事要求玩家调查云川边缘的灵气波纹异常。异常不是单纯灵脉波动，而是某处旧承诺被重新牵动后在水脉中留下的回响。
- 可知信息：太一道庭法箓秩序稳定但名额稀缺；谢观微身体衰退；法箓不等于天命正确。
- 不可知信息：司马承景具体状态、法箓元婴方向的完整源流、谢观微最终推演。

### 入口 B：混元山/龙骧军府外围

玩家以关陇本地散修、军府外围修士或混元山边缘弟子身份在龙骧军府封锁线外求生。

- 初始身份：外围修士，未获主峰承认。
- 初始目标：在紊乱区找到足以支撑修行的安全节点。
- 首次接触主线：一处本应稳定的军府补给节点失效，原因不是灵气枯竭，而是旧军约、战后安置承诺与地脉残痕同时被牵动。
- 可知信息：苻渊仍在主峰闭关；龙骧军府守护的不只是山门，也是某个未完成承诺。
- 不可知信息：苻渊闭关内容、德业元婴方向、龙脊之变完整因果。

### 入口 C：太虚观

玩家在关陇位格真空中接触太虚观，被引入业痕、宿慧和轮回承接的解释框架。

- 初始身份：关陇散修、难民修士或旧灾变受害者后代。
- 初始目标：通过因果试炼，理解自身与旧业残痕的关系。
- 首次接触主线：试炼中出现不属于玩家个人的旧业回响，指向龙脊之变当天某个未被记录的承诺断裂。
- 可知信息：太虚观认为死亡与断代不等于归零；姚观寂拥有不完整前世碎片。
- 不可知信息：前世碎片是否可靠、轮回/宿慧元婴方向的完整效果、封禁裂缝内究竟有什么。

### 入口 D：玄荒殿

玩家出生于漠北荒域，在玄荒殿血脉试炼中接触龙脊北麓的异常波动。

- 初始身份：部族后裔或外来试炼者。
- 初始目标：证明自身可承载血脉共鸣并参与南下探索。
- 首次接触主线：血脉节点对龙脊余震产生异常反应，显示旧灾变不仅牵动人族宗门，也影响更古老的血脉残响。
- 可知信息：血脉共鸣也有边界，不是天然正确的位格来源。
- 不可知信息：上古血脉残响来源、其与德业反噬的关系。

### 入口 E：散修

玩家没有宗门背景，作为独立散修在龙脊边缘求存。

- 初始身份：无宗门散修。
- 初始目标：找到未被大宗门垄断的安全节点。
- 首次接触主线：玩家发现一处被旧散修互保记号标注的通道，标记含义不是“此处可占”，而是“从此处往下，别欠无名之债”。
- 可知信息：散修互保也能形成真实位格压力；卫长庚等人正在寻找不依赖门阀的道路。
- 不可知信息：古老记号源头、散修互保与苻渊失败之间的关系。

## 三、章节节拍

### 节拍一：初涉修真

玩家完成所属入口的低风险试炼，获得第一个稳定修炼资源或临时节点使用权。

本节拍只让玩家听说龙脊之变：十五年前，龙脊发生过一场灾变，此后灵脉、人心、血脉、寿元账、观测记录与旧约都变得不稳定。

禁止项：

- 不得见到苻渊、司马承景、谢观微等高阶核心人物。
- 不得解释自辟元婴。
- 不得让玩家获得金丹位格。

### 节拍二：余震扩散

玩家所在据点出现余震：阵法失灵、灵田异变、军府旧约被触发、因果试炼失真、血脉节点躁动、妖血契波动、星图缺口、雷池误鸣、火脉账目异常、阴河潮汐反常或散修营地互保誓约失效。

玩家调查后发现，余震不是随机扩散，而是沿着“曾经有人承诺、有人受益、有人未被安置、有人拒绝承认”的关系链扩散。

信息误导：

- 太一道庭低阶修士会把它解释为地脉紊乱。
- 混元山残部会把它解释为苻渊未醒。
- 太虚观修士会把它解释为旧业未了。
- 天机楼观测员会把它解释为数据缺口。
- 玄荒/玄冥相关修士会把它解释为血脉、真形或妖血边界失稳。
- 玉清、赤霄、地藏等外域修士会把它解释为雷劫承受、寿元旧账或阴河回声。

这些解释都只对一部分负责，没有任何低阶 NPC 全知。

### 节拍三：安全节点争夺

各方势力开始争夺龙脊边缘或本地映射出的安全节点。争夺对象不是“强灵脉”，而是能暂时隔离德业反噬、允许低阶修士稳定修行、并把本地异常连接到跨域证据链的局部条件。

候选节点：

| 节点 | 位置 | 表层用途 | 深层线索 |
|------|------|----------|----------|
| 苍台节点 | 龙脊南麓 | 太一与混元残部争夺的稳定阵基 | 王玄略曾标注“承压未定” |
| 狼喉节点 | 龙脊北麓 | 玄荒殿血脉试炼的外缘节点 | 血脉回响与旧军约同时出现 |
| 回波峡节点 | 龙脊西段 | 太虚观与散修都能感知业痕 | 谢观微推演模型无法完整解释 |
| 枯荣坪节点 | 龙脊东段 | 无宗门完整记录的空白节点 | 坤舆谱残篇与散修旧记号互相矛盾 |
| 远端映射节点 | 各出生地本地据点 | 江左水脉、河西观测、陇西雷池、太行火脉或蜀川阴河等远端异常 | 指向第二章互证，不替代龙脊核心节点 |

玩家成长：

- 境界推进到筑基门槛或筑基初期。
- 首次理解“节点稳定”与“位格承接”有关，但不获得金丹席位。
- 与至少一名跨势力低阶 NPC 建立弱联系，作为第二章信息纽带。
- 若玩家绑定中小门派、分院、家族或散修营地，本节拍可记录其节点归属、供养能力和见证资格；这些结果只影响资源来源、声望、补线成本和后续锚点，不授予高阶力量。

### 节拍四：信息碎片

玩家在节点中获得一块无法单独解释的碎片。

| 入口 | 信息碎片 | 指向 |
|------|----------|------|
| 太一 | 谢观微早期推演中有一组“不可验证承诺链” | 谢观微弟子或谢观微本人一次短接触 |
| 混元 | 坤舆谱残篇记录了地脉、人群迁移与旧约压力的交叉标记 | 吕星枢或王玄略旧弟子 |
| 太虚 | 因果回溯显示龙脊之变当天有人把“共同体责任”强行上承 | 姚观寂与钟离幽线索 |
| 玄荒 | 血脉节点听见不属于苍狼古神的沉旧回响 | 姚观寂或巴蜀线索 |
| 散修 | 古老互保记号提示“不要只看灵脉，看谁欠谁” | 卫长庚线索 |
| 远端出生地 | 本地异常与龙脊边缘节点同频，但无法单独解释 | 第二章坤舆残篇、天机观测或跨域报告 |

重要 NPC 接触限制：

- 谢观微：仅太一入口可在节拍四短接触一次，不给完整答案。
- 姚观寂：仅太虚入口可做一次不完整回溯。
- 拓跋烈、卫长庚、吕星枢、钟离幽可根据入口以书信、报告、中介或一次短场景出现。
- 苻渊不出现，司马承景不出现。

### 节拍五：章末抉择

玩家决定如何处理信息碎片。

抉择维度：

| 抉择 | 选项 A | 选项 B | 后续影响 |
|------|--------|--------|----------|
| 信息态度 | 分享给更多势力 | 只交给所属势力 | 第二章跨势力信息与信任度 |
| 探索方向 | 向龙脊深处推进 | 巩固当前安全节点 | 第二章起始地点与风险等级 |
| 位格倾向 | 寻求法箓、宿慧、血脉或军府支持 | 保留自辟可能 | 第二章修行资源与路线提示 |

章末钩子：

1. 坤舆谱残篇显示仍有若干“承压未定”标记散落各域。
2. 谢观微确认某条承诺链正在重新发亮，但他不知道苻渊是否主动引发。
3. 龙骧军府封锁升级，主峰出现闭关以来罕见的灵力异动。
4. 太虚观发现德业残痕与轮回承接并不完全重合。
5. 散修互保网络开始出现“欠账自动回响”的异常。
6. 若玩家出生于非关陇地区，章末必须保留本地异常档案或见证记录，并通过天机情报、宗门委托、九霄盟任务或跨域报告接入第二章。

## 四、NPC 与知识边界

| NPC | 第一章功能 | 知识边界 |
|-----|------------|----------|
| 谢观微 | 风险边界提示者 | 知道提前发动会反噬，不知道完整真相 |
| 谢凌沧 | 太一道庭调度压力的侧面呈现 | 知道水脉震动，不知道苻渊闭关内容 |
| 苻渊 | 不出场的核心悬念 | 只能通过主峰异动、旧部态度和残痕体现 |
| 王玄略 | 不在场的信息源 | 坤舆谱残篇只提供边界数据，不提供终局答案 |
| 司马承景 | 第一章不出现 | 不得以投影、梦境、传音等形式介入 |
| 姚观寂 | 宿慧与业痕解释者 | 前世碎片不完整，不能当全知答案 |
| 卫长庚 | 散修互保道路提示者 | 知道散修记号，不知道苻渊完整计划 |
| 钟离幽 | 封禁与阴河线索 | 知道局部目击，不知道封禁终局 |

## 五、设计约束

1. 玩家境界上限为筑基初期。
2. 全章不出现完整自辟元婴说明，只用碎片让玩家意识到“位格可以被开辟，也可能失败”。
3. 不出现全知 NPC。
4. 不提前揭露苻渊失败的完整真相。
5. 不写具体战斗数值、倍率、掉落概率。
6. 不使用旧北地统合口径。
7. 苻渊不得出关，谢观微不得在第一章陨落，司马承景不得出现。
8. 中小门派和低阶共同体只能作为第一章入口差异、据点服务、声望对象、节点归属和后续锚点，不在本章扩展为完整宗门经营系统。
9. 不得把第一章默认成单一关陇开局；关陇是近源入口，其他七个可选出生地必须先处理本地异常再取得跨域线索。
