## 一、概要

- 一句话简介：玩家在龙脊南麓的苍台节点卷入一场围绕旧承接网络阵基残骸的争夺——太一道庭的低阶弟子、混元山残部、龙骧军府的斥候和不明身份的外部势力都在试图控制这处被王玄略标注为"承压未定"的节点。
- 玩家目标：在苍台节点取得至少一份节点异常证据（旧承接接口残骸的灵纹记录、冯老兵的目击口述或敌对势力的遗落报告），并决定节点的短期归属倾向（帮助某一方守住或让节点暂时保持中立）。
- 叙事作用：将"安全节点争夺"从抽象的节拍概念落地为一场具体的多方角力——各方争夺的不是强灵脉，而是旧承接网络的残余结构信息；通过冯老兵的目击记忆和矿工石根挖出的旧残片，向玩家展示龙脊旧承接网络在微观尺度上的"断裂证据"；为节拍四信息碎片中的"坤舆谱残篇与散修旧记号矛盾"积累物证。

## 三、参与角色

- NPC：
  - NPC-GUIDE-05（老台守·冯）：苍台节点的唯一长期驻守者、旧承接网络遗迹的非正式守护人。提供安全路线导航、旧接口位置标注、龙脊之变当天的目击碎片（"西边先断的，然后是北边"）。在本任务中，冯老兵不参与战斗，但玩家选择帮助某一方时，他的态度会微妙变化——他默认倾向混元山残部（因为那是他以前的同袍），但若玩家能证明"帮助混元山残部只会让节点更快被外部势力吞掉"，他可以勉强接受中立方案。
  - NPC-STEWARD-02（军府校尉·吴）：龙骧军府外围营地的任务分发者。若玩家从吴校尉处接取本任务，他要求玩家在苍台至少确保"不要让外人拿到旧接口的残骸"——但他不能派兵支援，因为龙骧外围营地本身正面临补给节点失效的压力（节拍二余震影响）。
  - `npc_tpl_hunyuan_residual_contender`（待回填：建议回填一名 NPC-RIVAL-01 混元残部·石敢——此人身份为混元山旧玄甲道军的中层军官后代，试图通过控制旧承接接口来证明自己"有资格继承混元山的遗产"。此人不是混元山主峰认可的正式代表，但身后跟着一小群同样失去方向的旧部子弟。）：苍台节点争夺的直接竞争者——携数名残部子弟试图在旧接口遗迹上重建一个小型阵基
  - `npc_tpl_taiyi_low_expedition`（待回填：建议回填一名太一道庭外门派出的低阶勘察弟子——此人在节拍二的"阵法失灵"中被派往关陇调查水脉异常的外溢影响，偶然在苍台发现了旧承接网络的遗迹。他是学者型——不擅长战斗，但有将旧接口灵纹临摹下来的技术能力。）：太一道庭勘察队代表——希望获取苍台旧接口的灵纹数据以补充谢观微的水脉推演模型
  - `npc_tpl_cangtai_outside_scavenger`（待回填：建议回填一名 NPC-RIVAL-02 不知名拾荒者——此人身份不明，在龙脊各节点之间游荡，专门收集旧承接网络时期的法器残片。石根在废矿中见过此人但未交谈。）：不明身份的拾荒者/情报贩子——对旧承接接口残骸的商业价值更感兴趣，背后可能关联某个外部势力（关陇坊市联盟的私下委托、天机楼外围的自由情报员、或漠北玄荒殿的渗透者）
  - NPC-QUESTER-02（矿工·石根）：可选的辅助信息源——石根在苍台外围的废矿中挖出了旧承接接口的阵基底座碎片。他可帮玩家辨认碎片上的灵纹类型（"这个不是矿——这些纹路是烧上去的"），但不参与节点争夺。
  - NPC-SCOUT-03（消息通·黑耳）：可选的辅助情报源——黑耳从回波峡方向听到风声，说"有人在出高价收苍台的旧阵基残片"。他可以用人情换这条情报的来源。
- 势力：
  - 混元山残部（含龙骧军府外围）
  - 太一道庭（低阶勘察层）
  - 关陇坊市联盟（经济中立方，暗中收购旧残片）
  - 不明身份的外部渗透者（天机楼外围自由情报员、漠北玄荒殿渗透者或独立拾荒者——不锁定具体身份，留给后续 L3 或第二章确定）
- 敌人/中立方：
  - `npc_tpl_hunyuan_residual_contender` 携小队（战斗遭遇——低阶战棋遭遇。若玩家选择支持混元山残部，则此 NPC 转为临时盟友；若玩家反对，则转为战斗敌人。不写具体数值。）
  - 苍台外围的散修盗采者（非战斗——经对话或威胁可劝退。石根提供了他们的营地位置。）
  - 晶化土鼍（苍台节点地下旧灵脉管道中残留的妖兽——非必须战斗。若玩家在探索地下旧接口遗迹时触发，为练气后期至筑基初期强度。击败后可获得黄土灵晶碎片和旧接口灵纹的物理样本。）

重要 NPC 出场限制复核：
- 王玄略：不出场。通过冯老兵的回忆和旧承接接口残骸上的标记风格间接出现——冯老兵记得王玄略说过"这里可以承压"，但不理解这句话的完整含义。
- 苻渊、司马承景：不出场，不提及。
- 谢观微：不出场。太一道庭勘察队提及"谢氏道脉对关陇异常数据有兴趣"——仅作为远距离文书请求出现。
- 姚观寂、拓跋烈、卫长庚、吕星枢、钟离幽：不出场。

## 五、选项与分支

本任务为单节点主线任务，核心分支在阶段 3 的立场选择和阶段 4B 的冲突解决方法。

| 选择 | 条件 | 短期结果 | 长期读取（第二章） |
|------|------|----------|-------------------|
| 支持太一勘察队 | 太一出身或符箓/术法背景 | 获得旧接口灵纹完整临摹数据（`clue_ch01_cangtai_fracture_sequence`）；太一勘察队留在苍台继续监测；混元残部子弟离开苍台 | 谢观微推演模型中的关陇水脉参数更完整——第二章江左情报中多一条补线数据 |
| 支持混元山残部 | 混元山/龙骧军府出身，或经冯老兵担保 | 残部子弟守住旧接口但发现未知灵纹协议标记（`clue_ch01_cangtai_unknown_protocol`）；冯老兵对玩家的信任加深 | 第二章混元山内部线索中多一条"旧接口异常标记"——与坤舆谱残篇对接 |
| 调停中立 | 阶段 2 中与至少两方充分交流 | 三方共享数据但都不独占；旧残骸留在苍台原地；拾荒者去向不明（钩子）；冯老兵对玩家说"今天是第一次有人不是来抢它的" | 第二章跨势力弱联系更强——各方对玩家保持"可以再合作"的开放态度 |
| 推迟选择 | 进入阶段 4A 探索地下遗迹 | 先获得王玄略刻字和基座碎片记录（`clue_ch01_cangtai_wang_inscription`、`clue_ch01_cangtai_base_fracture_record`），再返回阶段 3 重选立场 | 第二章坤舆遗脉成员会注意到"你在苍台发现了王先生的手迹"——提供额外帮助 |

| 苍台被外部势力秘密渗透（隐藏路线） | 阶段 2 中如果玩家仅与一或两方接触、未发现拾荒者的真实意图，且阶段 3 选择了调停中立，拾荒者在离开前会暗中收买某方并带走一小块残骸 | 玩家获得较少的灵纹数据；拾荒者去向不明；`story_ch01_node_cangtai_partial_loss` | 第二章该拾荒者已被某外部势力正式吸收——他在苍台获得的数据成为该势力干涉关陇的筹码 |

## 六、玩法接口

- SettlementScene：
  - 苍台节点废墟平台与周边营地（多方势力对话、任务接取/提交）
  - 冯老兵的驻守哨位（信息查询——旧承接网络遗迹、苍台历史）
  - 旧承接接口残骸（环境叙事交互点——灵纹观察）
- WorldScene：
  - 从龙骧外围营地/太一水脉浅滩/关陇坊市联盟前往苍台的移动路径
  - 苍台节点的归属状态变化后的世界地图更新（节点归属标记、安全/不安全状态）
- AdventureScene：
  - 苍台地下旧灵脉管道（探索、环境叙事、晶化土鼍遭遇）
  - 旧承接接口基座残骸（核心环境叙事点）
- Combat：
  - 晶化土鼍（练气后期至筑基初期——地下管道伏击战，低阶战棋遭遇）
  - 混元残部子弟小队（若走 A 路线且话术失败——筑基初期强度，小队规模待战斗表确定，军阵协同）
  - 拾荒者雇佣的散修劫匪（若走 B 路线——练气后期至筑基初期，小队规模待战斗表确定，不写具体数值）
- 修炼/境界：
  - 苍台节点内的旧灵脉残余灵气可用于短暂修炼（灵气浓度不稳定——效率低于稳定节点，可能触发"灵纹共鸣"获得额外领悟；具体收益待修炼数值表确定）
  - 不突破筑基后期，不授予金丹位格
- 道具/奖励：
  - 旧接口灵纹记录（关键线索物品——不可交易不可丢弃，节拍四信息碎片需要）
  - 黄土灵晶碎片（若击败晶化土鼍——低阶土属性灵矿）
  - 冯老兵的铁木拐杖拓片（若获得冯老兵的足够信任——上面有苍台旧编号 CT-044 和四个刻字名字的模糊痕迹，节拍四中可用于与坤舆遗脉对比信息）
  - 奖励强度档：低→中阶（取决于冲突解决方式和探索深度）
- 声望/关系：
  - 冯老兵（NPC-GUIDE-05）关系提升——具体关系深度取决于玩家在阶段 2/3/4A 中的表现
  - 支持方的声望提升（太一或混元山/龙骧军府）
  - 跨势力弱联系：即使选择了某一方，其他方对玩家的印象也保留（"竞争过但守规矩"）
- 世界状态：
  - 苍台节点归属标记（secured / contested / partial_loss）
  - 龙脊南麓安全节点数量变化

## 七、失败与回退

本任务不可整体失败——玩家永远可以通过至少一条路径获得足够的节点异常证据以推进 Beat 04。具体处理：

| 失败/暂缓情况 | 处理方式 | 状态变化 |
|--------------|----------|----------|
| 节点争夺中战斗失败（选 A 或 B 时） | 战斗失败不导致任务失败——玩家撤退回冯老兵的哨位，冯老兵提供治疗（"我说过——地下的东西不要硬碰"）。重试时敌人强度不变，但冯老兵可以提供额外的战术建议（减益敌人某项抗性一次）。连续失败两次后，冯老兵建议走中立路线（"打不过就不要硬打——用嘴说试试"） | 添加：`story_ch01_node_cangtai_combat_retry_1` / `_retry_2`；不影响主线推进 |
| 地下探索中被灵气反冲逼退 | 返回地面接受冯老兵的治疗和指导。第二次进入时地下灵脉处于相对稳定期——反冲强度降低但仍需消耗灵力。核心探索点（王玄略刻字和基座碎片）不会因中途撤退而消失 | 添加：`story_ch01_node_cangtai_deep_retreat`；不影响可获得的信息碎片 |
| 中立调停失败（阶段 4B 选 C 时） | 若话术/声望对抗连续失败，太一勘察队和混元残部之间冲突升级——玩家被迫在二者之间选择一方支持（退回到 A 或 B 路线）。但不必战斗——玩家通过倾向性表态解决危机 | 添加：`story_ch01_node_cangtai_mediation_failed`——第二章跨势力 NPC 对玩家的中立性评估略降 |
| 被拾荒者暗中带走残骸（隐藏路线） | 若发生此情况，玩家事后可追至关陇坊市联盟查询（通过黑耳的情报或石根的矿工网络）。残骸可能已被转手但留下交易记录——该记录本身就是有效的节点异常证据 | 添加：`story_ch01_node_cangtai_partial_loss` 和 `clue_ch01_cangtai_scavenger_trail`（追查线索——可作为第二章跨地区线索钩子） |
| 吴校尉不满意结果（选 A 或中立时） | 若节点数据被太一或外部势力获取，吴校尉在回报时面色不虞——但不会降低军功或在主线入口锁死，因为"你至少没让外人把残骸整个拆走" | 添加：`story_ch01_node_cangtai_wu_displeased`（不影响主线，仅影响吴校尉的后续对话语气） |

回退保证：
- 节点异常证据（旧接口灵纹记录、王玄略刻字、冯老兵的目击口述、基座碎片灵纹记录、拾荒者交易追查线索）在任何路径中至少可获得一份——不存在"所有线索都被封死"的情况。
- 即使玩家选择立场导致战斗，不战斗的路线永远可用（对话/潜行/推迟选择→中立）。
- 不受任何其他节点任务的结果阻塞——即使 `quest_ch01_node_langhou` 等并行任务尚未开始，本任务可独立完成。
