# 背景与重要 NPC 设计规范

✅ 已审核（2026-07-05 Codex；变更范围：同步德业元婴自辟失败与“一源、多化、多界；元婴唯一”口径）

## 一、世界背景方向

1. 时代骨架只借用“乱世、门阀、北地共同体、法统续存、宗教融合”的结构张力，不复写真实历史事件、人物结局、战役过程或台词，不使用现实战役作为剧情因果模板。
2. 龙脊之变的因果必须是苻渊试图自辟【名称待定】（德业元婴方向）失败，导致地脉、人心、道统共同反噬。王玄略负责边界校准，判断“可能成立但尚未成熟”；谢观微负责风险推演，阻止提前发动；谢氏水府调度只能成为切断扩散或隔离反噬的关键条件，不得写成全知全能、单独摧毁北方秩序的万能法术。
3. 时间锚点固定为：371 年秋王玄略身死；372 年秋龙脊之变；387 年秋游戏开始。
4. 关键信息必须分层：谢观微知风险但不知全盘崩坏；钟离幽知裂缝而不知起因；吕星枢掌握数据而不知总因；司马承景可知更深，但必须有边界与不确定性。不得让多个 NPC 同时“唯一知晓全部真相”。

## 二、重要 NPC 写作字段

每名重要 NPC 必须单独文件，至少包含：

1. 历史锚点：借用的结构与明确不照抄的部分。
2. 叙事层级：本章功能、当前目标、失败代价、行动时限。
3. 知识边界：已知、误判、不可知的事实分别列明。
4. 位格状态：具体元婴方向、源/化/界位格、占据方式（夺取/继承/敕封/暂寄/自辟）与是否存在空位。元婴必须唯一，不得写成常规升境模板；金丹必须有真实位格，不得写成无位格低配版本。
5. 关系限制：最多三条强关系；其余关系写为阵营或弱联系，避免关系网失控。
6. 战斗表达：人物志只写战法标签、战略威胁和克制关系；命中率、伤害倍率等具体数值移入术法、神通或数据文件。

## 三、位格与势力约束

1. 不得把完整金丹席位体系写成单一门派私产；宗门拥有的是传承、资源、叙事解释权或敕封能力。
2. 源位每条分支唯一；化位、界位可扩展但必须继承分支变量。既有 NPC 若出现同一具体位格被重复占据，或“已满”与“仍有空位”并存，必须在迁移时修正为唯一状态。
3. 慕容朔类“妖血注入但不产生独立金丹位格”的设定，不得称妖血敕籍，应称妖血契、血脉注入或同类关系。

## 四、太一道庭与司马承景

1. 太一道庭凭【名称待定】（太一道庭/仙朝法箓元婴方向）的残存公共法统接口维系法箓秩序；它继承法统与正统名义，不拥有对全域灵脉的实际统治力，也不天然证明天命正确。
2. 司马承景保留为真实存在的唯一高位元婴残损承接者，用于展示法箓公共法统的源头、代价与衰退；可通过外封祭坛或道印回响留下线索，但不应作为常规可击杀战斗单位，第一章不得直接出现。
3. 太一道庭金丹可占据真实源/化/界位格，也可通过有限递减的法箓敕封、暂寄或自凝方式取得使用权；不得写成“所有太一金丹均由司马承景敕封”。
