## 二、境界与栖息环境

石甲兽为**练气期低阶妖兽**，盘踞于**关陇玄域·关中平原外围的黄土旧道**（`guanzhong_wild` 场景）。其栖息区域处于关中灵矿带与黄土裂谷边缘交接处，地表为废弃古道与碎石堆积，周围偶有龙脊之变后残余的低强度灵气波动。

### 行为动机

- 受残余灵气惊扰后不再被动回避，会主动**护住退路**并攻击靠近的修士。
- 不具有领地意识外的智能策略——不设伏、不追击远离旧道范围的目标、不主动切换攻击目标。
- 被打败后同一古道再次经过时可能遇到同一物种的其他个体，因此遭遇**可重复进入**；每场均为独立战斗，不累积削弱或特殊状态。

### 环境约束

- 只在 `guanzhong_wild` 中以唯一正式敌人身份出现，不扩散到其他 Adventure。
- 不因时间、天气或玩家境界改变行为；不关联灵气风暴、节点修复或战修道途等关陇地区独有机制。
- 不属于关中主线的信息载体——不揭示龙脊之变、灵脉节点、势力立场或世界真相。

## 三、外观与战斗识别

### 外观特征

- **厚甲覆盖**：体表覆盖多层深褐色至灰黑色岩质甲壳，背甲最为厚重，边缘有不规则裂痕——系本土妖兽长期在黄土灵矿带活动、体表吸附灵矿碎屑后矿化形成。
- **低伏体型**：四肢粗短贴地，重心极低，正面轮廓呈扁平梯形；高度约至成年修士腰部。
- **迟缓步态**：移动缓慢，每一步伴随碎石摩擦声；转向时甲壳碰撞发出沉闷声响。
- **战斗姿态**：遇敌后收拢四肢、压低重心，将背甲朝向来敌方向，形成一面天然盾墙。

### 战斗识别特征

| 特征 | 描述 |
|------|------|
| 移速 | 缓慢——CTB 行动条推进速度低，玩家通常先手 |
| 攻击方式 | 近战基础攻击——以头角顶撞或以侧甲撞击，单目标 |
| 格挡倾向 | 高基础格挡率（15%），格挡减伤 25%——厚甲天然优势 |
| 暴击 | 低基础暴击率（5%），暴击倍率 10%——不追求精准打击 |
| 闪避 | 无基础闪避——笨重不灵活 |
| 魂盾 | 无魂盾——纯物理防御 |
| 术法/神通 | 无——当前无已装备术法或神通 |
| 特殊能力 | 无——不新增未实现能力 |

具体战斗数值（根骨 18、体魄 16、灵力/神念/反应各 6、天赋 4、境界倍率 1.2）全部来自既有 `CharacterData` 模板，本档案只引用、不重写。完整 CTB 结算公式与等级计算由战斗系统决定。

## 四、AI 行为

AI 类别：`ai_melee`（近战 AI）

最小行为语义（首轮由正式近战 AI 复用现有确定性顺序）：

1. **尝试已装备能力**：无已装备术法/神通，此步实际空过。
2. **接近目标**：向目标移动，缩短距离至相邻。
3. **相邻基础攻击**：与目标相邻时发动普通近战攻击。
4. **不能行动时防御**：被控制、无法移动或无法攻击时进入防御状态，获得防御加成。

石甲兽因无已装备能力，实际表现为"接近→近战→受阻时防御"的简单循环。不包含以下行为（且本档案不授权新增）：

- 远程攻击、范围攻击、弹幕或召唤
- 切换目标、仇恨管理、撤退或诱敌策略
- Boss 阶段切换、狂暴、回血或特殊状态
- 环境互动、地形利用或队友协作
- 任何未在 `ai_melee` 中注册的行为分支

## 五、术法与神通

- 当前无已装备术法（`equippedSpells` 为空）
- 当前无已装备神通（`equippedSkills` 为空）
- 当前无可使用术法槽位（`maxSpellSlots=0`）和神通槽位（`maxSkillSlots=0`）
- 战斗属性由通用战斗模板 `Char_Enemy_enemy_shijiahou.asset`（`CharacterData`）承载；本档案不新增或调整任何战斗数值

## 六、掉落候选

战斗胜利后生成结构化结算，掉落条目由既有 `Enemies.csv` 定义：

| 候选物品 | itemId | 来源语义 |
|----------|--------|----------|
| 石甲碎片 | `item_shijia_piece` | 石甲兽被击败后碎裂脱落的岩质甲壳残片——因体表矿化而具有微弱的土属性灵力，是低阶炼器与土系阵法的常见基底材料。 |
| 劣质灵石 | `item_lingshi_low` | 石甲兽长期在残余灵气环境中活动，体内少量灵气凝结形成的劣质结晶；外观粗糙不纯，仅能提供微量灵力补充。 |

- 具体掉落概率、数量、堆叠上限和奖励参数统一由 `N-GZ-REWARD-01`（首批掉落、堆叠与悬赏奖励参数）锁定；本档案不对数值做出结论。
- 掉落由战斗系统按 `EnemyData.dropEntries[]` 的 `dropChancePercent` 与随机源执行；运行时不得再由 `realmMultiplier` 推导默认掉落。
- 不存在石甲兽专属的第三掉落物、特殊兑换或跨系统合成的隐藏产物。

## 七、使用范围与重复遭遇

### 正式引用

- **唯一正式 Adventure**：`guanzhong_wild`（关中野外·石甲兽阻路）
- **遭遇数量**：每场 `enemyCount=1`
- **绑定方式**：Adventure 场景在探索初始化前将 `Char_Enemy_enemy_shijiahou` 作为唯一敌人绑定；正式引用缺失时遭遇启动明确报错，不使用 fallback 敌人。

### 遭遇流程

```text
关中城(guanzhong_city) → 野外入口(guanzhong_wild)
  → 遭遇石甲兽(enemy_shijiahou, enemyCount=1)
  → 胜利或败北
  → 清除 Adventure 上下文，返回 guanzhong_city
```

### 重复遭遇边界

- 每次从关中城进入 `guanzhong_wild` 均触发同一场低阶石甲兽遭遇。
- 不累积独立状态——不因重复次数改变敌人强度、行为、掉落或解锁额外内容。
- 不升级为支线任务、不触发隐藏 Boss、不成为关中主线节点的前置条件。
- 重复遭遇不提供"跳过战斗"或"自动结算"等便捷通道。

### 未授权引用

- 关中城外其他 Adventure、其他地区（漠北、中州、陇西等）或副本不得直接复用本档案的 `enemyId`。
- 本档案不定义石甲兽在悬赏（`bounty_guanzhong_shijiahou`）以外的任何任务目标用途；悬赏的击败进度规则由 `BountyRuntime` 与 `C-GZ-BOUNTY-01` 负责。

## 八、与战斗模板的边界

本档案（`EnemyData` 事实）与战斗模板（`CharacterData` 事实）的分工：

| 方面 | 本档案（EnemyData） | 战斗模板（CharacterData） |
|------|---------------------|--------------------------|
| 身份 | enemyId、正式显示名、描述、类型、AI、境界 | charName、baseLevel |
| 属性 | 指向模板，不重写 | 根骨、体魄、灵力、神念、反应、天赋 |
| 战斗参数 | 只描述识别特征（高格挡、无闪避、无术法） | 实际数值：blockRate、dodgeRate、critRate 等 |
| 掉落 | 指出候选物品与来源语义 | 不涉及 |
| AI | 指出 aiProfileId 与最小行为语义 | 不涉及 |
| 使用范围 | 指定 Adventure 与遭遇边界 | 不涉及 |

禁止项重申：不修改 `CharacterData` 的属性、倍率、格挡率、暴击率或任何战斗参数；不新增 `equippedSpells`；不修改 `Enemies.csv`、`Language.csv` 或 `.asset` 文件。
