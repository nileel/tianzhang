# 练气疗伤丹药 · 活血丹

2026-10-09 Codex 设计核验；D-COMBAT-AP-ITEM-01。负责人已授权一种练气自用疗伤丹药及新角色初始取得；本文是独立 L2 内容定义，Unity 接入与数值定案尚未完成。

## 身份与命名来源

- 名称：活血丹（三字）。
- 稳定 itemId：item_huoxue_dan；显示名键同 ID，说明键 item_huoxue_dan_description。
- 品级：下品；类别：丹药，生产投影 itemCategory=pill、contentScope=content_scope_production。
- 适用境界：最低练气，实际使用仅限练气九品；筑基及以上、凡人和未知境界均不可使用。同名道具不跨境界。
- 命名来源：《仙授理伤续断秘方》“又治伤损方论·活血丹”，已有同名伤损药方；2026-10-09 核对原文。只取典籍名称与伤损意象，游戏效果和材料说明由本项目定义。
- 原文链接：[仙授理伤续断秘方·活血丹](https://zh.wikisource.org/zh-hant/仙授理傷續斷秘方#活血丹)。原文所列乳香、没药、骨碎补等只提供命名与材料意象的依据，不把古方药效映射成游戏规则。

## 丹药模板与效果绑定

| 字段 | 内容 |
|---|---|
| 名称 | 活血丹 |
| 品级 | 下品 |
| 适用境界 | 仅练气期存活修士 |
| 触发 | 正式战斗个人回合内成功确认使用一颗 |
| 条件 | 使用者有该药库存、行动力足够且允许主动使用道具；完整资格、目标及版本校验通过 |
| 目标 | 使用者自身；TargetId 必须等于 ActorId |
| 效果类型 | 即时恢复当前生命；只绑定这一条效果，不递归调用效果包 |
| 参数 | 恢复量候选80，实际恢复 min(80, 生命上限−当前生命)；截断溢出，不形成护盾 |
| 副作用 | 无；消耗药物和行动力属于明示使用成本 |
| 使用限制 | 每次恰一颗；每次须重新报价和确认。库存与AP足够即可重复使用，不额外设置每回合／每战次数；满血仍是合法使用且照常付费；死亡不能使用或复活 |
| 炼制材料 | 乳香、没药、骨碎补（仅世界观参考，不配置数量、配方、炼制或材料产出） |
| 说明 | 练气修士随身备下的伤损丹药，药力温和，服后缓解新伤、补回当下耗损的气血。其效止于疗伤，不增长生命上限，也不助突破。 |

不恢复灵力、不改变生命上限、不提供永久成长、持续治疗、复活、状态清除或突破位效果；不改练气.txt 的聚灵丹、洗髓丹与培元丹。本药只开放本次批准的正式战斗自用入口，非战斗使用不在本次交付中。

## 取得与保存

练气新角色建立时由现有 CreateNewPlayer→BeginNewGame 链一次性发放候选3颗，在初始存档写入前通过 InventoryGrantUseCase 验证并提交。仅新建练气角色适用；读档、场景重进、再次开战及已有存档无药时均不补发，也不改变境界。

每次成功使用立即由 InventoryStore 唯一扣除一颗；战后不再次扣药。沿既有非战斗保存入口保存剩余数量，读档按存档恢复。临时战斗生命、AP、CT、冷却与报价不加入存档；本药不改变现有战斗资源长期写回规则。
