【道具设计规范 v1.2】

═══════════════════════════════════════════════════════════
一、概述
═══════════════════════════════════════════════════════════

✅ 已审核（2026-07-22 Codex；增加唯一剧情遗物分支）

现行道具分为丹药（炼制品）、天材地宝（天然机缘物）和唯一剧情遗物。
丹药与天材地宝通过明示的效果绑定影响修炼、战斗或角色成长，不按品级自动获得通用突破加成；唯一剧情遗物使用独立的身份、权限与承载模板，不纳入四品消耗品体系。

设计原则：
- 丹药偏主动炼制，具体用途由效果绑定与使用限制决定
- 天材地宝偏机缘获取，可承载永久容量修正、特性或属性效果
- 唯一剧情遗物偏持续剧情状态、权限与世界交互；同一身份只允许一个有效实例
- 所有效果平铺记录触发、条件、目标、效果类型和参数，不建立递归效果包

═══════════════════════════════════════════════════════════
二、品级体系
═══════════════════════════════════════════════════════════

丹药与天材地宝沿用四品制：下品 / 中品 / 上品 / 极品。唯一剧情遗物不用品级表达权限高低。

品级用于内容稀有度、产出与同类物的品质区分，不自动映射为突破概率、道基凝聚值或金丹凝聚值。
任何数值效果都必须由该道具自己的效果绑定明确给出，并进入对应机制的独立数值验证。

═══════════════════════════════════════════════════════════
三、效果绑定与永久扩府效果
═══════════════════════════════════════════════════════════

每件道具可以平铺装载一条或多条效果绑定。每条绑定只保存：

- 触发。
- 条件。
- 目标。
- 效果类型。
- 参数。

连续结果使用有序的多条绑定表达，不得由一条绑定递归调用另一组效果。

永久扩府效果的统一口径：

- 效果类型为“紫府容量上限永久 +1”。
- 仅能在筑基期取得并使用；结丹后不能使用扩府效果。
- 同一角色最多获得两层，不因道具名称或品级提高层数上限。
- 使用后只增加紫府总容量，仍须完成普通的筑府流程；不会直接生成紫府或镇府神通。
- 多种天材地宝可以复用同一容量修正效果，但具体物品、品级、稀有度与掉落分布由后续内容任务确定。

六、唯一剧情遗物模板
═══════════════════════════════════════════════════════════

每件唯一剧情遗物必须单独文件，至少填写：

┌────────────────┬─────────────────────────────────────────┐
│ 字段           │ 说明                                    │
├────────────────┼─────────────────────────────────────────┤
│ 名称           │ 遗物正式名称                            │
│ 稳定ID         │ 唯一内容身份                            │
│ 唯一实例       │ 世界中有效实例数量及复制品处理          │
│ 持有/认主状态  │ 当前持有、认主、争议、转授或遗失状态    │
│ 权限类型       │ 通行、归属、调衡、见证等明确权限        │
│ 现实支点       │ 权限成立依赖的遗物本体、设施、节点等    │
│ 可用范围       │ 目标类型、地理/网络范围与规模上限       │
│ 受限承载账本   │ 充能、耐久或等价的容量/占用/认可状态    │
│ 失效条件       │ 何时拒绝调用、降级或停止承认            │
│ 剧情状态       │ 当前可知状态与信息揭露边界              │
│ 可调用规则档案 │ 可调用档案或明确“不适用”                │
│ 禁止越权项     │ 不能替代的遗物、境界、修复或规则权限    │
└────────────────┴─────────────────────────────────────────┘

唯一剧情遗物的复制品、拓印、残片和投影默认只提供研究或线索价值，不自动产生第二个有效实例。权限必须同时依赖明确现实支点和可用范围；“唯一”不等于无条件全图生效。

剧情遗物的受限承载可以是充能、耐久，也可以是条目占用、节点承载、界印认可、现实供给或其他等价账本。若内容不以损耗为核心，不得用随意掉耐久制造日常忙碌。

═══════════════════════════════════════════════════════════
七、设计约束
═══════════════════════════════════════════════════════════

1. 当前玩家境界覆盖：练气、筑基、金丹；凡人境不设道具。元婴、化神道具仅作 NPC/背景预留；炼虚已从境界体系删除，不得建立对应道具文件或效果绑定。
2. 每个当前玩家大境界丹药2-4种、天材地宝1-2种
3. 丹药命名须有典籍或丹道传承依据，不可杜撰
4. 天材地宝命名须取自志怪典籍或仙侠世界观中的知名灵物
5. 同名道具不可跨境界使用（如"洗髓丹"仅限练气期使用）
6. 极品道具每个境界最多1种，避免泛滥
7. 副作用需明确标注，不可隐藏
8. 扩府效果只能引用统一的永久容量修正，并受“筑基期、每人最多两层”角色约束；具体物品不得自行改写上限
9. 道具不得按品级自动套用通用突破概率、道基凝聚值或金丹凝聚值
10. 效果绑定不得递归调用任意效果包
11. 唯一剧情遗物必须记录唯一实例、持有／认主、权限、现实支点、范围、受限承载、失效、剧情状态和可调用档案
12. 剧情遗物不能只凭名称越过目标协议、设施状态、组织授权、现实供给或高阶冲突

八、修订记录
═══════════════════════════════════════════════════════════

v1.0 - 初始版
  - 定义丹药/天材地宝双轨设计体系
  - 引入突破位机制（每境界突破道具数限制）
  - 定义品级→加成映射规则
  - 当前玩家链按练气→金丹配置道具；高阶道具另作 NPC/背景内容管理

v1.1 - 筑基、紫府与丹相事实源迁移
  - 删除品级到突破概率、道基凝聚值与金丹凝聚值的通用映射
  - 改用平铺效果绑定
  - 增加筑基期永久扩府效果的统一模板边界

v1.2 - 唯一剧情遗物分支
  - 保留丹药与天材地宝原模板
  - 增加唯一实例、权限、现实支点、范围、受限承载和剧情状态字段
  - 允许以等价受限承载账本替代无意义的通用耐久消耗
