# 《天章》设定索引

✅ 已审核（2026-07-22 Codex；旧版聚合稿降级为索引）

> 本文件不再承载与下列权威事实源重复的长篇设定，也不得作为旧版高阶内容、世界历史或地区细节的现行依据。2026-07-22 以前曾收录于本文件的“统一上古仙朝”“天门意外崩塌”“后仙朝时代”“真仙／炼虚内容”和重复九域资料，只保留在 Git 历史中供溯源；现行内容必须读取对应独立事实源。

## 一、项目身份

- 游戏名：《天章》。名称保留。
- 世界名：太玄界。
- 类型：2D 沙盒世界、战棋玩法的修仙游戏。
- 当前玩家完整成长链止于金丹；世界境界与高阶内容边界以修行事实源和开发管理状态为准。

《天章》之名的现行解释：“天”同时指太玄界真实而受损的本界天意，以及曾参与本界历史的上界秩序；“章”既指《册界天章》中完整登记的治理条目，也指人间共同体必须共同承担的未来章程。它不表示天庭给所有修士颁发境界。

## 二、宇宙观与世界历史

- 大道、本界天意、上界天庭、藩界／直属界域、上古太玄道庭与绝地天通：`docs/基础设定/太玄界天意与绝地天通设定.txt`
- 面向剧情生产的四层世界背景、近代龙脊之变与游戏当代：`docs/剧情/世界背景故事.txt`
- 背景与重要 NPC 生产约束：`docs/剧情/背景与重要NPC设计规范.txt`
- 全类型剧情分层、字段、知识边界和生产流程：`docs/剧情/剧情生产规范.txt`

现行历史硬边界：

1. 权威历史中不存在统一“上古仙朝”。上古太玄道庭崩解后，直接进入遗产分散、具体地方政权兴亡和宗门成长的时代。
2. 太一道庭只继承上古太玄道庭南方法箓支系，不拥有全界正统。
3. 司马承景是后世公共法统的重整者与残损承接者，不是仙朝末代道主。
4. 远古绝地天通与近代龙脊之变是两场独立事件。
5. “天门崩塌”可作为后世公共误称、传闻或不完整史观出现，不再作为作者视角的完整因果。

## 三、修行与战斗规则

- 修行境界与玩家成长边界：`docs/基础设定/修行境界.txt`
- 金丹结构、阶段、三实位、载体、核心、死亡与元婴晋升：`docs/基础设定/元婴锚点与金丹位格设定.txt`
- 十七道路与五十一个基础效果：`docs/基础设定/元婴锚点与金丹位格矩阵.txt`
- 装配、兼容、确定性冲突、跨阶挑战与山河体：`docs/基础设定/金丹基础效果装配与冲突规则.txt`
- 自辟元婴方向：`docs/基础设定/自辟元婴方向设定.txt`
- 战场空间与环境：`docs/基础设定/战场空间与环境规则.txt`
- 五行显化与环境交互：`docs/基础设定/五行显化与环境交互规则.txt`
- 状态、时空与因果结算：`docs/基础设定/战斗状态与时空因果结算规则.txt`
- 筑基、紫府与丹相相关事实：按 `开发管理/设计-当前状态.txt` 所列现行入口读取。

天庭的跨界治理位格不映射为太玄界的新境界，不占用十七道路的元婴锚点。飞升是跨界通行、迁移和制度筛选，不等于自动进入炼虚。

- 《册界天章》：`docs/道具/剧情遗物/册界天章.txt`

三者职责固定为通行、归属、调衡。任何内容都不得让《册界天章》绕过完整条目、范围、节点、界印或组织授权、现实支点、现实供给、世界代价、金丹冲突和元婴受锚状态。

## 六、内容规范

- 功法：`docs/角色养成/功法设计规范.txt` 与 `docs/角色养成/功法/功法设计.txt`
- 术法：`docs/角色养成/术法设计规范.txt` 与 `docs/角色养成/术法/术法设计.txt`

非规则描述类完成品仍须每个单独一个文件。具体强度、倍率、概率、资源收益或战斗表现不得只凭叙事文档认定，涉及数值结论时按项目规则运行 BattleSim 或相应验证。

## 七、实现与状态边界

设计文档、CSV、Unity 运行时、保存／读取、UI 和数值验证是不同状态层。某项规则写入事实源，不表示其数据或玩法已经实现。当前完成度、风险和批准范围只以 `开发管理/设计-当前状态.txt` 及任务事实源为准。

本次宇宙观迁移不生产批量册界条目，不修改 CSV、Unity、保存、UI 或 BattleSim。后续实现必须另获授权并按数据链路与运行时事实源执行。
