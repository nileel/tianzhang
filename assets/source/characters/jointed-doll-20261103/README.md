# 苻渊完整肢体＋外挂衣片实验

本次根据用户提出的关节人偶方案，独立生成完整着衣主体、单片袖挂件、单片前袍与单片后侧袍，再镜像挂件装配。前臂与裤腿已在四视图阶段统一炭黑／旧金裂纹配色。生成和装配没有复用上一轮缺少内部肢体的整袍壳。

## 来源与费用

[四组建模四视图及精确提示词](../../../generated-character-art/fuyuan-jointed-doll-production-20261103/README.md)。主体 H3.1 超清几何／4K／目标 25000 四边面，三类挂件 H3.1 标准几何／4K／目标 3000 四边面。四项各一个候选，实际 55＋40＋40＋40＝175 点，余额 2635→2460；包括此前实验累计 320 点。用户已明确授权后续直接使用现有点数，未充值、未订阅。

各单位目录保留 `source.zip`、原始 FBX、原始 4096×4096 JPG，文件哈希见 [source-manifest.json](source-manifest.json)。未覆盖旧实验或正式 Unity 资产。

## 装配与绑定

- 高度按主体头顶至鞋底归一到 1.8 米，Z 向上，前方为 -Y，角色左侧为 +X。
- 共 7 个网格：完整主体＋两片袖挂件＋两片前袍＋两片后侧袍；4 份原始 4K 材质，23 根骨，44553 个网格面。面数不是三角面数。
- 保留完整主体拓扑与 UV，逐顶点坐标／面连接／UV 哈希与归一化原件完全相同，见 [body-preservation.json](working/body-preservation.json)。肢体大段以单骨影响为主，肩肘髋膝踝只使用相邻两骨过渡，避免切开身体造成敞口。
- 六片挂件各自单骨刚性；袖根属于前臂，四片袍根属于 hips。衣片摆动使用动作关键帧，不加布料物理。
- 袖挂片按高 0.48 米／宽 0.28 米适配，袍片按当前主体比例配到高 0.90 米，前片宽 0.32、后片宽 0.42 米。尺寸适配保留原有 UV 和完整背衬；镜像时翻转面朝向。
- 挂点经过静态校准：Tripo 腰部并非以 Y=0 对称，后袍根改到真实腰背表面；袖片放在前臂背侧，避免正面片体与手掌重叠。
- [build_doll.py](working/build_doll.py) 在 `four-sources-normalized.blend` 基准上完成绑定和装配；`jointed-doll-rig-base.blend` 为动画前的 T 姿基准。

六片挂件均为闭合网格（边界边与非流形边均为 0），各顶点仅一个影响。主体保留 Tripo 原件的 242 条边界边和 281 条非流形边，主要是原始细节网格；不能称为水密打印模型。权重和网格记录见 [mesh-qa.json](working/mesh-qa.json)。

## 交付与实际验证

- 可编辑含贴图文件：`working/fuyuan-jointed-doll.blend`。
- 含骨、三动作、嵌入贴图的 FBX：`export/fuyuan-jointed-doll.fbx`。导出使用 `FBX_SCALE_UNITS`，并只在导出时三角化；Unity 实际导入 88955 个三角面，与源网格预期一致，已无自相交面丢弃提示。
- [实际播放器和三动作视频](../../../../artifacts/fuyuan-jointed-doll-20261103/runtime/README.md)：7 个蒙皮网格，4 个实际 4096² 材质；走路 1.567 秒、施法 2.367 秒、攻击 1.967 秒，30fps，三动作六方向实际录制 1086 帧。
- [animate_doll.py](working/animate_doll.py) 使用实际 rest 骨位、双段腿 IK 与固定髋高，脚底保持原静置方向；袖片补偿父臂旋转并保留关键帧摆动。前后袍按膝、脚和大腿的表面间隙计算让位角，未把屈膝角度直接当作袍片摆角。
- 后侧头发的 432 个顶点原先落入肩臂权重区，已明确改回 head。头随胸而动，没有另加发链。
- 首次播放器包围盒因遗漏单位导出选项被放大 100 倍，未采用该录制。恢复项目既有单位选项后，包围盒回到米级、角色正常显示；失败原始证据另存 `runtime/capture-unit-mismatch/`，不混入最终视频。

此处完成的是生成、装配、导出与三动作可播放的结构实验。独立复核只覆盖所列静态图和精选实际运行帧，不把全部录制帧等同于逐帧无穿插验收。

## 已知外观边界

完整主体与独立挂片的结构可行，静态侧视仍有较大的袍片间开口，袖片也偏薄护板感，尚未还原原画的连续宽袖长袍轮廓。手指仍有连片感，保留整手刚性；头发贴肩背，不加入头发物理。概念图、网页结果图和静态截图不等于全部动作无穿插。

原始 ZIP／FBX／Blend 与播放器二进制保留在本地忽略目录，不代表已由 Git 备份；版本控制只纳入明确列出的输入、脚本、记录和精选验证证据。
