D12 集成步骤2：按已确认的 V3 重做战斗 HUD
日期：2026-11-18

2026-11-19补充：本记录的双尺寸测试在切换尺寸后重载场景，未覆盖同场动态切换。用户截图暴露 CanvasScaler 更新晚于 HUD 逆缩放、旧结果被缓存的问题；根因、修复及五尺寸连续切换证据见 ../d12-hud-resize-fix-20261119/验收说明.txt。

结果与根因
用户指出上一版 UI 与设计图不一致，并明确要求重做。上一版 6cc79fc0 只证明装配、命令和状态接通，却复用了旧面板、图标和大块布局；固定 1920 Canvas 整体缩放也没有实现 V3 的 rem 与断点规则。撤回原视觉完成结论，旧记录保留为当时的功能证据，本目录替代其视觉交付。
事实源为 ../d12-ui-proposal-v1-20261029/v3-20261030/ 的 README.md、hud.css、hud.js 和双尺寸 visuals。此次重做步骤2的 HUD 表现，不把步骤3统一确认或步骤4正式场景 View 算作完成。

实施
1. 从 hud.js 提取原 SVG 图标，按 hud.css 的渐变、颜色、边框输出 CombatV3 专用贴图；export-v3-assets.cjs 可用 Sharp 重新导出。旧 CombatCompactUiAssets 共享资源未修改。新增 D12CombatHudAssets 只负责本 HUD 的导入、贴图和按钮样式。
2. 现有 CombatHudRoot 使用 D12CombatHudLayout 实现 clamp(18px,1.04vw,20px) 的局部缩放、1450px 断点、内容宽底栏与32px底部留白；不修改探索 Canvas。资源卡、紧凑公开次序、独立状态行、窄报价、选中／焦点边框、短名、构筑标记及暗角按 V3 重排。长详情由“目”查看，战报由“录”查看。
3. 运行时文本探针确认旧按钮仍有左右各16px内边距，造成 Esc、录、菜单及长费用裁切；专用样式统一为2px，报价按真实标题／余额宽度伸缩。保留真实小数 AP，不截断或伪造数据来贴合静态稿。
4. 收势只列本人能力；切换收势清空冻结报价，关闭按钮按自身 key 选择能力模式。重复局部 Rebuild 清理已迁入 HUD 的金丹根节点。探索返回入口恢复原样式。

运行时所有者与数值证据
正式入口 AdventureSceneInstaller → CombatHudPresenter／CombatCommandInput → CombatActionBarView、CombatActionPreviewView；金丹链为 JindanRehearsalPresenter → JindanHudPresentation → JindanHudSnapshot → JindanDemoView。D12CombatHudBuilder 保存层级和引用；D12CombatHudLayout 在 LateUpdate 写局部缩放、底栏与报价尺寸，HorizontalLayoutGroup 写实际可见槽位置，视图继续写文字、状态和可交互性。
父链：UICanvas（Screen Space Overlay、参考1920×1080、Expand）/CombatHudRoot/CombatHotbar/CombatActionBar/ActionViewport/ActionContent。probe 使用 GetWorldCorners → WorldToScreenPoint（overlay camera=null），日志坐标原点在左下。before/ 保留修改前同场景采样；layout/ 保留最终采样、文本 preferred 尺寸和按钮射线证据。

尚存差异与任务边界
字体使用项目已有 GuanzhongChinese，未导入浏览器稿的系统字体；不宣称逐像素一致。长明截图在施放当回合，真实显示火0/3、当回合不维护，与设计主对照的首次维护后帧不同。固定尺度预设装配与参与人数按实际数据呈现。
普通攻击、普通术法和移动仍是现有点格提交，界面如实显示“点格施行”；左键锁定候选后同区确认属于步骤3，未伪造确认按钮。已存在的结束／防御／自施法及金丹确认继续走真实命令。
棋盘火域、支点、显隐等正式 View 接入及完整连续原速试玩仍属步骤4和 D12 总项，未因 HUD 重做标为完成。本次未改战斗核心、存档格式、角色装配 CSV 或程序集依赖，未扩展 BattleSim。

复现
打开 src 工程，运行正式 AdventureScene；普通开局检查普通栏，长明试玩建角并入场第二段检查同场普通／金丹切换，固定尺度阳照挑战检查多入口。需要重建时只调用 TianZhang.Editor.D12CombatHudBuilder.Rebuild。不得让批处理与打开同一工程的 Unity 编辑器并行。
