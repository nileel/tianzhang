## 可从图确认的视觉内容

- 六角顶面与外露柱体侧壁对应，独立模块清楚；同高度地块紧密相接，细接缝保留边界，没有逐块割裂成悬空小岛。
- 低谷、中台、高台三个主要视觉层次明确；高差处露出石质侧面，同高区域形成连续草土表面。
- 地面路线可目视追踪：左下入口 → 左侧连续坡面 → 中台 → 后右阶梯 → 高台。前右短阶提供中台到低处岸台的第二连接，两处阶梯的踏步与平台均可辨。
- 中台前缘没有坡阶的裸露断崖表现潜在飞行捷径；V3 聚焦地形，没有绘制飞行者或飞行 UI。
- 低残垣、较高墙段、植被、水岸与高台石碑保留为后续资源拆分线索，不在本轮固定每件资产的尺寸和数量。
- 山雾、暖光冷影、前深后淡与原有视觉方向连续；主要战场保持可读，没有用大型领域光罩盖住地形。

## 不能从图推导的规则

- 艺术化格线不保证精确百格、严格六邻接、地图尺寸或路径长度；可达性、第二绕行路线、双格转向和净空须由 D1–D3 地图数据与实机验证。
- 崖壁米制高度与坡度不是规则档位；台阶踏步不额外增加规则高度档。落地只用三档规则地面高度，飞行高度另按原型确定，仍单柱单占位。
- 水深、岸边可涉水区域、残墙阻挡、燃料、材质、耐久和掩体档必须配表；不凭图像自动赋予规则。
- 石碑只是规则支点造型，不默认具备传送或任何特定领域；飞行状态与合法落点预览仍须后续单独设计、实现。
- 背景瀑布、远山和景深树木是装饰；不扩展为全图流体、可到达远景或树木系统。
- 不从本图取角色身份、战斗数值、费用或技能名称。V3 中两人仅为比例示意。
