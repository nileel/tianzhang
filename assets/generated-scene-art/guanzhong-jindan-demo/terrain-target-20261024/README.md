## 不能从图推导的规则

- 艺术化格线不保证精确百格、严格六邻接、地图尺寸或路径长度；可达性、第二绕行路线、双格转向和净空须由 D1–D3 地图数据与实机验证。
- 崖壁米制高度、坡度和小石台视觉高低不是规则档位；落地只用三档规则地面高度，飞行高度另按原型确定，仍单柱单占位。
- 水深、岸边可涉水区域、残墙阻挡、燃料、材质、耐久和掩体档必须配表；不凭图像自动赋予规则。
- 空中光圈是位置提示构想，不是最终 UI 形状；实际预览须贴合法六角格。石碑只是规则支点造型，不默认具备传送或任何特定领域。
- 背景瀑布、远山和景深树木是装饰；不扩展为全图流体、可到达远景或树木系统。
- 不从本图取角色身份、战斗数值、费用或技能名称。图中三人是比例与用途示意。
