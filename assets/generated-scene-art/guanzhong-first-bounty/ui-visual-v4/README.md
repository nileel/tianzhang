## 本轮变化

1. 撤掉城镇底部整栏。头像、姓名/道号、境界、生命/灵力固定左上；通用入口固定右上，更多项按需展开。
2. 中上方 `.city-context` 是城名与出城的共同 DOM 所有者。区域名、城名、操作区一起排列；未来城市管理归入内部 `.city-actions`，不另挂到全局功能栏。
3. 悬赏、坊市、客栈、情报、旧水驿改为场景对象入口。名字常显，引线指向占位对象，悬停/键盘焦点显示说明。悬赏四态直接更新场景名牌，领奖后对象仍可点，但没有再次领奖入口。
4. 保留按需展开的右侧悬赏文书；顶部玩家信息、城镇组件、通用入口均不被文书遮挡。更多下拉与文书互斥，Esc 可关闭。
5. 大幅城名缩为组件内题字。原 SVG 城景仍为构图占位，仅补两个简单的悬赏板/情报亭代理以锚定点击对象，不是正式背景制作。

通用功能只交付入口布局与点击反馈，反馈显示在外部审阅栏。角色、背包、功法、术法、门派页面没有在本轮制作。姓名、道号、境界与资源值均为设计示例，不能据此锁定正式角色设定。
