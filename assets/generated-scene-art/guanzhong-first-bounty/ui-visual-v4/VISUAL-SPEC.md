# 关中城镇 UI v4 · 布局与组件规范

承接用户认可的方向二。视觉使用 v3 的墨蓝漆面、暖纸、玉色交互、朱砂印章及有限铜线；本轮不新增色彩体系。具体颜色/字体/按钮制作方式仍见 [v3 基础规范](../ui-visual-v3/VISUAL-SPEC.md)。本文件替代该规范的**城镇底栏、大城名、事务入口位置**部分；战斗部分沿用。

## 信息所有者

| 组件 | 内容 | 归属与行为 |
| --- | --- | --- |
| 玩家摘要 | 头像、姓名、道号、境界、生命、灵力 | 左上固定；点击角色入口。非核心属性进入角色页 |
| 通用入口 | 角色、背包、功法、术法、门派、更多 | 右上固定；全局功能不混入城镇服务 |
| 城镇信息组件 | 区域、城名、出城 | 同一个 `.city-context`；城镇切换时作为一个整体更新 |
| 城镇操作区 | 当前出城；未来城市管理 | 同一个组件内部 `.city-actions`，城市管理有真实能力和权限后才显示 |
| 场景对象 | 悬赏板、坊市、客栈、情报、旧水驿 | 名牌锚定对象、按需打开事务；名字不依赖悬停 |
| 悬赏文书 | 目标、奖励、当前下一步操作 | 右侧按需展开，四态逻辑沿用 |

出城本版属于城镇组件，不另设一个竞争的城门入口；后续如采用建筑入口应重新确认统一出口归属。全局“山河”是原有世界地图入口占位，不是第二个可执行的出城动作。

未来城市管理与出城同属一个操作列表，跟随当前城镇上下文；空间不足时操作区折为组件内第二行，禁止把管理按钮挤入通用菜单。此为归属约束，不代表城市管理已实现。本版没有空管理按钮或无权限的假入口。

## 尺寸与排布

以下为 1920×1080 设计画布坐标；1280 宽按 2/3 缩放，正式 Unity 要重新验收字体与安全区。

- 玩家摘要：左 52、上 34、宽 456，自适应内容高度约 196。头像 82×114；姓名 29，道号 17，境界 18，资源标签 18、数字 19。
- 通用入口：右 52、上 34，单项 82×88、间距 5、两边 padding 10。图标 31，题签 23。更多下拉宽 190、位于入口下方 116。
- 城镇组件：左 650、上 34、宽 594，padding 20×24。区域 16，城名 39；出城 29，目的地 17。标题与操作由同一个外框及内部细分隔线承载。
- 悬赏文书：右 52、上 230、宽 510、高 770，正文和四态按钮使用 v3 组件。避开顶部三组常驻信息。
- 场景入口：以各自对象的锚点布置，悬赏名牌宽度随状态文案自适应；建筑名 27，状态/说明 17。名牌与锚点由细线相连。点击区包含名牌至对象锚点的区域，不要求精确点中文字。
- 场景占位说明位于底部中央，属于本原型审阅标识，不作为正式产品组件。

## 状态与层级

- 名牌：普通墨蓝底/细框；悬停或键盘焦点加强边界、显示说明；展开中使用玉色底与实框。
- 悬赏名牌：可揭榜、已接取、可领奖、已领取。名牌状态和文书状态使用同一个原型状态源；已领取仍保留地点，不提供重复领取按钮。
- 出城按钮：普通、悬停、键盘焦点、按下；目的地始终独立显示。后续无通行条件时应由正式规则投影禁用原因，本轮未编造该规则。
- 通用入口：点击在外部审阅栏报告目标入口，主画面不伪装成已经打开完整系统页。
- 更多与文书互斥；Esc 关闭；点其他区域关闭更多。常驻信息在普通事务之上保持可见，但未来模态确认/剧情按其正式层级拦截交互，“常驻”不等于永远压在所有弹层之上。

## 后续 Unity 对应

复用 v3 字体/九宫格/图标制作合同；增加城镇上下文组件、头像摘要、通用入口组和场景名牌锚点。文字、资源条、图标、状态标签、按钮保持独立，不烘焙为整屏图片。城镇身份与操作使用单一上下文；场景对象提供 ID 与锚点，正式状态由现有系统投影。原型的示例角色数据、术法入口反馈和奖励状态不能代替运行时数据源。
