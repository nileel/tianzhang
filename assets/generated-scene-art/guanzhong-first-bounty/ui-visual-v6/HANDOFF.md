不建设窗口管理器、导航框架或完整全游戏页面；不迁移所有历史原型；不改 Unity Builder、Prefab、表现合同或战斗规则。需要正式运行时实现时另按最新任务范围处理。

最小复用合同：

- 布局结构/内容数据/皮肤三者分开，页面不得复制共享美术文件。
- 资源唯一出处，稳定语义槽位；替换包包括贴图/矢量、字体、颜色与状态配置。图片里不能烘焙文字。
- 普通/悬停/按下/焦点/选中/禁用/确认统一，禁用原因由数据决定。
- 九宫格建议、尺寸、内边距、缩放与长文本规则明确；尺寸变体共用资源。
- 专门界面例外逐项说明，即使布局专用也尽量复用基础控件与皮肤。
- Unity 仅写未来映射与所需表现数据，不宣称正式已接入。当前 CombatHudSnapshot 缺 CT、多单位顺序、状态、范围等完整投影，实施前须重查。
