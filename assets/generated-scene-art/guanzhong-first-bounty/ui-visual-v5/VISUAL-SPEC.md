# 战斗 UI v5 · 有限组件与视觉规范

适用于本版战斗表面及其与城镇 v4 的共同语言。设计结果待用户判断，不作为 Unity 已实施合同。实际源值以 `style.css`、继承的 v4/v3 CSS 及可操作原型为准。

## 视觉语言

底层用墨蓝漆面承载常驻操作，暖纸承载阅读与提交前确认；玉色用于交互，朱砂用于敌方与负面状态，哑铜只做面板首线与关键确认。两角 HUD 不因战斗改换位置。装饰限印章、折角徽记、细分隔线与线描图标，不叠法阵或满框金线。

| 用途 | 色值 / 表现 |
|---|---|
| 深底 / 漆面 | `#101e2a` / `#182c3a`，至 `#304b57` 的轻渐变 |
| 主字 / 次字 | `#f4ead4` / `#bbc7c5` |
| 纸面 / 深字 | `#ede1c7`、`#f3e8d0` / `#324d49` |
| 玉色交互 | `#a6d1c0`；实色确认底 `#3d6963` |
| 敌方与负面 | `#a84e3a`；徽记暗底 `#854d42` |
| 哑铜与当前强调 | `#b99c68`；关键选中线 `#e8deaa` |
| 正负资源 | 生命青黄渐变；灵力青蓝渐变；文字同时标明数值 |

字体：名称/标题使用系统楷体（KaiTi / STKaiti / SimSun 回退），数值/说明使用微软雅黑；数字等宽。不能把字体回退截图当作最终商用字体批准。1920 画布下，地图标题 48、目标名称 31、轴标题 29、确认标题 28、行内角色名 21、正文 18–19、次级 16–17、招式名18、快捷键13。1280按2/3整体缩放，最低支持范围待正式运行时可访问性评估。

## 完整交互状态

| 状态 | 视觉 | 可操作规则 |
|---|---|---|
| 普通 | 半透漆底、低对比单线、清楚图标名 | 点击进入选择/详情 |
| 悬停 | 底色提亮，细线转暖玉色 | title给出成本/作用或禁用原因 |
| 键盘焦点 | 3px玉色外框＋4px外偏移 | 1–6/M选动作，Esc取消；不绑定快捷确认以避免误施行 |
| 选中 | 玉色实底、暖色下线、aria-pressed | 只代表正在预览，未扣资源 |
| 当前行动 | 独立行与世界“行动”小签 | 与被查看目标分离 |
| 禁用 | 去饱和图标/文字、低对比边线、明确原因 | aria-disabled，鼠标/快捷键可获得原因，但不能执行；行动耗尽理由优先 |
| 待目标 / 无效目标 | 预览保留、施行禁用、解释原因 | 允许换目标；不隐藏玩家操作栏 |
| 可确认 | 纸面说明＋玉色实底施行按钮 | 取消不改变数值；确认后关闭预览、更新固定展示快照 |
| 等待 / 结束 | 独立文字与确认说明 | 等待有CT保留语义；结束说明放弃的余量；正式合法性需由玩法层投影 |

## 后续 Unity 对接所需数据

需要由现有玩法查询/表现合同提供：稳定单位ID、阵营、可见属性、状态及持续单位、当前行动者、接下来排序、CT当前值与阈值、行动/移动余量、物品数量、每个动作的可用性与原因、合法目标/范围、成本、可透露的预计结果、操作后顺序预览。HUD 只投影，不重算规则。

图标采用本地 SVG symbol 线稿；正式资源需保留可独立替换的图标、头像框、条形资源、按钮底/边/状态层、面板首线/底纹。常规面板适合九宫格；本轮未产出最终切片或 Unity prefab。图标、术法样例名称与数字均未建立新的内容设定。

本版已覆盖两角公共组件与战斗新增组件。城镇地图服务标记、城市标题/出城组件及悬赏纸面继续以 v4 的规范与原型为比较基线。
