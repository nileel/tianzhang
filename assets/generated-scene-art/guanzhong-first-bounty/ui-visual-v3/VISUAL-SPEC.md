# 关中 UI v3 · 有限视觉合同（待用户判断）

本合同只覆盖城镇默认/悬赏、战斗待行动/预览及其直接状态。值来源为同目录 `style.css`；[组件页](components.html) 用同一 CSS 展示。布局沿用 v2，不扩大菜单或战斗功能。

## 颜色、文字与材质

| Token | 值 | 用途 |
| --- | --- | --- |
| ink / ink-deep | #182c3a / #101e2a | 主面板、阴影层 |
| ink-raised | #294654 | 漆面受光、分层 |
| paper / paper-bright | #ede1c7 / #f8efd9 | 文书正文、暖色高光 |
| text / muted | #f4ead4 / #bbc7c5 | 深底主字、辅助字 |
| jade | #a6d1c0 | 选中、焦点、可行动提示 |
| cinnabar | #a84e3a | 悬赏印章、敌方身份 |
| copper | #b99c68 | 少量顶边、分隔点 |

漆面采用明暗渐变、1px 内线与软阴影；文书为暖纸渐变，正文区不加噪点；印章和题签是局部朱砂块。不要把禁用文字整体设透明度。颜色语义均辅以文字、边框或位置。

标题用系统楷体（KaiTi → STKaiti → SimSun）；中文正文和数值用微软雅黑（Microsoft YaHei UI → Microsoft YaHei）。本轮不打包字体；Unity 制作时核对发行许可或确定授权替代，不把系统字体安装视为发行授权。

1920 基准字号：城名112，文书48，页题37，预览31，动作26，正文20–22，资源/原因17–18，最小快捷键/辅助16。文书段落行高1.65，详情1.85。关键数字固定位置，生命/灵力同时具名。1280 为 2/3 缩放，正式实现以独立分辨率验收确定最小正文。

| --- | --- | --- |
| 常驻底栏 | 城镇左右62/底36/高155；战斗左右48/底34/高163 | 墨蓝底，信息与动作分区，细内缘 |
| 悬赏文书 | 右82/上142，510×738；padding40；暗题头+暖纸正文 | 可接/已接/可领/已领；只保留当前下一步 |
| 事务入口 | 右95/上241，宽420 | 印记+标题+说明+方向；领奖后退出待办 |
| 头像 | 城镇88×108，战斗91×122 | 拱顶轮廓；批准母版 CSS 裁切 |
| 行动顺序 | 顶35/居中；当前、接续、下次三段 | 当前浅玉底和实框；每个可点单位返回详情 |
| 动作按钮 | 128×119，间距12 | 普通细框；悬停提亮；选中菱点+玉底+内线；未装配虚线+原因 |
| 确认按钮 | 最小高63，水平padding25 | 玉石明暗面；hover提亮；按下位移1px；disabled灰蓝并保留原因 |
| 次级按钮/关闭 | 安静底或透明底；关闭44×44 | hover有浅底/边界；focus-visible 3px玉色外框 |
| 资源条 | 生命8px，灵力6px；数字和名称独立 | 生命草玉，灵力石青；填充保留暗轨道 |
| 预览条 | 居中/底219，宽968，最小高126 | 名称→预计值→取消→确认；超距禁用文案明确 |
| 单位/地形详情 | 右56/上220，宽342 | 墨蓝面板、分行数值、可关闭 |
| 战报/结果/提示 | 战报左侧按需；结果居中；提示顶163 | 提示不盖预览按钮，pointer-events:none |

普通、hover、selected、disabled、confirm/focus 不依赖同一色差：普通有细框；hover增强明暗；selected增加菱点与内线；disabled增加虚线或原因；确认使用实体按钮；键盘焦点使用外框。支持 reduced-motion，所有按钮均保留文字名称。

12个图标：悬赏册、坊市、客栈、情报、旧水驿、移动、徒手、术法符、神通菱形、防御、待机、灵石。32×32 viewBox、round cap/join、1.5笔画；动作展示38px时1.35笔画。图标不可代替动作名称，不添加人物未拥有的武器或法术。

## 后续 Unity 制作拆分

1. 深色面板底与内缘作为同一套九宫格基底；文书暗题头与暖纸正文独立九宫格，印章位置可调整。不要导出整屏贴图。
2. 按钮底、选中菱点、图标、头像框各自为 Sprite；正常/悬停/选中可通过同一底片与材质参数组合。资源条用填充或裁切，值来自快照。
3. 标题、说明、数字、禁用原因、奖励数量与印章汉字保留独立文本组件。弹层、上下栏跟随统一 UI 画布与安全区，不烘焙1920坐标进背景。
4. 用已批准母版确定性裁切头像；不得重新生成人物来配框。正式场景明暗完成后，再检查深浅背景上的边缘对比。
5. 当前行动、CT、命令可用性、预览结果、范围、路线、地形详情均由规则侧事实投影。原型固定数值不可迁入正式结算。

## 范围与接受

本轮交付完整的有限视觉表达与两表面可操作样板，视觉是否达到目标由用户判断。城镇正式背景、正式切图/图集、Unity 字体与接入、真实数据投影、Tripo/高差通行、角色/音画反馈和全流程验收分别属于后续任务。
