07 / Unity 制作边界

分层制作，消费真实投影

可直接复用的设计

两表面布局、文书层级、六动作、七种颜色职责、头像裁切、按钮五态。CSS变量是本版视觉值来源；12个线描 SVG 图标保存在原型内。

资源制作

墨蓝面板与暖纸文书分别做九宫格；按钮底与边缘独立切片；图标独立Sprite；文字与条形填充由Unity绘制。楷体/微软雅黑需另核发行许可或选授权替代字体。

运行时另项接入

行动轴/CT、范围、预计结果与禁用原因仍待规则查询投影。不得在UI内复制规则。城景、Tripo地形、角色表现和音画反馈分别按对应任务推进。
