# 苻渊单方向分层骨骼试验

日期：2026-09-08。用户明确授权的一次独立可行性试验；不领取队列任务。

## 范围与来源

- 唯一角色：苻渊。已实际查看批准 dialogue-transparent 人物、profile-wide 辅助图与六向样张。
- 固定方向 1，根节点语义 Y=150°，规则邻格 (1,-1)。采用六向样张的前侧朝画面左方观察方向。
- 项目 Unity 6000.3.18f1，无 2D Animation。工程镜头静态事实 pitch=38°、yaw=0°、orthographicSize=6.2；运行时尺寸待实际测量。
- 旧 .spine 是栅格时间线，不能复用为骨骼资产。

## 最小设计

制作约 12 个可独立编辑的 RGBA 部件：完整无臂躯干（包括会露出的腋下和侧身）、后袍摆、前袍片、头、后发、近侧宽袖、远侧宽袖、两只手及腕、两只脚、近袖内衬。所有关节重叠，袖腹保留足够下垂体积。

内置 ImageGen 制作一套可拆分部件母图；只做确定性分槽与组装，不用逐帧生成替代骨骼。先检查拼装和运动露出区域，再绑定。Unity 官方 SpriteSkin 保存骨骼、网格和权重，AnimationClip 保存关键帧。袖根、肘、腕与袖腹由不同骨骼影响，袖腹有轻微时延。

待机为呼吸与发/袖摆跟随；施法为蓄势、抬臂、前挥、停留和收势。固定双脚；无特效、布料模拟、自研动画框架或付费外部工具。

## 验证与停止

Unity 真实连续播放待机→施法→待机；记录近景、38°战棋镜头和 1920×1080 下实际角色像素尺寸。记录有效 SpriteSkin、变形顶点、双脚漂移、关键关节和回环误差，同时检查透明裂口、拉尖、纹理塌陷、遮挡。

重复缺陷先判别素材/分层/权重/曲线/排序根因，只做最小修正。无法解释或需要新增多套机制、付费工具、多方向时保留现场并停止扩展。单方向结论不推广到六方向与批量生产。
