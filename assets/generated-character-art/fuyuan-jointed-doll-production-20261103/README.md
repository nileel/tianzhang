## 生成单位与视图

- `body/`：完整着衣主体，含上下臂、手、大小腿、脚；短内袍，T 姿，不带宽袖或长袍挂片。
- `sleeve/`：单片袖挂件，生成后镜像装配两片。
- `front-panel/`：单片带象牙白内边的前袍挂片，装配两片。
- `rear-panel/`：单片无白色纵条的后侧袍挂片，装配两片。

每个目录的 `front.png/back.png/left.png/right.png` 是同一物件的四视图。人体左视图鼻尖朝画面左，右视图朝画面右；挂片的正面为外表面、背面为内衬。Tripo 上传顺序为正面主槽、左侧、右侧、背面，逐槽核对后生成。未将部件陈列图作为多视图输入。

各目录 `prompts.md` 保留精确提示词、比例与图像限制；`tripo-input-settings.png` 保留实际输入槽与设置；`tripo-result.png` 是生成结果网页画面。图中尺寸不是实测几何尺寸，装配尺寸按实际 1.8 米主体适配。
