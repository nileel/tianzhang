# 氛围题字版立绘提示词

用途：保存批准分层资产的静态合成预览，可用于审批、宣传或明确的静态回退。PC 人物介绍运行时以 `../profile-wide/prompts.md` 的背景、人物、FX、姓名、道号和印章独立层为事实源，不从本目录成图反向抠图。

## 通用检查

- 题字必须只包含角色名与道号，不新增其他可读文字。
- 题字位于左侧，角色居中或略偏右。
- 印章必须是小型朱砂篆刻印面，不是红圈、红椭圆、现代徽章或水印。
- 生成后必须检查中文准确性，尤其是偏复杂字：苻、渊、澜、微。
