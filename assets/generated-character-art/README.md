# 角色立绘生成工作流

本目录保存从 `assets/source/参考图片/` 提炼出的角色立绘风格、提示词与当前生成结果。

## 目录

- `no-title/`：无字原版立绘与提示词。
- `titled/`：image2 氛围题字版立绘与提示词。
- `dialogue-transparent/`：无题字、无背景的透明 PNG 对话立绘与提示词。

## 生成流程

1. 先读取角色事实源：`docs/剧情/世界背景故事.txt` 与 `docs/剧情/重要NPC/<角色名>.txt`。
2. 若生成新角色，按角色所属势力、道号、外貌、法器、道途气质提取视觉关键词。
3. 参考 `no-title/prompts.md` 生成无字原版。无字版禁止题字、印章、UI、水印和额外可读文字。
4. 需要对话立绘时，参考 `dialogue-transparent/prompts.md` 生成纯角色绿幕源图，再用本地抠图脚本转成带 alpha 的透明 PNG。透明版禁止题字、印章、淡稿、背景笔刷、地面和投影。
5. 需要题字时，参考 `titled/prompts.md` 生成氛围题字版。题字版可让 image2 直接生成书法题字和朱砂篆刻印章，但必须人工放大检查中文准确性。
6. 若 image2 题字写错或不可读，改走稳定版：用无字原版立绘 + 真实字体本地叠字；字体需先确认授权和字形质量。
7. 生成后把最终图复制进对应目录，不覆盖旧结果；废稿图不保留。

## 验收清单

- 角色外貌、服饰、法器与 NPC 文档一致。
- 无字版没有任何题字、印章、UI、水印或现代元素。
- 透明版是 RGBA PNG，四角透明，没有背景、地面、投影或可见绿幕边。
- 题字版只包含角色名与道号，不新增无关文字。
- 朱砂印章像传统篆刻印面，不是红圈、红椭圆或现代徽章。
- 文件名包含角色拼音、道号拼音和版本用途。
