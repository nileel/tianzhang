# 角色立绘生成工作流

本目录保存从 `assets/source/参考图片/` 提炼出的角色立绘风格、提示词与当前生成结果。

## 目录

- `no-title/`：无字原版立绘与提示词。
- `titled/`：静态合成预览与宣传图；不作为运行时分层事实源。
- `dialogue-transparent/`：无题字、无背景的透明 PNG 对话立绘与提示词。
- `profile-wide/`：PC 16:9 人物介绍分层资产、统一风格提示词与静态合成预览。
- `model-preview/`：依据批准立绘生成的运行时 3D 模型效果演示；只用于美术方向评审，不作为 Unity 正式模型资源。
- `fuyuan-static-chess-battle-pose/`：苻渊静态 3D 棋子路线的同定姿前／左／右／后输入与无文字联系表；只供下一阶段在获单独 credits 授权后使用，不是 Unity 资源或旧绑定路线输入。

## 生成流程

1. 先读取角色事实源：`docs/剧情/世界背景故事.txt` 与 `docs/剧情/重要NPC/<角色名>.txt`。
2. 若生成新角色，按角色所属势力、道号、外貌、法器、道途气质提取视觉关键词。
3. 参考 `no-title/prompts.md` 生成无字原版。无字版禁止题字、印章、UI、水印和额外可读文字。
4. 需要人物介绍或角色资料界面时，以 `profile-wide/prompts.md` 为当前统一风格入口：分别生产无人物背景、透明全身人物、可选法相 FX、姓名、道号和印章，最后合成 16:9 静态预览。
5. 透明全身人物是人物介绍、对话半身和头像裁切默认共用的母版。参考 `dialogue-transparent/prompts.md` 生成纯绿幕源图，再用本地抠图脚本转成 RGBA PNG；禁止题字、印章、背景笔刷、地面和投影。
6. 姓名与道号必须同时保留正确的繁体文本数据。书法美术字优先从已验字样张逐像素提取，或使用已确认授权且字形正确的字体；不得依赖 AI 重写复杂汉字。印章单独导出透明 PNG。
7. `titled/` 只保存批准层的静态合成效果，用于审批、宣传或明确的静态回退；运行时不得从合成图反向抠取人物或文字。
8. 生成后把最终图复制进对应目录。用户明确要求替换时可覆盖稳定文件名，否则使用版本号；废稿与绿幕中间图不保留。

## 验收清单

- 角色外貌、服饰、法器与 NPC 文档一致。
- 无字版没有任何题字、印章、UI、水印或现代元素。
- 透明版是 RGBA PNG，四角透明，没有背景、地面、投影或可见绿幕边。
- PC 人物介绍背景与 FX 使用严格 16:9；透明人物母版保持竖向全身构图，不强制横向拉伸。
- 人物介绍与对话默认引用同一透明人物母版；只有特殊表情、伤势、换装或裁切清晰度不足时才允许对话覆盖图。
- 题字版只包含角色名与道号，不新增无关文字。
- 朱砂印章像传统篆刻印面，不是红圈、红椭圆或现代徽章。
- 脸和手保持精致二次元国风绘制感，不出现毛孔、摄影皮肤、油腻高光或拟真 3D 体积。
- 文件名包含角色拼音、道号拼音和版本用途。
