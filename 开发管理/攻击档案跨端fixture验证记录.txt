### 恢复半成品的根因与最小修复

1. art 三行尾随空字段使字段数 35/35/36 vs 34（既有 `ParseCSV`／`ReadFixtureRows` 按列数严格失败关闭）→ 行重写为恰 34 字段。
2. 扇形行尾列错位（恢复行继承原稿中间多一逗号导致的位移：`areaAllowedStates` 读到 `enemy`）→ 按测试断言值重建尾列；阵营按契约允许的子集以单值 `ally` 承载——BattleSim 按原 CSV 行逐字 `Split(',')` 读取，双值阵营字段（`ally,enemy`）无法在 34 列对齐下解析，且契约正例矩阵未要求多值阵营。
3. Unity `AttackProfileDataTests` 以 `lines[1]` 当表头，而 fixture 有 3 行注释（表头在第 4 行）→ 改为取首个非注释行；变异用例的合表同时剔除重复表头行。
4. Unity 变异用例朝向索引 25→26（`areaFacing` 列）、扇形扇角越界值 `"east"`→`"2"`（并补合法朝向使检查到达形状契约）。
5. BattleSim `ValidateAttackProfileTable` 的效果／资源／冷却／距离检查只对 `area` 行生效，单目标行变异负例全部误通过 → 移到每行（与 Unity `ParseAttackProfileRow` 顺序一致）。
6. BattleSim 负例 `areaAllowedFactions="ally,enemy"` 实际合法（字典序子集）→ 改未知枚举 `neutral`。
7. BattleSim 负例表以数据行充当 `lines[0]` 表头（行字典空值键冲突）→ 表头行前置；重复 ID 负例以显式追加同 ID 行表达（变异 ID 后按 ID 匹配会替换掉原行）。
8. `AssertEqual(null, …)` 泛型推断编译错误 → 显式 `(GameAreaTargetingConfig)null`。
9. Unity 测试缺 `using System;` 与 `UnityEngine.Object` 限定（`StringComparer`／`Object` 二义性）→ 补齐。

### 负例与失败关闭

- Unity `TryBuildAttackProfileProjection`（最窄投影入口，复用既有严格解析与 `CopyTo`，失败销毁全部临时对象、不写 asset）：重复 ID、短行、未知展示键、未知境界／元素需求、负资源、倒置区间、非数值倍率、错误种类专属字段（basic 混入 contentScope）、三种非法形状（圆形带朝向、直线带半径、扇形扇角越界）、未知形状／朝向、单目标混入范围列、未知阻断。
- BattleSim `ValidateAttackProfileTable` 18 项：重复 ID、短行、未知境界／元素需求、未知元素、负资源、非法区间、三种非法形状、未知形状／朝向／阻断／阵营／状态、单目标混入范围列、`battlesim_cooldown_unit_unresolved`、`unsupported_effect_semantics`。
- asset ID 冲突：`TryValidateAttackProfileAssetIdProjection` 对非规范路径同 ID asset 返回 `attack_profile_asset_id_duplicate`（测试在既有 Fixtures 旁创建并清理临时 asset，不写生产目录）。

### 稳定失败原因（契约锁定）

- `battlesim_cooldown_unit_unresolved`：CSV 的 `cooldownTicks` 是 Unity 刻；BattleSim 回合与刻无权威换算前，非零值拒绝，不读旧回合默认值。
- `unsupported_effect_semantics`：heal／buff／debuff／movement 在既有 BattleSim 载体无字段，拒绝而非丢列。
- 圆形无朝向：line／fan 强制合法非空六角方向；circle 空朝向不补任何默认方向。
