# 战场角色 2D 与静态 3D 可玩比较验证记录

## 技术复核结论

2026-08-25，Codex 在 `AdventureScene/VisualBaselineBoard` 运行同一比较入口。入口的 `BattleVisualComparisonController` 只编排既有隔离表现控制器：2D 路线为 `BattleAnimationSpriteProbeGroup`，静态 3D 路线为六个 `FacingProbe_*`。切换时两条路线互斥，旧 `TacticalSpriteProbeGroup` 始终关闭。

两条路线共用场景、相机、光照、地块、尺度、接地、占格和六个 `StaticChessPresentationEvent` 语义。EditMode 复核静态 3D 材质 `_BaseMap` 仍引用已修正的实际 BaseColor；2D 保持既有战斗 atlas。新输入不触碰正式单位、战斗规则、方向、AI、结算或存档所有者。

## 实际运行与自动验证

- Unity PlayMode：`ComparisonButtonsSwitchSymmetricRoutesAndReplayEverySharedEvent` 在真实 `AdventureScene` 中依次调用两条路线、六方向、六事件和复位；路线互斥、当前事件、根节点复位与全部探针待机均通过。新增 `TwoDimensionalMotionModeDefaultsToPureFramesAndSwitchesWithoutRootResidue` 数值验证默认纯帧模式的根节点位置／旋转误差小于 `0.0001`，整体动效在同一采样点的根节点位移大于 `0.001`，动作中切换模式精确复位，并验证 2D 模式跨路线切换保留。完整 PlayMode：14/14 通过。
- Unity EditMode：场景持久化入口、两枚模式按钮的可见文字与唯一持久事件、面板边界、默认静态 3D 路线及 BaseColor 引用均通过。当前完整 EditMode XML：428/428 通过。项目包装脚本在测试结束后的工作区恢复阶段遇到 Windows 映射文件占用并返回非零，测试产生的 145 个自动重序列化噪声已按测试前清单全部清除；2026-08-27 本轮以 `-ValidateResultOnly` 对同一 XML 再次验证通过。

## 非结论与剩余条件

上述记录只证明共同技术条件与可运行性，不是视觉评分，也不宣布 2D 或静态 3D 胜出。用户决定卡仍等待 `D-CHAR-BATTLE-VISUAL-COST-EVIDENCE-01` 提供同口径成本证据，之后必须由用户实机选择 A／B／C。
