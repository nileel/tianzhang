# TQ-018 TacticalGridModel 与渲染接口兼容层归档

状态：已完成 / 已验证（2026-06-30 Codex / gpt-5.5 自产；不进入复审队列）

## 任务目标

在不改变 CTB、伤害、寻路、冷却、技能范围和探索战斗流程结果的前提下，建立战棋规则层与渲染层的第一层兼容边界，为后续 2D Tilemap 与 2.5D 表现共用规则数据做准备。

## 本轮改动

- `src/Assets/Scripts/Grid/TacticalGridModel.cs`
  - 新增 `TacticalGridModel`、`TacticalTileData`、`TacticalTerrainType`。
  - 支持 `HexCoord` 格子、地形类型、高度、地面/飞行/视线/落点阻挡、单位占用。
  - 提供 `FromHexGrid` / `ToHexGrid` 兼容入口，保持现有 `HexGrid` 规则可迁移。
- `src/Assets/Scripts/Grid/ITacticalRenderer.cs`
  - 新增渲染接口，统一网格渲染、屏幕坐标换算、高亮、清理覆盖层和单位标记放置入口。
- `src/Assets/Scripts/Grid/TilemapTacticalRenderer.cs`
  - 新增 Tilemap 适配器，复用现有 `HexTilemapManager` 与 2D Tilemap，不引入 2.5D 实现。
- `src/Assets/Scripts/Tilemap/HexTilemapManager.cs`
  - 暴露 `TacticalGrid` 快照和 `TilemapTacticalRenderer`。
  - `GenerateHexGrid` 改为先从当前 `HexGrid` 重建 `TacticalGridModel`，再交给 Tilemap renderer 绘制。
  - 旧的 `ScreenToHex`、`HexToWorld`、高亮、单位标记和 `HexGrid` API 保持可用。
- `src/Assets/Tests/EditMode/TacticalGridModelTests.cs`
  - 新增 Unity/NUnit EditMode 规则层测试，覆盖 `HexGrid` 到 `TacticalGridModel` 的阻挡/占用/高度默认值映射，以及反向导出到 `HexGrid`。
- `src/Assets/Tests/EditMode/TianZhang.EditModeTests.asmdef`
  - 新增 Unity Test Framework 测试程序集。首次将测试放在普通脚本目录时，Unity Test Runner 显示 `No tests to show`；已迁移到标准 EditMode 测试程序集。
- `src/Assets/Scripts/TianZhang.Runtime.asmdef`
  - 新增运行时代码显式程序集，解决 EditMode 测试 asmdef 不能可靠引用预定义 `Assembly-CSharp` 导致的 `TianZhang.Core` 不可见问题。
  - 显式引用 `Unity.InputSystem`、`Unity.InputSystem.ForUI`、`UnityEngine.UI`，修复 runtime asmdef 下 `UnityEngine.InputSystem` / UGUI 命名空间不可见问题。
- `src/Assets/Scripts/Editor/TianZhang.Editor.asmdef`
  - 新增 Editor 工具程序集并引用 runtime 与对应 Unity 包程序集，避免 `Assets/Scripts/Editor` 下工具脚本混入运行时程序集。
- `src/Assembly-CSharp.csproj`
  - 加入新增 Grid 运行时脚本；测试脚本移出业务程序集，由 Unity Test Runner 的 EditMode asmdef 管理。
