# U-URP-MIGRATE-01 · URP 安装、绑定与完整迁移

## 来源与当前边界

- 按 `开发管理/任务归档/U-URP-PREFLIGHT-01.txt` 的冻结结果一次完成包安装、Pipeline Asset／Quality 绑定、保留资产迁移和正式场景回归；不重新扫描已删除原型或旧视觉。
- 项目为 Unity `6000.3.18f1`，本机该 Editor 内置 `com.unity.render-pipelines.universal` 为 `17.3.0`（依赖 `com.unity.render-pipelines.core`、`com.unity.shadergraph` 均为 `17.3.0`，以及 `com.unity.render-pipelines.universal-config` `17.0.3`）。只安装此精确版本，不嵌入包源。
- 正式表现是 2D：四个正式场景各有 1 个正交 Main Camera 和 1 个 ScreenSpaceOverlay Canvas；Adventure 另有 1 个 SpriteRenderer，正式场景没有 Tilemap 或 TMP 组件。唯一正式运行时 Sprite Prefab 为 `src/Assets/Resources/UnitMarker.prefab`，Adventure Builder 只把四个 `Adventure*.asset` TileBase 与对应 Sprite 作为只读存在性闸门。

## 必查范围

- `开发管理/任务归档/U-URP-PREFLIGHT-01.txt` 的版本、资产、回滚和验证冻结；`src/ProjectSettings/ProjectVersion.txt`、`src/Packages/manifest.json`、`src/Packages/packages-lock.json`、`src/ProjectSettings/GraphicsSettings.asset`、`src/ProjectSettings/QualitySettings.asset` 与 `src/ProjectSettings/EditorBuildSettings.asset`。
- `src/Assets/Scenes/StartMenuScene.unity`、`WorldScene.unity`、`SettlementScene.unity`、`AdventureScene.unity`；`src/Assets/Scripts/Editor/SceneBuildSupport.cs`、`AdventureSceneBuilder.cs`、`SceneArchitectureValidator.cs`；`src/Assets/Resources/UnitMarker.prefab` 与 `src/Assets/Resources/Tiles/AdventureGround.asset`、`AdventureMoveHighlight.asset`、`AdventureAttackHighlight.asset`、`AdventureSelected.asset`。
- `src/Assets/TextMesh Pro/Resources/Fonts & Materials/LiberationSans SDF - Drop Shadow.mat`、`LiberationSans SDF - Outline.mat` 和 `src/Assets/TextMesh Pro/Shaders/`：它们是仓库内仅有的材质／Shader 文件，但正式场景没有 TMP 组件或其序列化引用，保持不转换；正式 UI 继续由 `SceneBuildSupport.CreateText` 的 UGUI `Text` 与 `LegacyRuntime.ttf` 生成。
- `src/Assets/Tests/EditMode/SceneArchitectureEditorTests.cs`、`GuanzhongFormalEndToEndTests.cs`、`src/Assets/Tests/PlayMode/GuanzhongBasicAttackPlayModeTests.cs`、`tools/run-unity-editmode-tests.ps1`、`tools/run-unity-playmode-tests.ps1`。
- Unity 6.3 官方 URP requirements、Built-In-to-URP upgrade、Render Pipeline Converter 与 active render pipeline 文档；官方说明每个 Unity patch 的 installer 含当前包版本，转换不可逆且转换前必须备份。

## 实施范围

- 在 `manifest.json` 安装 `com.unity.render-pipelines.universal` `17.3.0`，让 Unity 更新锁文件；创建唯一 `TianZhangUniversalRenderPipeline.asset` 与同目录 `TianZhangUniversalRenderPipeline_Renderer.asset`，使用 **2D Renderer**，并把它绑定为 Graphics 默认和所有 Quality level 的唯一 Render Pipeline Asset。
- 接受 Unity 17.3 自动生成并登记在 GraphicsSettings 的 `Assets/UniversalRenderPipelineGlobalSettings.asset` 与 `Assets/DefaultVolumeProfile.asset`；这两个路径由 URP 17.3 `Ensure` 的默认路径固定，不能另造平行全局设置或 Volume Profile。
- 只审计正式场景和 `UnitMarker.prefab` 的 Built-in 默认 Sprite／UI material reference；先查看 Converter 初始化的精确清单，再只转换清单中的这些已冻结路径。没有项目自定义 Material／Shader，也没有正式 TMP 序列化引用，故不得运行会改写 `Assets/TextMesh Pro/`、旧 `GroundTile`／`MoveHighlight`／`AttackHighlight`／`Selected` 或其他非正式资产的转换器。
- 保持 4 个 Build Settings 场景的顺序、正交相机、ScreenSpaceOverlay UI、Adventure ground、UnitMarker、四项 Adventure TileBase、移动／攻击／选中高亮、正式场景 owner 与所有业务行为不变。

## 禁止项

- 不保留两套渲染管线，不复制场景，不增加静默材质回退，不迁移已删除的 Built-in 临时视觉，不新增角色、外观或正式美术。

- 运行 `pwsh -NoProfile -ExecutionPolicy Bypass -File tools/run-unity-editmode-tests.ps1` 与 `pwsh -NoProfile -ExecutionPolicy Bypass -File tools/run-unity-playmode-tests.ps1`，并以 `SceneArchitectureValidator.ValidateForBatchMode` 复核四个正式场景与 Build Settings 顺序。

## 完成条件

- 项目只使用 URP `17.3.0` 的唯一 2D Pipeline，Global Settings／Default Volume Profile、Graphics 和 Quality 指向完整，且 Converter 对冻结资产无警告或失败。
- 四个正式场景、保留 Sprite／TileBase／高亮、UGUI 文本与正式 Adventure→Combat→返回流程均通过自动与人工回归；不存在 Built-in 与 URP 双轨、未登记材质、未登记 shader、未登记资产改写或半迁移状态。
