## 二级属性来源

当前二级属性来源仍符合 A4/A5 校准口径：裸先天气运、神识、资质不直接给战斗二级属性。`ResolveSecondary` 从功法权重中取 `>0.15` 的前两项，每章给 3% 或 5%；另有功法倾向补偿：闪避率 = 气运权重 x 30，暴击率 = 神识权重 x 30，暴击伤害 = 资质权重 x 80。

| Build | 功法 | 权重来源 | 篇章二级 | 倾向补偿 |
|------|------|----------|----------|----------|
| 肉盾型 | 混元同尘典 | GongFaStars | 格挡率 + 魂盾率 | 闪避 6.0，暴击 4.2，暴伤 13.6 |
| 玉清·剑修 / 玉清·雷修 | 疾雷破山经 | GongFaStars | 格挡率 + 命中率 | 闪避 1.8，暴击 9.0，暴伤 9.6 |
| 太一·符修 | 云篆度人经 | GongFaStars | 命中率 + 暴击伤害 | 闪避 5.4，暴击 8.7，暴伤 19.2 |
| 太虚·玄感 | 南华玄感录 | 0.2 回退 | 格挡率 + 魂盾率 | 闪避 6.0，暴击 6.0，暴伤 16.0 |
| 混元·正法 | 绳墨正法录 | 0.2 回退 | 格挡率 + 魂盾率 | 闪避 6.0，暴击 6.0，暴伤 16.0 |
| 玉清·雷劫 / 玉清·苦行 / 玉清·雷体 | 对应功法 | 0.2 回退 | 格挡率 + 魂盾率 | 闪避 6.0，暴击 6.0，暴伤 16.0 |

二级属性不是旧口径污染来源，但会放大差异：缺 `GongFaStars` 的后接入 Build 统一落到 0.2 回退，得到同一组通用二级属性，无法体现各自机制定位。

## 根因判断

1. 样本筛选：解释金丹矩阵 NA、紫府矩阵 NA，以及修炼型 Build 的金丹/紫府样本稀疏；不解释筑基五段混合矩阵的全面 0/100。
2. 功法成长表：是主因之一。`云篆度人经` 在 `GongFaTables` 中缺 `练气` 成长，当前 `SubGrowthSum` 遇到已存在功法表但缺前序境界时直接 `break`，导致太一·符修在筑基阶段吃不到练气和筑基小境界成长，是其筑基/紫府同境 0% 的直接原因。
3. 功法星级表与回退：`九霄雷劫录`、`苦行剑典`、`雷池淬体功`、`南华玄感录`、`绳墨正法录` 等 Build 缺 `GongFaStars`，权重统一回退到 0.2；同时缺专属 `GongFaTables` 时使用通用成长近似，导致机制 Build 的属性底盘同质化。
4. 功法机制与 AI 行为：也是主因之一。当前 AI 固定按“神通 > 术法 > 普攻”，不会比较 HP 成本、目标类型、封丹/削位机会或符胆层数收益。`yuqing_kuxing` 在筑基无恢复时仍持续 HP 换伤，太一符修在筑基只有低倍率符法循环，都会扩大低胜率。
5. 二级属性分配：不是主因，但会放大极化。强势物理/防御 Build 同时获得较完整成长和有效防御/命中二级属性；后接入机制 Build 多数只拿到回退二级属性，机制收益不足以覆盖基础成长短板。

## 后续建议

1. 先拆 N-BAL-02A：补齐 `云篆度人经` 练气成长或修改 `SubGrowthSum` 的缺境界回退策略，并加 self-test 锁定“缺前序境界不会归零整条成长链”。
2. 再拆 N-BAL-02B：为 `九霄雷劫录`、`苦行剑典`、`雷池淬体功`、`南华玄感录`、`绳墨正法录` 补齐 `GongFaStars` 与必要成长表，避免 0.2 回退成为长期平衡口径。
3. 单独拆 N-AI-01A：给 HP 换伤、符胆、玄感、阵法类 Build 增加最小策略条件；不要在未修成长表前用全局伤害倍率补偿。
4. 调参顺序应为：成长表完整性 -> 权重/二级属性定位 -> AI 条件 -> 最后才调整 Combat 倍率。
