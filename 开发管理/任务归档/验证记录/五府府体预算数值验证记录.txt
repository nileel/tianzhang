# 五府府体预算数值验证记录

状态：✅ 已验证（N-FPD-MANSION-01，2026-07-25）

## 范围与口径

- 本记录只验证已经确认的命、魂、识、悟、运五项府体效果的参数区间与一至五府预算边界；机制的触发、条件、目标、效果类型与参数名保持 `docs/superpowers/specs/2026-07-21-five-mansion-body-effects-design.md` 原定义。
- 当前 BattleSim 的紫府神通／府位输入仍是未接入占位，不把本审计结果伪装为既有伤害、属性、成丹、位格或丹相倍率。
- 共同审计口径为每座完整紫府 1.00 府体预算分、五府总上限 5.00。预算分只比较已确认的异质效果，不进入运行时资源、属性、槽位或倍率。

## 锁定输入

| 紫府 | 参数区间（默认） | 目标指标／上限 |
|---|---|---|
| 命府 | 启动阈值为最大生命类资源 30%～40%（35%）；单次恢复为 8%～12%（10%） | 单次恢复不高于 12%，阈值不高于 40%。 |
| 魂府 | 可拦截既有状态标签 2～3 个；明确排除标签至少 1 个 | 每次只阻止一项待写入状态；不改写伤害、资源或位格。 |
| 识府 | 侦知范围修正 0～+1 格（+1）；揭示字段 1～2 个 | 只作用于当前合法查询；不得全局揭示。 |
| 悟府 | 主动修炼标签 1 个；进度修正 8%～12%（10%） | 单次修正不高于 12%；不改被动灵力、周期、资源或成功规则。 |
| 运府 | 线索字段 1～2 个；范围为当前已合法生成候选集 | 不生成候选、不替换掉落、不改概率。 |

审计的均衡 Build 为五项先天属性均为 8；五类极端 Build 分别使根骨／魂魄／神识／资质／气运之一为 15、其余为 3。二者均须先通过 `BuildInputRules.Validate`。软亲和回归使用相同五府 Build 的 0.80 与 1.20 筑府成本系数；该系数不进入建成后的预算计算。

## 结论与残留风险

- 命、魂、识、悟、运各自有一个受统一 1.00 预算分约束的独立收益；第四、第五府没有被金丹三实位折算或排除。
- 预算不改变五府平等，也不按府数生成数量性收益；软亲和只影响筑府过程，不影响建成后的最终强度。
- 仍未覆盖的数据 schema、标签词表、镇府神通、丹枢主／辅承载、资源／冷却账本、伤害结算和槽位预算，分别留给 D-FPD-SCHEMA-01、N-FPD-DANXIANG-01 与 N-SLOT-01；本任务不提前实施或锁定它们。
