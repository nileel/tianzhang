# D-ELEMENT-01 element 字段导入器 schema 断言归档

完成时间：2026-07-09
执行方：Codex / gpt-5.5
来源：`开发管理/任务列表/数据链路任务.txt`

## 目标

为术法/神通独立 `element` 字段补导入器 schema 断言，防止 `elementReq` 学习门槛列与技能五行属性列因列序变化被错读。

## 修改范围

- `src/Assets/Scripts/Editor/DataConfigImporter.cs`
  - 新增 `GetRequiredColumnValue`，按表头读取必填列，缺表头、缺单元格或空值时抛出 `InvalidDataException`。
  - 新增 `RequireColumns` 与 `FindColumnIndex`，统一表头定位逻辑。
  - `ImportSpells` 与 `ImportSkills` 导入前断言 `element` 表头存在。
  - `ImportSpells` 与 `ImportSkills` 读取技能五行属性时改为按 `element` 表头读取，不再使用硬编码列号。
- `src/Assets/Tests/EditMode/SceneArchitectureEditorTests.cs`
  - 新增 `ElementLookupRequiresIndependentElementColumnAndUsesHeaderOrder`，覆盖：
    - `elementReq` 在 `element` 前时仍读取 `element`。
    - `element` 在 `elementReq` 前时仍读取 `element`。
    - 缺少 `element` 表头时抛出 `InvalidDataException`。
- `开发管理/任务列表/数据链路任务.txt`
  - 标记 D-ELEMENT-01 已完成。
- `开发管理/当前任务队列.txt`、`开发管理/设计-当前状态.txt`
  - 记录本轮完成事实。
