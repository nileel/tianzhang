### 逐状态实施与验收

| 状态 | 必须行为与证据 |
| --- | --- |
| Loading/初始化失败 | 入口不可用、保留原始原因，不启动返回或结算 |
| Exploration | 常驻返回沿用探索返回语义，消费既有返回目标一次 |
| 我方待命、Ongoing、无演出 | 可打开一个确认框；框内等待不会推进规则、命令或回合，背后输入被阻挡 |
| 攻击/术法/换术/换装/道具/移动预览 | 先撤销候选再确认；未确认资源不提交；继续战斗后不自动执行旧候选 |
| 我方移动/攻击演出 | 入口可见但禁用并提示行动演出中；不打断、不缓存，恢复可操作后须重新点击 |
| 敌方行动/演出（含连续行动） | 可见但禁用并提示等待我方行动；不缓存点击，下一我方行动不自动弹框 |
| 回合转换、我方输入未开放 | 禁用并提示回合切换中，不插入资源提交步骤 |
| 最后一击已成立胜负但演出未完 | 正式胜负优先，不能用撤离逃避；等待原结算 |
| 已结算/Returning | 禁用并显示正在返回；不重复清理或消费导航 |
| 继续战斗 | 角色、库存、悬赏、规则会话与导航不变；恢复合法输入，候选可清空 |
| 连点退出/确认、过期候选、迟到回调 | 至多一框、一次清理、一次导航；退出后无奖励写入，无状态倒退 |
