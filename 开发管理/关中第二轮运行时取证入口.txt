用途：U-GZ-R2-BOUNTY-01、D-GZ-R2-OBSTACLE-01、U-GZ-R2-SPAWN-01 的隔离取证与重新 ready 准备。2026-10-12 负责人授权补齐入口和直接测试范围；本次不实施按钮修复、障碍资源替换或出生点变更。

在任务自己的 worktree 根运行（PowerShell 7）：

pwsh -NoProfile -ExecutionPolicy Bypass -File tools/run-unity-playmode-tests.ps1 -ProjectPath (Join-Path (Get-Location) 'src') -ResultXmlPath (Join-Path (Get-Location) 'src/Logs/gz-r2-entry.xml') -TestFilter TianZhang.Tests.PlayMode.GuanzhongRuntimeEvidencePlayModeTests -EnableGraphics

- 本机入口使用 Unity 6000.3.18f1。新 worktree 不需要预存 Library：Unity 首次启动会导入并编译，不复制主工作区的 Library/csproj、不接管主工作区编辑器。
- 必须使用 EnableGraphics。默认无图形模式仍用于原有非视觉测试，不用其截图作视觉证据。
- TestFilter 是 Unity 原生过滤器。只取悬赏时用完整方法名 BountyPointerPipelineAtBothResolutions，只取战场时用 BattlefieldBoundsAndSpawnProjectionAtBothResolutions（前缀仍为 TianZhang.Tests.PlayMode.GuanzhongRuntimeEvidencePlayModeTests.）。
- 结果 XML 与同名 .log 位于调用者给定路径；截图、文本、原始 mesh JSON 位于 src/Logs/gz-r2-evidence/，均为忽略的取证产物。后续执行必须用自身修改后的 worktree 重跑，不能拿本次基线代替验收。
- 运行器沿用现有正式资产快照/恢复；测试只创建临时新档，不读取或覆盖用户存档。不得在测试运行期间同时编辑同一 worktree 的 Assets/ProjectSettings。
- 以 XML 非零测试数、failed=0、实际 Screen 尺寸断言、截图目检和测量正文共同判定入口成功。等待真实资源导入/着色器编译属于首次初始化，不是重试失败业务。取证异常不调整生产资源绕过。

## 取证覆盖与验收区别

悬赏：从正式 StartMenu→World→Settlement 新档链进入，使用 InputSystem 虚拟 Mouse/Keyboard 向正式输入模块送事件，通过 Raycaster/EventSystem 命中真实按钮；不调用 Button.onClick.Invoke、ExecuteEvents 或改按钮监听器。记录 normal/hover/press/release/leave 时的 sprite、interactable、实际 Canvas 比例和焦点，断言指针进入/按下/释放/点击及 Available→Accepted。此为真实运行时输入链的自动化验证，不宣称物理鼠标人工试玩。

悬赏执行卡仍需完成两按钮状态修复及四种悬赏状态、重复操作拒绝、键盘焦点可见性的业务验收；ObjectiveCompleted/Claimed 必须经正式战斗/领取链取得，不把能力基线的通过当成修复完成。允许在同一取证测试中补验收断言。

战场：从正式新档进入 Adventure 首战，读取 CombatMovementView 的正式 battlefieldCamera、EncounterCoordinator 的 session/spawned、36 个 GuanzhongHex 和四个 GuanzhongObstacle。输出世界/屏幕中心、父级、Renderer AABB、朝上三角面包络、原始运行时 Mesh 世界顶点/投影顶点/三角形，以及玩家到各格的只读路径报价。路径报价使用充足查询预算且不改角色 AP；它只能证明拓扑可达，不代替实际逐回合移动接敌。

世界 AABB 投影不等于可见像素轮廓；朝上面包络（normal·up≥0.8）可能包含岩壁台阶，不直接充当地块顶面足迹。原始 mesh JSON 与截图用于辨认实际顶面三角形、接地和遮挡，不凭包络猜 scale。VisualBaselineOccluder 单独标识，不混作目标障碍物。

两项测试均强制实际分辨率 1920×1080 与 1366×768；首轮着色器编译结束后才截图，屏幕尺寸或截图缺失直接失败。不得只调用 Screen.SetResolution 后宣称双分辨率已完成。
