# M-EXP-PREFLIGHT-01A · 风险索引、经验卡模板与只读匹配器基础

## 来源与当前边界

- 直接事实源是批准规格的“L1 风险索引”“匹配规则”“L2 经验卡”“开工前运行流程”“错误处理”“验证设计”。
- 本卡输出机器 schema、文本模板和单一只读入口；只用测试 fixture，不读取或晋级真实历史经验。
- schema 2、L0、小时入口、ready 迁移和门禁不属于本卡。

## 必查范围

- 批准规格上述六节全文及字段枚举、600 Unicode 字符和最多 3 条 `must_read` 合同。
- `开发管理/状态与建议维护规则.txt#状态与队列` 的 schema 1 当前合同。
- `tools/check-task-cards.ps1::Get-Card`，只用于复用任务卡分隔符和现有字段，不修改该脚本。
- `tools/test-check-task-cards.ps1::Get-Metadata/Get-CardText`，只用于 fixture 形状参考。

## 实施范围

- 建立顶层精确为 `schemaVersion/experiences/gates` 的空 `风险索引.json`，不写真实经验。
- 建立批准规格固定章节的经验卡模板，`## 开工前` 明示 120～200 字符边界。
- 建立 `tools/get-experience-risk-preflight.ps1`：接收 TaskId 或 TaskCardPath，原生 JSON 解析，路径归一化、字面量文本匹配、状态／域／阶段过滤、显式引用、去重、限量、digest 绑定、精确正文提取和稳定 JSON 错误；只读且不执行 gate 命令。
- 测试全部使用临时 fixture，覆盖规格列出的 10 类正反例及工作树只读证明。
- Codex 复审通过后归档本卡，并只移除十张种子卡中的本前置，使其按既定顺序进入 ready。

## 禁止项

- 不创建正式经验卡、不选择种子、不扫描归档、不修改任务卡 schema、不接入任何人工或自动强制点。
- 不使用正则索引、关键词权重、向量检索、模型排序、第二索引、外部服务、runtime 字段、重试或 feature flag。
- 不把 JSON 变成命令执行面，不在零命中时补泛化建议，不静默截断超过 3 条的 `must_read`。

## 验证

- `pwsh -NoProfile -ExecutionPolicy Bypass -File tools/test-get-experience-risk-preflight.ps1`。
- 以合法零命中 fixture 调用 `tools/get-experience-risk-preflight.ps1`，核对 stdout 只有一个 JSON 对象且工作树无变化。
- `pwsh -NoProfile -ExecutionPolicy Bypass -File tools/check-task-cards.ps1`。
- `pwsh -NoProfile -ExecutionPolicy Bypass -File tools/check-review-text.ps1 -Paths 开发管理,tools`。
- `git diff --check`。

## 完成条件

- 空生产索引、模板、只读匹配器和 fixture 测试均通过；非法 schema、缺指针／门禁、重复 ID、非法枚举、大小写／分隔符、显式引用、限量与只读行为均有稳定证据。
- 没有真实经验或门禁被顺带激活；十张种子卡只在 Codex 独立复审通过后解除本前置。

## 停止条件

- 批准字段不能由 PowerShell 原生确定性解析，任务卡当前结构与规格冲突，或实现需要第二索引、外部服务、新 runtime 状态、模型判断与兼容分支。
- fixture 无法证明只读，或必须修改真实任务卡／归档才能测试。
