# A-CHAR-2D-BATTLE-ANIM-PILOT-01 · 苻渊2D战斗动画样例生产

## 来源与当前边界

- 只消费负责人 A 批准的 `docs/superpowers/specs/2026-08-24-2d-battle-animation-production-pipeline-design.md`；其技术选择门、文件名、六状态 atlas、成本记录和人工视觉矩阵是本卡唯一生产合同。
- 苻渊是公平比较的固定单角色样例，不是正式角色批次。现有 `fuyuan-2d-tactical-sprite/` 是旧静态样张，只可作为身份、六向和锚点参考，不能覆盖、扩帧或冒充新 atlas；剧情立绘继续只承担 UI／剧情用途。
- 选定生产方法的工具／费用／credits 必须已实际获得授权并记录；未获授权、没有可编辑母源或选择门未通过即停止，不推断零成本。

## 必查范围

- 完成并获 A 批准的 2D pipeline 规格完整正文；`docs/superpowers/specs/2026-08-24-2d-battle-animation-reference-research.md` 的 S7 与“《龙胤立志传》画面下限的受控使用”。
- `assets/generated-character-art/README.md`、`docs/剧情/重要NPC/苻渊.txt`、`assets/generated-character-art/fuyuan-2d-tactical-sprite/prompts.md` 与 `docs/superpowers/specs/2026-08-21-2d-tactical-character-production-contract.md` 的 §二～§五。
- 本卡 `expectedPaths` 的 source-selection、manifest、production log、六个 atlas 与 `开发管理/苻渊2D战斗动画样例生产记录.txt`；只在选定方法时读取相应一份母源，不创建其余三份空文件。

## 实施范围

- 先以攻击、受击、死亡的六向试片完成四种待选方法的真实 `source-selection.md`；不自动把未尝试方法判失败。只有一项方法满足质量门并有实际时间、费用／credits、次数与返工记录，才完成唯一可编辑母源和 `idle/move/attack/hit/cast/death` 六个 atlas。
- 每个 atlas 为方向 `0..5` 的六行等格 `768×768` RGBA 输出；每状态实际帧数、格矩形、事件帧、脚底锚点、输入与输出 SHA-256 进入 manifest。保持苻渊身份、服饰和黑／灰／金主色，以及固定斜俯视六角镜头可读性。
- 用 production log 与管理记录逐项记录人工分钟、工具／版本、实际 credits／费用、生成／制作次数、失败、人工修订、返工和 QA。完成后只解除 Unity integration 的本卡 blocker，不复制到 `src/`、不接入 Unity 或正式单位。

## 禁止项

- 不在 pipeline A 批准前生产；不把《龙胤立志传》画面、旧静态精灵或 UI 立绘当作技术、帧数、方向数、成本或新动画资产事实。
- 不以镜像、逐方向补画、私有锚点／缩放、减少方向、常驻特效、规则改动或 fallback 使试片通过；不建立第三条混合路线。
- 不修改 Unity、战斗规则、剧情立绘职责、正式单位或其他角色资产；不隐藏失败生成、人工修订、工具费用或制作时间。

## 验证

- 自动检查六状态、六方向、等帧数、`768×768` RGBA cell、透明角、manifest／atlas SHA-256、事件顺序和脚底锚点覆盖；缺项或不一致即失败关闭。
- 固定 `AdventureScene/VisualBaselineBoard`、相机、光照、地块和 `1920×1080` 人工视觉矩阵逐项确认角色清晰度、移动、攻击、受击、施法、死亡、特效分层、宽袖／武器、接地、遮挡和多单位可读性；机器检查不得代替此结论。
- 核对两份日志足以供成本证据卡读取实际而非推断的分钟、费用／credits、次数、返工和失败原因；状态变更时运行 `pwsh -NoProfile -ExecutionPolicy Bypass -File tools/check-task-cards.ps1`。

## 完成条件

- 一项可复核方法通过攻击、受击、死亡高风险门，且形成唯一可编辑母源、六个通过合同的 source atlas、manifest、source-selection 与完整生产／成本记录；未接入正式游戏。
- Unity integration 的完整业务 expectedPaths、验证与停止条件不需再猜测；本卡 blocker 被移除后，下游只按自身其余条件进入 ready。

## 停止条件

- pipeline 未获 A 批准、选定方法没有工具／费用授权、没有可编辑母源、任一高风险语义／身份／主色／六向／锚点失败，或需要扩大到未列状态、方向与资产路径。
- 生产需要修改 Unity、正式内容、战斗规则，或用旧静态精灵／剧情立绘替代；没有候选通过选择门时只留下真实日志并停止。
