# A-CHAR-PORTRAIT-STYLE-01 · 默认男主模块化 UI 立绘八组合样张

## 来源与当前边界

- 仅依据 `input-contract.json` 生产并评审默认男主的八种模块化 UI 立绘组合；不包含 3D Toon、Unity 或运行时接入。

## 必查范围

- 输入合同、批准母版及其 manifest、项目立绘 README。

## 实施范围

- 生产九个固定组件，以冻结层序确定性合成八个全身、八个半身和八个头像，并提交提示、manifest 与联系表供书面评审。

## 禁止项

- 不生成组合专用层、逐图补丁、随机替代或不同 UI 母版；不修改 Unity、CSV、存档、3D 资产或运行时。

## 验证

- 检查九组件、八组合、锚点、遮挡、裁切与像素哈希满足输入合同；全身、半身和头像只从同一 composite 裁切。

## 完成条件

- 八组合获得 UI 立绘风格与模块兼容性书面评审，所有字面量输出和 manifest 可复核。

## 停止条件

- 任何组件必须仅在某一组合使用，或需要偏移、缩放、组合补丁、不同身份母版或修改运行时所有权时停止。
