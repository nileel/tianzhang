# A-CHAR-PORTRAIT-INTERFACE-01A · 标准接口合同与 A 门 checkpoint

## 来源与当前边界

把已批准设计投影为完整 input contract、逐门提示合同和一次调用的 A 门生产 checkpoint；本卡不调用图片模型。

## 必查范围

- docs/superpowers/specs/2026-09-03-standard-interface-player-modular-portrait-design.md 完整正文。
- assets/generated-character-art/README.md 中透明立绘与正式资产规则。
- 本卡直接前置的任务卡或完成归档；交接摘要不能替代组件、manifest 与验证原文。

## 禁止项

- 未取得本门独立生产授权时不得调用 GPT Image 2 或任何图片模型。
- 不使用 FLUX、KSampler、LoRA、扩散重画、自动重试、绿幕回退、人工语义抠图、组合专用补丁或第二套头部接口。
- 不修改 Unity、CSV、存档、3D 资产或运行时所有权。

## 停止条件

- 需要平移、缩放、旋转、再次重采样或组合专用覆盖才能连接标准接口。
- 模型输出含不属于具名组件的头部、颈部皮肤、衣装、头发或胡须像素，且只能通过反向抠图清理。
- 需要扩大图片调用预算、自动重试或改变已批准组件合同。

## 实施范围

- 新建 assets/generated-character-art/player-modular-portrait-interface-v1/input-contract.json 与 prompts.md，冻结原生 1024×1536、中央裁切、887×1774 规范化、13 个组件、四道授权门和 64 组合合同。
- 将旧 A-CHAR-PORTRAIT-STYLE-01 的 stateReason 改为被新父项取代并继续 frozen；不得删除其历史实验。
- 完整形成 A 门标准光头提示、参考输入、background=transparent、output_format=png、一次调用预算、验收与失败处理。
- 完成时只把 01B 转入等待负责人授权的非 ready 状态，不顺带调用模型。

## 验证

- input contract、prompts、设计文档、父子任务与旧卡的替代关系一致。
- A 门只有一次调用，未包含 B/C1/C2 调用授权。
- 运行任务卡、审核文本、数据链、空白与 Git 差异检查。

## 完成条件

- 新合同和提示可直接形成 A 门独立授权决定；旧四母图提示和 checkpoint 明确失效。
- 01B 的路径、输入、输出、预算、验证与停止条件已冻结。
