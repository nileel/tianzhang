# C-GZ-ITEM-01 · 关中首批最小物品档案

## 来源与当前边界

- `Enemies.csv` 已引用 `item_shijia_piece` 与 `item_lingshi_low`，`Language.csv` 已提供“石甲碎片”和“劣质灵石”，但仓库没有对应独立物品档案或运行时 `ItemData`。
- 本卡只建立首批正式物品身份和用途边界，供掉落与一次性悬赏引用；不建设商店、价格、装备、使用效果或全局经济。
- 现有道具规范只完整覆盖丹药、天材地宝和唯一剧情遗物；本卡按已确认的最小正式框架新增“基础资源／妖兽材料”身份，不把二者伪装成上述三类。

## 实施范围

- 完整重写 `docs/道具/基础资源/劣质灵石.txt`，不沿用现有长篇结构；只保留：
  - 稳定 ID `item_lingshi_low`、正式名称、基础资源类别、可堆叠身份。
  - `Enemies.csv` 的候选 ID 引用，以及未来可作为掉落或悬赏奖励库存单位的允许边界。
  - 一句身份描述：“劣质灵石是稳定 ID 为 `item_lingshi_low` 的基础资源。”不得增加形成方式、外观、产地、灵气、修炼或流通语义。
- 完整重写 `docs/道具/妖兽材料/石甲碎片.txt`，不沿用现有长篇结构；只保留：
  - 稳定 ID `item_shijia_piece`、正式名称、妖兽材料类别、可堆叠身份。
  - `Enemies.csv` 的候选 ID 引用，以及未来可作为掉落或悬赏奖励库存单位的允许边界。
  - 一句身份描述：“石甲碎片是稳定 ID 为 `item_shijia_piece` 的妖兽材料。”不得增加外观、材质、怪物生理或掉落过程。

## 禁止项

- 不填写价格、汇率、修炼收益、装备效果、炼器配方、掉落概率、奖励数量或堆叠上限。

- 不修改 CSV、Language、asset、背包、掉落、悬赏、商店或存档代码。
- 不批量补齐其他 Enemies CSV 行引用的物品。
- 不写自然生成、灵气渗透、妖兽活动区、灵矿边缘、甲壳受击碎裂、体表、外观、材质、生态、晶化／矿化或其他无直接来源的描述。
- 不把任一物品写成当前运行时已经掉落、已进入背包或可作为悬赏击杀证据；悬赏只允许表达为未来奖励库存候选。
