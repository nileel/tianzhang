- 唯一批准规格为 `docs/superpowers/specs/2026-09-01-formal-player-modular-portrait-input-freeze-design.md`；负责人于 2026-09-02 明确批准该书面合同。
- 单一结果是建立与批准规格一致的 `assets/generated-character-art/player-modular-portrait-style-v1/input-contract.json`，并把原样张卡投影为只负责默认男主模块化 UI 立绘八组合生产与评审的后续任务。
- 本卡不调用 ImageGen、不生成任何样图，不修改 Unity、CSV、存档、运行时或 3D 资产。

## 必查范围

- `docs/superpowers/specs/2026-09-01-formal-player-modular-portrait-input-freeze-design.md` 完整文件。
- `assets/generated-character-art/dialogue-transparent/formal-player-default-male-v1.png`、同名 manifest，以及 `docs/superpowers/specs/2026-08-29-formal-player-default-male-v2-production-chain.md` 中默认男主身份与批准来源边界。
- `assets/generated-character-art/README.md` 的角色立绘生产规则；`assets/generated-character-art/dialogue-transparent/fu-yuan-hanhong-zhenjun-standing-black-gold-v1.png` 只作项目画风参考。
- `开发管理/任务卡/A-CHAR-PORTRAIT-STYLE-01.txt` 完整文件和 `开发管理/任务列表/场景与Unity任务.txt` 中同 ID 投影。

## 实施范围

- 复核批准基准母版、基准 manifest 和画风参考的实际路径与 SHA-256；按批准规格逐字段建立 schema 1 `input-contract.json`，不得添加规格未列出的顶层字段。
- 逐项投影固定组件、两个脸型、两种发型、两套固定配色服装、八组合、五层顺序、九个组件路径、共同锚点、两组下颌目标、容差、脸型变化矩形、合成与像素哈希规则、三个裁切矩形、后续输出路径和本次批准证据。
- 为 `A-CHAR-PORTRAIT-STYLE-01` 保留原 ID、route、owner、priority 和 sourceBacklog；移除 3D Toon 职责，收窄为八组合 UI 立绘生产与评审，并把九个组件、八个 composite、八个半身、八个头像、提示、manifest 和联系表写成完整字面量 expectedPaths。
- 同步场景与 Unity backlog 投影；本卡完成时归档并从当前队列移除。原样张卡的具名前置只由后续正常 QueueMaintenance 移除和重新判断，不在本卡直接置为 ready。

## 禁止项

- 不生成、编辑、抠取或合成图片；不从批准扁平母版反向制造正式图层。
- 不修改 Unity／CSV／`AppearanceProfileData`／存档／运行时，不恢复旧模块化 3D 或 Toon 路线，不建立后续数据接入卡。
- 不增加自动对齐、偏移、缩放、随机替代、组合专用覆盖层、逐图修补、相近 ID 或从文件名猜测关系的机制。
- 不扩大到女性体型、完整创角批次或第二套人物身份。

## 验证

- JSON 与批准规格的稳定 ID、八组合、画布、坐标、容差、九个组件路径、二十四个组合／裁切路径、图层顺序、合成规则和裁切矩形逐项一致，且批准来源的路径、尺寸和 SHA-256 可复核。
- `input-contract.json` 只包含规格冻结的顶层字段，不引用不存在的 Unity asset、Prefab、材质、3D 模块或运行时缓存。
- 原样张卡只保留 UI 立绘职责，具名前置与全部未来字面量路径完整，不被本卡直接置为 ready。
- 运行 `pwsh -NoProfile -ExecutionPolicy Bypass -File tools/check-task-cards.ps1`、`pwsh -NoProfile -ExecutionPolicy Bypass -File tools/check-review-text.ps1 -Paths docs,开发管理`、预期路径 whitespace 检查和暂存后的 `git diff --cached --check`。

## 完成条件

- `input-contract.json` 与批准规格一致，批准来源及负责人批准证据可追溯；原样张卡职责和路径边界完成收窄。
- 本卡归档后，后续生产不需要猜测组件身份、拼合锚点、图层所有权、组合矩阵或输出路径，且本卡没有产生图片、Unity、存档、3D 或运行时副作用。
