## 筑基、紫府与丹相后续 Unity 任务卡

### U-FPD-RULE-01 · 道基与紫府运行时

- 依赖：D-FPD-SCHEMA-01；N-FPD-GROWTH-01、N-FPD-MANSION-01、N-FPD-CULTIVATE-01；至少一组合法与非法 fixture。
- 预期路径：`src/Assets/Scripts` 中现有角色成长／会话所有者、相关数据模型，`src/Assets/Tests/EditMode`；不得新建第二套角色成长服务。进入当前队列前由实时扫描展开字面量路径。
- 范围：接入唯一道基、四阶段连续进度、容量释放、最多两层扩府、五类紫府两段建造、每府唯一镇府神通、平铺效果绑定、固定周期行动、闭关重复和结丹永久锁。
- 验证：允许／拒绝 fixture 覆盖凡品筑基、下品零府、两层扩府、重复府属、失败回退、结丹后养基／扩府／开府、递归效果包和同府多神通；运行相关编译与 EditMode。
- 完成条件：所有硬门槛有单一持久化所有者和可观察状态，不以 UI、默认值或兼容分支代替规则。
- 停止条件：现有所有者无法容纳新状态且需要新建平行成长服务，或数据契约／数值尚未锁定。

### U-FPD-AI-01 · NPC 自主修炼

- 依赖：U-FPD-RULE-01、N-FPD-NPC-01。
- 预期路径：现有 NPC 决策／世界时间所有者、权重数据、相关 EditMode 测试；进入队列前展开字面量路径。
- 范围：先过滤非法行动，再读取基础、性格、门派、境界目标、寿元、资源与环境权重；只在规定事件重算，不每日扫描全世界。
- 验证：固定世界状态得到稳定排序；寿元将尽不能绕过道基第四阶段、至少一府或证位条件；玩家不能替 NPC 逐人设计划。
- 完成条件：权重可由数据调整，行为顺序不写死，NPC 与玩家共享行动成本与硬条件。
- 停止条件：实现要求 NPC 读取未知事实、每日全世界扫描或用硬编码顺序替代权重数据。

### U-FPD-SAVE-01 · 筑基与紫府持久化

- 依赖：U-FPD-RULE-01；S-SAVE-01 的存档版本与迁移基础已由 TQ-070 完成。
- 预期路径：S-SAVE-01 确认的存档所有者、角色成长快照、相关 EditMode 测试；不得另建平行存档格式。
- 范围：持久化道基身份／进度、天然与扩府容量、五府状态、镇府神通实例／强化节点、当前修炼行动、停止原因和结丹永久锁。
- 验证：新档、合法旧档迁移、非法档拒绝、保存读取幂等、结丹后篡改容量或紫府失败关闭；不可重复领取扩府层或修炼结算。
- 完成条件：读档后所有不可逆事实和唯一实例 ID 保持稳定，没有半迁移状态。
- 停止条件：S-SAVE-01 尚未提供版本／迁移边界，或需要另建平行存档格式和兼容读取层。

### U-FPD-UI-01 · 筑基与唯一丹相界面

- 依赖：U-FPD-RULE-01、D-FPD-MIGRATE-01、N-SLOT-01、N-FPD-DANXIANG-01；使用 2026-07-17 UI 规格，不复用未采纳样图布局。
- 预期路径：现有境界／角色 UI 所有者、相关 UI 数据适配与 EditMode／PlayMode 测试；进入队列前展开字面量路径。
- 范围：显示第一至第四阶段、天然／已释放／扩府／总容量、0～5 座紫府未建／府胚／建成、每府府体与镇府神通、结丹不可逆确认，以及一个丹枢核心／一个丹相中的 1～3 主承载与辅助输入。
- 验证：0、1、3、5 府角色及一至三稳定位格快照；未知信息不泄露；第四、第五府可见但不生成额外位格、丹相或槽位。
- 完成条件：界面只消费真实字段，不从颜色、名称或静态图推断规则状态。
- 停止条件：真实字段、槽位预算或丹相主辅数据尚不可用；不得用静态假数据先锁死布局。
