# 11 月 24 日金丹演武复玩

## 发行版实玩

从关中城的长明试玩档出发，依次进入各段并取得四次结算，最后返城保存。

| 遭遇 | 操作与反馈 |
|---|---|
| 基础演练 | 本人移动到浅水格，向江汐施放飞星指，再主动结束行动，挑战达成。选移动时棋盘上会出现「演练目标」，第一步容易找到。 |
| 登高与御风 | 同伴石衡起飞，移到高台。等对手也飞上来，从相邻格普攻命中获胜。两人的青色投影把空中位置标得很清楚。出生镜头看不到目标格，拉远后仍需向右上平移。[御风登高结算](earth-air-win.jpg) |
| 水火与筑路 | 本人守阵，阵心由 600 降到 225。我在维护前先走到了撤离格。地火后来点燃，任务又叫我走到脚下那格，下次行动前阵心已毁。失败结算交代了原因，过程中却缺少告诉我走早了的提示。[守阵失败结算](fire-defeat.jpg) |
| 破封与观形 | 操控晏衡经过 (8,12)，绕行到 (9,12)，再走到 (8,13)。隐身时月坛和封边仍可见，能凭这些线索找人。靠近后亲眼看到朔宁重新显形，随即获胜。[隐者与月坛](gate-hidden.jpg) · [绕门结算](gate-near-win.jpg) |

## 十条正式打法

下表来自同日 1366×768 的 Unity 图形 PlayMode。测试通过正式战斗界面选行动、点棋盘、确认报价并读取结算。十条均获胜，再从结果页返回挑战选择。五种本人构筑另做存读档与队伍装配检查，覆盖每种构筑的四个入口，共二十组配置。

| 遭遇与打法 | 从行动记录和画面核对的结果 |
|---|---|
| 登高 · 沿坡 | 沿坡阶走到 (8,12) 花 406.247 AP，随后普攻命中空中对手。 |
| 登高 · 御风极重 | 起飞并跨高，到达后主动落地，再用极重压低敌人。落地与压落分别扣费。 |
| 水火 · 蓄澜开路 | 涨潮浇灭 (5,6)，随后花 62.5 AP 步行穿过原火格才获胜。水退火熄很明显，刚施法时几块湿地相似；选移动后才有目标标记。 |
| 水火 · 厚载拆阵 | 石衡两记破垒打毁阵心，坡脚仍有余火。切换江汐，用潮眼灭火并步行通过 (9,8)。 |
| 水火 · 长明维持 | 从侧面展开，以防御守住通路。维护已生效、阵心剩 225 耐久时才撤至高台，仍能获胜。 |
| 水火 · 收阵重燃 | 收阵留下余火，借余火转移。到高台时冷却已好，仍缺可燃格；再守一轮，剩 224 生命时重新展开获胜。 |
| 破封 · 绕门近察 | 单向封边迫使角色绕一步，抵达相邻门格花 41.666 AP。接近隐者后自然现形。 |
| 破封 · 破锚阳照 | 配合定尺和阳照完成观察，七次贯石击破两层门锚。原先要绕行的边随后可以直穿，花 20.833 AP。 |
| 破封 · 守门藏真 | 敌人绕行后再拉开距离。退出近距时仍受阳照观察，维持藏真，等观察失效获胜。 |
| 破封 · 开门诱敌 | 花 25 AP 收关，把对方引出门口，穿过开放的门，再展开藏真并脱离观察。 |

## 根据试玩调整

- 登高开场告诉玩家用方向键向右上平移，选择移动时用基础演练已有的「演练目标」标出 (8,12)。[高台选格](high-goal.png)
- 长明守阵先提示等地格引燃再撤。提前站上高台、随后才满足条件时，会提示先离开，再步行回到撤离格。「长明地火」计数与棋盘上的同名标记一致，环境火单独存在。[长明守阵画面](fire-count.png)
- 守门方布下一项能力会看到另一项的位置；两术齐备后提示结束行动，让对手尝试过门。主动收关后改为引开对手、穿过门枢；已退出近距却仍受阳照时提示维持藏真。[两术齐备](gate-ready.png) · [收关后](gate-open.png)

1366×768 下，亮云上的淡金色目标文字仍较难读。长明守阵提示已缩成一行，封关与藏真齐备时的下一步也能在同一行读完。
