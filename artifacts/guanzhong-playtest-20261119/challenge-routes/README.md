## 重试与保存

基础演练要求本人到 (4,1)、施放飞星指并主动结束行动。挑战中直接保存会被拒绝，“撤离并保存”会清理本次战场。读回后在准备页重新选段，同配置重试沿用固定种子和配置 v1。基础、一、二、三段依次使用种子 20261119 至 20261122。[撤离后的选项](withdrawal.png) · [阵心被毁后的失败页](fire-defeat.png)
