## 根据反馈作的修订

- 金丹战场在可见棋子的血条旁区分“你、友、敌”。人物详情同时给出身上的效果、最近一次水火结算和脚下地块。未展开的固定阵位显示其不可攻击状态。
- 地图标出长明实际点燃的格子与余火。点开燃烧格能区分已有地火和金丹来源。基础移动教学给出目的地标记。潮水一次浇灭多格时，说明可任选通行格，并优先提示原先要求浇灭的那一格。
- 独立画面观察者从第一版截帧辨认出了阵眼，但看不清谁在两人之间起手，粗线也像棋盘标记。第二版把起势收在施法者胸手附近，用带亮芯的流光连接落点，火柱在阵眼升起后收为灯焰。领域维持期间仍能看清格边和棋子。

## 修订版复测

第三名试玩者从修订版菜单新建长明角色「望岚」。两次基础演练分别点选干地 (1,3) 和浅水 (4,2)，两处均在自己所点的格子立起 600/600 耐久的阵心。点人物看到了“施法中·长明”，点阵心能查看所在格地表与耐久。头顶的“你／敌”标识和起手位置可以同时入镜。[干地施法，原速四秒](long-bright-cast.mp4) · [浅水施法，原速四秒](long-bright-shallows.mp4) · [人物与脚下地块](caster-inspection.png) · [所选阵心](chosen-center.png) · [修订版角色资料页](character-details.png)

浅水复测继续到维护结算。灵力从 5000 降至 4800，火从 0/3 增到 2/3，阵心所在浅水格受热变为湿泥，另一格标出了“长明地火”。在 1366×768 下，地块说明较长时需用滚轮读末行。[跨回合实测](maintained-domain.png)

画面观察者复看了干地录像。约 1.05 秒能从“你”旁的聚火认出施法者，1.43 至 1.73 秒能跟踪火弧进入目标格，1.83 秒火柱升起，2.35 秒后只留下常亮灯焰。仍有两点美术局限：从这个镜位看，火峰边缘有平面贴片感；远处细格线单独不足以判断某一格是否正在燃烧，精确局部状态可通过地火标记和点格详情确认。
